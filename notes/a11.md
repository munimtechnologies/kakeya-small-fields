**Correction (2026-10-18, before this note was first published).** Lemma 63 is not new: it is

it needs only dim U+ = k, not Case B, and that the intersection over all complements turns the
statements modulo x0 into statements about the maps on X_1 itself. See the remarks after each
lemma.

## What changes

- **Lemma 63** (= Lemma 34 of case-b.md). Every anisotropic system with t = 2 and dim V = 2 is one
  of two kinds: (i) beta = 0, sigma is a linear bijection and every A_h is 0; or (ii) beta != 0,
  sigma takes one value e twice and the value f = beta(a, b) once, the two elements with value e
  have the same map (the projection onto span(f) along span(e)), and the third element has map 0.
  Both kinds occur.
- **Lemma 64.** Let u have rank t - k with k = 2 or 3, and let U+ have the largest dimension that
  Lemma 30 allows, dim U+ = k. Then **every A_h with h in U+ maps X_1 = ker A_u into itself**, and
  some h in U+ outside span(u) maps X_1 into span(x0). Lemma 30 only gave this for the line
  span(x0); in Case B, Proposition 27 of case-b.md already gave it.
- **Corollary 41 (t = 6).** In the configurations (A4) and (B4) of Corollary 39, the three maps of
  U+ keep X_1, and one of them, outside span(A_u), sends X_1 into span(x0). In (A4) this element is
  either in ker phi or an element v with phi(v) = x0 whose map on X_1 is the projection onto
  span(x0) along a plane L, and then ker A_v n ker A_(u + v) = L.

## Setting

As in [a10.md](a10.md): X = F_2^t, sigma : V -> X quadratic with polar form beta, h -> A_h linear,
and

    A_(h') sigma(h) = (I + A_h) beta(h, h')                                    (*)

for all h, h' in V. For u in V put x0 = sigma(u), phi = beta(u, .), P = phi(V), X_1 = ker A_u,
R = Im A_u and U+ = {h : phi(h) in span(x0)}. Lemma 30 of
[rank-restriction.md](rank-restriction.md): for h in U+, A_h x0 = phi(h) and sigma(h) lies in X_1;
if the system is anisotropic and u != 0, sigma(h) is not in span(x0) for h in U+ outside span(u), and
dim U+ <= 1 + A(k - 1), where k = dim X_1.

## Lemma 63 (anisotropic systems with t = dim V = 2)

**Lemma 63.** Let dim X = dim V = 2 and let (sigma, alpha) be anisotropic. Then exactly one of the
following holds.

(i) beta = 0. Then sigma is a linear bijection V -> X and A_h = 0 for every h.

(ii) beta != 0. Then f = beta(h, h') is the same non-zero vector for every pair of distinct non-zero
     h, h', and V has a basis a, b with

         sigma(a) = sigma(b) = e,   sigma(a + b) = f,   A_a = A_b = p,   A_(a + b) = 0,

     where e, f is a basis of X and p is the projection onto span(f) along span(e) (p e = 0,
     p f = f). The element a + b is the one non-zero element with sigma = f.

Both kinds satisfy (*), so both occur.

*Proof.* beta is alternating, so beta(h, h) = 0, and on a plane beta(a, b) = beta(a, a + b) =
beta(b, a + b).

(i) If beta = 0, sigma is additive, so linear, and one-to-one because it is anisotropic; so it maps
V onto X. (*) reads A_(h') sigma(h) = 0 for all h, h', and the sigma(h) span X, so every A_(h') = 0.

(ii) Let f != 0 be the common value of beta. For the three non-zero elements a, b, c = a + b,
sigma(a) + sigma(b) + sigma(c) = beta(a, b) = f. The three values are non-zero vectors of F_2^2.
If they were distinct, their sum would be 0, not f. If they were all equal to some e, their sum
would be e, so e = f; but then (*) with h = a, h' = b gives A_b f = (I + A_a) f, where
A_b f = A_b sigma(b) = 0 and A_a f = A_a sigma(a) = 0 (Lemma 21(b)), so f = 0, which is false. So
exactly two values agree; name the elements so that sigma(a) = sigma(b) = e != sigma(c). The sum
gives sigma(c) = f, so e != f and e, f is a basis.

Now A_a e = A_a sigma(a) = 0, and (*) with h = b, h' = a gives A_a e = A_a sigma(b) = (I + A_b) f,
so A_b f = f. By symmetry A_b e = 0 and A_a f = f. So A_a = A_b = p and A_c = A_a + A_b = 0.

For the converse, (*) holds trivially when h or h' is 0, and for the nine pairs of non-zero
elements of the system in (ii) it reads: h = h' gives A_a e = A_b e = A_c f = 0; (a, b), (b, a),
(a, c) and (b, c) give A_b e = A_a e = A_c e = 0 = (I + p) f; (c, a) and (c, b) give
A_a f = A_b f = f = (I + A_c) f. In (i) both sides are 0. QED

This is Lemma 34 of [case-b.md](case-b.md): its type (i) is kind (i), and its type (ii), with
sigma(v_1) = sigma(v_2) = a and delta = beta(v_1, v_2), is kind (ii) with e = a and f = delta (there
A_(v_1) and A_(v_2) kill a and fix delta, which on F_2^2 makes both the projection p). Lemma 34 also
counts the systems in fixed bases (24: 6 of type (i), 18 of type (ii)), and `cube_groups/case_b.py`
checks that count exhaustively. The proof above is a little shorter, and it adds that the third
element has map 0.

So in every anisotropic system with t = dim V = 2 some non-zero element has map 0, and the line
span(e) (kind (ii)) or every line (kind (i)) is killed by every map. The same argument at t = 1 is
one line: sigma(a) = e and A_a e = 0, so A_a = 0.

## Lemma 64 (U+ keeps ker A_u)

**Lemma 64.** Let (sigma, alpha) be anisotropic, let u != 0 have rank t - k with k = 2 or k = 3, and
suppose dim U+ = k (the largest value that Lemma 30 allows, as A(1) = 1 and A(2) = 2). Then:

(a) A_h maps X_1 into itself for every h in U+;

(b) if k = 2, A_h maps X_1 into span(x0) for every h in U+;

(c) if k = 3, either (i) beta(h, h') lies in span(x0) for all h, h' in U+, and A_h maps X_1 into
    span(x0) for every h in U+; or (ii) U+ has a basis u, a, b with

        sigma(a) = e + *,  sigma(b) = e + *,  sigma(a + b) = f + *,  beta(a, b) = f + *,

    where * stands for elements of span(x0) and x0, e, f is a basis of X_1, and on X_1

        A_(a + b) X_1 in span(x0),   A_a e, A_b e in span(x0),   A_a f, A_b f in f + span(x0).

In both cases of (c) some h in U+ outside span(u) maps X_1 into span(x0).

*Proof.* Fix a complement Z of X_1 in X and let pi_Z be the projection onto X_1 along Z. By
Lemma 26(a) of [finite-groups.md](../finite-groups.md), sigma on U+ with the maps pi_Z A_h on X_1 is
a system with values in X_1 (sigma(U+) lies in X_1 by Lemma 30(a)). The line span(x0) is invariant:
pi_Z A_h x0 = phi(h), which lies in span(x0). By Lemma 27(a), dividing by span(x0) gives a system on
U+ with values in X_1 / span(x0), of dimension k - 1. In it, u has value 0 and map 0
(pi_Z A_u = 0 on X_1 = ker A_u), and for h in U+, sigma(h + u) = sigma(h) + x0 + phi(h) and
beta(h + u, h') = beta(h, h') + phi(h') agree with sigma(h) and beta(h, h') modulo x0. So the
system comes from a system on U+ / span(u), of dimension k - 1, with values in a space of dimension
k - 1, and it is anisotropic because sigma(h) is not in span(x0) for h in U+ outside span(u)
(Lemma 30(b)).

For k = 2 it has dimension 1, and its map is 0 (the remark after Lemma 63). For k = 3 it has
dimension 2, and Lemma 63 applies. Which kind occurs, and which classes play a, b and a + b, depends
only on sigma and beta modulo x0, not on Z. Kind (i) says that every map pi_Z A_h sends X_1 into
span(x0); kind (ii) says the same for h = a + b, and that pi_Z A_a and pi_Z A_b send e into span(x0)
and f into f + span(x0). (Kind (i) is the case beta = 0 modulo x0; then sigma modulo x0 is linear on
U+ / span(u).)

So for each of these statements there is a fixed vector y of X_1 (0 or f) and a vector x of X_1 with
pi_Z A_h x in y + span(x0) for every complement Z, that is, A_h x - y in span(x0) + Z for every Z. We
show that the intersection of the subspaces span(x0) + Z over all complements Z of X_1 is span(x0);
then A_h x lies in y + span(x0), which is every claim of (b) and (c), and (a) follows because
A_u X_1 = 0 and the maps of a basis of U+ keep X_1.

Let w be in span(x0) + Z for every Z. If w is in X_1, write w = c x0 + z with z in Z; then z lies in
X_1 n Z = 0, so w is in span(x0). If w is not in X_1, fix one complement Z_0 and write w = w_1 + z_0
with w_1 in X_1 and z_0 != 0 in Z_0. The complements of X_1 are the graphs Z_T = {z + T z : z in Z_0}
of the linear maps T : Z_0 -> X_1, and w lies in span(x0) + Z_T exactly when w_1 + T z_0 lies in
span(x0). As z_0 != 0, T z_0 can be any vector of X_1, and span(x0) != X_1 (k >= 2), so some T
makes w_1 + T z_0 fall outside span(x0). So such a w does not exist. QED

For k = 2 this is close to what is known: in Case B of the tight dimension (the Remark after
Proposition 26 in [tight-cases.md](tight-cases.md)) A_v kills X_1, which is stronger; in Case A it
says that A_v, for phi(v) = x0, acts on X_1 as the projection onto span(x0) along span(sigma(v)).
For k = 3, the proof of Proposition 27(d) of [case-b.md](case-b.md) already makes the same
quotient (N carries a system with values in X_1, span(x0) is invariant, divide by it and factor out
u) and applies Lemma 34 to it, but only in Case B, where U+ = ker phi has dimension k because
dim V = t + k - 1; there (*) then gives the maps on X_1 directly. Lemma 64 needs only dim U+ = k,
so it applies to elements whose dimension count has slack, such as (A4) and (B4) below.

## Corollary 41 (the configurations (A4) and (B4) at t = 6)

**Corollary 41.** Let an anisotropic system with t = 6 and dim V = 7 have no element of rank 4, and
let u have rank 3 in configuration (A4) or (B4) of Corollary 39 (so k = 3 and dim U+ = 3). Then
every A_h with h in U+ maps X_1 into itself, and:

(a) in (B4), U+ = ker phi, and some m in ker phi outside span(u) has A_m x0 = 0 and
    A_m X_1 in span(x0); so A_m kills x0 and sigma(m), it has rank at most 1 on X_1, and
    A_m^2 X_1 = 0. Every A_h with h in ker phi kills x0 and maps X_1 n (P + span(x0)) into X_1 n R;

(b) in (A4), with ker phi = span(u, n) and phi(v) = x0, one of the following holds:

    (b1) some m in {n, n + u} has A_m x0 = 0 and A_m X_1 in span(x0);

    (b2) some v' in {v, v + n} (phi(v') = x0) acts on X_1 as the projection onto span(x0) along a
         plane L = ker A_(v') n X_1, and then ker A_(v') n ker A_(u + v') = L, which contains
         sigma(v'). Moreover either L lies in P, and then X_1 lies in P and L lies in R (so
         d = dim(X_1 n R) >= 2), or L does not lie in P, and then R lies in P and is spanned by
         ker A_(v') n P and ker A_(u + v') n P, both of dimension 2.

*Proof.* Lemma 64 with k = 3 gives the first sentence and an element m of U+ outside span(u) with
A_m X_1 in span(x0); A_(m + u) has the same restriction to X_1, so m can be changed by u.

(a) In (B4), U+ = ker phi, and Lemma 30(a) gives A_m x0 = phi(m) = 0 and A_m sigma(m) = 0
(Lemma 21(b)). sigma(m) lies in X_1 outside span(x0), so A_m kills a plane of X_1, and the image
A_m X_1 lies in span(x0), which A_m kills. The last sentence is Corollary 39 for (B4) together with
the first sentence.

(b) In (A4), U+ = span(u, n, v), so modulo u, m is n, v or v + n. If it is n, this is (b1) (as in
(a), A_n x0 = phi(n) = 0). Otherwise put v' = m (or m + u); phi(v') = x0, so A_(v') x0 = x0 by
Lemma 30(a). A_(v') maps X_1 into span(x0) and fixes x0, so on X_1 it is the projection onto
span(x0) along its kernel L, a plane. A_(u + v') = A_u + A_(v') agrees with A_(v') on X_1, and
ker A_(v') n ker A_(u + v') lies in X_1 (Lemma 62(b)), so it is L. sigma(v') lies in it by
Lemma 62(c).

By Lemma 62(b), K = ker A_(v') n P and K' = ker A_(u + v') n P lie in R, which has dimension 3; each
has dimension at least 2 (Corollary 39), and K n K' = L n P. P is a hyperplane (dimension 5). If L
lies in P, then L lies in K, so in R, and X_1 = L + span(x0) lies in P because x0 does. If not,
L n P is a line, so dim(K + K') >= 2 + 2 - 1 = 3 = dim R; then K + K' = R, both have dimension 2,
and R lies in P. QED

So the open part of (A4) and (B4) at t = 6 now has, besides the counting of Lemma 62, a plane-level
flag span(x0) < X_1 kept by all of U+, and an element of U+ outside span(u) whose map on X_1 is as
small as it can be (rank at most 1, into span(x0)). (B5), where dim U+ = 2 is one below the bound
of Lemma 30, is not touched: there the quotient system has dimension 1 in a space of dimension 2,
and Lemma 63 does not apply. Neither are the configurations of Corollary 40 at t = 8, where
dim U+ is 4 or 5 and the quotient system would need the systems with t = 4 and dim V = 4.

## What would come next

- A version of Lemma 63 one size up (all anisotropic systems with t = dim V = 3, or with t = 4 and
  dim V = 4) would give Lemma 64 for k = 4 and 5, and so reach the configuration (6, 5) of
  Corollary 40 at t = 8. We do not know whether every such system has a non-zero element with map 0.
- At t = 6, (b1) and (a) give an element m of ker phi whose map has a very small restriction to
  X_1; Lemma 60 of [a8.md](a8.md) handled the case A_m = 0 in the tight Case B, and its argument
  (the subspace U+(m) and the set Fix(A_u) + span(x0)) is the natural next step here.
