## What changes

- **Lemma 61.** In an anisotropic system with t = 6 and dim V = 7, Case A at rank 4 comes down to
  **21 normal forms** of the matrix A_u: 11 with Im A_u n ker A_u of dimension 1 and 10 with
  dimension 2. This is the count of Lemma 49 of [case-a.md](case-a.md) one size up. At t = 6 there
  are 3,124,800 candidate matrices, too many for the orbit computation that `case_a.py` used at
  t = 5, so the orbits are found by hand.
- **Job m24** (`cube_groups/a6_casea.py`) runs the Case A search of `case_a.py`, unchanged, on these
  21 normal forms, with controls at t = 3, 4 and 5. Its predictions were written down before it was
  queued (m24/predictions.md).
- **Corollary 37.** If job m23 (Case B, [a8.md](a8.md)) and job m24 (Case A) find all of their
  t = 6 instances UNSAT, then no anisotropic system with t = 6 and dim V = 7 has an element of
  rank 4. A(6) = 6 then holds if and only if no such system has an element of rank 3.
- Lemma 52, the hand proof that rules out Case A at t = 5, does not carry over to t = 6 as it stands
  (last section before Computation).

## Setting

As in [case-a.md](case-a.md): X = F_2^t, sigma : V -> X quadratic with polar form beta, h -> A_h
linear, and

    A_(h') sigma(h) = (I + A_h) beta(h, h')                                    (*)

for all h, h' in V. Case A: dim V = t + 1, u has rank A_u = t - 2, and phi = beta(u, .) maps V onto
X. By Lemma 48, such a system has bases with sigma(u) = e_0, sigma(v_1) = e_1, beta(u, v_i) = e_(i-1)
and A_u = C, where C kills e_0 and e_1, has rank t - 2 and has e_1 in its image, and C may be
replaced by any matrix of its orbit under conjugation by

    G = {g in GL(X) : g e_0 = e_0, g e_1 = e_1}.

At t = 6 (so rank 4, k = 2, dim V = 7), |G| = 60 x 56 x 48 x 32 = 5,160,960, and there are
155 x 20,160 = 3,124,800 candidates C: a 4-dimensional image R through e_1 (155 choices, one for
each 3-dimensional subspace of F_2^6 / span(e_1)) and an ordered basis of it, the images of
e_2, ..., e_5 (|GL_4(F_2)| = 20,160 choices).

## Lemma 61 (the orbits at t = 6)

Write X_1 = span(e_0, e_1) and S = span(e_2, ..., e_5), and f_j for the class of e_(j+2) in X / X_1.
A candidate C kills X_1, so it is given by two maps on X / X_1: Cbar : X / X_1 -> X / X_1 (the map
that C induces, a 4 x 4 matrix) and c : X / X_1 -> X_1 (the X_1-component of C). An element of G has
the block form g = [[I, B], [0, P]] with B : X / X_1 -> X_1 and P in GL_4(F_2), and

    g^(-1) C g  has  Cbar' = P^(-1) Cbar P  and  c' = (c + B P^(-1) Cbar) P.          (1)

**Lemma 61.** Let K = ker Cbar. A pair (Cbar, c) is a candidate exactly when c is one-to-one on K
and c(K) contains e_1; then d = dim(Im C n X_1) = dim K is 1 or 2. Its G-orbit depends only on the
similarity class of Cbar and on the map c restricted to K, taken up to c|K -> c|K o P|K for P in
the centraliser of Cbar. The orbits are:

(a) d = 1: one orbit for each of the **11 similarity classes of 4 x 4 matrices of rank 3**, with
    c(K) = span(e_1);

(b) d = 2: for each of the **6 classes of rank 2**, the isomorphisms K -> X_1 (6 of them) up to the
    image H of the centraliser in GL(K). H = GL(K) (one orbit) for 0 + 0 + Q with Q invertible
    (3 classes) and for J_2 + J_2; H has order 2 (three orbits, told apart by the value
    y = c(k) in {e_0, e_1, e_0 + e_1} at the vector k spanning K n Im Cbar) for J_2 + 0 + 1 and for
    J_3 + 0.

So there are 11 + 3 + 1 + 3 + 3 = **21 orbits**. Their sizes are (the size of the class of Cbar in
M_4(F_2)) x 64 in (a), and x 96 / (number of orbits of that class) in (b):

    d = 1   Cbar       J4      J3+1    J2+I    J2+J2(1)  J2+F4   0+I   0+J2(1)+1  0+J3(1)  0+F4+1  0+F8a  0+F8b
            class      2,520   5,040   1,680   5,040     3,360   120   2,520      5,040    6,720   2,880  2,880
    d = 2   Cbar       0+0+I   0+0+J2(1)  0+0+F4  J2+0+1 (x3)  J3+0 (x3)  J2+J2
            class      560     1,680      1,120   2,520        1,260      210

Here J_m is the nilpotent Jordan block of size m, J_m(1) = I + J_m, and F4, F8a and F8b are the
companion matrices of x^2 + x + 1, x^3 + x + 1 and x^3 + x^2 + 1. The rank-3 classes add up to
37,800 and the rank-2 classes to 7,350, the numbers of 4 x 4 matrices over F_2 of rank 3 and 2, and
the orbit sizes add up to 37,800 x 64 + 7,350 x 96 = 3,124,800, the number of candidates.

*Proof.* C kills X_1 and has rank 4 = dim X / X_1, so it is one-to-one on X / X_1. As C x = c(x) +
(Cbar x, lifted to S), C x = 0 exactly when x is in K and c(x) = 0, so C is one-to-one exactly when
c is one-to-one on K. Then Im C n X_1 = c(K), so e_1 in Im C means e_1 in c(K), and d = dim K <= 2.

(1) is the product of block matrices. Take first P = I: c' = c + B Cbar, and the maps B Cbar, for
all B, are exactly the maps X / X_1 -> X_1 that vanish on K. So for fixed Cbar the orbit of c is
determined by c|K, and every c with the same c|K is in it. A general g with Cbar' = Cbar has P in the
centraliser of Cbar, and then c' = c P + B Cbar, so c'|K = c|K o P|K, as B Cbar vanishes on K and
P K = K.
Elements of G fix X_1 pointwise, so nothing acts on the values of c.

(a) d = 1: c|K sends the vector spanning K to e_1, so there is one orbit per class.

(b) d = 2: c|K is one of the 6 isomorphisms K -> X_1, and H acts on them freely (on the right), so
there are 6 / |H| orbits. For 0 + 0 + Q, the block GL_2 on K commutes with Cbar, so H = GL(K). For
J_2 + J_2 (chains f_2 -> f_0 and f_3 -> f_1), K = Im Cbar, and the centraliser GL_2(F_2[x]/x^2)
maps onto GL(K). For J_2 + 0 + 1 (f_2 -> f_0, f_1 -> 0, f_3 -> f_3) and J_3 + 0 (f_3 -> f_2 -> f_0,
f_1 -> 0), K = span(f_0, f_1) and K n Im Cbar = span(f_0). Every P in the centraliser keeps this
line, so it fixes f_0, and H lies in {1, (f_1 -> f_1 + f_0)}; the transvection f_1 -> f_1 + f_0
(fixing the other f_j) commutes with Cbar in both cases, so |H| = 2. In these two classes,
y = c(f_0) is an invariant of the orbit (by (1), c'(f_0) = c(f_0) when P is in the centraliser), and
it takes the three non-zero values of X_1.

The classes: a matrix of rank 3 has exactly one nilpotent Jordan block J_m (m = 1, ..., 4) and an
invertible part of size 4 - m: 1 + 1 + 3 + 6 classes, as GL_2(F_2) has 3 classes and GL_3(F_2) has 6.
A matrix of rank 2 has two nilpotent blocks: (1, 1) with an invertible 2 x 2 part (3 classes),
(2, 1) with [1], (3, 1) and (2, 2). Each class size is 20,160 divided by the order of the
centraliser (for example 8 for J4, the units of F_2[x]/x^4, and 168 for 0 + I), which gives the
table; the two sums are the standard counts of matrices of rank 3 and 2. QED

`a6_casea.py` checks all of this without using the proof: each of its 21 matrices is a candidate
with the d stated; no two of them are conjugate under G (it solves g C_1 = C_2 g as a linear system
in g and looks for an invertible solution); and |G| / |stabiliser| is the orbit size in the table,
with the 21 sizes adding up to 3,124,800. So the 21 orbits are all of them. Three stabilisers are
also checked against values found by hand: 32 for J4 (C is then a single chain e_5 -> e_4 -> ... ->
e_1 -> 0 next to e_0 -> 0), 672 for 0 + I and 256 for J2 + J2.

## Job m24 and Corollary 37

Job m24 (`a6_casea.py`) runs `case_a.solve_one` unchanged on the 21 normal forms: the CNF of
`sat_aniso.py` with dim X = 6 and dim V = 7, with sigma(v_0), sigma(v_1), beta(v_0, .) and
A_(v_0) = C fixed by unit clauses. It does not encode Lemmas 50 to 52. Each instance has 6 minutes,
140 minutes in all, after the selfcheck and the 13 control instances of job m15 at t = 3, 4 and 5
(UNSAT by Proposition 25 and Lemma 52). Its predictions were written down before it was queued: the
selfcheck and the controls are graded; the 21 instances at t = 6 are exploratory. At t = 5 every
Case A instance of job m15 took under a second, so we expect these to be decided too. A verified
SAT answer would be an anisotropic system with t = 6 and dim V = 7, so A(6) = 7, and we would
publish it.

**Corollary 37.** Suppose every one of the 32 instances of job m23 and the 21 instances of job m24 is
UNSAT. Then no anisotropic system with t = 6 and dim V = 7 has an element of rank 4, and A(6) = 6
holds if and only if no such system has an element of rank 3.

*Proof.* An element u of rank 4 has k = 2 and dim V = t + k - 1, so by Proposition 26 of
[tight-cases.md](tight-cases.md) (which needs A(1) = 1) it is in Case A or Case B. In Case B it is
in one of the 32 normal forms of job m23 (Corollary 36 of a8.md), and in Case A in one of the 21
normal forms of Lemma 61. For the second statement, such a system is irreducible, its non-zero
elements have rank at most 4, and not all of them have rank at most 2 (the last section of a8.md),
so if none has rank 4, some has rank 3; and a system with t = 6 and dim V >= 7 restricts to one with
dim V = 7. QED

Corollary 37 would rest on the SAT answers of both jobs, without proof certificates, and on the hand
proofs of Lemmas 35 to 39, 48 and 61 that set up their normal forms.

## Why Lemma 52 does not carry over

At t = 5, Lemma 52 ruled out Case A by hand. Its Steps 1 to 3 hold at t = 6 with one change. For r in
Rad and p = x0 + r, the two elements h = s(p) and h + u have A_h = I + N_h with N_h mapping X into R
(Lemma 51(d)), so A_h keeps R, ker A_h lies in R, and the restriction P_h of A_h to R has rank
rank A_h - 2 <= 2, on a space R of dimension 4. At t = 5 the bound was rank <= 1 on a space of
dimension 3. Step 4 (x0 not in R) then needs the two maps P_1, P_2 at p = x0 + z, whose sum a has
rank 3, to have kernels meeting exactly in ker a. That followed at t = 5 from rank P_1 + rank P_2 =
rank a, but at t = 6 the ranks can be (1, 2), (2, 1) or (2, 2). Step 5 (x0 in R) needs P_h of rank
at most 1 to pin down the image of P_h from one vector, which also fails. So at t = 6 the case is
left to job m24.

## Computation

`cube_groups/a6_casea.py` (new; its unit tests gate the commit that adds it) has four parts.

- **selfcheck** (pure Python): the 21 representatives, the check that each is a candidate with the d
  of Lemma 61, |G| = 5,160,960, the stabilisers (as {g in G : g C = C g}, found by solving a linear
  system in the 24 free entries of g and keeping the invertible solutions), the orbit sizes against
  the table and their sum against 3,124,800, the three hand stabilisers, a check that no two
  representatives are conjugate, and a check that the solver finds a known g on a conjugated pair.
- **controls**: the 1, 3 and 9 orbits of `case_a.py` at t = 3, 4 and 5 (job m15's instances).
- **solve**: the 21 orbits at t = 6 through `case_a.solve_one`, each in a child process with a time
  budget. A SAT answer counts only with a model that passes the brute-force check of (*), anisotropy
  and the normal form.
- **grade**: the pre-registered predictions.

The unit tests check the representatives (21 distinct candidates, d split 11 and 10), the hand
counts (the sums 37,800 x 64, 7,350 x 96 and 3,124,800, and that every orbit size divides |G|), the
J4 representative column by column, the three hand stabilisers, the transporter on a conjugated
pair and on a non-conjugate pair, the full selfcheck, and the grader on made-up results.
