## Corollary 47 (rank 3 at t = 6: only (B5), and not every type of it)

**Corollary 47 (computer-assisted).** Let an anisotropic system have t = 6 and dim V = 7.

(i) No element of rank exactly 3 is in the configuration (B4) = ("B", 4). Hence every element of
rank exactly 3 is in (B5) = ("B", 5).

(ii) Let w be an element of rank exactly 3, K_w = ker A_w and I_w = Im A_w. Then K_w n I_w != 0,
and if dim(K_w n I_w) = 1 then sigma(w) is not in I_w. Equivalently, since
rank A_w^2 = dim A_w(I_w) = 3 - dim(K_w n I_w): rank A_w^2 <= 2, and if rank A_w^2 = 2 then
sigma(w) is not in Im A_w.

*Proof.* (i) Corollary 46 (ii) ([a17.md](a17.md)) covers the 37 pair orbits of (B4) other than o001
and o026. The only class of o001 and class 8 of o026 were the only classes of those two orbits not
already UNSAT in job m30, and job m32 found both UNSAT. So every class of every pair orbit of (B4)
is UNSAT, and the argument of Corollary 46 (Lemma 67, then Lemma 70, then the facts of Lemma 69)
gives (i). With Corollary 39 ([a10.md](a10.md)) and Corollary 46 (i), w is in (B5).

(ii) By (i), w is in (B5). By Lemma 67 applied to w, there is a linear change of coordinates of X,
together with a basis of V, that puts the system in the normal form for w with
(ker A_w, Im A_w) equal to the representative pair of one of the eleven pair orbits. A change of
coordinates g of X sends (K_w, I_w, sigma(w)) to (g K_w, g I_w, g sigma(w)). So it keeps
dim(K_w n I_w), and whether sigma(w) lies in I_w. In the normal form sigma(w) = e_0 = x0. By the
table above, the representatives with dim(X_1 n R) = 0 are exactly pair orbits 9 and 10. The only
one with dim(X_1 n R) = 1 and x0 in R is pair orbit 5. Every class of these three orbits is UNSAT
(m30 and m32). So by Lemma 70 a w of either excluded kind would give a model of one of those
UNSAT instances. QED

The proof relies on the SAT solver's UNSAT answers for every class of (A4) (141), of (B4) (401) and
of (B5) pair orbits 5, 9 and 10 (28), all saved without proof certificates (cadical195 through
python-sat). It is computer-assisted and has not been checked by a human.

**Remarks.**

- (ii) is a statement about every element of rank 3, not only about the element u that a search
  fixes. It is what "closure propagation" in [a19.md](a19.md) asked for: a closed type of (B5)
  excludes that type everywhere in the system. The two invariants used are exactly the ones that
  do not depend on the normal form. The finer split of pair orbits 3 and 4 (same invariants) and of
  7 and 8 (same invariants) needs P_w = beta(w, V), which a search does not fix for w != u.
- (ii) fails for dim V = 6, as it should: in the positive control of job m32 (three copies of
  Lemma 63 (ii)), u = a_1 + a_2 + a_3 has rank 3 with ker A_u n Im A_u = 0. So the corollary
  uses dim V = 7 through the searches, and no general identity forces it.
- Lemma 72 (c) ([a19.md](a19.md)) assumed that no element of rank exactly 3 is in (B4). By (i)
  that now holds, so Lemma 72 (c) holds unconditionally: if r_w = 3 for w = h_1 or u + h_1, then
  dim beta(w, V) = 5, sigma(w) is not in beta(w, V), and ker beta(w, .) = W.

## Lemma 73 (Corollary 47 in the split of Lemma 71)

In the split of Lemma 71 ([a18.md](a18.md)), s = sigma(h_1) and N = A_(h_1) are fixed. N kills
L = span(x0, s) and maps into R. For w = u + h_1, sigma(w) = x0 + s (beta(u, h_1) = 0) and
A_w = A_u + N, which also kills L (A_u kills X_1, which contains x0 and s) and maps into R.
dim L = 2 because s != 0 and s != x0.

**Lemma 73.** In (B5) at t = 6 and dim V = 7, with the notation above, let w be h_1 or u + h_1 and
suppose rank A_w = 3. Then Im A_w = R, and ker A_w = K is a 3-dimensional subspace containing L.
By Corollary 47 (ii): K n R != 0, and if dim(K n R) = 1 then sigma(w) is not in R. Write
a = dim(L n R). Among the 15 subspaces K of dimension 3 containing L (each the kernel of exactly
|GL_3(F_2)| = 168 maps from X onto R that kill L, 15 x 168 = 2520 in all):

    a = dim(L n R)   dim(K n R) = 1 + a   dim(K n R) = a   allowed kernels
    0                       7                  8          7 (the 8 with K n R = 0 are excluded)
    1, sigma(w) in R        3                 12          3 (the 12 with dim 1 are excluded)
    1, sigma(w) not in R    3                 12          15
    2                      15                  0          15

*Proof.* Im A_w lies in R (Lemma 71 (ii) for N; A_u maps into R), and its rank is 3 = dim R, so
Im A_w = R. Then K = ker A_w has dimension 3 and contains L. Write K = L + span(k).
K + R = (L + R) + span(k), where dim(L + R) = 5 - a. If k is in L + R, then dim(K + R) = 5 - a and
dim(K n R) = 6 - (5 - a) = 1 + a. Otherwise dim(K + R) = 6 - a and dim(K n R) = a. The subspaces
K correspond to the lines of X / L (dimension 4), and those with k in L + R to the lines of
(L + R) / L, which has dimension 3 - a: 7, 3 and 1 lines for a = 0, 1, 2. That gives the counts in
the table. Corollary 47 (ii) applies to w because w has rank exactly 3 in a system with t = 6 and
dim V = 7. When a = 0, sigma(w) is in L and L n R = 0, so sigma(w) is not in R and only the
condition K n R != 0 bites. When a = 2, dim(K n R) >= 2 always. QED

**What this prunes, by pair orbit.** sigma(h_1) = s and sigma(u + h_1) = x0 + s.

- Pair orbits 0 and 1 (x0 in R): a >= 1, and L n R contains x0 itself. If s is in R, a = 2. If s
  is not in R, then x0 + s is not in R either, so neither sigma(w) is in R. Either way nothing is
  excluded. Lemma 73 does not help in these two orbits, which hold 4 of the 25 open classes,
  including the hardest-looking one (pair orbit 0, a single class of all 168 matrices).
- Pair orbits 2, 3, 4, 6, 7 and 8 (x0 not in R): L n R is 0 or the line through whichever of s
  and x0 + s lies in R (at most one does, as x0 is not in R). If neither does (a = 0), each w
  of rank 3 loses 8 of its 15 kernels. If s is in R, w = h_1 at rank 3 keeps only 3 of 15 kernels
  and u + h_1 loses nothing. If x0 + s is in R, it is the other way round. Which case occurs
  depends on s and on X_1 n R (dimension 1 in pair orbits 6 to 8, 2 in pair orbits 2 to 4).
- Of the 4096 candidates N for one s, 2520 have rank 3 (a19.md). With a = 0, Lemma 73 for
  w = h_1 alone leaves 1576 + 1176 = 2752 of them. The joint effect of both w (rank A_u + N also
  depends on N) is a count for the code, and it has not been computed here.

So Lemma 73 is a filter on the candidate list of Lemma 71, not new clauses. It needs no rank
encoding, because N is fixed in each instance. It would be applied before the H_A-orbits are taken.
Since rank, kernel and image are conjugation-invariant and H_A fixes x0 and R, the filter is a
union of H_A-orbits and can be applied either before or after. If the split of Lemma 71 is used
(the decision rule of job m35 in [a18.md](a18.md)), the filter goes in. It must be checked in the
selfcheck against the counts in the table above, for one s of each kind.
