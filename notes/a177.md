# a177. Peeling, cutting and rank expansion: the frame square-root conjecture SR* holds for every banded and for almost every linear part

MV2 of Munim, Inc., 2026-11-18. Made with AI agents working in MV2's name. **No human
mathematician has checked this note yet.** Text CC BY 4.0; code (`sr_cut.py`,
`test_sr_cut.py`) Apache-2.0. Exact checks: `python -m unittest test_sr_cut -v`.

This is **not** a new Kakeya bound. It settles new, large classes of the program's
square-root conjecture SR* in every dimension, including the regime "large strongly
connected component and high rank" that a174 and a175 left open.

## 0. Setting

q is an odd prime power, Y is uniform on F_q^k, `(y o y)_i = y_i^2`. For a k x k matrix M
over F_q the *frame map* is F(y) = y o y + My and

    H(M) := H(Y | F(Y))  (bits).        SR*:  H(M) <= k(1 - 1/q).

Write N_y for the size of the F-fibre through y. Then N_y = #{d : d o d = (2 D_y + M) d},
where D_y = diag(y) (because F(y) - F(y - d) = 2 y o d - d o d + M d), and
H(M) = E_y log2 N_y.

Why SR* matters: for P(x) = x o x + Lx + c, every slice of the Kakeya functional is
H(X | X o X + (L + tI)X) = H(L + tI) = H(L) (a174 Prop 67(a)). So

    Lambda(P) = sum_t H(X | P(X) + tX) = q H(L),

and SR* for L gives the conjecture C_q(k): Lambda(P) <= k(q - 1) for P. If C_q(k) held
for all maps and all k, it would give the exact Kakeya growth constant
beta_q = q 2^(-(q-1)/q) of F_q (README Thm 2). More generally, a174 Cor 58.2 handles
P(x) = A((Sx) o (Sx)) + Lx + c with A, S invertible: there the slices are
M_t = A^-1 (L + tI) S^-1 and Lambda(P) = sum_t H(M_t).

Known before this note:
- every SCC of the digraph of M of size <= K0(q) (K0(3) = 14, K0(5) = 41, K0(7) = 71)
  (a174 Cor 58.1);
- cycles (a174);
- low rank (a174 Thm 59, a175 Thm 60).

The digraph has an edge i -> j when i != j and M_ij != 0 ("row i reads input j"). Open:
large SCCs of high rank.

## 1. Peeling (Lemma 139)

Fix an order i_1, ..., i_k of the coordinates and put K_j = {i_1, ..., i_j}. At step j let
U = complement of K_{j-1} (it contains i = i_j) and let R be the row space of M[K_{j-1}, U]
inside F_q^U. Call step j
- **linear** if e_i lies in R;
- **quadratic** if, for some alpha in F_q, the vector rho_i + alpha e_i lies in R. Here
  rho_i is row i of M restricted to U, with its i-th entry set to 0. This includes the
  case where every input of row i is already known.
- **free** otherwise.

**Lemma 139.** For every order,

    H(M) <= (#free) log2 q + (#quadratic)(1 - 1/q).

*Proof.* By the chain rule, H(Y | F) = sum_j H(Y_i | F, Y_K) with K = K_{j-1}. For a known
row r in K,

    sum_{l in U} M_rl Y_l = F_r - Y_r^2 - sum_{l in K} M_rl Y_l

is a function of (F, Y_K). Hence v . Y_U is a function of (F, Y_K) for every v in R.

- *Linear step:* Y_i is determined, so the term is 0.
- *Quadratic step:* write v = rho_i + alpha e_i in R. Row i reads

      F_i = Y_i^2 + M_ii Y_i + sum_{l in K} M_il Y_l + v . Y_U - alpha Y_i,

  so Y_i^2 + beta Y_i is a function of (F, Y_K), with beta = M_ii - alpha a constant.
  Because Y_i is independent of Y_K,

      H(Y_i | F, Y_K) <= H(Y_i | Y_i^2 + beta Y_i) = 1 - 1/q.

  The map y -> y^2 + beta y has one 1-point fibre and (q-1)/2 two-point fibres.
- *Free step:* the term is at most log2 q. []

The orders that put sink components first recover a174's bound k(1 - 1/q) for acyclic
digraphs. Linear steps are what beat it.

**Corollary 139.1 (propagation).** Let Cl(S) be the closure of S under linear steps.
If Cl(S) = [k], then Y is a function of (F(Y), Y_S), and H(M) <= H(Y_S | F) <= |S| log2 q.

## 2. Banded linear parts (Theorem 63, Proposition 71)

**Theorem 63.** Suppose M has *upper bandwidth w >= 1* with a nonzero outer band, that is,
M_ij = 0 for j > i + w and M_{i,i+w} != 0 for 1 <= i <= k - w. The part below the band is
arbitrary. Then for every k:

    H(M) <= w log2 q.

*Proof.* Take S = {1, ..., w}. When K = {1, ..., m} with m >= w, row r = m + 1 - w is known.
It reads no column beyond m + 1, so its restriction to U = {m+1, ..., k} is
M_{r,m+1} e_{m+1}, which is not 0. The step for m + 1 is therefore linear, and
Corollary 139.1 applies. []

**Proposition 71 (cyclic bands).** Suppose row i reads only columns i - w', ..., i + w
(mod k) and M_{i,i+w} != 0 for every i, with w + w' < k. Then H(M) <= (w + w') log2 q.
Example: cyclic tridiagonal matrices with a nonzero super-diagonal have H(M) <= 2 log2 q.

*Proof.* Seed {1, ..., w + w'}. With K = {1, ..., m}, row r = m + 1 - w satisfies
r - w' >= 1 and r + w = m + 1 <= k. So its only unknown input is m + 1. []

**Corollary 63.1 (Kakeya maps with banded linear part).** Let P(x) = x o x + Lx + c with
L as in Theorem 63. Then

    Lambda(P) = q H(L) <= q w log2 q,

which is bounded independently of the dimension. Hence C_q(k) holds for P when
k >= w q log2 q / (q - 1), and also when k <= K0(q) (a174). At q = 3 this covers every
k for every w <= 6.

This class contains strongly connected matrices of full rank, for example every
tridiagonal L whose two off-diagonals are nonzero. For those, a174's Corollary 58.1 does not reach them beyond k = K0(q) (14 at q = 3),
and a175's low-rank results do not apply. The corollary also shows quantitatively that
extremal maps (Lambda = k(q-1)) are far from banded: banded maps have Lambda = O(1).

## 3. Cutting (Lemma 140)

**Lemma 140.** For every S in [k],

    H(M) <= H(M_SS) + H(M_{S^c S^c}) + min(rank M[S, S^c], rank M[S^c, S]) log2 q.

*Proof.* Let tau = M[S, S^c] Y_{S^c}. Then

    H(Y | F) = H(Y_S | F) + H(Y_{S^c} | F, Y_S)
            <= H(tau) + H(Y_S | F, tau) + H(Y_{S^c} | F, Y_S).

- Given tau, F_S - tau = Y_S o Y_S + M_SS Y_S. Y_S is independent of tau, so
  H(Y_S | F, tau) <= H(M_SS).
- Given Y_S, F_{S^c} - M[S^c, S] Y_S is the frame map of M_{S^c S^c} applied to Y_{S^c},
  which is independent of Y_S. So the last term is <= H(M_{S^c S^c}).
- H(tau) = rank M[S, S^c] log2 q.

Swapping S and S^c gives the other rank. []

The rank-0 case is a174 Prop 67(b). **Corollary 140.1.** For every S, H(M) is at most
min-rank x log2 q plus the sum of H(M_CC) over the SCCs C of M_SS and of M_{S^c S^c}.
So SR* holds whenever the SCC gaps |C|(1 - 1/q) - H(M_CC) add up to at least the cut
cost. For 2 <= |C| <= K0(q), a174 bounds each gap below by
|C|(1 - 1/q) - log2 Phi_q(|C|).

## 4. Rank expansion and almost every M (Theorem 64)

For T in [k] let rho(T) = rank M[T^c, T] (rows outside T, columns in T).

**Theorem 64.** Suppose k >= 2 and

    rho(T) >= ceil(min(|T|, k - |T|) / 2)   for every T

("half rank expansion"). Then H(M) < k(1 - 1/q). Quantitatively, for every k,

    H(M) <= log2[ (1 + a/c)^k + (a + 1/c)^k ],   a = (q-1)/q, c = sqrt(q-1).

*Proof.* a174 Thm 58 gives the exact identity E N = sum_T q^-|T| V(T), where V(T) counts
the vectors d of support exactly T with M[T^c, T] d_T = 0. Those d_T are vectors of full
support in a kernel of dimension |T| - rho(T). Projecting onto an information set shows
there are at most (q-1)^(|T| - rho(T)) of them. With Jensen and the hypothesis:

    H(M) <= log2 E N <= log2 sum_t C(k,t) a^t c^(-min(t, k-t))
         <= log2[ sum_t C(k,t) a^t (c^-t + c^-(k-t)) ]
          = log2[ (1 + a/c)^k + (a + 1/c)^k ].

Put b = 2^(1 - 1/q), r1 = (1 + a/c)/b and r2 = (a + 1/c)/b.

- At q = 3: r1 = 0.92693 and r2 = 0.86542, so r1^k + r2^k <= 0.9515 < 1 for k >= 7.
- For q >= 5: r1 and r2 are both <= (1 + 1/sqrt(q-1))/b <= 0.8616, so the sum is < 1
  for k >= 5.

That gives H(M) < k(1 - 1/q) in those ranges. For smaller k (2 <= k <= 6), the hypothesis
gives rho(T) >= 1 for every proper nonempty T, which means the digraph is strongly
connected. Since k <= K0(q), a174 Cor 58.1 then gives the strict inequality. []

**Corollary 64.1 (almost every linear part).** Let M be uniform over all k x k matrices
over F_q and x = k q^(-k/8) < 1. Then

    P(M is not half-expanding) <= 4x/(1 - x)  ->  0,

so SR* holds strictly for all but an exponentially small fraction of matrices.

*Proof.* Fix T with min(|T|, k - |T|) = m. The block M[T^c, T] uses only off-diagonal
entries, so it is uniform. View its m short vectors in F_q^n, where n = max >= k/2. Its
rank is at most rho0 = ceil(m/2) - 1 only if they lie in some rho0-dimensional subspace.
There are at most 2 q^(rho0 (n - rho0)) such subspaces for q >= 3, because
prod_{j>=1}(1 - 3^-j) >= 1/2. Each contains all m vectors with probability
q^(-(n - rho0) m). Hence

    P <= 2 q^(-(n - rho0)(m - rho0)) <= 2 q^(-km/8),

since n - rho0 > k/4 and m - rho0 > m/2. There are at most 2 k^m sets T with this m, and
summing over m gives the bound. []

For example the bound is below 0.07 at (q, k) = (3, 60) and below 1e-4 at (3, 120). The
true fraction is far smaller; the bound is crude.

**Corollary 64.2 (Kakeya).** Fix invertible A and S, and let L be uniform. Each slice
M_t = A^-1 (L + tI) S^-1 is then uniform. So, with probability at least 1 - 4qx/(1 - x),

    Lambda(A((Sx) o (Sx)) + Lx + c) < k(q - 1).

Under full expansion (rho(T) = min(|T|, k - |T|), for example when M[T^c, T] has full
rank for every T), the same computation gives H(M) <= log2[(1 + 1/q)^k + (a + 1/(q-1))^k],
about k log2(1 + 1/q). Hence Lambda(P) is at most about 1.25k at q = 3, against the
conjectured maximum 2k.

## 5. Erratum to a176

a176 Proposition 70 states that the q = 3 one-point gap is at least
2 log2(e) ln(5/4) > 0.644. In fact 2 log2(e) ln(5/4) = 2 log2(5/4) = 0.643856..., which is
*not* above 0.644. The correct statement is "> 0.6438". Theorem 62 uses the bound 0.64,
and the code constant `Q3_GAP = 0.64` in `frame_local.py` is unaffected. Every conclusion
of a176 stands. (`test_sr_cut.py` checks the constant.)

## 6. What this does and does not do

Done, in every dimension, for the frame algebra:
- SR* for banded and cyclic-banded linear parts (Theorem 63, Proposition 71), with
  H(M) = O(1);
- a general peeling bound (Lemma 139) and a cut lemma with a rank price (Lemma 140);
- SR* for every half-rank-expanding M, hence for almost every M (Theorem 64,
  Corollary 64.1);
- C_q(k) for the corresponding Kakeya maps x o x + Lx + c (and conjugates, for almost
  every L).

Not done:
- **The hard frame regime that remains:** sparse matrices with large SCCs, poor rank
  expansion and no cheap cut. Examples are bounded-degree random digraphs (some columns
  are read by no outside row), and rings of near-extremal blocks such as rank-one cJ
  blocks joined by single edges, where the cut cost log2 q exceeds the summed gaps of two
  blocks.
- Other algebras (a173's general unital SR*).
- C_q(k) for all maps, which is the actual Kakeya problem.

Prior art: SR* and the functional are MV2's own (notes a159-a176). The techniques used
(chain rule, Jensen, ranks of random matrices) are standard. A search of arXiv and Google
on 2026-11-18 found no improvement on Bukh-Chao (Discrete Analysis 2021:26) for the
fixed-q exponential constant.
