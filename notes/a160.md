## Where this sits

Note a159 set out a route to the Kakeya block conjecture C_q(k): Lambda(P) <= k(q-1) for every map
P of F_q^k, where X is uniform on F_q^k, Y_t = P(X) + tX and Lambda(P) = sum_t H(X | Y_t) (bits).
By Theorem 2, C_q(k) for every k is equivalent to beta_q = q 2^(-(q-1)/q) being the exact Kakeya
growth constant of F_q. Theorem 35 gave the chain bound

    Lambda(P) <= Lambda_l(P) + (1/q) sum_a Lambda(Q_a),     Lambda_l(P) = sum_t H(l(X) | Y_t),

and Corollary 125 said: C_q(k-1) together with

    Lemma L_q(k): every P on F_q^k has a nonzero functional l with Lambda_l(P) <= q - 1

implies C_q(k). Since C_q(1) is a theorem, L_q(2) would have given C_q(2), i.e. h_2 = 2 h_1, for
every q. This note shows that L_q(2) is false whenever q is even and at least 4, by an explicit
algebraic family. The weaker L'_q(2) (some (l, v) whose whole chain bound is at most 2(q-1)) is
untouched, and it does hold for the q = 4 example below.

## Theorem 36

Let q = 2^m >= 4, E = F_{q^2} viewed as F_q^2, s in E \ F_q, and

    P(x) = x^(-1) + s x          (0^(-1) = 0).

Then every Y_t is exactly 2-to-1, Lambda(P) = q <= 2(q-1), and for every nonzero F_q-linear
functional l,

    Lambda_l(P) = q - 1 + 2/q              if ker l = F_q,
    Lambda_l(P) = q - 1 + (q - 2)/q^2      otherwise.

In particular min_l Lambda_l(P) = q - 1 + (q-2)/q^2 > q - 1, so L_q(2) fails. (For q = 4:
7/2 and 25/8 against the bound 3.)

**Proof.** Fix t in F_q and put u = s + t; u != 0 since s is not in F_q. Then Y_t = X^(-1) + uX.
For c != 0 the equation x^(-1) + ux = c has no solution x = 0 and, for x != 0, is
u x^2 + c x + 1 = 0, which is separable (derivative c != 0) with root product 1/u: the fibre is
empty or a pair {x, 1/(ux)} with x != 1/(ux). For c = 0 the fibre is {0, x0} with x0 = u^(-1/2)
(squaring is bijective in characteristic 2). So every fibre has size 2 and
H(X | Y_t) = 1 for each t, giving Lambda(P) = q.

With fibres of size 2, H(l(X) | Y_t) = (2/q^2) times the number of fibres {x, x'} with
l(x) != l(x'), i.e. whose difference x + x' is not in D = ker l. Over all t there are q * q^2/2
fibres, so Lambda_l(P) = q - 2 N_D / q^2, where N_D counts the pairs (t, fibre) with difference in
D. Write D = F_q d0.

Fix u. The fibre {0, x0} has difference x0. A fibre {x, 1/(ux)} has difference c = x + 1/(ux),
and conversely for c != 0 the pair of roots of x^2 + cx + 1/u is a fibre with difference c if and
only if that quadratic splits over E, i.e. (substituting x = cz) Tr_{E/F_2}(1/(u c^2)) = 0. So the
fibres with difference in D \ {0} correspond to the lambda in F_q^* with
Tr_{E/F_2}(mu e) = 0, where mu = lambda^(-2) runs over F_q^* and e = 1/(u d0^2). Now
Tr_{E/F_2}(mu e) = Tr_{F_q/F_2}(mu tau) with tau = Tr_{E/F_q}(e) = e + e^q. If tau != 0, exactly
q/2 - 1 of the mu in F_q^* give trace 0; if tau = 0, all q - 1 do. And tau = 0 iff e is in F_q
iff u is in F_q^* d0^(-2). The fibre {0, x0} has x0 in D iff u^(-1) is in F_q d0^2, which is the
same condition. Hence

    N_D(u) = q/2 - 1 + (q/2 + 1) [u in F_q^* d0^(-2)].

As t runs over F_q, u runs over the affine line s + F_q, which misses 0 and has direction F_q. The
punctured line F_q^* d0^(-2) meets it once if d0^(-2) is not in F_q, and never if it is; and
d0^(-2) is in F_q iff d0 is, i.e. iff D = F_q. Summing over u:

    N_D = q(q/2 - 1) + (q/2 + 1) = q^2/2 - q/2 + 1   (D != F_q),     N_{F_q} = q^2/2 - q.

Substituting gives the two values of Lambda_l(P). As a check, the q + 1 lines receive
(q^2/2 - q) + q(q^2/2 - q/2 + 1) = q^3/2 pairs, all of them. For q = 2 the formula gives
min_l Lambda_l = 1 = q - 1, consistent with C_2. QED.

## Why this family

A counting remark explains it. If every Y_t is a perfect matching then Lambda(P) = q and
Lambda_l(P) = q - 2 N_D/q^2. Summing over the q + 1 lines, L fails only if the q * q^2/2 matched
pairs are spread so evenly over directions that every line gets fewer than q^2/2 of them. For odd
q a matching leaves a point out, there are at most q(q^2 - 1)/2 pairs, and the averaging shows
pure matchings can never break L. For even q there is room, and x -> x^(-1) + ux is the classical
2-to-1 map whose pair differences x + 1/(ux) are equidistributed by a trace condition. So the
odd-q case (pre-registered guess E3 at q = 3) remains open, and a counterexample there would need
larger fibres.

## Hand check at q = 4 (now also a unit test)

F_16 = F_2[a]/(a^4 + a + 1), F_4 = {0, 1, w = a^5, w^2 = a^10}, s = a (a^2 + a = w, so
gamma = w in the code's F_4[y]/(y^2 + y + gamma) with y = a). For u = a, a^2, a^4, a^8 (the four
values of s + t), the 8 pairs at u = a have differences in the lines of classes
3, 2, 2, 0, 2, 1, 4, 2 (class = discrete log mod 5). Frobenius multiplies the classes by 2, so
the totals over the four u are 4, 7, 7, 7, 7. That gives Lambda_l = (32 - 4)/8 = 7/2 for
ker l = F_4 and (32 - 7)/8 = 25/8 for the other four lines, while Lambda(P) = 4.

For l = first coordinate (kernel F_4 a), v = 1, the four slice maps Q_b on F_4 have
Lambda(Q_0) = 3 and Lambda(Q_1) = Lambda(Q_w) = Lambda(Q_{w^2}) = 3/2 + (3/4) log2 3, so the
chain bound of Theorem 35 is 25/8 + (1/4)(3 + 3(3/2 + (3/4) log2 3)) = 5 + (9/16) log2 3 = 5.89,
which is at most 6. So L'_4(2) holds for this map: the chain route is not closed by it.

## Consequences

1. Corollary 125 cannot prove C_q(2) for even q >= 4; any proof by Theorem 35 must use the full
   chain bound (L') or a different decomposition.
2. The counterexample is far from threatening C itself: Lambda(P) = q, against the bound
   2(q - 1). Maps that break L cheaply carry little total loss.
3. Pre-registered expectation E4 (every F_2-linear map at (4,2) satisfies L) is not affected:
   P is not additive. E3's guess, that L fails at (3,2), is still open.
