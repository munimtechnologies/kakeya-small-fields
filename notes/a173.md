## 0. Summary

Program (a159-a172): for a map P of F_q^k let A_t(x) = P(x) + tx and

    Lambda(P) = sum_{t in F_q} H(X | A_t(X))      (bits, X uniform on F_q^k).

By Theorem 2 (README) the Kakeya growth constant of F_q is beta_q = q 2^(-lambda*/q), with
lambda* = sup_k max_P Lambda(P)/k over **all** maps P. The conjecture C_q(k), Lambda <= k(q-1),
would give the exact constant beta_q = q 2^(-(q-1)/q). Quadratic maps are the test class. a172
wrote a quadratic map P(x) = x o x + Lx + c as a commutative algebra (x o y the polarization of
the quadratic part) and showed (Lemma 127): **if the algebra has a unit, then
Lambda(P) = q H(X | P(X)) for every L.** This note adds three results, each for every odd q
and every k.

1. **Isotope reduction (Theorem 54).** Call P *regular* if some multiplication operator
   R_p : x -> p o x (p in F_q^k) is invertible, i.e. the Jacobian of the quadratic part is
   invertible at some F_q-point. Twisting the product to x * y = R_p^(-1)(x o y) gives a unital
   algebra (unit p), and **every slice A_t of P becomes a unital map** with the same fibres. As
   a result the following are equivalent for each (q, k):
   * C_q(k) holds for every unital quadratic map;
   * C_q(k) holds for every regular quadratic map;
   * every slice of every regular quadratic map satisfies H(X | A_t X) <= k(1 - 1/q).

   So within regular maps the average-over-t conjecture is equivalent to its unital special case
   and then holds **slice by slice**. With Theorems 38 and 43 this gives the slice-wise bound for
   every regular quadratic map with k <= 3 (Corollary 54.2). At least a 1 - k/q fraction of all
   quadratic maps are regular (Proposition 65), and a167's G_n family is regular.
2. **Spin factors (Theorem 55).** For every spin factor J(V, phi) = F_q 1 + V
   (v o w = phi(v, w) 1, phi any symmetric bilinear form on V = F_q^n, degenerate allowed),
   we give an exact formula for H(Y | Y^2) and prove
   
       Lambda(y o y + l o y + c) = q H(Y | Y^2) <= (n + 1)(q - 1),
   
   with equality only for J = F_q or F_q x F_q. For n >= 2 and phi != 0, J is **not
   associative**, so this is the first non-associative unital class settled at every fixed q in
   every dimension. Spin factors are exactly the unital commutative algebras of degree <= 2
   (every element satisfies a quadratic equation; Proposition 64).
3. **Spectral lemma (Theorem 56).** A_t is injective if and only if -t is not an
   eigenvalue in F_q of any operator R_u + L. Hence every algebra with a flag lowered by all R_u
   and by L (in particular every commutative nilpotent algebra, associative or not, with L in a
   compatible class) has Lambda = H(X | P X) <= k log2 q < k(q - 1). This extends a172's
   Lemma 128 from associative to arbitrary nilpotent algebras.

**Limits.** None of this proves C_q(k) for k >= 4. The open part of the quadratic program is
now cleanly split: (i) the *unital square-root entropy conjecture* SR*_q(k) of Section 2
(unital algebras, **arbitrary** linear part), which by Theorem 54 is equivalent to C_q(k) for
all regular quadratic maps; and (ii) the non-regular maps, whose Jacobian is singular at every
F_q-point. Spin factors are settled only for linear parts L = R_l. Quadratic maps are a special
case of the real question (all maps), so **nothing here proves beta_q.**

## 1. Isotopes

Fix q odd and a commutative algebra A = (F_q^k, o). As in a172, P(x) = x o x + Lx + c and
DQ(x) = 2 R_x. For p with R_p invertible define

    x * y = R_p^(-1) (x o y).

This is bilinear and commutative, and p * x = R_p^(-1) R_p x = x, so p is a unit. (This is the
classical notion of an isotope of an algebra, Albert 1942; McCrimmon's Jordan isotopes are a
special case.)

> **Theorem 54 (isotope reduction).** Let R_p be invertible. For every t in F_q and every x,
>
>     R_p^(-1) A_t(x) = x * x + M_t x + R_p^(-1) c,     M_t = R_p^(-1)(L + tI).
>
> Hence H(X | A_t X) = H(X | X * X + M_t X), the fibre entropy of a **unital** quadratic map,
> and by Lemma 127 in the isotope this equals H(X | X * X + (M_t + sI) X) for every s in F_q.

*Proof.* R_p^(-1)(x o x) = x * x by definition, and R_p^(-1) is a bijection of F_q^k, so A_t and
R_p^(-1) A_t have the same fibres. The last claim is Lemma 127 for the unital algebra
(F_q^k, *) with linear part M_t. []

Define the **unital square-root entropy conjecture** SR*_q(k): for every unital commutative
algebra B of dimension k over F_q and every linear map M,

    H(Y | Y^2 + M Y) <= k (1 - 1/q).

(a172 stated it as SR_q(k) and proved it for associative B with M = R_l. Here M is arbitrary.)

> **Corollary 54.1 (equivalences).** For each odd q and each k the following are equivalent:
> (a) C_q(k) for every unital quadratic map; (b) SR*_q(k); (c) H(X | A_t X) <= k(1 - 1/q)
> for every regular quadratic map P and every t; (d) C_q(k) for every regular quadratic map.

*Proof.* (a) <=> (b): for unital P = y^2 + My + c, Lemma 127 gives Lambda(P) = q H(Y | P Y), and
the constant c does not change fibres. (b) => (c): Theorem 54. (c) => (d): sum over the q values
of t. (d) => (a): a unital algebra is regular (R_e = I). []

So the regular part of the quadratic conjecture **improves itself**: if the average over the q
slices is at most k(q - 1) for all regular maps, then each single slice is at most k(1 - 1/q).
This fails for general maps (the zero map has a slice with H = k log2 q), so it is a structural
feature of the quadratic class.

> **Corollary 54.2 (k <= 3, slice-wise).** For every odd q, every k <= 3, every regular quadratic
> map P of F_q^k and every t: H(X | A_t X) <= k(1 - 1/q).

*Proof.* C_q(1) is the README's value of h_1, and Theorems 38 (k = 2) and 43 (k = 3, a166) prove C_q(k)
for every map of degree <= 2, in particular for unital ones. Apply Corollary 54.1. []

**Example (G_n is regular).** For a167's G_n, (u, s) o (w, t) = (sw + tu, phi(u, w)), the
operator R_(u,s) has block matrix [[s I, u], [phi(u, .), 0]] and determinant
-s^(n-1) phi(u, u). It is invertible at s = 1 and any u with phi(u, u) != 0. So every slice of
G_n is a unital SR* instance. Its isotope linear parts R_p^(-1)(L + tI) are not multiplication
operators, which is why G_n is not covered by Theorem 55 below. (a167 handled it directly.)

> **Proposition 65 (most quadratic maps are regular).** Among all commutative algebra structures
> on F_q^k (equivalently, all quadratic parts Q), at most a k/q fraction are not regular. If
> q > k, P is regular if and only if det R_x is not the zero polynomial.

*Proof.* Let x0 = (1, ..., 1). det R_(x0) is a polynomial of degree k in the structure constants.
It is not the zero polynomial, because the frame algebra e_i o e_i = e_i has R_(x0) = I. By the
Schwartz-Zippel lemma it vanishes on at most a k/q fraction of all structure constants, and a
non-regular algebra has det R_(x0) = 0. For the second claim: det R_x is a polynomial in x of
degree k < q, so all its individual degrees are < q. Such a polynomial vanishes at every point of
F_q^k only if it is the zero polynomial. []

The non-regular maps include affine maps (Q = 0), algebras with a nonzero annihilator
(R_p w = 0 for all p) and algebras whose products span a proper subspace. Section 4 treats the
nilpotent ones.

## 2. Degree-2 algebras are spin factors

For a symmetric bilinear form phi on V = F_q^n (any rank) let J = J(V, phi) = F_q 1 + V with

    (a + v) o (b + w) = (ab + phi(v, w)) 1 + (a w + b v).

So (a + v)^2 = (a^2 + Phi(v)) 1 + 2a v, with Phi(v) = phi(v, v).

> **Proposition 64.** (i) Every y = a + v in J satisfies y^2 = 2a y - (a^2 - Phi(v)) 1.
> (ii) Conversely, let B be a unital commutative algebra of dimension k >= 2 with a linear form T
> and a quadratic form N such that y^2 = T(y) y - N(y) 1 for all y. Then B is isomorphic to a
> spin factor J(V, phi) with V = ker T.

*Proof.* (i) is a direct expansion. (ii) Polarizing (q odd) gives
y o z = (T(y) z + T(z) y - N(y, z) 1)/2 with N(y, z) = N(y + z) - N(y) - N(z). Put z = 1 and take
y not in F_q 1 (possible as k >= 2). Comparing coefficients of y gives T(1) = 2, so V = ker T is
a complement of F_q 1. For v, w in V the formula gives v o w = -N(v, w)/2 . 1, a multiple of 1.
So B = J(V, phi) with phi(v, w) = -N(v, w)/2. []

For n >= 2 and phi != 0, J is not associative. Pick v with Phi(v) != 0 and w not parallel to v.
Then (v o v) o w = Phi(v) w, but v o (v o w) = phi(v, w) v.

## 3. Spin factors

For p in F_q let N(p) = #{w in V : Phi(w) = p}, let Sq* be the set of nonzero squares, write
sigma(p) = 1 if p is in Sq* and 0 otherwise, and put S = sum_{p in Sq*} N(p).

**Fibres of squaring.** Let y = a + v and z = b + w. Then z^2 = y^2 if and only if
b^2 + Phi(w) = a^2 + Phi(v) and bw = av.

* **I: a != 0, v != 0.** Then b != 0 and w = (a/b) v. Multiplying by b^2 gives
  (b^2 - a^2)(b^2 - Phi(v)) = 0. So the fibre has **4** points if Phi(v) is in Sq* and
  Phi(v) != a^2, and **2** (z = +-y) otherwise.
* **II: a != 0, v = 0.** b != 0 forces w = 0 and b = +-a; b = 0 needs Phi(w) = a^2. Size
  2 + N(a^2).
* **III: a = 0** (any v, including 0). b != 0 forces w = 0 and b^2 = Phi(v); b = 0 needs
  Phi(w) = Phi(v). Size N(Phi(v)) + 2 sigma(Phi(v)).

Summing log2 of the fibre size over all q^(n+1) points: for v != 0 with Phi(v) in Sq*, exactly
q - 3 of the q - 1 values a != 0 have a^2 != Phi(v). Hence

    q^(n+1) H(Y | Y^2) = (q^n - 1)(q - 1) + (q - 3) S + 2 sum_{c in Sq*} log2(2 + N(c))
                         + sum_{p in F_q} N(p) log2(N(p) + 2 sigma(p)).            (*)

Checks: n = 0 gives (q - 1)/q (J = F_q). For n = 1 and Phi(v) = d v^2: d in Sq* gives
2(1 - 1/q) (J = F_q x F_q); d a non-square gives 1 - q^(-2) (J = F_(q^2), a172 Cor. 53.1);
d = 0 gives (q - 1 + log2 q)/q (dual numbers).

> **Theorem 55.** Let q be odd, n >= 0, phi any symmetric bilinear form on F_q^n, J = J(V, phi)
> of dimension k = n + 1, and l, c in J. Then P(y) = y o y + l o y + c satisfies
>
>     Lambda(P) = q H(Y | Y^2) <= k (q - 1),
>
> with equality if and only if n = 0, or n = 1 and phi(v, v) = d v^2 with d a nonzero square
> (that is, J = F_q^k).

*Proof.* Lambda(P) = q H(Y | Y^2) by Lemma 127, because y^2 + l o y = (y + l/2)^2 - l^2/4. For
n <= 1 the values above give the claim (log2 q < q - 1 and 1 - q^(-2) < 2(1 - 1/q)). Let n >= 2.

*A uniform bound.* Bound the three groups of points separately.
* In group I the average of log2 |fibre| over a != 0 is at most 1 + (q - 3)/(q - 1).
* In group II, N(a^2) <= q^n - 1, since w = 0 is excluded.
* In group III, by Jensen,
  q^(-n) sum_v log2(N(Phi v) + 2 sigma) <= log2(q^(-n) sum_p N(p)(N(p) + 2 sigma(p))),
  and the argument is at most q^n + 2 (N(p) <= q^n).

With u = q^(-n) this gives

    q H(Y | Y^2) <= G(q, n) := (2q - 4)(1 - u) + (q - 1) u log2(q^n + 1) + log2(q^n + 2).

*G(q, n) < (n + 1)(q - 1) for n >= 2.* Use log2(q^n + a) <= n log2 q + a u / ln 2. Then

    (n + 1)(q - 1) - G >= [(n - 1)(q - 1) + 2 - n log2 q (1 + (q - 1)u)]
                          + u [2q - 4 - 2/ln 2 - (q - 1)u/ln 2].

* For q >= 5 the second bracket is positive (2q - 4 >= 6 > 2.89 + 0.24), and (q - 1)u < 1/q.
  So the first bracket is > n c_q - (q - 3), where c_q = (q - 1) - (1 + 1/q) log2 q > 0. At
  n = 2 this is q + 1 - 2(1 + 1/q) log2 q >= q + 1 - 2.4 log2 q > 0 (0.43 at q = 5,
  increasing for q > 3.5). Larger n only adds c_q > 0.
* For q = 3 and n >= 3 the first bracket is n(2 - log2 3 (1 + 2 . 3^(-n))) >= 0.297 n, while
  the second is >= -0.992 u >= -0.037.
* For (q, n) = (3, 2), G = 16/9 + (2/9) log2 10 + log2 11 = 5.9754 < 6.

So for n >= 2 the inequality is strict. []

The exact values for q = 3, n = 2 are below (all five isometry classes of forms on F_3^2).
The maximum is the degenerate phi = 0, which is the associative square-zero ring of a172:

| 0 | 9, 0, 0 | (18 + 9 log2 9)/27 = 1.723 | strict |

## 4. A spectral lemma

> **Theorem 56.** For any commutative algebra, any L and c, and t in F_q: A_t is injective if
> and only if there are no u in F_q^k and d != 0 with (R_u + L) d = -t d. Hence
> Lambda(P) = sum over t in T of H(X | A_t X) <= |T| k log2 q, where T is the set of t for which
> -t is an F_q-eigenvalue of some R_u + L.

*Proof.* A_t(x) - A_t(x') = (x + x') o (x - x') + (L + tI)(x - x'), by commutativity. The map
(x, x') -> (u, d) = (x + x', x - x') is a bijection (q odd). []

> **Corollary 56.1 (flag-nilpotent algebras).** Suppose F_q^k = F_1 > F_2 > ... > F_(k+1) = 0 is a
> complete flag with R_u F_i in F_(i+1) for every u, and L F_i in F_(i+1). Then T is contained
> in {0}, and Lambda(P) = H(X | P X) <= k log2 q < k(q - 1).

Every R_u + L is strictly triangular in an adapted basis, so it is nilpotent and its only
eigenvalue is 0. This covers every commutative nilpotent algebra, associative or not, with the
flag refining N > N^2 > ... (N^i the span of all products of i elements). It also covers every
L that lowers that flag, for example L = R_l. a172's Lemma 128 was the associative case with
L = R_l. The tests include a flag-nilpotent algebra that is not even power-associative
(e_0^2 = e_1, e_0 e_1 = e_2, e_1^2 = e_3: x = e_0 has x^2 x^2 = e_3 != 0 = (x^2 x) x).

## 5. What this says about the program

* **The quadratic conjecture now has two halves.** The regular half is exactly SR*_q(k)
  (Corollary 54.1). The non-regular half (Jacobian singular at every F_q-point) is at most a k/q
  fraction of quadratic parts. It contains the nilpotent case (settled, Corollary 56.1) and
  the annihilator and hyperplane-image cases (open).
* **SR*_q(k) is a single-map question with no t.** For each unital algebra it asks how often
  y^2 + My has many solutions. Theorem 53 (associative, M = R_l) and Theorem 55 (degree 2,
  M = R_l) settle it for multiplication operators. The next targets are spin factors with
  **arbitrary** M (this would cover every slice of G_n for all n) and frames F_q^k with
  arbitrary M.
* **A search target.** A unital algebra B and an M with H(Y | Y^2 + MY) > k(1 - 1/q) would
  refute C_q(k) itself (Corollary 54.1(a)). The pre-registered search in the playbook
  (random unital algebras with random M, q = 3, k = 3..5) tests exactly this. It needs one fibre
  count per map.

## 6. Tests (`test_isotopes.py`)

* Theorem 54. Random commutative algebras for (q, k) in {(3,2), (3,3), (3,4), (5,2), (5,3),
  (7,2)}. Find a regular point p and check that p is a unit of the isotope. Check the identity
  R_p^(-1) A_t(x) = x * x + M_t x + R_p^(-1) c at every x and t, and that the entropy does not
  change under M_t -> M_t + sI.
* Corollary 54.2. Every slice of random regular maps for k <= 3 (q = 3, 5, 7) is at most
  k(1 - 1/q).
* G_n is regular. Proposition 65: an exhaustive count over all algebras on F_3^2 and F_5^2.
* Theorem 55. Brute-force H(Y | Y^2) equals the formula (*) for **every** symmetric form with
  (q, n <= 3) = 3, (q, n <= 2) = 5 and (q, n <= 2) = 7. Random forms for (3, 4), (5, 3), (11, 1),
  (11, 2) and (13, 2). Each check confirms equality exactly in the stated cases, a gap > 10^(-3)
  otherwise, and q H <= G(q, n).
  Also checked: the q = 3, n = 2 table; G(q, n) < (n + 1)(q - 1) for all primes q <= 101 and
  2 <= n <= 40; and Lambda(y o y + l o y + c) = q H(Y | Y^2) by brute force over t.
* Theorem 56. For random algebras and L, A_t is injective iff t is not in T. Corollary 56.1:
  random flag-nilpotent algebras and the non-power-associative example.
