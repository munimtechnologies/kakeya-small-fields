## What changes

- **Lemma 93 (by hand).** In the second-matrix split, h_1 can be chosen in N = ker phi outside
  span(u) so that A_(h_1) has the largest rank on X_1 = ker A_u among all such elements. Then in
  an instance whose representative has rank 0 on X_1, **every A_n with n in N vanishes on X_1**,
  and **beta(n, n') = 0 for all n, n' in N**. The first statement is a set of unit clauses: 42 per
  instance of (B5) and 21 per instance of (B6). They are aimed at the slow instances: 13 of the
  14 split instances still open in (B5), and all 7 open kind-L instances of (B6), are of rank 0.
- **The rank-0 sweep.** For a whole class of A_u, the case "every element of N has rank 0 on X_1"
  is one instance, with no symmetry argument needed. If that instance is UNSAT, Lemma 93 lets the
  class's split skip all of its rank-0 representatives.
- **Proposition 33 (by hand)** sets up the split for the 51 open classes of (B6) with d <= 2. The
  set of possible maps A_(h_1) is the one of Proposition 30: 176126 maps when d >= 1 and 176128
  when d = 0. The stabiliser G of (x0, P, A_u) has order 2^(3d) times a count of pairs (h, a).
  Its order is computed for all 51 classes, and the sums over the classes of seven complete pair
  orbits match an independent count of the pair stabilisers. **For the 7 classes with d = 0 the
  split is counted exactly: 9755 instances (552 to 3840 per class).** For d >= 1 only the lower
  bound ceil(|Adm| / (2 |G|)) is given: 1007 for d = 2 and 6785 for d = 1.
- So the full split of these 51 classes runs to tens of thousands of instances. At the 1.3 to 2.0 s
  per instance of the (B5) splits, that is about 10 to 30 hours of CPU. Jobs m63 and m64 (below,
  staged with their predictions, not queued: 4 jobs are pending) first measure whether Lemma 93
  and the sweep make the rank-0 cases cheap.

## Lemma 93

**Lemma 93.** Let u be in (B6) or (B5), and let r be the largest rank on X_1 of A_n over n in N
outside span(u).

(a) There is a system in the class with A_u fixed in which v_1 = h_1 has rank exactly r on X_1 and
    A_(h_1) is the chosen representative of its class under G and h_1 -> h_1 + u. So the class is
    empty if and only if, for every representative of rank r, the instance with the added
    condition "every A_n, n in N, has rank at most r on X_1" is UNSAT.

(b) If r = 0, then A_n = 0 on X_1 and beta(n, n') = 0 for all n, n' in N.

*Proof.* (a) The rank of A_n on X_1 is kept by G, since every g in G keeps X_1 = ker A_u and
conjugates A_n. It is also kept by n -> n + u, since A_u = 0 on X_1. The split of Propositions 30
to 32 works for any choice of h_1 in N outside span(u): a base change in G (followed by a new
basis of V) and, if needed, the swap of h_1 and h_1 + u bring A_(h_1) to its representative.
Choose an h_1 of the largest rank. The other elements of N keep their ranks under the base change.

(b) With r = 0 and A_u = 0 on X_1, every A_n with n in N vanishes on X_1 by linearity. For n, n'
in N, (*) with h = n and h' = n' reads A_(n') sigma(n) = beta(n, n') + A_n beta(n, n'). The left
side is 0, since sigma(n) lies in X_1. The term A_n beta(n, n') is 0, since beta(n, n') lies in
X_1. So beta(n, n') = 0. QED

As clauses: for a rank-0 instance, (b) is A_(v_i) = 0 on the basis vectors of X_1 other than x0
for 2 <= i < kd. That is 7 * 3 = 21 unit clauses for each such v_i: 42 in (B5), 21 in (B6). The
column at x0 is already 0 by m42's hints. beta(v_i, v_j) = 0 then follows by unit propagation
from (L) of sat_aniso.py and the hints, so no clause is added for it. For r = 1, "rank at most 1 on
X_1" is not linear and is not used yet.

**The rank-0 sweep.** For a class of A_u, the systems with r = 0 are the models of one instance:
m42's instance plus A_(v_i) = 0 on X_1 for 1 <= i < kd (42 unit clauses in (B6), 63 in (B5)). This
is a case split on the system, so it needs no symmetry argument. If that instance is UNSAT, then
r >= 1 in every system of the class, and by (a) the split needs only the representatives of rank 1
and 2 on X_1.

Prior art in these notes: a grep of notes/*.md on 2026-10-21 found no earlier choice of h_1 by
rank. The observation that the slow split instances are of rank 0 is from [a48.md](a48.md) to
[a51.md](a51.md).

## Proposition 33

Write S = span(e_4, e_5, e_6), so that X = X_1 + S and A_u maps S onto R. Let r_j = A_u e_j
(j = 4, 5, 6). In the basis (r_4, r_5, r_6) of R, write M for the 3 x 3 matrix of the S-parts of the
r_j (in the basis e_4, e_5, e_6), rho for the row of their e_0-coefficients, and X' for the 3 x 3
matrix of their parts in X_1 n P = span(e_1, e_2, e_3). Then rank M = 3 - d.

**Proposition 33.** Let u be in (B6) with d <= 2.

(a) For every n in N outside span(u), A_n lies in Adm: A x0 = 0, A(X) inside R, rank of A on X_1
    at most 2, and, when d >= 1, A != 0 and A != A_u. So |Adm| = 344 * 512 - 2 = 176126 when
    d >= 1 and 344 * 512 = 176128 when d = 0.

(b) Every g in G is g e_0 = e_0, g = h on X_1 n P, g = a + B on S. Here h is in GL_3, a is in GL(R)
    (and acts on S through A_u), and B maps S into X_1 n P. The conditions are aM = Ma,
    rho a = rho, and B M = X' a + h X'. So

        |G| = 2^(3d) * #{(h, a) : aM = Ma, rho a = rho, (X' a + h X') K = 0},

    where K spans ker M (dimension d). G acts on A = (K_A, L_A), the maps on X_1 n P and on S, by

        (K_A, L_A) -> (a K_A h^(-1),  a (L_A + K_A h^(-1) B) a^(-1)),

    and n -> n + u adds the identity to L_A.

(c) The orders, by hand, for the 51 classes (m58.py's names and A_u), with the lower bound
    ceil(|Adm| / (2 |G|)) on the number of classes of Adm:

*Proof.* (a) This is Proposition 30 (a): Proposition 29 (c) gives A_n x0 = 0 and Im A_n inside R.
A_n kills x0 and sigma(n), which are independent in X_1, so its rank on X_1 is at most 2. Corollary
60 gives A_n != 0 and A_(n + u) != 0 when d >= 1. In (B6) the image lies in R, so A is a singular
3 x 3 matrix K_A on X_1 n P (344 choices) together with any L_A on S (512).

(b) g fixes x0, keeps P, and keeps X_1 and R because it commutes with A_u. On X_1 it is
diag(1, h). On S it is a vector of S plus B s with B s in X_1 n P, since g S lies in P. A_u g = g A_u
on S says that the S-part of g is a, carried to S by A_u, and that g r_j = a r_j for each j.
Comparing parts gives aM = Ma on S, rho a = rho on e_0 (g fixes e_0 and B has no e_0-part), and
B M = X' a + h X' on X_1 n P. B M runs over the matrices whose rows lie in the row space of M,
that is, those killed by K. The solutions B form a coset of {B : BM = 0}, of dimension 3d. g is
invertible exactly when h and a are. The action is g A g^(-1) written in these blocks: with
g^(-1) = (h^(-1), a^(-1), h^(-1) B a^(-1)) it gives the formula. For d = 3 (M = 0, K = I) this is
Proposition 30 (b), and it gives 86016 and 12288 again in kinds P and graph.

(c) For each class, M is read from A_u. Its centraliser in GL_3 comes from its similarity type:
diag(1, 0, 0), E_12 (that is, J_2(0) + 0), J_3(0), J_2(0) + 1, the swap plus 0,
C(x^2 + x + 1) + 0 or + 1, diag(1, 1, 0), J_3(1), J_2(1) + 1, and the two cubics, with centralisers
of order 6, 8, 4, 2, 2, 3, 6, 4, 8 and 7. Then the conditions rho a = rho and h = (determined) on X'K are
imposed. Three examples:

- o004_c000 (A_u: e_4 -> e_4, e_5 -> e_2, e_6 -> e_1): M = E_11, so a = diag(1, a') with a' in
  GL_2 (6). rho = 0. On K = span(r_5, r_6), h must act on span(e_2, e_1) as a' does, and h e_3 has 4
  choices. |G| = 2^6 * 6 * 4 = 1536.
- o009_c004 (e_4 -> e_0 + e_1 + e_4 + e_5, e_5 -> e_4, e_6 -> e_0 + e_1): M = C(x^2 + x + 1) + 0, so
  a = a' + 1 with a' in F_4^*. rho = (1, 0, 1) forces a' = I. On K = span(r_6), h e_1 = e_1 (24).
  |G| = 2^3 * 24 = 192.
- o012_c001 (e_4 -> e_0 + e_4 + e_6, e_5 -> e_5, e_6 -> e_0 + e_4): d = 0, X' = 0, and M is
  1 + C(x^2 + x + 1). F_4^* acts freely on non-zero forms, so rho = (1, 0, 1) forces a = I. h is
  free and B = 0, so |G| = 168.

(d) For d = 0 and these pairs, X' = 0 and B = 0, so G = GL_3 x C, where C = {a : aM = Ma,
rho a = rho}. G acts by K_A -> a K_A h^(-1) and L_A -> a L_A a^(-1). The maps K_A with a given
image W (a subspace of R of dimension at most 2) form one orbit of the h's. A pair (K_A, L_A) is
then classified by the C-orbit of W and the orbit of L_A under Stab_C(W) and L -> L + I. No
element (c, flip) fixes any L, because the trace of L + I is the trace of L plus 1. So by
Burnside's lemma the L-count for a stabiliser S is (sum over c in S of |C_(M_3)(c)|) / (2 |S|).
The centraliser algebras have 512 elements (c = I), 32 (a transvection) or 8 (a regular
unipotent, an element of order 7, or one of order 3 with a fixed vector), which gives:

- o011_c003, o011_c004 (C = F_8^*, a Singer cycle, free on lines and on planes): 40 + 256 + 256 = 552.
- o011_c002 (C = <J_3(1)>, cyclic of order 4): stabiliser C for W = 0, ker N and ker N^2 (70 each,
  560 / 8), order 2 for two orbits of size 2 (136 each), trivial for two orbits of size 4 (256
  each): 70 + 2 * (70 + 136 + 256) = 994.
- o012_c001 (C = 1): 15 subspaces W, 256 each: 3840.
- o012_c004 (C = {I, I + N^2}, a transvection): W = 0 and 3 lines and 3 planes fixed (136 each),
  2 + 2 free orbits (256 each): 136 + 2 * (3 * 136 + 2 * 256) = 1976.
- o012_c009 (C of order 3, fixing one line and one plane): W = 0, that line, that plane (88 each,
  528 / 6), and 2 + 2 free orbits (256 each): 88 + 2 * (88 + 512) = 1288.
- o012_c011 (C the centraliser of a transvection, of order 8, all of it keeping rho): orbits of
  lines of sizes 1, 2, 4 with stabilisers of order 8, 4, 2 (43, 76, 136), the same for planes, and
  43 for W = 0: 43 + 2 * 255 = 553.

The sizes add up: in each case the classes partition the 344 * 512 maps, since every orbit of K_A
is counted once with all 512 L_A. QED

**What (d) shows.** The classes of Adm number about 7.4 times the lower bound for d = 0 (9755
against 1311): h acts only on K_A and the flip only on L_A, so the identity term of Burnside's
lemma is far from the whole sum. Nothing like that has been computed for d >= 1, where the B-part
of G also moves L_A by K_A h^(-1) B. A guess (low confidence): the 44 classes with d >= 1 have 2 to 8
times their bound of 7792, so the 51 classes have about 25,000 to 70,000 split instances in all.
