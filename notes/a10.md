# Lemma 33 without tightness (Lemma 62), and rank 3 at t = 6 and t = 8

[a9.md](a9.md). Numbering continues from a9.md (Lemma 62, Corollaries 38 to 40). It was researched
and written with AI agents working in MV2's name. **This is partial progress: it settles no new

## What changes

- **Lemma 62.** The counting of Lemma 33 ([tight-cases.md](tight-cases.md)) needs neither a tight
  dimension nor phi(V) = X. If u has rank rho, x0 = sigma(u) lies in phi(V), phi(V) has codimension
  c, and some v with phi(v) = x0 has A_v and A_(u + v) of rank at most rho, then
  **2 rho + 2c >= t + 1**. For c = 0 this is the step of Proposition 26(d), which there used the
  tight dimension only to bound the ranks.
- **Corollary 38.** For an element u of the largest rank rho in an anisotropic system: either x0 is
  not in phi(V), or dim V <= t - c0 + A(k - 1) with c0 = max(0, ceil((t + 1 - 2 rho) / 2)). This
  improves Lemma 30 by c0 in the branch where x0 lies in phi(V).
- **Corollary 39 (t = 6, dim V = 7, no element of rank 4).** Every element of rank 3 is in one of
  three configurations, (B5), (A4) and (B4) below; the fourth one that Lemma 30 allows, phi(V) = X,
  is ruled out. In (A4), Im A_u meets ker A_u. By Corollary 37, "no element of rank 4" holds if jobs
  m23 and m24 find all of their instances UNSAT.
- **Corollary 40 (t = 8, dim V = 11, no element of rank 4).** Every element of rank 3 has x0 outside
  phi(V), and U+ = ker phi has dimension 4 or 5. So A(8) <= 10, which would settle (11, 2), comes
  down to case (i) of Proposition 28 (rank 4 in shape (c)), A(6) = 7 (case (ii)), and these two
  configurations of rank 3.

## Setting

As in [a8.md](a8.md): X = F_2^t, sigma : V -> X quadratic with polar form beta, h -> A_h linear, and

    A_(h') sigma(h) = (I + A_h) beta(h, h')                                    (*)
    A_(h') beta(h_1, h_2) = A_(h_1) beta(h_2, h') + A_(h_2) beta(h_1, h').      (Q)

For u in V put x0 = sigma(u), phi = beta(u, .), P = phi(V), X_1 = ker A_u, R = Im A_u, rho = rank A_u,
k = t - rho, d = dim(X_1 n R) and U+ = {h : phi(h) in span(x0)}. The system is anisotropic and
u != 0, so x0 != 0. We use (*) with h -> u, (Q) with h' -> u, and Lemma 30(a):

    A_h x0 = (I + A_u) phi(h)                         for all h,                (1)
    A_u beta(h_1, h_2) = A_(h_1) phi(h_2) + A_(h_2) phi(h_1)   for all h_1, h_2,  (2)
    A_h x0 = phi(h) and A_u sigma(h) = 0              for h in U+.              (3)

## Lemma 62 (the counting of Lemma 33 with slack)

**Lemma 62.** Suppose x0 lies in P, let c = t - dim P, and let v satisfy phi(v) = x0. Put
w = u + v, K_v = ker A_v and K_w = ker A_w. Then:

(a) A_v x0 = x0, and I + A_v and I + A_w map P into R;

(b) K_v n P and K_w n P lie in R, and K_v n K_w is a subspace of X_1 that does not contain x0;

(c) s = sigma(v) = sigma(w) lies in X_1 n K_v n K_w and not in span(x0);

(d) if A_v and A_w have rank at most rho, then 2 rho + 2c >= t + 1.

*Proof.* (a) v is in U+, so A_v x0 = phi(v) = x0 by (3). By (2) with h_1 = v and (1),

    A_u beta(v, h) = A_v phi(h) + A_h x0 = A_v phi(h) + (I + A_u) phi(h),

so (I + A_v) phi(h) = A_u (beta(v, h) + phi(h)) lies in R for every h. Then
I + A_w = (I + A_v) + A_u also maps P into R.

(b) For y in K_v n P, y = (I + A_v) y, which lies in R by (a); the same for K_w. On K_v n K_w,
A_u = A_v + A_w vanishes, so K_v n K_w lies in X_1, and it does not contain x0 as A_v x0 = x0 != 0.

(c) beta(u, v) = x0, so sigma(w) = x0 + s + x0 = s. By (3), s lies in X_1. A_v s = A_v sigma(v) = 0 and
A_w s = A_w sigma(w) = 0 (Lemma 21(b)). v is not in span(u), because phi(v) = x0 != 0 = phi(u), so
by Lemma 30(b) s is not in span(x0).

(d) dim K_v >= t - rho = k and dim K_w >= k, so dim(K_v n P) >= k - c and dim(K_w n P) >= k - c. By
(b) both lie in R, and their intersection lies in K_v n K_w, a proper subspace of X_1 (it misses
x0), of dimension at most k - 1. So

    2(k - c) - (k - 1) <= dim((K_v n P) + (K_w n P)) <= dim R = t - k,

that is t >= 2k + 1 - 2c, or 2 rho + 2c >= t + 1. QED

For c = 0 this is Lemma 33 with the step (d) of Proposition 26 in front of it. Proposition 26 used
the tight dimension dim V = t + k - 1 only to know that no element has rank above rho (its part
(a)). Lemma 62 asks this only of the two elements v and u + v; every element of v + ker phi can play
the part of v. Part (c) shows that K_v n K_w is never 0, which Lemma 33 did not say.

## Corollary 38 (elements of the largest rank)

**Corollary 38.** Let u have the largest rank rho among the elements of an anisotropic system. If
x0 lies in P, then c >= c0 = max(0, ceil((t + 1 - 2 rho) / 2)), codim U+ = t - 1 - c, and

    dim V <= t - c0 + A(k - 1).

*Proof.* Lemma 62(d) applies to any v with phi(v) = x0 and gives c >= c0. As in the proof of
Lemma 30(b), codim U+ = dim P - 1 = t - 1 - c when x0 lies in P, and dim U+ <= 1 + A(k - 1). Add.
QED

So for an element of the largest rank with 2 rho <= t, the branch "x0 in phi(V)" of Lemma 30 loses
at least ceil((t + 1 - 2 rho) / 2) >= 1. For rank 3: c0 = 1 at t = 6 and t = 7, and c0 = 2 at t = 8.

## Corollary 39 (rank 3 at t = 6)

**Corollary 39.** Let an anisotropic system with t = 6 and dim V = 7 have no element of rank 4. Then
every non-zero element has rank at most 3, some element has rank 3, and every element u of rank 3 is
in one of the following configurations (k = 3, so X_1 has dimension 3):

(B5) x0 is not in P, P is a hyperplane, and U+ = ker phi has dimension 2;

(A4) x0 is in P, P has dimension 5, ker phi has dimension 2 and U+ has dimension 3;

(B4) x0 is not in P, P has dimension 4, and U+ = ker phi has dimension 3.

In (B5) and (B4), every n in ker phi has A_n x0 = 0, sigma(n) in X_1, and A_n maps the subspace
P + span(x0) (all of X in (B5), a hyperplane in (B4)) into R. In (A4), take v with phi(v) = x0: then
K_v n P and K_(u + v) n P are subspaces of R of dimension at least 2 that meet in a non-zero subspace
of X_1, so d >= 1, and s = sigma(v) = sigma(u + v) is a vector of X_1 outside span(x0) that A_v and
A_(u + v) both kill. In (A4) and (B4), U+ / span(u) carries an anisotropic system of dimension 2
with values in X_1 / span(x0), which has dimension 2.

*Proof.* Rank 5 would give dim V <= 6 + A(0) = 6 (Lemma 30), and rank 6 does not occur (every A_h is
singular). The last section of a8.md shows that not every element has rank <= 2. So the largest
rank is 3, and Lemma 62 applies to every element of rank 3 and every v. By Lemma 30, dim U+ <= 1 +
A(2) = 3 and dim V = codim U+ + dim U+ = 7.

If x0 is in P: Corollary 38 with t = 6, rho = 3 gives c >= 1, so dim P <= 5 and
codim U+ = dim P - 1 <= 4; then dim U+ >= 3, so dim U+ = 3 and dim P = 5. This is (A4), and
ker phi has dimension 7 - 5 = 2. If x0 is not in P: U+ is the preimage of P n span(x0) = 0, so
U+ = ker phi and codim U+ = dim P <= 5; with dim U+ <= 3, dim P is 5 or 4. These are (B5) and (B4).

For n in ker phi, (3) gives A_n x0 = 0 and A_u sigma(n) = 0, and (2) with h_1 = n gives
A_n phi(h) = A_u beta(n, h), which lies in R; so A_n maps P + span(x0) into R. In (B5),
P + span(x0) = X as x0 is not in the hyperplane P.

In (A4), dim K_v >= 3 and dim K_(u + v) >= 3, so their intersections with P (dimension 5) have
dimension at least 2. They lie in R by Lemma 62(b), and two subspaces of dimension at least 2 in
the 3-dimensional R meet in a non-zero subspace, which lies in K_v n K_(u + v), so in X_1 (Lemma
62(b)). The statement on s is Lemma 62(c). The last sentence is the quotient system in the proof of
Lemma 30(b), of dimension dim U+ - 1 = 2. QED

In (A4) the inequality of Lemma 62(d) reads 6 + 2 >= 7 and has slack 1, as Lemma 30 has. In (B5)
and (B4) the counting of Lemma 62 has no element v to work with, as in Case B (the last section of
tight-cases.md). So A(6) = 6 now needs: jobs m23 and m24 all UNSAT, and no element of rank 3 in
(B5), (A4) or (B4).

## Corollary 40 (rank 3 at t = 8)

**Corollary 40.** Let an anisotropic system with t = 8 and dim V = 11 have no element of rank 4.
Then some element has rank 3, every non-zero element has rank at most 3, and every element u of
rank 3 has x0 outside P and U+ = ker phi, with (dim P, dim U+) = (7, 4) or (6, 5). For n in ker phi,
A_n x0 = 0, sigma(n) lies in X_1 (dimension 5) and A_n maps P + span(x0) into R; when dim P = 7,
Im A_n lies in R.

*Proof.* The system is irreducible (the reducible bound is 10, Step 1 of the proof of Theorem 30).
By Lemma 30, rank 5 gives dim V <= 8 + A(2) = 10, rank 6 gives 8 + A(1) = 9, and rank 7 gives 8;
rank 8 does not occur. By Lemmas 28 and 29 not every element has rank <= 2. So the largest rank is
3, k = 5, and Corollary 38 gives c >= ceil((9 - 6) / 2) = 2 if x0 is in P. Then
codim U+ = 7 - c <= 5 and dim U+ >= 6, but Lemma 30 gives dim U+ <= 1 + A(4) = 5 (Theorem 26). So
x0 is not in P, U+ = ker phi and codim U+ = dim P <= 7; with dim U+ <= 5, dim P is 6 or 7. The rest
is the argument of Corollary 39. QED

With Proposition 28, an anisotropic system with t = 8 and dim V = 11 has (i) an element of rank 4 in
shape (c) with d >= 3 and n -> A_n one-to-one on U+, or (ii) A(6) = 7, or (iii) no element of rank
4, and then every element of rank 3 is in one of the two configurations of Corollary 40. Before
this note, case (iii) allowed four configurations for each element of rank 3.
