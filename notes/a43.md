## Proposition 31

Write Q = R n P (a plane, as x0 is in R and not in P), T = X_1 n P (dimension 3, containing Q),
choose t_3 in T outside Q and a complement S of T in P, so that X_1 = T + span(x0),
R = span(x0) + Q, X = X_1 + S, and A_u maps S onto R; write psi for A_u on S.

**Proposition 31.** Let u be in (B6) with d = 3 and x0 in R.

(a) An element g of G is given by a in GL(Q), q in Q and tau : S -> T, freely: g = a on Q,
    g x0 = x0, g t_3 = t_3 + q, and g = psi^(-1) g_R psi + tau on S, where g_R = 1 + a is g on
    R = span(x0) + Q. So |G| = 6 * 4 * 512 = 12288, and the pairs (a, q) form a group H of order
    24 (the affine group of the plane Q, isomorphic to S_4).

(b) A map A in Adm is a pair (alpha, betat): alpha = A on T, a map T -> R that is not one-to-one,
    and betat = A psi^(-1) in End(R). g in G sends it to

        (g_R alpha g_T^(-1),  g_R betat g_R^(-1) + alpha' c)       alpha' = g_R alpha g_T^(-1),

    with g_T = g on T and c running over all maps R -> T as tau varies. So the class of A is that
    of alpha under (a, q) : alpha -> g_R alpha g_T^(-1), together with betabar = pi betat in
    Hom(R, R / Im alpha) under betabar -> gbar_R betabar g_R^(-1) for (a, q) fixing alpha. The
    move n -> n + u adds pi to betabar. The pair (alpha, betat) = (0, 0) or (0, I) is A = 0 or A_u.

(c) Adm has 308 classes under G and n -> n + u: 51, 174 and 83 with rank 0, 1 and 2 on X_1.

*Proof.* (a) g keeps X_1 = ker A_u, R = Im A_u, P, so also T = X_1 n P and Q = R n P. T / Q has
dimension 1, so g t_3 is in t_3 + Q. On S, A_u g s = g A_u s fixes the S-part of g s as
psi^(-1) g_R psi s, and the T-part tau(s) is free (X = X_1 + S, T = X_1 n P, and g s must lie in
P). Conversely every (a, q, tau) gives an invertible map that fixes x0, keeps P and commutes with
A_u (on X_1 both sides are 0; on S, A_u g s = g_R A_u s = g A_u s).

(b) A kills x0, so A is determined by alpha and by A on S. On T, g A g^(-1) = g_R alpha g_T^(-1),
as g keeps T. On S, g^(-1) s = psi^(-1) g_R^(-1) psi s + (a vector of T), and A sends that vector
of T into Im alpha; after g_R the extra term is alpha' c for a map c : R -> T, and as tau runs over
all maps S -> T so does c. So betat is determined modulo Hom(R, Im alpha'), that is by betabar. The
move adds A_u, which is 0 on T and psi on S, so alpha is unchanged and betat gains I. The action
of G commutes with the move because g commutes with A_u.

(c) Burnside's lemma for H x Z_2 (order 48; the Z_2 is the move) on the pairs (alpha, betabar).
A fixed pair needs alpha fixed by h = (a, q), that is g_R alpha = alpha g_T, and then betabar in
W = Hom(R, R / Im alpha) with gbar_R betabar g_R^(-1) = betabar (without the move) or
= betabar + pi (with it). Fixed points are constant on the five conjugacy classes of H. In the
basis x0, r_1, r_2 of R and r_1, r_2, t_3 of T (Q = span(r_1, r_2)), write alpha as the row x
(x0-part on Q), the number xi (x0-part of alpha t_3), the 2 x 2 matrix M (Q-part on Q) and the
vector m (Q-part of alpha t_3). Then alpha is fixed by (a, q) exactly when x a = x, x q = 0,
a M = M a and (a + I) m = M q. |W| = 512, 64, 8 for rank 0, 1, 2.

    class of h in H (size)         alpha fixed, rank 0/1/2   pairs fixed   with the move
    identity (1)                       1 / 49 / 294              6000             0
    a = I, q != 0 (3)                  1 / 21 /  42              2192             0
    a of order 3 (8)                   1 /  1 /   3                18             0
    a = transvection, q in Im(a + I) (6)   1 /  9 /  14           184            72
    a = transvection, q not in Im(a + I) (6)  1 / 3 / 4            80            16

- Identity: every singular alpha (1 + 49 + 294 = 344), all of W; the move fixes nothing as pi != 0.
- a = I, q = r_1: alpha r_1 = 0 and the rest is free (64 maps: 1, 21, 42 by rank); g_R = I, so all
  of W is fixed and the move fixes nothing: 512 + 21 * 64 + 42 * 8 = 2192.
- a of order 3, q = 0: Q is irreducible for a, so x = 0, m = 0, M is in F_2[a] = {0, I, a, a^2}
  and xi is free; singular are (0, 0), (0, 1) and the three invertible M with xi = 0, of ranks 0, 1,
  2, 2, 2. Fixed betabar: 8 (the centraliser of 1 + a in End(R)), 4, and 2 each; with the move none,
  as pi is not orthogonal under the trace form to the fixed points of the dual action (for alpha = 0
  the centraliser contains the projection on x0, of trace 1; for Im alpha = span(x0) it contains a,
  of trace 1; for Im alpha = Q, betabar g_R^(-1) - betabar vanishes at x0 = g_R x0, while pi
  does not).
  8 + 4 + 3 * 2 = 18.
- a r_1 = r_1, a r_2 = r_1 + r_2, q = 0: x = (0, x_2), M = lambda I + mu E_12, m = (m_1, 0), xi
  free: 32 maps, with determinant lambda xi, so 24 singular: rank 0 once; rank 1 with image
  span(x0), span(r_1), span(x0 + r_1) three times each; rank 2 with image span(x0, r_1) six times,
  Q four times and span(r_1, x0 + r_2) four times. g_R is the transvection 1 + J_2 of R; the fixed
  betabar are Hom_g(R, R / Im alpha): 32 for alpha = 0; 8, 16, 8 for the three lines; 4 for each
  plane. The move has solutions (as many as the fixed points) exactly for the images span(x0),
  span(x0 + r_1) and span(x0, r_1), and not for 0, span(r_1), Q or span(r_1, x0 + r_2); for
  example, with Im alpha = span(x0, r_1), betabar = the form with betabar(r_1) = 1 gives
  betabar g_R^(-1) - betabar = pi. So 32 + (24 + 48 + 24) + 14 * 4 = 184 and (24 + 24) + 6 * 4 = 72.
- The same a with q = r_2: x = 0, lambda = 0, M = mu E_12, m = (m_1, mu), xi free: 8 maps, all
  singular: rank 0 once, rank 1 with images span(x0), span(r_1), span(x0 + r_1) once each, rank 2
  with image Q twice and span(r_1, x0 + r_2) twice. g_R is the same transvection, so the same fixed
  counts: 32 + 8 + 16 + 8 + 4 * 4 = 80 and 8 + 8 = 16.

The sum is 6000 + 3 * 2192 + 8 * 18 + 6 * (184 + 72) + 6 * (80 + 16) = 14832 = 48 * 309. The rank
of alpha is an invariant, and the same sum taken rank by rank gives 2496, 8352 and 3984, that is
52, 174 and 83 orbits (each a whole number, a check on the table). Removing the orbit {0, A_u}
leaves 51 + 174 + 83 = 308. QED

As a further check, the classes of alpha alone under H number (344 + 3 * 64 + 8 * 5 + 6 * 24 +
6 * 8) / 24 = 768 / 24 = 32.

**Why kind L has so many more classes.** In kind P the group acts on alpha by conjugation through
all of GL(R) (168 elements), and in kind graph through the 24 elements of GL(R) fixing a form. In
kind L the 24 elements of H act on R only through a in GL(Q) (6 elements); the 4 translations q
act only on T. For alpha = 0 that leaves End(R) under 6 conjugations and the move, 52 orbits, and
51 after {0, I} is removed, against 6 in kind P.
