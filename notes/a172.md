## 0. Summary

Program (a159-a171): for a map P of F_q^k let A_t(x) = P(x) + tx and

    Lambda(P) = sum_{t in F_q} H(X | A_t(X))      (bits, X uniform on F_q^k).

By Theorem 2 (README) the Kakeya growth constant of F_q is beta_q = q 2^(-lambda*/q), with
lambda* = sup_k max_P Lambda(P)/k. The conjecture C_q(k), Lambda <= k(q-1), would give the
exact constant beta_q = q 2^(-(q-1)/q). What matters for beta_q is a **fixed q and every k**.
Large q (a171) does not reach it.

A quadratic map P(x) = Q(x) + Lx + c is the same thing as a commutative (not necessarily
associative) algebra structure x o y = (Q(x+y) - Q(x) - Q(y))/2 on F_q^k, together with L and
c. Q is then the squaring map x -> x o x. This note uses that dictionary to get three results.
All of them hold for **every odd q and every k**, and none needs nondegeneracy.

1. **Unit reduction (Lemma 127).** If the algebra has a unit e, then
   A_t(x) = P(x + te/2) + const_t, so
   
       Lambda(P) = q H(X | P(X))    for every linear part L.
   
   The sum over the q directions collapses to the fibre entropy of the single map P. For unital
   maps, C_q(k) is therefore the statement H(X | P(X)) <= k(1 - 1/q), a "square-root entropy"
   bound (Section 5).
2. **Associative algebras (Theorem 53).** Let A be any commutative associative F_q-algebra of
   dimension k, unital or not, nondegenerate or not, and let l, c lie in A. Then
   P(x) = x^2 + l x + c satisfies
   
       Lambda(P) <= k(q - 1),
   
   with equality if and only if A is isomorphic to F_q^k, i.e. P is a frame product. The class
   contains every finite field F_(q^k), every truncated polynomial ring F_q[s]/(s^k), the dual
   numbers of a170 and every product of these. Many of these are **degenerate**: they have
   nonzero elements with x^2 = 0, which is the regime a171 could not touch.
3. **Unitization (Proposition 62).** For every commutative algebra A, with its unitization
   A^+ = F_q 1 + A and the extended map P^+,
   
       Lambda(P) <= Lambda(P^+) <= Lambda(P) + (q - 1),
   
   with Lambda(P^+) = Lambda(P) + (q - 1) exactly when L = 0. So the pure squaring map of any
   algebra, including a167's degenerate G_n, satisfies C_q(k) as soon as the square-root
   entropy bound holds for unital algebras of dimension k + 1 (Corollary 62.1).

Along the way we get exact Kakeya entropies of finite commutative rings. Squaring in
F_(q^k) has Lambda = q - q^(1-k) for **every** k (a168 Proposition 54 checked k = 2, 3).
F_q[s]/(s^2) has Lambda = q - 1 + log2 q. Proposition 63 gives a closed form for F_q[s]/(s^k).

**Limits.** Theorem 53 covers only associative algebras with L a multiplication operator. For
general L, and for non-associative algebras (Jordan algebras such as the spin factor behind
G_n, and generic algebras), C_q(k) remains open for k >= 4 at fixed q. **Nothing here proves
beta_q.** What it adds is the first class with all k at every fixed odd q that contains both
maps respecting no subspace (fields) and degenerate maps. It also reduces the unital case to
a single-map entropy question.

## 1. The dictionary

Fix q odd. For a quadratic map P(x) = Q(x) + Lx + c of F_q^k put
x o y = (Q(x+y) - Q(x) - Q(y))/2. This is bilinear and symmetric, and x o x = Q(x). Conversely
every commutative algebra gives back Q(x) = x o x. Conjugating P by E in GL_k(F_q) transports
the algebra structure along E, and Lambda is invariant (a171 Section 1). So Lambda depends only
on the isomorphism class of (A, L, c) up to this transport.

| map | algebra |
|---|---|
| frame product (a_i x_i^2 + l_i x_i + c_i), a_i != 0 | F_q^k (split etale), L = R_l diagonal |
| squaring in F_(q^k) | the field F_(q^k) |
| dual-number square (x_1^2, 2 x_1 x_2) of a170 | F_q[s]/(s^2) |
| G_n of a167 | (u, s) o (w, t) = (s w + t u, phi(u, w)), a degenerate Jordan-type algebra |

Two translations are useful.

* **Nondegenerate** (a170) means Q(z) != 0 for z != 0 over the algebraic closure: the
  algebra has no nonzero square-zero element after extending scalars.
* **Unital** means there is e with e o x = x for all x. Since DQ(y) = 2 R_y with
  R_y x = y o x, this says that **DQ equals 2I at some point**, i.e. the identity matrix is a
  Jacobian of the quadratic part. Frame products and fields are unital. Nilpotent algebras and
  G_n are not.

The pair count also has an algebra form. Since z o z - y o y = (z - y) o (z + y) in any
commutative algebra, P(z) = P(y) iff (z - y) o (z + y) + L(z - y) = 0. This is a167's
Proposition 52 written in algebra notation.

## 2. The unit reduction

> **Lemma 127.** Let P(x) = x o x + Lx + c, where the algebra has a unit e and L is any linear
> map. Then for every t,
>
>     A_t(x) = P(x + t e / 2) - Q(t e / 2) - (t/2) L e,
>
> so every A_t has the same multiset of fibre sizes as P, and Lambda(P) = q H(X | P(X)).

*Proof.* Q(x + s) = Q(x) + 2 x o s + Q(s), and for s = te/2 the middle term is t x o e = tx.
So Q(x) + tx = Q(x + te/2) - Q(te/2). Also Lx = L(x + te/2) - (t/2)Le. Adding gives the
identity. Translation by te/2 is a bijection of F_q^k that preserves the uniform measure, so
H(X | A_t X) = H(X | P X) for every t. []

**Corollary 127.1.** For unital P, C_q(k) is equivalent to H(X | P(X)) <= k(1 - 1/q), and
also to H(P(X)) >= k(log2 q - 1 + 1/q). For a frame product, H(X | P(X)) = k(1 - 1/q):
each coordinate has fibres {x, -x - l/a} of size 2, except for one point.

## 3. Associative algebras

> **Lemma 128 (nil part).** Let N be a commutative associative algebra in which every element
> is nilpotent, and let l be in N. For P(x) = x^2 + l x + c on N, A_t is injective for every
> t != 0, and Lambda(P) = H(Y | Y^2 + l Y) <= (dim N) log2 q < (dim N)(q - 1).

*Proof.* Work in the unitization N^+. A_t(x) - A_t(x') = (x - x')(x + x' + l + t 1). For
t != 0, the element t1 + n with n = x + x' + l nilpotent is a unit, with inverse
t^(-1) sum_i (-n/t)^i. So A_t(x) = A_t(x') forces x = x'. The t = 0 term is H(Y | P(Y)) with Y
uniform on N, which is at most log2 |N|. Finally log2 q < q - 1 for q >= 3. []

> **Lemma 129 (local algebras).** Let (B, m) be a commutative associative local F_q-algebra
> with unit, of dimension k and residue field F_(q^f), q odd. Then
>
>     H(Y | Y^2) = (1 - q^(-f)) + q^(-f) H_m,    H_m = H(Y | Y^2 ; Y uniform on m) <= (k - f) log2 q.

*Proof.* Let y be a unit. If z^2 = y^2, then z is a unit and u = z/y has u^2 = 1, i.e.
(u - 1)(u + 1) = 0. The difference of u + 1 and u - 1 is 2, a unit, so u - 1 and u + 1 are not
both in m. One of them is a unit, so the other is 0, and u = +-1. Since q is odd, y != -y, so
the fibre of y is {y, -y}: exactly 1 bit. If y is in m, then z^2 = y^2 is in m, and z is in m
because m is prime. So fibres of points of m stay in m. The units have proportion
1 - |m|/|B| = 1 - q^(-f), and |m| = q^(k-f). []

> **Theorem 53.** Let A be a commutative associative F_q-algebra of dimension k (q odd), with
> or without unit, and let l, c be in A. Then P(x) = x^2 + l x + c satisfies
> Lambda(P) <= k(q - 1), with equality if and only if A is isomorphic to F_q^k.

*Proof.* *Decomposition.* A is finite, so for every a in A some power e = a^N is idempotent.
If a is not nilpotent, then e != 0. Choose an idempotent e with |eA| maximal (e = 0 allowed),
and put N = {x - ex}. Then A = eA + N (x = ex + (x - ex)), the sum is direct (x in eA gives
ex = x, x in N gives ex = e(y - ey) = 0, so x = 0), and eA . N = 0 because
(ea)(y - ey) = e a y - e^2 a y = 0. Both summands are ideals, eA is unital with unit
e, and the multiplication is componentwise. If some b in N were not nilpotent, a power f of b
would be a nonzero idempotent in N. Then ef = 0, e + f would be idempotent, and
(e + f)A would contain eA and f, which is not in eA (f = ef would give f = 0). That
contradicts maximality. So every element of N is nilpotent. Moreover eA, being a finite
commutative ring with unit, is a product of local rings B_1 x ... x B_r (Artinian structure
theorem).

*Additivity.* Write l and c in components. Then P is the product of the maps
x_i -> x_i^2 + l_i x_i + c_i on the factors, and Lambda of a product map is the sum of the
Lambdas, because fibres of a product map are products of fibres and X has independent uniform
components.

*Unital factors.* On B_i, Lemma 127 (with L = R_l) and x^2 + l x = (x + l/2)^2 - l^2/4 give
Lambda = q H(Y | Y^2). By Lemma 129, with k_i = dim B_i and f_i its residue degree,

    Lambda(B_i) <= q (1 - q^(-f_i)) + q^(1 - f_i) (k_i - f_i) log2 q.

Now q(1 - q^(-f)) <= f(q - 1), with equality iff f = 1 (for f >= 2 the left side is < q and
the right side is >= 2(q - 1) >= q). Also q^(1-f) log2 q <= log2 q < q - 1. So
Lambda(B_i) <= k_i (q - 1), with equality iff f_i = k_i = 1, i.e. B_i = F_q.

*Nil factor.* Lemma 128 gives Lambda < (dim N)(q - 1) unless N = 0.

Summing, Lambda(P) <= k(q - 1), with equality iff N = 0 and every B_i = F_q, i.e. A = F_q^k.
Conversely, F_q^k with any l, c is a frame product, so Lambda = k(q - 1). []

**Corollary 53.1 (exact values).**
* Fields: squaring in F_(q^k) (any l) has Lambda = q(1 - q^(-k)) = q - q^(1-k), for every k.
  Units have fibres {+-y}, and 0 is alone.
* Square-zero local rings F_q[s_1, ..., s_m]/(s_i s_j): Lambda = q - 1 + m log2 q. Here
  every y in m has y^2 = 0, so its fibre is m. The dual numbers are m = 1.

> **Proposition 63 (truncated polynomial rings).** For A = F_q[s]/(s^k), any l and c, and
> m = ceil(k/2),
>
>     Lambda = q [ sum_{j=0}^{m-1} (1 - 1/q) q^(-j) (1 + j log2 q) + q^(-m) (k - m) log2 q ].

*Proof.* By Lemma 127, Lambda = q H(Y | Y^2). Write y = s^j u with u a unit. This happens with
probability (1 - 1/q) q^(-j). If 2j < k, then z^2 = y^2 forces z = s^j w with w a unit and
w^2 = u^2 mod s^(k-2j). The local-ring argument of Lemma 129 gives w = +-u mod s^(k-2j). Here
w is determined mod s^(k-j), so the fibre has 2 q^j points. If 2j >= k, then y^2 = 0, and the
fibre is {z : z^2 = 0} = s^m A, of size q^(k-m). []

## 4. Unitization

For a commutative algebra A of dimension k with linear map L, let A^+ = F_q 1 + A (product
(a 1 + x)(b 1 + y) = ab 1 + (a y + b x + x o y)) and P^+(y) = y^2 + L'y, where
L'(tau 1 + x) = L x.

> **Proposition 62.** For every commutative algebra A (any q odd, any L),
>
>     Lambda(P) <= Lambda(P^+) <= Lambda(P) + (q - 1),
>
> and Lambda(P^+) = Lambda(P) + (q - 1) when L = 0.

*Proof.* Let Y be uniform on A^+ and tau its 1-coefficient. For Y = (t/2) 1 + X with X in A,

    P^+(Y) = (t^2/4) 1 + (X o X + t X + L X) = (t^2/4) 1 + A_t(X).

So on the slice tau = t/2, P^+(Y) and A_t(X) determine each other. Since t/2 runs over F_q as t
does, Lambda(P) = q H(Y | P^+(Y), tau). By Lemma 127 (A^+ has unit 1),
Lambda(P^+) = q H(Y | P^+(Y)). Since tau is a function of Y,

    H(Y | P^+ Y) = H(Y | P^+ Y, tau) + H(tau | P^+ Y).

The 1-coefficient of P^+(Y) is tau^2, so H(tau | P^+ Y) <= H(tau | tau^2) = (q - 1)/q. This
gives both inequalities. If L = 0, then P^+(-Y) = P^+(Y) and negation maps the slice tau to
-tau. So given P^+(Y), tau is +-tau_0 with equal probability: 1 bit when tau_0 != 0. Hence
H(tau | P^+ Y) = P(tau != 0) = (q - 1)/q exactly. []

**Corollary 62.1.** Suppose every unital commutative algebra B of dimension k + 1 satisfies
H(Y | Y^2) <= (k + 1)(1 - 1/q). Then the squaring map of every commutative algebra of dimension
k satisfies C_q(k). This covers the degenerate G_n of a167 (with L = 0) and all nilpotent
algebras. (Proof: Lambda(sq_A) = Lambda(sq_{A^+}) - (q - 1) = q H(Y | Y^2)_{A^+} - (q - 1)
<= (k + 1)(q - 1) - (q - 1).)

## 5. What this says about the program

* **A cleaner conjecture for the unital class.** For unital quadratic maps, C_q(k) is the
  *square-root entropy conjecture* SR_q(k): for every unital commutative F_q-algebra B of
  dimension k and every linear L,

      E_Y log2 #{z : z^2 + L z = Y^2 + L Y} <= k (1 - 1/q),

  with equality only for F_q^k. Theorem 53 proves SR_q(k) for associative B with L = R_l.
  Corollary 62.1 shows that SR_q(k + 1) with L = 0 implies C_q(k) for every pure squaring map,
  unital or not. The t-direction of the Kakeya problem has disappeared from the statement.
* **Why associativity helps.** In an associative algebra, z^2 = y^2 factors as
  (z - y)(z + y) = 0, and units have only the square roots +-1. In a non-associative algebra
  that factorization still holds, but (z - y) o (z + y) = 0 no longer forces z = +-y for
  invertible-looking y. In the spin factor, a typical y^2 has 4 square roots (y has two
  "eigenvalues", and each can change sign), which is how G_n gets its large fibres.
* **Next steps.** (1) SR_q(k) for unital **Jordan** algebras, using power-associativity
  (F[y] is associative) and the classification of simple Jordan algebras over finite fields
  (fields, spin factors, Hermitian matrices). The spin factor and G_n live here. (2) Theorem 53
  with general L (not a multiplication operator) for A = F_q^k: the frames with an arbitrary
  linear part. (3) A pre-registered search for counterexamples to SR_3(4) among random unital
  algebras with random L. By Lemma 127 it needs only one fibre count per map instead of q.

## 6. Tests (`test_algebras.py`)

* Lemma 127: random unital commutative algebras (non-associative in general) with random L and
  c for (q, k) in {(3,2), (3,3), (3,4), (5,2), (5,3), (7,2)}, frame algebras with a general L,
  and fields. For every t, the sorted fibre sizes of A_t equal those of P, and
  Lambda = q H(X | P X).
* Theorem 53: F_q[s]/(f) for **every** monic f of degree k, for (q, k <= 4) = 3,
  (q, k <= 3) = 5 and (q, k <= 2) = 7, with random l and c. Lambda <= k(q-1), with equality
  exactly when f has k distinct roots in F_q, and a gap > 10^(-3) otherwise. Also square-zero
  local rings, nilpotent algebras (A_t injective for t != 0; Lambda <= (dim N) log2 q), products
  of a monogenic algebra with a nilpotent one (non-unital), and split algebras (equality).
* Corollary 53.1 and Proposition 63: fields F_9, F_27, F_81, F_25, F_125, F_49; F_q[s]/(s^k)
  for (3, k <= 5), (5, k <= 3), (7, 2), (7, 3); dual numbers.
* Proposition 62: random commutative algebras for (q, k) in {(3,1), (3,2), (3,3), (5,1),
  (5,2)}: equality for L = 0 and both inequalities for random L. G_n of a167 for n = 2, 3
  (q = 3) and n = 2 (q = 5).
