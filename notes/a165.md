## 0. Where this sits

Program: the exact Kakeya constant of F_q (see a159-a164). For a map P of F_q^k let
Lambda(P) = sum_{t in F_q} H(X | P(X) + tX) (bits, X uniform). Conjecture C_q(k):
Lambda(P) <= k(q-1). By Theorem 2, C_q(k) for all k is equivalent to q 2^(-(q-1)/q) being
the exact Kakeya growth constant of F_q. A counterexample would give a new record upper
bound for Kakeya sets over F_q.

a164 (Theorem 40) proved C_q(3) for degree-2 maps (q odd) unless the map respects no
subspace and the set D of *cylinder directions* is large: |D| > 2q+1+|Z0|/(q-1), and
(q-1)|D \ U| > |Z0 \ U| for every plane U. Proposition 48 then says that the cylinder locus
Z contains two rational lines, or a rational line and a conic, or all of P^2 (q >= 5).
That leftover is the *residual case*. Until now no residual map was known, so it was
unclear whether the residual case is empty or where a counterexample would live.

This note does three things:
1. It classifies degree-2 maps with **two type-(b) structures** (the algebraic source of
   a line of cylinder directions, a164 Section 4) on different lines. There is a
   two-parameter family F_{rho,delta}. All members but one satisfy Theorem 40(c).
2. The one exception E is **the first explicit residual map**. It has 3q cylinder
   directions on three lines, Z0 is empty, and the pair-count bound exceeds 3(q-1).
3. Its Lambda is nonetheless computed **exactly** (Proposition 49), and it is far below
   the bound: Lambda(E) = q - 1 + O(log q), against 3(q-1).

So the two-pencil part of the residual case holds C_q(3). Maps with many cylinder
directions have huge fibres and lose *little* information: here the pair count overstates
Lambda by a factor of about 3.

## 1. Moves and structures

The following moves preserve Lambda, the counts |D| and |Z0|, and whether P respects a
subspace: conjugation P -> A P A^-1 (A in GL_3); input and output translations; adding sI
(this shifts t); and multiplying P by a nonzero scalar.

**Definition.** A *type-(b) structure* (m, c, a, v, s) of a degree-2 map P of F_q^3
consists of a nonzero linear form m, a vector c with m(c) != 0, a in ker m, a vector v and
a scalar s, such that for every x

    P(x) - P(0) - [ m(x) x + m(x)^2 a + m(x) v + s x ]  is in  F_q c.

This is the normal form of a164 Section 4 / the residual notes: Q is congruent to
m(x)(x + m(x)a) mod c, and L is congruent to sI + v (x) m mod c. The moves above carry
structures to structures. In particular, a translation x -> x+u changes only v, s and the
constants, and adds m(u) to s.

**Lemma 116.** If P has a type-(b) structure, every direction w in ker m has a nonzero
functional phi with phi(w) = 0 and phi∘P constant along lines in direction w. So
rank[M_w | w | Lw] <= 2. If moreover r_w != 0 (r_w = rank of x -> B(x,w) mod w), then w
is a cylinder direction (r_w = 1, active).

*Proof.* Take phi != 0 in c^perp ∩ w^perp. Then phi∘P(x) = const + m(x)phi(x) +
m(x)^2 phi(a) + m(x)phi(v) + s phi(x). Both m and phi are constant along w. The rank
statement follows because phi kills w, the image of M_w and Lw. If r_w = 1 then
rank[M_w | w] = 2, so Lw lies in that span (active). ∎

## 2. Theorem 41 (classification of two pencils)

**Theorem 41.** Let q be odd and P a degree-2 map of F_q^3 with two type-(b) structures
S_i = (m_i, c_i, a_i, v_i, s_i), where ker m1 != ker m2. Then, up to the moves of
Section 1, P = F_{rho,delta} for some rho, delta in F_q, where

    F_{rho,delta}(x) = ( (2x1+x2)x3 - rho(x1+x2)^2 - 2x1^2 - 3x1x2 - x2^2 - delta(x1+x2),
                         x1(x1+x2),
                         x1 x3 ).

Further:
(i) F_{rho,delta} has the structures (x1, e1, e2, 0, 0) and
    (-(x1+x2), (1,0,1), (-1,1,rho), (delta,0,0), 0);
(ii) F_{rho,delta} respects no nonzero proper subspace;
(iii) D = {w1 = 0} ∪ {w1 + w2 = 0} (2q+1 directions) unless (rho, delta) = (-1/2, 0). For
    E := F_{-1/2,0}, D = {w1 = 0} ∪ {w1+w2 = 0} ∪ {w1 + w2 = 2w3} (3q directions; the
    three lines form a triangle) and Z0 is empty.
Consequently every F_{rho,delta} other than E satisfies Theorem 40(c) of a164, so
Lambda <= 3(q-1). E satisfies neither (b) nor (c): it is residual.

*Proof.* **Normal form of S1.** Put c1 = e1 with m1(c1) = 1, x1 := m1, and choose e2, e3
spanning ker m1. Subtract s1·I. The quadratic part is Q = x1 x + x1^2 a1 + q1(x) e1.

**The quadratic identity.** From both structures, x1 x + x1^2 a1 + q1 e1 =
m2 x + m2^2 a2 + q2 c2. Let n = x1 - m2 (nonzero, since ker m1 != ker m2). Then
n(x) x = m2^2 a2 - x1^2 a1 + q2 c2 - q1 e1. Apply any psi != 0 with psi(e1) = psi(c2) = 0:

    n(x) psi(x) = psi(a2) m2(x)^2 - psi(a1) x1^2.

If m2 = mu x1 (mu != 1), the right side is a multiple of x1^2, so psi ∝ x1. That
contradicts psi(e1) = 0. So x1 and m2 are independent, psi = p x1 + r m2 lies in their
span, and comparing coefficients of (x1 - m2)(p x1 + r m2) = p x1^2 + (r-p) x1 m2 - r m2^2
gives r = p and psi(a1) = psi(a2) = -p. So psi ∝ x1 + m2 is unique. Hence c2 is not
proportional to e1 (otherwise psi would range over a plane), and psi(a1) = psi(a2) != 0.
In particular a1 != 0.

**Coordinates.** Take e2 := a1 (in ker x1), and e3 in ker x1 ∩ ker m2 (adjust e3 by a
multiple of e2). Write psi = p(x1 + m2). Then psi(e1) = 0 gives m2(e1) = -1, and
psi(a1) = -p with a1 = e2 gives m2(e2) = -1. With m2(e3) = 0 this makes m2 = -(x1 + x2),
and psi ∝ x2. Then psi(a2) = -p forces (a2)_1 = -1, and a2 in ker m2 gives
a2 = (-1, 1, rho). psi(c2) = 0 and
m2(c2) != 0 give c2 = (1, 0, g) up to scale. Write s := x1 + x2. Component by component:
component 2 is (2x1+x2)x2 = s^2 - x1^2, an identity; component 3 gives
g q2 = (2x1+x2)x3 - rho s^2, so g != 0; component 1 gives q1 = q2 - s^2 - (2x1+x2)x1.
Rescaling x3 (conjugation by diag(1,1,1/g)) makes g = 1 (rho changes to rho/g). So

    Q = ((2x1+x2)x3 - rho s^2 - 2x1^2 - 3x1x2 - x2^2,  x1^2 + x1x2,  x1x3).

**Linear part.** With s1 = 0, S1 gives L x = (l(x), v12 x1, v13 x1). S2 says that
L - s2 I - v2 (x) m2 has image in F_q c2. Testing against e2^* and e1^* - e3^* (which kill
c2) gives v12 = -s2, v22 = s2 and l(x) = v13 x1 + s2(x1 - x3) - d(x1 + x2) with d free. The
input translation x -> x + (0, s2, -v13) removes the linear terms of components 2 and 3.
It keeps both structures, with s1 = 0 unchanged since m1(u) = 0. Applying the same
computation to the translated map now gives v12 = v13 = 0, so s2 = 0 and
L x = (-delta(x1+x2), 0, 0). This is F_{rho,delta}.

**(i)** Direct substitution. For S2 the remainder is ((2x1+x2)x3 - rho s^2)(1,0,1).

**(ii)** If n∘P depended only on n·x, its quadratic part would be kappa (n·x)^2. The
x3^2 coefficient gives kappa n3^2 = 0, and the x2x3 coefficient gives n1 = 2 kappa n2 n3.
Either kappa = 0, so n1 = 0 and then n2(x1^2+x1x2) + n3 x1x3 = 0, forcing n = 0. Or
n3 = 0, so n1 = 0 and n2(x1^2 + x1x2) = kappa n2^2 x2^2, forcing n = 0. For an invariant
line <w>, B(x,w) must lie in <w> for all x. If w1 != 0, components 2 and 3 of B(x,w),
namely (2w1+w2)x1 + w1x2 and w3x1 + w1x3, are independent forms, which is impossible.
If w1 = 0, the first component must vanish identically. Its x3 coefficient is w2 and its
x1 coefficient is then 2w3, so w = 0. The same computation shows that r_w = 0 never
occurs.

**(iii)** By Lemma 116 and (ii), every w in ker m1 or ker m2 is in D. Let w1 != 0 and
S := w1 + w2 != 0. Rows 2 and 3 of the 3x5 matrix [M_w | w | Lw] are
(w1+S, w1, 0, w2, 0) and (w3, 0, w1, w3, 0), of rank 2. So w is in Z iff row 1,
(2w3-(2rho+3)S-w1, w3-(2rho+2)S-w1, w1+S, w1, -delta S), is a combination
alpha·row2 + beta·row3. The last column forces delta = 0. The x2 and x3 columns fix
alpha and beta. The x1 column then reduces to S(2w3 - (2rho+2)S) = 0, so
w3 = (rho+1)S. The w column then reduces to (2rho+1) S w1 = 0, so rho = -1/2. For E
the extra directions are exactly the line w1 + w2 = 2w3 minus its two points on the
other lines (q-1 points), so |D| = 3q. Since L = 0, every direction is active, so Z0 is
empty. The counts: (q-1)|D| = 3q(q-1) > (2q+1)(q-1) fails (c), and D lies in no line of
P^2, so (b) fails. ∎

## 3. Proposition 49 (the residual map E, exactly)

E(x) = ( (2x1+x2)x3 - (3x1+x2)(x1+x2)/2,  x1(x1+x2),  x1x3 ).

**Proposition 49.** For every odd q and every t in F_q, the fibres of E + tI are:
(q-1)^3/2 fibres of size 2, 3(q-1) fibres of size q-1, and one fibre of size 3q-2. Hence

    Lambda(E) = [ (q-1)^3 + (3q-2) log2(3q-2) + 3(q-1)^2 log2(q-1) ] / q^2  <  3(q-1).

(q = 3: 4.406 vs 6; q = 5: 8.324 vs 12; q = 7: 11.753 vs 18; q = 11: 17.770 vs 30.)

*Proof.* Use coordinates a = x1, b = x1 + x2, c = x3, and write the output in the same
coordinates. The output of Y_t is equivalent to the triple
alpha = ab + t(b - a), beta = (a+t)c, gamma = (a+b)c - b^2/2 + tb. Put s = a + t.
If s != 0 then b = A/s + t with A := alpha - t^2 = s(b-t), and c = beta/s. Substituting,

    gamma = beta + t^2/2 + A(beta - A/2)/s^2 = beta + t^2/2 + (b-t)(c-(b-t)/2).

So, for s != 0, the output determines s up to the equation s^2 = A(beta - A/2)/(gamma -
beta - t^2/2). There are four cases.
- **Generic** (s != 0, b != t, c != (b-t)/2; (q-1)^3 points): s' = ±s, giving fibres of
  size 2. The points with s = 0 have A = 0 and so cannot join.
- **b = t, c != 0** ((q-1)^2 points): every s' != 0 with b' = t, c' = beta/s' fits;
  these are fibres of size q-1.
- **c = (b-t)/2, b != t** ((q-1)^2 points): every s' != 0 fits; fibres of size q-1.
- **s = 0** (q^2 points). Output (t^2, 0, t^2/2 + u(c - u/2)) with u = b - t. If
  u(c - u/2) != 0, the fibre is the q-1 solutions of u(c-u/2) = const (fibres of size
  q-1). The 2q-1 points with u(c - u/2) = 0 share their output with the q-1 points
  (s != 0, b = t, c = 0). Together they form one fibre of 3q-2 points.
The counts add up to q^3. The bound: for q = 3, 5 compare the numbers above. For q >= 7,
use (q-1)^3/q^2 <= q-1 and the inequality 3 log2 q + 3 log2(3q)/q <= 2(q-1). ∎

**What E says.** E carries the most cylinder structure seen so far: three type-(b) lines
and no inactive direction. That is exactly where the a164 pair count (log2 n <= n - 1 per
fibre) is weakest. Here sum_w Pi_w / q^3 = (q-1)(4q^2-2q+1)/q^2 > 3(q-1). Yet
Lambda(E) ~ q + 3 log2 q, because cylinder directions merge into fibres of size q-1 and
3q-2, where log2 n is far below n - 1. This is evidence that **the residual case is a
weakness of the pair count, not a source of counterexamples**.

## 4. Status of C_q(3) for degree-2 maps (q odd)

Proved: (a) invariant subspace, (b), (c) (a164); two type-(b) structures on different
lines (Theorem 41 + Prop 49, this note). Open residual shapes:
- a rational line l in Z that is not a type-(b) line. Plan (not yet a claim): along l,
  the 3x5 pencil [M_w | w | Lw] has rank 2. Kronecker's theorem sorts it by the degree
  eta of its left kernel phi_w (Lemma 115's functional).
  - eta = 0: phi is constant, so P respects the plane of l.
  - eta = 1: phi_w moves on a line of functionals. This is expected to be type (b) or
    an invariant line, via pencils of singular conics; it still has to be written out.
  - eta = 2: phi_w traces a conic. Then the right kernel is three constant vectors.
    Equivalently, B(y, .)|W and L|W all lie in span(id_W, T) for a single map
    T: W -> F_q^3, where W is the plane of l. This shape is not yet classified.
- a rational line plus a conic (Veronese-type), and Z = P^2;
- q = 3 (Prop 48 needs q >= 5), and even q.
Next: a fibre-size bound that uses log2 n instead of n - 1 on cylinder directions
(Proposition 49 shows it is needed), aiming at a uniform proof of the residual case.
