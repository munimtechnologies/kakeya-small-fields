## 0. Summary

Program (a159-a170): for a map P of F_q^k let A_t(x) = P(x) + tx and

    Lambda(P) = sum_{t in F_q} H(X | A_t(X))      (bits, X uniform on F_q^k).

By Theorem 2 (README) the Kakeya growth constant of F_q is beta_q = q 2^(-lambda*/q), with
lambda* = sup_k max_P Lambda(P)/k. The conjecture C_q(k), Lambda <= k(q-1), would give
lambda* = q - 1, the value of the frame products (a_1 x_1^2 + l_1 x_1, ..., a_k x_k^2 + l_k x_k),
and so the exact constant beta_q = q 2^(-(q-1)/q). For quadratic maps C_q(k) was known only for
k <= 3 (Theorems 38, 43). For k >= 4 it was open, and a167 showed that the sufficient condition
Q_4 fails.

This note proves C_q(k) in **every dimension k** for nondegenerate quadratic maps once q is
large, and it shows that frame products are the only maps that attain it. *Nondegenerate*
means that the top-degree forms have no common zero in P^(k-1) over the algebraic closure, as
in a170. This holds for a generic quadratic map.

> **Corollary 52.1.** For every k >= 1 there is q0(k) such that for every odd prime power
> q >= q0(k) and every nondegenerate quadratic map P of F_q^k,
>
>     Lambda(P) <= k(q-1),
>
> with equality if and only if P is F_q-affinely conjugate to a frame product. If P is not, then
> Lambda(P) <= q log2(2^k - 1 + O_k(q^(-1/2))), a gap of about q/(2^k ln 2) bits below k(q-1).

The proof splits on c(P), the number of absolutely irreducible components defined over F_q of
the *partner variety* {(x, y, t) : y != x, A_t(y) = A_t(x)}. Generically c(P) is small, and
nondegeneracy gives c(P) <= 2^k - 1.

* **c(P) <= 2^k - 2 (Theorem 51).** Jensen's inequality reduces Lambda to a point count, and
  Lang-Weil gives Lambda(P) <= q log2(1 + c(P) + O_k(q^(-1/2))). This is below k(q-1) for large q.
* **c(P) = 2^k - 1 (Theorem 52).** Here every partner is F_q-rational. Then (i) partners are
  integral over F_q[x, t], hence polynomial, and by degree affine-linear in (x, t). (ii) They
  form a group whose linear parts lie in O(Q) = {M : Q(Mx) = Q(x)}. (iii) For nondegenerate Q,
  O(Q) consists of commuting involutions (Lemma 126). A group of order 2^k forces a frame
  product (Proposition 60).

The new tools are an algebraic group, the **affine partner group** G(P), and Lemma 126. They
need no information theory at all. Proposition 60 is exact for every odd q, not only large q,
and the tests check it by brute force at q = 3 for every nondegenerate quadratic top part of
F_3^2, as well as at q = 5, 7 and on F_3^3.

**Limits.** (a) Degenerate maps are not covered. These include a167's G_n and the dual-number
examples, the "degeneracy at infinity" mechanism of a170 Section 3. (b) q0(k) grows like
2^(4.3k), so for a fixed q only finitely many k are covered. The exact constant beta_q needs
every k at a fixed q, so this note does not prove it, even for quadratic maps. (c) The explicit
q0 values in Remark 51.1 use the constants of Cafure-Matera as quoted; the existence of q0(k)
needs only Lang-Weil.

## 1. Setup

Fix an odd prime power q, write F for the algebraic closure of F_q, and let P be quadratic:

    P(x) = Q(x) + Lx + c,   Q = (Q_1, ..., Q_k) quadratic forms,   B(x, y) = (Q(x+y) - Q(x) - Q(y))/2,

so that Q(x) = B(x, x) and DP(x) = 2B(x, .) + L. P is nondegenerate when Q(z) != 0 for all
z in F^k, z != 0. Conjugation x -> E^(-1) P(Ex) (E in GL_k(F_q)) and adding constants preserve
Lambda, because A_t becomes E^(-1) A_t(E .).

**Partner identity.** For y = Mx + tw + v (M a k x k matrix, w, v vectors), comparing the
coefficients of A_t(y) - A_t(x) as a polynomial in (x, t) shows that A_t(y) = A_t(x)
identically if and only if

    (t^2)  Q(w) + w = 0                    (t)  2B(w, v) + Lw + v = 0
    (tx)   (I + 2B(w, .)) M = I             (x)  2B(Mx, v) + LMx = Lx
    (xx)   Q(Mx) = Q(x) for all x           (1)  Q(v) + Lv = 0.                            (1.1)

Such a triple (M, w, v) with entries in F_q is an **affine partner map**. G(P) is the set of
them, including the identity (I, 0, 0). The difference A_t(y) - A_t(x) has degree <= 2 in
each variable, so (1.1) holds as a polynomial identity exactly when it holds at every point of
F_q^(k+1). The tests use this to compute G(P) by brute force.

**Frame products.** For P(x) = (a_i x_i^2 + l_i x_i + c_i)_i with every a_i != 0, and every
subset S of {1..k}, the map y_S with (y_S)_i = -x_i - (l_i + t)/a_i for i in S and
(y_S)_i = x_i otherwise is an affine partner map. So |G(P)| = 2^k. Each coordinate has
fibres {x, -x - (l+t)/a} plus one fixed point, so Lambda = k(q-1) and

    sum_t N_t = q (2q - 1)^k,   where N_t = #{(x, y) : A_t(x) = A_t(y)}.                    (1.2)

## 2. The orthogonal group of a nondegenerate quadratic map

> **Lemma 126.** Let Q be nondegenerate and q odd. Every k x k matrix M over F with
> Q(Mx) = Q(x) for all x satisfies M^2 = I. Hence O(Q) = {M : Q o M = Q} is an elementary
> abelian 2-group, simultaneously diagonalizable, of order at most 2^k.

*Proof.* M is invertible: Mz = 0 gives Q(z) = Q(Mz) = 0, so z = 0. Let Mz = mu z with z != 0.
Then Q(z) = Q(Mz) = mu^2 Q(z) and Q(z) != 0, so mu = +-1. Suppose M had a Jordan block of size
>= 2 for mu: Mz = mu z and Mw = mu w + z with z != 0. Then M^n w = mu^n w + n mu^(n-1) z and

    Q(w) = Q(M^n w) = Q(w) + 2n mu B(w, z) + n^2 Q(z)        (n = 1, 2).

Subtracting twice the n = 1 equation from the n = 2 equation gives 2 Q(z) = 0, which is
impossible since q is odd. So M is diagonalizable with eigenvalues +-1, i.e. M^2 = I. A group in
which every element is an involution is abelian. Commuting diagonalizable matrices are
simultaneously diagonalizable, and a group of +-1 diagonal matrices has at most 2^k elements. []

For a frame product O(Q) is exactly the 2^k sign matrices. For squaring in F_(q^k) (a170
Proposition 59) the F_q-points of O(Q) are only +-I: over F, Q becomes coordinatewise squaring,
and the Galois action permutes the k coordinates transitively. The tests check both cases.

## 3. The affine partner group

> **Proposition 60.** Let P be a nondegenerate quadratic map of F_q^k, q odd. Then G(P) is an
> elementary abelian 2-group under composition at fixed t, (M, w, v) -> M is an injective
> homomorphism G(P) -> O(Q), and |G(P)| <= 2^k. Equality holds if and only if P is
> F_q-affinely conjugate to a frame product.

*Proof.* If g, h are affine partner maps, so is g o h, given by
(M_g M_h, M_g w_h + w_g, M_g v_h + v_g), because A_t(g(h(x,t),t)) = A_t(h(x,t)) = A_t(x). By
(1.1, xx) the linear parts lie in O(Q).

*Kernel.* If M = I, then (tx) gives B(w, .) = 0, so Q(w) = B(w, w) = 0 and w = 0. Likewise (x)
gives B(., v) = 0, so v = 0. Only the identity has linear part I.

*Group.* By Lemma 126, g o g has linear part M^2 = I, so g o g = id. Thus G(P) is closed under
composition, every element is its own inverse, and g -> M_g is injective. So G(P) embeds in
O(Q) and |G(P)| <= 2^k.

*Equality.* Suppose |G(P)| = 2^k. The linear parts are k x k matrices over F_q, so they form a
subgroup of O(Q)(F_q) of order 2^k: commuting involutions over F_q. Decompose F_q^k into their
joint eigenspaces V_chi, where chi runs over the characters G -> {+-1} that occur. G acts
faithfully, so it embeds in {+-1}^(#chi). Since #chi <= k and |G| = 2^k, every V_chi is a line
F_q e_i and G is the full group of sign matrices in the basis e_1, ..., e_k. In this basis
Q(Dx) = Q(x) for every sign matrix D. Flipping x_i alone kills every monomial x_i x_j with
j != i (q odd), so Q(x) = sum_i x_i^2 c_i for some vectors c_i.

Let g = (M, w, v) be the element with M = diag(1, .., -1 (place i), .., 1). By (tx),
2B(w, .) = M^(-1) - I = M - I = -2 E_ii, i.e. sum_l w_l x_l c_l = -x_i e_i for all x. Hence
w_i c_i = -e_i, so c_i = a_i e_i with a_i = -1/w_i != 0. By (x), L(M - I)x = -2B(Mx, v), i.e.

    x_i L e_i = sum_l (Mx)_l v_l a_l e_l   for all x.

Comparing the coefficients of x_i gives L e_i = -a_i v_i e_i. So L is diagonal too, and in the
basis e_i, P = (a_i x_i^2 + l_i x_i)_i + const is a frame product. The converse is Section 1. []

**Remark 60.1.** Proposition 60 holds for every odd q, small q included. A nondegenerate
quadratic map has at most 2^k - 1 *global* affine symmetries of the partner type, and only
frames have all of them.

## 4. Non-split partner covers lose a linear amount of entropy

Let V'' = {(x, y, t) in F^(2k+1) : A_t(y) = A_t(x)}. It is cut out by k quadrics. The diagonal
Delta = {y = x} is one irreducible component, of dimension k+1 and degree 1.

* Every component of V'' has dimension >= k+1 (k equations). The projection to (x, t) has
  finite fibres: for fixed (x, t), A_t(y) = A_t(x) is a system whose top forms Q have no common
  zero, so it has exactly 2^k solutions over F counted with multiplicity, by affine Bezout. So
  every component has dimension exactly k+1 and dominates the (x, t)-space.
* By Heintz's Bezout inequality (deg = sum of the degrees of the irreducible components), the
  components C != Delta have total degree sum deg C <= 2^k - 1 =: D.
* Let c(P) be the number of components C != Delta that are defined over F_q (sigma(C) = C,
  sigma = Frobenius). Over a generic point of the base the fibres of distinct components are
  disjoint and each has >= 1 point. The generic fibre has at most D points other than y = x.
  So c(P) <= D.

> **Theorem 51.** Let P be a nondegenerate quadratic map of F_q^k, q odd. Then
>
>     Lambda(P) <= q log2( 1 + c(P) + (D-1)(D-2) q^(-1/2) + A_k q^(-1) ),
>
> where D = 2^k - 1 and A_k depends only on k.

*Proof.* For each t, with weights |F|/q^k over the fibres F of A_t and Jensen's inequality,

    H(X | A_t X) = sum_F (|F|/q^k) log2 |F| <= log2( sum_F |F|^2 / q^k ) = log2(N_t / q^k),

and by Jensen again over t, Lambda <= q log2( sum_t N_t / q^(k+1) ). Next,
sum_t N_t = q^(k+1) + |W'(F_q)| with W' = V'' \ Delta, and every F_q-point of W' lies on a
component C != Delta.

If C is defined over F_q, it is absolutely irreducible of dimension k+1 and degree delta_C. The
Lang-Weil bound gives |C(F_q)| <= q^(k+1) + (delta_C - 1)(delta_C - 2) q^(k+1/2) + A' q^k, with
A' depending only on (2k+1, k+1, delta_C).

If C is not defined over F_q, its F_q-points lie in C ∩ sigma(C), which has dimension <= k and
degree <= delta_C^2. By the bound |V(F_q)| <= deg(V) q^(dim V), valid for every affine variety
(Cafure-Matera, Lemma 2.1), there are at most delta_C^2 q^k such points.

Sum over components, using sum delta_C <= D and
sum (delta_C - 1)(delta_C - 2) <= (D-1)(D-2). (With a_C = delta_C - 1 >= 0 and A = sum a_C, the
left side is sum a_C^2 - A <= A^2 - A <= (D-1)(D-2).) []

**Remark 51.1 (explicit constants).** Cafure-Matera, Theorem 7.1, as usually quoted, gives
A' = 5 delta^(13/3) for q > 2(r+1) delta^2. Then one can take A_k = 5 D^(13/3) + D^2 for
q > 2(k+2) D^2. We quote this constant and have not re-derived it. With these constants,
q log2(D + e_k(q)) <= k(q-1) holds from q0(k) on, where e_k is the error term of Theorem 51.
The tests check the arithmetic:

| k | 2 | 3 | 4 | 5 |
|---|---|---|---|---|
| q0(k), about | 650 | 2.8 * 10^4 | 7.9 * 10^5 | 1.8 * 10^7 |

The left side decreases in q and the right side 2^(k(q-1)/q) increases, so the inequality
holds for every q >= q0(k). For k = 2, 3 the conclusion C_q(k) was already known for all odd q
(Theorems 38, 43). What is new there is the gap and the equality case.

**Heuristic meaning.** By Chebotarev for function fields, 1 + c(P) is the average fibre size
for large q. Lambda/q tends to at most log2(1 + c(P)): the number of rational components of the
partner cover is the large-q entropy of the block. For squaring in F_(q^k), c = 1 and Lambda/q
tends to 1, which matches the exact value Lambda = q - q^(1-k) of a170 Proposition 59.

## 5. Split partner covers are frames

> **Theorem 52.** Let P be a nondegenerate quadratic map of F_q^k, q odd, with c(P) = 2^k - 1.
> Then P is F_q-affinely conjugate to a frame product.

*Proof.* By Section 4, c(P) = D forces every component C != Delta to be defined over F_q with a
single point over the generic point of the base. The generic fibre then has D + 1 = 2^k
distinct points. These have total multiplicity 2^k by Bezout, so each has multiplicity 1. The
projection C -> base is therefore generically étale of degree 1, i.e. birational and defined
over F_q. So the j-th partner is a rational map y_j = y_j(x, t) in F_q(x, t)^k.

*Integrality.* Let R = F_q[x, t] and S = R[y]/(A_t(y) - A_t(x)). The top forms Q_i(y) have only
the trivial common zero over F. By the Nullstellensatz, (y_1, ..., y_k)^N lies in (Q_1, ..., Q_k)
for some N, so modulo the equations every monomial of degree >= N in y reduces to lower degree
with coefficients in R. So S is a finite R-module and every element of S is integral over R.
The R-algebra map S -> Frac(R), y -> y_j(x, t), therefore sends y_1, ..., y_k to elements of
Frac(R) that are integral over R. R is a UFD, hence integrally closed, so y_j has polynomial
coordinates.

*Degree.* Suppose y_j has total degree e >= 2 in (x, t), with top homogeneous part Y != 0.
The degree-2e part of A_t(y_j) = A_t(x) is Q(Y) = 0, because ty_j has degree e + 1 < 2e and the
right side has degree 2. So Y(x, t) is a nonzero zero of Q over the field F_q(x, t),
contradicting nondegeneracy, since Q has no nontrivial zero over any extension field. Hence
e <= 1: y_j = M_j x + t w_j + v_j is an affine partner map.

So G(P) contains the identity and the D maps y_j, and |G(P)| >= 2^k. Proposition 60 gives
equality, and P is conjugate to a frame product. []

*Proof of Corollary 52.1.* If c(P) = 2^k - 1, P is a frame product up to conjugation (Theorem
52), so Lambda = k(q-1). Otherwise c(P) <= 2^k - 2, and Theorem 51 with Remark 51.1 gives
Lambda(P) <= q log2(2^k - 1 + e_k(q)) < k(q-1) for q >= q0(k). The gap is
k(q-1) - Lambda >= q log2(2^k / (2^k - 1 + e_k(q))) - k, which is about q/(2^k ln 2) - k. []

## 6. What this says about the program

* **The three deficit mechanisms of a170 Section 3, revisited.** For nondegenerate quadratics,
  Galois (iii) is the whole story at large q. Any loss of rationality in the partner cover costs
  a constant fraction of q bits, and full rationality forces a frame. Collisions (i) matter
  only at the O(1) level, which a170 handles exactly. Degeneracy at infinity (ii) is the one
  mechanism this note does not touch.
* **Where a counterexample to C_q(k) could still live**, among quadratic maps: degenerate maps
  (top forms with a common zero), or small q relative to k. This is the regime of the record
  question at q = 3, 5. Pre-registered searches (peel-search, a168 Section 6) should target
  degenerate quadratic maps first.
* **Next steps.** (1) Extend Theorem 51 to degenerate maps by bounding the positive-dimensional
  fibres, which is the G_n type. (2) Make q0(k) polynomial in 2^k, or remove it, by replacing
  Lang-Weil with an exact Galois count for the partner cover. (3) The analogue of Proposition 60
  for degree d >= 3, where O(Q) is still finite (Q(Mz) = mu^d Q(z) forces mu^d = 1).

## 7. Tests (`test_splitgroup.py`)

  Lambda <= sum_t log2(N_t/q^k) <= q log2(1 + M/q^(k+1)).
* (1.2) and Lambda = k(q-1) for frame products and random F_q-conjugates of them, up to
  F_5^3.
* Lemma 126, by brute force over all k x k matrices: every one of the nondegenerate binary
  quadratic top forms Q over F_3 (resultant != 0), random ones over F_5 and F_7, conjugated
  frames on F_3^3 (|O| = 8) and squaring in F_9, F_25, F_27 (|O| = 2).
* Proposition 60, by brute force over all matrices M and all (w, v): for every nondegenerate
  top form over F_3^2, with L = 0 and with a random L, G(P) is an elementary abelian 2-group of
  order <= 4, and it has order 4 exactly when some E in GL_2(F_3) makes E^(-1) P(E x) a
  coordinatewise map. The same holds for random maps over F_5^2 and F_7^2, for conjugated
  frames on F_3^3 (|G| = 8), and for squaring in F_9, F_25, F_49, F_27 (|G| = 2).
* Remark 51.1: q0(k) for k = 2..5 lies in the ranges stated above, and the inequality holds
