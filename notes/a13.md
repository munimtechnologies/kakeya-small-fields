## Lemma 66 (the base change inside U+)

**Lemma 66.** Let n be v or u + v, and suppose that M_n is invertible.

(a) n is a Case B element of rank t - 2 with ker A_n = X_1, Im A_n = R and U+(n) = N; beta(n, h)
    lies in X_1 exactly when h lies in W, and P_n n X_1 = beta(n, W) = span(beta(n, w)) is a line
    not containing sigma(n).

(b) The second element n' of N (the one with sigma(n') spanning P_n n X_1) and the matrix M' of n'
    with respect to n are:

        type   n        n'       M'                  needs
        i      u + v    v        (I + M)^(-1) M      I + M invertible
        ii     v        u        M^(-1)              M invertible
        iii    v        u + v    M^(-1) + I          M invertible
        iii    u + v    u        (I + M)^(-1)        I + M invertible

    In type i, M is singular, and in type ii, I + M is singular (Lemma 40), so the rows above are
    the only possibilities.

(c) w is an admissible choice for n too: beta(n, w) = sigma(n'), G_n = G, the type of n is the type
    of u, and q_n = [sigma(w)] = q as a vector of X/X_1.

(d) So if some anisotropic system with dim X = t and dim V = t + 1 has a Case B element of rank
    t - 2 in the normal form of Lemma 41 with pair (M, q), it has one in that normal form with the
    pair obtained from (M', q) by Lemma 39 (M' -> g^(-1) M' g, q -> g^(-1) q, with g taking M' to
    the chosen matrix of its class, then the chosen vector of the C(M')-orbit), of the same type.
    Each move of the table is undone by a move of the table, so this is a symmetric relation.

*Proof.* (a) A_n = T M_n T^(-1) A_u with T and M_n invertible gives ker A_n = ker A_u = X_1 and
Im A_n = T M_n (X/X_1) = R, so rank A_n = t - 2 and dim V = t + 1 = t + k - 1 with k = 2. By
Proposition 26 of [tight-cases.md](tight-cases.md), n is in Case A or Case B. beta(n, .) vanishes on
N, so its image has dimension at most dim V - 2 = t - 1, and n is not in Case A (where beta(n, .) is
onto X). So n is in Case B: P_n = beta(n, V) is a hyperplane missing sigma(n), and U+(n) =
ker beta(n, .) has dimension 2 and contains N, so U+(n) = N. By Lemma 38(a), [beta(n, h)] =
M_n [phi(h)], which is 0 exactly when [phi(h)] = 0, that is, when phi(h) lies in X_1 n P = Y, that
is, when h lies in W. So beta(n, h) lies in X_1 exactly for h in W, and P_n n X_1 = beta(n, W). As
beta(n, N) = 0 and W = N + span(w), this is span(beta(n, w)); it is a line, since sigma(n) lies in
X_1 but not in P_n.

(b) phi(w) = e_1 and beta(v, w) = G e_1 (Lemma 38(d)), which is 0, x0 or x0 + e_1 in types i, ii,
iii (Lemma 40). So beta(v, w) is 0, x0 = sigma(u), x0 + e_1 = sigma(u + v), and beta(u + v, w) =
e_1 + beta(v, w) is e_1 = sigma(v), x0 + e_1 = sigma(u + v), x0 = sigma(u). By (a), beta(n, w) spans
a line of X_1 that does not contain sigma(n): for n = v this rules out type i (beta(v, w) = 0), and
for n = u + v it rules out type ii (beta(u + v, w) = sigma(u + v)); in the four remaining cases
n' is the element of N whose value is beta(n, w), as sigma is one-to-one on N: n' = v, u, u + v, u
in the order of the table. These exclusions agree with Lemma 40: M q = 0 in type i (M singular) and
M q = q in type ii (I + M singular).

The matrix of n' with respect to n: A_(n') x = T M_(n') [x] = (T M_n)(M_n^(-1) M_(n')) [x], and
T M_n is the isomorphism X/X_1 -> R induced by A_n (T_n [x] = A_n x = T M_n [x]). So
M' = M_n^(-1) M_(n'): (I + M)^(-1) M, M^(-1) I, M^(-1)(I + M) = M^(-1) + I and (I + M)^(-1) I.

(c) w lies in W = W_n and beta(n, w) = sigma(n') spans P_n n X_1 = Y_n, so w is a choice of h_y for
n with y = sigma(n') (Lemma 38(d) for n), and G_n = A_w restricted to X_1 = G and q_n = [sigma(w)]
= q. The type of n is read off from G_n sigma(n') written as a' sigma(n) + b' sigma(n') (Lemma 40
for n): type i, n = u + v, n' = v: G e_1 = 0, so (a', b') = (0, 0); type ii, n = v, n' = u:
G x0 = e_1 = sigma(n), so (1, 0); type iii, n = v, n' = u + v: G(x0 + e_1) = e_1 + x0 + e_1 = x0 =
sigma(n) + sigma(n'), so (1, 1); type iii, n = u + v, n' = u: G x0 = e_1 = sigma(n) + sigma(n'),
so (1, 1). As a check against Lemma 41(a): (I + M)^(-1) M q = 0; M^(-1) q = q; (M^(-1) + I) q is
neither 0 nor q, since q and M q are independent in type iii (T q = x0, T M q = e_1); and
(I + M)^(-1) q is neither 0 nor q, since M q != 0.

(d) Build the normal form of Lemmas 35, 37 and 41 from n: v_0 = n, v_1 = n' (sigma(n') is the new
e_1), v_2 = w (its beta with n is the new e_1), X_1 and R are unchanged, and [e_2], ..., [e_(t-1)]
is still a basis of X/X_1, in which the matrix of n' is M' and q_n = q by (c). Lemma 39 (with k = 2
there is no recombination) conjugates M' to the chosen matrix of its class and sends q to g^(-1) q,
and Lemma 41(b) moves q inside its C(M')-orbit and normalises the X_1-part of sigma(w). (We do not
claim that the X_1-part label of type ii, 0 or x0, is preserved: the two instances of a type ii pair
are treated as one.) For the symmetry: in type i, I + M' = (I + M)^(-1)(I + M + M) = (I + M)^(-1) is
invertible and (I + M')^(-1) M' = M; in type ii, (M^(-1))^(-1) = M; in type iii, from
M' = M^(-1) + I, I + M' = M^(-1) is invertible and (I + M')^(-1) = M, and from M' = (I + M)^(-1),
M' is invertible and M'^(-1) + I = M. QED

*Remark.* On the three matrices I, M, I + M of N the base changes act as the Mobius group
PGL_2(F_2) acts on M: x -> x/(1 + x) in type i, x -> 1/x in type ii, and the two elements of order
3, x -> (1 + x)/x and x -> 1/(1 + x), in type iii. On the eigenvalues of M in an algebraic closure
these are the same Mobius maps, which fix F_2 setwise. That is what decides which similarity
classes are identified: x -> (1 + x)/x permutes the roots of the three irreducible quartics
cyclically (theta -> theta^3 -> theta^11 -> theta for theta^4 = theta + 1), but maps each
irreducible cubic and x^2 + x + 1 to itself.

the Mobius map of the Remark, and keeps q; when M' is similar to M the move keeps the pair, since
M' is a polynomial in M with the same primary decomposition and the C(M)-orbit of q is determined by
the lattice of fully invariant submodules, which is the same for M and M'. Family by family, with
p = x^2 + x + 1, c_1 = x^3 + x + 1, c_2 = x^3 + x^2 + 1:

## Corollary 45 (no element of rank 4 at t = 6)

**Corollary 45.** No anisotropic system with t = 6 and dim V = 7 has an element of rank 4.
Consequently A(6) = 6 holds if and only if no anisotropic system with t = 6 and dim V = 7 has an
element of rank exactly 3; and every element of rank 3 of such a system is in one of the
configurations (A4), (B4), (B5) of Corollary 39 of [a10.md](a10.md).

*Proof.* Let u have rank 4 in such a system. Then k = t - rank A_u = 2 and dim V = 7 = t + k - 1, so
by Proposition 26 of [tight-cases.md](tight-cases.md) u is in Case A or in Case B. Case A is
excluded by Corollary 42 of [a9.md](a9.md). In Case B, Corollary 43 of [a12.md](a12.md) says that
one of the instances q2_t6_i03, q2_t6_i07, q2_t6_i119, q2_t6_i120 is satisfiable, and job m26 found
all four unsatisfiable. The second statement is the "if and only if" of Corollary 42 with the
rank-4 alternative removed, and the third is Corollary 39, whose hypothesis (no element of rank 4)
now holds for every such system. QED

This is computer-assisted: it rests on 21 + 142 + 4 = 167 solver answers saved without proof
certificates (jobs m24, m25 and m26), on the normal forms of Lemmas 48 and 61 (Case A) and of
Lemmas 35, 37, 41 and 65 (Case B), and on Corollary 36 of a8.md. The fallback of Lemma 68
([a15.md](a15.md), job m28: the element of U+ of rank 1 or 2 in each of the four instances) is no
longer needed for A(6) = 6. It stays useful as an independent check: by Lemma 68, UNSAT for all of
job m28's rank-1 and rank-2 shapes re-derives, without job m26, that q2_t6_i07, q2_t6_i119 and
q2_t6_i120 are unsatisfiable.

**What remains for A(6) = 6.** Only the elements of rank exactly 3, in the configurations (A4) =
("A", 5), (B4) = ("B", 4) and (B5) = ("B", 5). Job m27 ([a14.md](a14.md)) searched them split by
(ker A_u, Im A_u) and decided nothing; job m29 ([a16.md](a16.md)) adds the facts of Lemma 69; job
m30 ([a17.md](a17.md)) fixes the matrix A_u itself up to the stabiliser of the pair.
