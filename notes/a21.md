## Corollary 48 (rank 3 at t = 6: only two pair orbits of (B5))

**Corollary 48 (computer-assisted).** Let an anisotropic system have t = 6 and dim V = 7, and let w
be an element of rank exactly 3, with K_w = ker A_w, I_w = Im A_w and P_w = beta(w, V). Then

    K_w n I_w = K_w n P_w,   and this subspace has dimension 2.

Hence rank A_w^2 = 3 - dim(K_w n I_w) = 1, and sigma(w) is not in I_w (because sigma(w) is in
K_w, and it is not in P_w since w is in (B5)).

*Proof.* By Corollary 47 (i), w is in (B5). Put the system in the normal form of Lemma 67 for w:
sigma(w) = e_0, P_w = P = span(e_1, ..., e_5), and (K_w, I_w) is in one of the eleven pair orbits of
the group G = {g in GL(X) : g e_0 = e_0, g P = P}. For g in G, g(K n I) = gK n gI and
g(K n P) = gK n P. So whether K n I = K n P, and dim(K n I), are the same for every pair in one
G-orbit, and can be read off the representative. In every pair orbit dim(X_1 n P) = 2 (a20.md).
So K n I = K n P forces dim(X_1 n R) = 2, which leaves pair orbits 1 to 4. In pair orbit 1, x0 = e_0
is in R n X_1 but not in P. In pair orbit 3, e_0 + e_1 is in X_1 n R but not in P. In pair orbits 2
and 4, X_1 n R = span(e_1, e_2) = X_1 n P (the table). Every class of pair orbits 0, 1, 3 and 5 to 10
is UNSAT (m30, m32, m33, m34). So by Lemma 70, a w in one of those orbits would give a model of one
of those UNSAT instances. QED

The proof relies on the SAT solver's UNSAT answers for every class of (A4) (141) and of (B4) (401),
and for 62 classes of (B5) (Corollary 47 needed 28 of them). All were saved without proof
certificates (cadical195 through python-sat), so the result is computer-assisted and has not
been checked by a human.

**Remarks.**

- Corollary 48 is about every element of rank 3, not only the element u that a search fixes. So it
  can be used for h_1 and u + h_1 inside a search, as Lemma 74 does.
- Pair orbits 3 and 4 have the same four invariants of a6_r3.invariants, and still only 4 is
  open. The relation K n I = K n P is what separates them. A sharper invariant along these lines
  may separate the classes of pair orbits 2 and 4 too: inside one pair orbit, A_u up to the
  stabiliser of the pair.
- With Corollary 45 (no rank 4) and rank 5 impossible, a counterexample to A(6) = 6 has all ranks
  at most 3, and every element of rank 3 is of the kind in Corollary 48.

## Lemma 74 (Corollary 48 in the split of Lemma 71, pair orbits 2 and 4)

In the split of Lemma 71 ([a18.md](a18.md)), s = sigma(h_1) is in span(e_1, e_2), and
N = A_(h_1) kills L = span(x0, s) and maps into R. Lemma 73's notation: a = dim(L n R).

**Lemma 74.** In pair orbits 2 and 4 of (B5) at t = 6 and dim V = 7:

(i) s is in R, x0 and x0 + s are not, and a = 1, for each of the three choices of s.

(ii) rank A_(h_1) <= 2. So of the 4096 candidates for N per s, the 2520 of rank 3 are excluded,
and 1576 remain.

(iii) If A_u + A_(h_1) has rank 3, its kernel K is one of the 3 subspaces (out of 15) with
dim(K n R) = 2. Since that kernel contains sigma(u + h_1) = x0 + s, which is not in R, this agrees
with sigma(w) outside Im A_w.

*Proof.* (i) In both orbits X_1 n R = span(e_1, e_2) (the table), and s is a nonzero vector of
span(e_1, e_2). x0 = e_0 is not in R, so neither is x0 + s. L n R contains s, and not x0 or
x0 + s, so it is span(s).

(ii) If rank N = 3, then Im N = R (Lemma 73), and Corollary 48 for w = h_1 says sigma(h_1) = s is
not in Im N = R, against (i). N is a linear map from X / L (dimension 4) to R (dimension 3). There
are 2^12 = 4096 of them, and (2^4 - 1)(2^4 - 2)(2^4 - 4) = 2520 are onto.

(iii) By Lemma 73 with a = 1, dim(K n R) is 2 for 3 of the 15 kernels and 1 for the other 12.
Corollary 48 for w = u + h_1 needs dim(K n R) = 2. QED

So if pair orbits 2 or 4 survive jobs m36 and m37, the split of Lemma 71 for them starts from at
most 3 x 1576 = 4728 candidate pairs (s, N) per class instead of 12288, before the H_A-orbits are
taken and before the condition on u + h_1 (which depends on A_u + N, and is a count for the code).
Lemma 74 needs no new clauses either: N is fixed in each instance of that split.
