## What changes

- **Lemma 80.** In Case A at rank 4 for t = 7 and dim V = 9, bases can be chosen so that
  x0 = e_0, D = span(e_1, e_2), R = Im A_u = span(e_1, ..., e_4), ker phi = span(u, n) and phi
  takes the basis vectors of V to 0, 0, e_0, e_1, ..., e_6. Then A_u is one of 20160 matrices,
  and up to the group G of base changes that keep this form (|G| = 6^3 2^14 = 3538944) it is one
  of **six**: the class is the similarity class of the 2 x 2 map Pbar that A_u induces on R / D,
  which is zero, the identity, of order 3, unipotent, idempotent of rank 1 or nilpotent of rank 1.
- **Job m39** (cube_groups/a7_casea.py) is the exact search for each of the six, with the
  encoding of sat_aniso.py and the values of Lemma 80 fixed, once plain and once with five facts of
  Lemma 77 added. Its controls: at t = 5 the same encoder gives exactly the CNFs of case_a.py
  (UNSAT, Lemma 52 and job m15), and a planted system at t = 6 with a 3-dimensional ker phi must be
  SAT.

If all six classes are UNSAT, row 1 of the table in a24.md ("rank 4, Case A") is closed,
computer-assisted, and A(7) <= 8 comes down to Case B at rank 4 and the rank-3 configurations.

## Setting

As in [a24.md](a24.md): t = 7, dim V = 9, u of rank 4 in Case A, phi = beta(u, .) onto X,
ker phi = span(u, n), x0 = sigma(u), X_1 = ker A_u, R = Im A_u, D = X_1 n R. By Lemma 77 (a), (c)
and (d), x0 is not in R, D is a plane and X_1 = span(x0) + D. Write a for the restriction of A_u
to R: its kernel is D and its rank is 2.

## Lemma 80 (the normal form and its six classes)

**Lemma 80.** (a) There are bases e_0, ..., e_6 of X and v_0, ..., v_8 of V with x0 = e_0,
D = span(e_1, e_2), R = span(e_1, e_2, e_3, e_4), v_0 = u, v_1 = n, phi(v_2) = e_0 and
phi(v_i) = e_(i-2) for 3 <= i <= 8. Any two such bases of X differ by an element of

    G = {g in GL(X) : g e_0 = e_0, g D = D, g R = R},   |G| = 6^3 x 2^14 = 3538944,

and for every g in G a basis of V can be chosen again. So A_u can be taken to be any element of
its G-orbit in the set of candidates (A_u e_0 = A_u e_1 = A_u e_2 = 0, image R), which has
|GL_4(F_2)| = 20160 elements.

(b) A candidate is the same as an isomorphism L : W = X / X_1 -> R. In the bases [e_3], [e_4],
[e_5], [e_6] of W and e_1, e_2, e_3, e_4 of R, write

    L = [ L_11  L_12 ]      rows: D, then R / D;  columns: Rbar = (R + X_1) / X_1, then the rest.
        [ Pbar  S    ]

Pbar is the map that A_u induces on R / D (Rbar is R / D). The G-orbits are exactly the sets of
candidates with Pbar in one similarity class of 2 x 2 matrices over F_2. There are six, with these
sizes:

    Pbar             representative (A_u e_3, A_u e_4, A_u e_5, A_u e_6)     orbit size
    0                e_1,  e_2,        e_3,  e_4                              576
    I                e_3,  e_4,        e_1,  e_2                             1536
    order 3          e_4,  e_3 + e_4,  e_1,  e_2                             3072
    unipotent != I   e_3,  e_3 + e_4,  e_1,  e_2                             4608
    idempotent       e_3,  e_1,        e_4,  e_2                             6912
    nilpotent != 0   e_1,  e_3,        e_4,  e_2                             3456

(c) A_u is nilpotent exactly in the classes 0 and nilpotent. Im a n D has dimension 2 in class 0,
1 in the classes idempotent and nilpotent, and 0 in the other three.

*Proof.* (a) Pick e_1, e_2 spanning D, e_3, e_4 completing a basis of R, and e_5, e_6 completing
e_0, ..., e_4 (e_0 = x0 is outside R) to a basis of X. As phi is onto with kernel span(u, n),
v_0 = u, v_1 = n and any v_i over the stated values form a basis of V. A base change g of X turns
the system into (g A g^(-1), g sigma, g beta), so phi becomes g phi, and it keeps the form exactly
when g fixes x0 and keeps D and R; then new v_i over the new values exist again. In the basis
e_0, ..., e_6, g has column 0 equal to e_0, columns 1 and 2 in D, columns 3 and 4 in R, and the
diagonal blocks {1, 2}, {3, 4}, {5, 6} invertible: 6^3 choices for the blocks and 2^14 for the 14
free entries above them (4 in columns 3, 4; 10 in columns 5, 6).

(b) A candidate kills X_1 and maps onto R, so it is i L pi with pi : X -> W and i : R -> X, and L
is an isomorphism; there are |GL_4(F_2)| of them. An element g of G keeps X_1 = span(e_0) + D and
R, so g A_u g^(-1) corresponds to L' = a' L b^(-1), with a' the map g induces on R and b the map
it induces on W:

    a' = [ K  X ]      b = [ M  N ]      K, M, Q in GL_2(F_2), X, N arbitrary.
         [ 0  M ]          [ 0  Q ]

The same M appears twice because both are the map g induces on R / D = Rbar. Every such pair
(a', b) comes from some g (choose g on e_3, e_4 by a', and g e_5, g e_6 by b, adding anything in
X_1). Then the bottom row becomes

    [ M Pbar M^(-1) | M (S + Pbar N') Q^(-1) ],    N' = M^(-1) N arbitrary,

and the top row becomes K [L_11 | L_12] b^(-1) + X [Pbar | S] b^(-1). Since L is invertible, the
bottom row [Pbar | S] has rank 2, and with X and K arbitrary the top row can be made any pair of
rows that completes it to an invertible matrix: so, for a fixed bottom row, all 96 = (16 - 4)(16 - 8)
candidates lie in one orbit, and the orbits are those of the 210 bottom rows of rank 2. Now
Pbar runs through its similarity class, and for a fixed Pbar, S counts only modulo matrices with
columns in Im Pbar, up to M S Q^(-1) with M commuting with Pbar:
- Pbar = 0: S must be invertible, and M S Q^(-1) reaches all 6. Orbit 6 x 96 = 576.
- Pbar invertible (I: 1 matrix, order 3: 2, unipotent != I: 3): S + Pbar N' is arbitrary, so S
  can be made 0. Orbits 16 x 96 = 1536, 32 x 96 = 3072 and 48 x 96 = 4608.
- Pbar of rank 1 (idempotent: 6 matrices, nilpotent: 3): S counts only through its image in
  coker Pbar, a non-zero row (rank 2), and Q moves it to any of the 3 non-zero rows. For each Pbar
  there are 4 x 3 = 12 such S, so the orbits are 6 x 12 x 96 = 6912 and 3 x 12 x 96 = 3456.
The classes are told apart by (Pbar = 0, Pbar = I, trace, determinant), which g does not change,
and 576 + 1536 + 3072 + 4608 + 6912 + 3456 = 20160. The representatives are read off with
L_11, L_12 chosen to complete the bottom row.

(c) A_u^2 X = A_u R = Im a, and a acts on R with kernel D and induced map Pbar on R / D, so A_u is
nilpotent iff Pbar is. The plane Im a maps onto Im Pbar in R / D, so dim(Im a n D) = 2 - rank Pbar.
QED

The selfcheck of a7_casea.py recomputes (a) and (b) by an orbit closure over all 20160 candidates
under 20 transvections that generate G, and compares the six orbit sizes with the table.

## Job m39 (queued, not run)

For each class, the CNF of sat_aniso.encode for (t, dim V) = (7, 9), without its echelon form, with
112 unit clauses: sigma(v_0) = e_0, A_(v_0) = the representative, beta(v_0, v_i) = phi(v_i). An
UNSAT answer for a class means: no anisotropic system with t = 7 and dim V = 9 has an element of
rank 4 in Case A whose A_u is in that class. The variant "hint" adds 65 unit clauses for facts
already proved: sigma(n) in X_1 and A_n x0 = 0 by (3), Im A_n in R by (2), A_n D = 0 by Lemma 77
(f), sigma(v_2) in D by Lemma 77 (a), and A_(v_2) D = 0 by Lemma 77 (d).

    m39a   selfcheck; controls (planted t = 6, the 9 orbits of t = 5); classes 0, I, order 3, plain
    m39b   selfcheck; planted control; classes unipotent, idempotent, nilpotent, plain
    m39c   selfcheck; all six classes with the hints

Each class gets an equal share of what is left of 120 to 144 minutes. The predictions and the
decision rule (all six UNSAT expected; an UNKNOWN is re-run with at least twice the budget; a
verified SAT would mean A(7) = 9) were written before the jobs were queued.

- Case B at rank 4 (shapes (c) and (d2)) and the rank-3 configurations (A5), (B6), (B5) need their
