## What changes

- **Lemma 75 (by hand).** Let w be an element of rank exactly 3 as in Corollary 48, with
  K = ker A_w and I = Im A_w. Then A_w maps I onto a line l_w, and either l_w lies in K (A_w is
  nilpotent, A_w^3 = 0) or A_w fixes a non-zero vector v_w (A_w v_w = v_w, l_w = span(v_w)). In
  both open pair orbits, class m000 is the second kind and class m001 the first. So the classes
  inside one pair orbit are told apart by an invariant that does not depend on the normal form,
  which is the "sharper invariant" that a21.md asked for.
- In the same lemma: the map h -> A_h sigma(w) has kernel exactly ker beta(w, .) (dimension 2),
  except in the non-nilpotent class of pair orbit 2, where it has dimension 3.
- **Lemma 76 (conditional).** If jobs m36 and m37 close both classes of one kind (both m000 or
  both m001), then every element of rank 3 has a matrix of the other kind. In the split of Lemma 71
  this is a condition on N = A_(h_1) alone, and it keeps 216 or 288 of the 504 rank-3 candidates
  for A_u + N that Lemma 74 leaves per choice of s.

## Lemma 75 (rank 3 at t = 6: the line A_w(I) and the fixed vector)

**Lemma 75.** Let an anisotropic system have t = 6 and dim V = 7, and let w be an element of rank
exactly 3, with K = ker A_w, I = Im A_w, P_w = beta(w, V) and y = sigma(w). Then:

(i) A_w(I) = A_w^2(X) is a line l_w. Either l_w lies in K, and then A_w^3 = 0 (the nilpotent
kind), or A_w v = v for the non-zero vector v = v_w of l_w (the fixed kind). The kind is the same
for every matrix in one class of Lemma 70, and in pair orbits 2 and 4 the class m000 is of the
fixed kind and m001 of the nilpotent kind (96 and 72 matrices).

(ii) ker(I + A_w) is 0 for the nilpotent kind and span(v_w) for the fixed kind.

(iii) The map h -> A_h y has kernel beta(w, .)^(-1)(P_w n ker(I + A_w)). This is ker beta(w, .),
of dimension 2, unless w has the fixed kind and v_w lies in P_w; that happens exactly in the fixed
class of pair orbit 2, and then the kernel has dimension 3.

*Proof.* (i) By Corollary 48, dim(K n I) = 2, so A_w restricted to I (dimension 3) has rank 1, and
its image l_w = A_w(I) = A_w(A_w X) is a line. Let v span it. A_w v lies in l_w, so A_w v is 0 or
v. If A_w v = 0, then A_w^3 X = A_w l_w = 0. Otherwise A_w v = v. Conjugation by an invertible g
keeps A_w^3 = 0 or not, so the kind is a class invariant. For the four open classes, read A_u on R
from the table: in o002_m000, A_u e_3 = e_3; in o004_m000, A_u (e_0 + e_3) = A_u e_3 = e_0 + e_3;
in o002_m001, A_u e_3 = e_2 and A_u e_2 = 0; in o004_m001, A_u (e_0 + e_3) = e_2 and A_u e_2 = 0.
Count, as a check of the class sizes from job m30: A_u is a bijection from X / X_1 onto R, 168 of
them. R + X_1 / X_1 is the line through the class of e_3 in both orbits, and A_u sends it to any of
the 7 non-zero vectors of R, each with 168 / 7 = 24 completions. A_u is nilpotent exactly when that
vector lies in D (3 choices, 72 matrices) and of the fixed kind otherwise (4 choices, 96
matrices). These are the sizes of m001 and m000.

(ii) If A_w x = x, then x = A_w x is in I, so x = A_w x is in A_w(I) = l_w. For the nilpotent kind,
A_w kills l_w, so x = 0. For the fixed kind, l_w = span(v) and v is fixed.

(iii) (*) with h = w and h' = h gives A_h y = (I + A_w) beta(w, h). So A_h y = 0 exactly when
beta(w, h) is in P_w n ker(I + A_w). For the nilpotent kind that is 0. For the fixed kind it is
span(v) n P_w. Put w in its normal form (Lemma 67), which by Corollaries 47 and 48 has pair orbit 2
or 4 (in coordinates, as u above). In pair orbit 2, R lies in P, so v is in P_w. In pair orbit 4,
R n P = D (dimension 2 in the table of a21.md, and D lies in both), and v is in R but not in
D = R n X_1 (A_w v = v != 0), so v is not in P_w. The kernel of beta(w, .) has dimension
7 - 5 = 2 in (B5), and adding the preimage of span(v) adds one dimension. QED

**Remarks.**

- Lemma 75 (i) and (ii) use Corollary 48, which is computer-assisted. Part (iii) for w = u can be
  checked directly in the normal form: in o002_m000, v = e_3 = phi(h_4), so A_h x0 = 0 for every h
  in span(u, h_1, h_4). In the other three classes, A_h x0 = 0 only for h in W = span(u, h_1).
- Before this lemma, the classes inside one pair orbit were known only as orbits of the stabiliser
  computed by job m30. The kind is the same as asking whether A_w^3 = 0, so it can be read off any
  matrix, in any coordinates.
- No contradiction for the fixed class of pair orbit 2 was found by hand in this run. The extra
  dimension in (iii) is the most special structure among the four classes, and it is the natural
  place to look next.

## Lemma 76 (a filter for the split of Lemma 71, if one kind closes)

**Lemma 76 (conditional).** Suppose that both classes of the nilpotent kind (o002_m001 and
o004_m001) are UNSAT. Then in an anisotropic system with t = 6 and dim V = 7, every element of rank
exactly 3 has a matrix of the fixed kind. Likewise with the two kinds swapped.

In the split of Lemma 71 for a remaining class, with s and N = A_(h_1) fixed and w = u + h_1: if
A_u + N has rank 3, it must be of the remaining kind. Per choice of s, Lemma 74 leaves
3 x 168 = 504 rank-3 values of A_u + N (3 allowed kernels K); the nilpotent kind is 3 x 72 = 216 of
them, and the fixed kind 3 x 96 = 288.

*Proof.* By Corollaries 47 and 48, an element w of rank exactly 3 has, in its own normal form
(Lemma 67), a pair (ker A_w, Im A_w) in pair orbit 2 or 4, and by Lemma 70 its matrix is
conjugate to one of the two class representatives of that orbit. If the class has a model, so has
the instance (Lemma 70), so it is not one of the UNSAT classes. Its kind is that of the class
(Lemma 75 (i)). For the count: as N runs over the 4096 maps from X / L to R (L = span(x0, s)),
so does A_u + N, since A_u kills L. For one kernel K of dimension 3 containing L with
dim(K n R) = 2, the maps with kernel K onto R are the 168 bijections X / K -> R. Let r be a
vector of R outside K. The line of X / K through r goes to any of the 7 non-zero vectors of R
(24 completions each). The map is nilpotent exactly when that vector is in K n R (3 of 7). QED

Lemma 76 says nothing about h_1 itself, which has rank at most 2 in both pair orbits (Lemma 74
(ii)). If only one class closes, or one of each kind, Lemma 76 does not apply, because the pair
orbit of w = u + h_1 depends on beta(u + h_1, V), which the split does not fix.

## Exploratory guess, written before jobs m36 and m37 report

The fixed class of pair orbit 2 (o002_m000) has the most structure (Lemma 75 (iii)), so the guess
is that it is the most likely of the four to be UNSAT within its share: about 60 percent. Whether
the classes fall by kind (both m000 or both m001) is a coin toss as far as this note can tell. This
is not graded and does not change the decision rule of `m36/predictions.md`.
