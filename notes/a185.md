# a185. Conjecture S2 is false: the sticky selection game over F_3 grows strictly slower than 2^h, and Theorem 72 is the best any potential can give

## Summary

The selection game of a182-a184 bounds sticky Kakeya sets in F_3^n: |K| >= f(n) - 1, where f(h) is
the least possible largest coordinate of a game vector at height h. The classical sticky Kakeya set
{0,1}^n ∪ {0,2}^n (lines through P(d) = (d_j^2)_j) has 2^(n+1) - 1 points, and triangles give
f(h) <= 2^h. a183 proved f(h) >= 1.90499^h. Conjecture S2 (a183) said f(h) = 2^h for every h, which
would have meant the game proves the classical construction optimal among sticky sets.

1. **Proposition 82 (barrier).** Take any potential that is monotone, shifts by s when every
   coordinate is multiplied by e^s, and grows by at least mu at every node of the game, for all
   positive real children. Then mu <= mu* = 0.644488..., so the potential cannot certify a base
   above **beta* = e^(mu*) = 1.905012...**.
2. **Theorem 73.** Conjecture S2 is false: beta_s = lim f(h)^(1/h) < 2. If S2 held, the gauge of
   the normalised reachable set would be such a potential with mu = log 2 = 0.693 > mu*.
3. **Corollary 73.1.** Conjecture M of a184 (min + max >= 2^(h+1)) is false too, and
   f(h)/2^h -> 0 exponentially.
4. **Corollary 73.2.** Theorem 72's potential phi_c is optimal among all such potentials up to the
   choice of constants: the best member (c* = 0.24008, u* = 0.3807) attains beta* exactly, and
   Theorem 72's (0.24, 0.38) gives 1.9049966, within 1.6e-5 of it.

So the potential method is finished at 1.90501. The game constant beta_s lies in [1.90499, 2),
and the selection game cannot show that sticky Kakeya sets over F_3 need 2^(n - o(n)) points.
Whether they do is still open: the game is a relaxation, and the classical set has 2^(n+1) - 1
points.

## 1. The game, in log coordinates

Vectors L in R^3_{>0}. Leaf (1,1,1). affine(s): L_s = max_x L_s(x), L_t = sum_x L_t(x) for t != s.
triangle(iso): L_t = L_t(iso(t)) + max_{x != iso(t)} L_t(x). Write l = log L. A *potential* is a
function phi on R^3 with

- (P0) phi is nondecreasing in each coordinate;
- (P1) phi(l + s(1,1,1)) = phi(l) + s for every real s;
- (P3) phi(log N(c_0, c_1, c_2)) >= mu + min_x phi(log c_x) for every node type N and **all**
  positive real children c_x.

(P0) and (P1) make phi 1-Lipschitz in the sup norm. If phi(0) >= 0 and phi(l) <= max_t l_t, then
induction gives f(h) >= e^(mu h). a183's phi_c/3 is an example with mu = 0.644480.

For a probability vector beta on the three slices put

  A(beta) = (1 - max_t beta_t) log 3,   V(beta) = max_{w in simplex} sum_t beta_t h2(w_t),

with h2 the binary entropy in nats, and mu* = max_beta min(A(beta), V(beta)).

**Lemma 157 (triangle saddle).** Fix r in (0,1)^3. For a parent p, the children
c_x[x] = r_x p_x and c_x[t] = (1 - r_t) p_t (t != x) give back p under the triangle with
iso = identity. For a linear potential beta·l, child x lies below the parent by

  g_x(r) = -beta_x log r_x - sum_{t != x} beta_t log(1 - r_t).

If every beta_t > 0, then inf_r max_x g_x(r) = V(beta).

*Proof.* The triangle gives r_t p_t + (1 - r_t) p_t = p_t. For any probability vector w,
sum_x w_x g_x(r) = sum_t beta_t CE(w_t, r_t) >= sum_t beta_t h2(w_t), where CE is the binary
cross-entropy. Hence max_x g_x >= V. Conversely, the maximiser w* of sum_t beta_t h2(w_t) is
interior: h2' is infinite at 0 and at 1. Lagrange gives beta_t log((1 - w*_t)/w*_t) = nu for every
t. Put r = w*. Then g_x = nu - sum_t beta_t log(1 - w*_t) is the same for all x, so it equals
sum_x w*_x g_x = V. ∎

**Proposition 82.** Every potential satisfying (P0), (P1) and (P3) has mu <= mu*.

*Proof.* Let psi be the restriction of phi to the plane P = {l_0 + l_1 + l_2 = 0}. Then
phi(l) = psi(l - m(l)(1,1,1)) + m(l), with m(l) the mean of the l_t.

*Blow-down.* The functions psi_R(y) = psi(Ry)/R are equi-Lipschitz, and psi_R(0) -> 0. By
Arzelà-Ascoli, some R_n -> infinity gives psi_{R_n} -> Psi locally uniformly, with Psi Lipschitz.
By Rademacher, Psi is differentiable at some y0, with gradient g in P. Put beta = g + (1/3)(1,1,1).
Then beta >= 0 by (P0) and sum beta = 1. Fix eta > 0. Differentiability gives epsilon > 0 with
|Psi(y0 + z) - Psi(y0) - g·z| <= eta|z| for |z| <= epsilon. For large n, also
|psi_{R_n} - Psi| <= eta·epsilon on that ball. Unscaling, with l_n = R_n y0,

  |phi(l) - phi(l_n) - beta·(l - l_n)| <= 3 eta epsilon R_n          (*)

for every l whose projection to P lies within epsilon R_n of l_n.

*Affine trees.* Fix a slice s. In the full ternary tree of depth k, let every node be affine with
constant slice s and three equal children. A node l has children l - log 3 (1 - e_s), where e_s is
the unit vector of slice s, so the depth-k nodes are all l_n - k log 3 (1 - e_s). Iterating (P3)
gives phi(l_n) >= k mu + phi(l_n - k log 3 (1 - e_s)). Take k proportional to epsilon R_n so that
the tree stays in the ball. By (*), k mu <= k (1 - beta_s) log 3 + 3 eta epsilon R_n. Divide by k,
let n -> infinity and then eta -> 0. This gives mu <= (1 - beta_s) log 3 for every s, so
mu <= A(beta). If some beta_t = 0, then max beta >= 1/2 and mu <= (log 3)/2 = 0.549 < mu*, so
from here on every beta_t > 0.

*Triangle trees.* Fix r. In the full ternary tree of depth k, let every node be a triangle with
iso = identity. A node l has the children of Lemma 157, l - e^(x)(r), so beta·e^(x) = g_x(r).
Iterating (P3) gives phi(l_n) >= k mu + min over depth-k nodes of phi. Each depth-k node is
l_n minus a sum of k vectors e^(x_i), and by (*)
phi(l_n) - phi(node) <= k max_x g_x(r) + 3 eta epsilon R_n. Hence mu <= max_x g_x(r) for every r.
By Lemma 157, mu <= V(beta).

So mu <= min(A(beta), V(beta)) <= mu*. ∎

**Computing mu*.** V is convex: it is a maximum of functions linear in beta. Fix b = max beta.
For b > 1/2, A < 0.55 < mu*. For b in [1/3, 1/2], the vertices of {beta : max beta <= b} are the
permutations of (b, b, 1 - 2b), and V is symmetric, so V(beta) <= V(b, b, 1 - 2b). These vertices
are exactly a183's weights b = (1 + c)/3. Hence

  mu* = max_{0 <= c <= 1/2} min{ (2 - c)(log 3)/3 , V((1 - 2c)/3, (1 + c)/3, (1 + c)/3) }.

A decreases in c and V increases, so the maximum is where they cross: c* = 0.240084,
u* = 0.3807 (the KKT weights are (1 - 2u*, u*, u*)), mu* = 0.644488, 3mu* = 1.933465 and
beta* = e^(mu*) = 1.905012. The tests recompute these and check them on a grid of 1,891 points
of the simplex.

## 2. S2 is false

**Lemma 155 (the gauge potential).** Let U be the up-closure in R^3_{>0} of the union over h of
A_h / 2^h, and put Phi(v) = sup{ r : e^(-r) v ∈ U }. Then Phi is finite, satisfies (P0) and (P1),
and satisfies (P3) with mu = log 2. If S2 holds, then also Phi(v) <= log max_t v_t.

*Proof.* (1,1,1) ∈ U, so Phi(v) >= log min v. Under S2, every element of U has a coordinate >= 1,
which gives Phi(v) <= log max v. (P0) holds because U is an up-set, and (P1) holds by the
definition. For (P3), let r < min_x Phi(c_x). Then each e^(-r) c_x lies above some a_x / 2^(h_x)
with a_x ∈ A_(h_x). Lemma 154 (2A_h ⊆ A_(h+1)) lifts all three to one height H: the vector
2^(H - h_x) a_x lies in A_H. Every node is monotone and 1-homogeneous, so
e^(-r) N(c) >= N(a') / 2^H with N(a') ∈ A_(H+1). That is, e^(-r) N(c) / 2 ∈ U, and
Phi(N(c)) >= r + log 2. ∎

**Lemma 156.** mu* < log 2.

*Proof.* If A(beta) >= log 2, then max beta <= 1 - log_3 2 = 0.369 < 1/2, so all three beta_t > 0.
V(beta) = log 2 would need h2(w_t) = log 2, i.e. w_t = 1/2, for all three t, which is impossible
when sum w = 1. So min(A, V) < log 2 everywhere on the compact simplex, and by continuity the
maximum mu* is < log 2. (Numerically, V <= 0.637878 wherever A >= log 2, and mu* = 0.644488.) ∎

**Theorem 73.** Conjecture S2 is false: f(h) < 2^h for some h, and beta_s < 2.

*Proof.* If f(h) = 2^h for every h, Lemma 155 gives a potential with mu = log 2. Proposition 82
gives log 2 <= mu*, and Lemma 156 says this is false. By Proposition 78(d), f(H) < 2^H for some H,
so beta_s <= f(H)^(1/H) < 2. ∎

**Corollary 73.1.** By Lemma 154 the ratio f(h)/2^h never increases, and by submultiplicativity it
tends to 0 exponentially. By a184, Conjecture M also fails at some height.

The proof does not say at which height. f(h) = 2^h for h <= 3 (a184). The pre-registered job
`sticky-front-v1` computes f(h) exactly for h <= 9. Its S-BREAK outcome (f(h) < 2^h) is now a
prediction, but only if the first failure comes at height 9 or below. The tight structures
above live far from the leaves: their vectors are very lopsided, which takes many levels to build
from (1,1,1). An S-SUPPORT outcome up to h = 9 would therefore not contradict Theorem 73.

## 3. What this means

- **For the potential method.** Theorem 72 is essentially the end of the road. No monotone,
  homogeneous potential of any shape, with or without corrections, piecewise or smooth, can give
  a base above 1.905012. The playbook's planned potentials (a183 sec. 3; "non-Schur-concave",
  "bounded shape terms", LP potentials on log-shape grids) are all covered by Proposition 82,
  since each would be such a potential. A better lower bound for beta_s needs an argument that
  is not homogeneous, one that uses the floor (every coordinate is >= 1) in an essential way.
- **For sticky Kakeya sets.** Sticky Kakeya sets in F_3^n have between 1.90499^n - 1 and
  2^(n+1) - 1 points. The selection game cannot close this gap. Two directions remain. Either the
  game's cheap trees can be realised by actual sticky sets, which would give sticky Kakeya sets
  with fewer than 2^n points, a construction below the classical one inside the sticky class.
  Or the merges that the game counts as max are never that cheap in real sets.
- **Open questions.** (S3) Is beta_s = beta* = 1.905012? Proposition 82 shows that homogeneous
  potentials cannot tell. A proof of beta_s > beta* must use the floor. A proof of
  beta_s = beta* needs explicit trees whose lopsided vectors are built cheaply from (1,1,1).

## Checks (`test_sticky_barrier.py`, run before anything is published)

- V(1/3,1/3,1/3) = log(27/4)/3 (the a182 rate); the KKT weights satisfy the Lagrange condition
  and beat 5,000 random weight vectors; V is midpoint-convex on 200 random pairs.
- The affine trees and the triangle children are rebuilt exactly. The linear gaps equal
  (1 - beta_s) log 3 and g_x(r). The Gibbs identity sum_x w_x g_x = sum_t beta_t CE(w_t, r_t) holds,
  max_x g_x >= V for random r, and at r = w* all three gaps equal V (Lemma 157).
- c*, u*, mu*, beta* lie within the quoted ranges. min(A, V) <= mu* on a 1,891-point grid of the
  simplex. V < log 2 - 0.05 wherever A >= log 2 (Lemma 156). a183's constants come within 5e-5 of
  3mu*.
- The results file matches the code.

The blow-down step (Arzelà-Ascoli and Rademacher) is analysis, and no test checks it. It is the
step a referee should read first.

## Prior art

As in a183 and a184: we know of no earlier study of this game or of sticky Kakeya sets over finite
fields beyond the classical product construction. The argument has the same shape as the familiar
fact that a limit object, here the gauge of an invariant set, inherits local linear constraints
from its blow-down. We have not seen it used for Kakeya-type selection games. Pointers are welcome
at mv2@munimtech.com.
