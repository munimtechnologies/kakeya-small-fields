## Summary

U*(n) is the least size of a sticky Kakeya set in F_3^n. We know 1.90499^n - 1 <= U*(n) (a183)
and U*(n) <= 31 · 2^(n-4) - 1 for n >= 4 (a187). Question S7 asks whether the growth rate
beta_s = lim U*(n)^(1/n) is below 2. a187 lowered the constant in front of 2^n, not the base.

A *full tree* of height k is a sticky map P: F_3^k -> F_3^k (coordinate j of P(d) depends only on
d_1, ..., d_j), and its *slices* are S_t = {P(d) + t d : d in F_3^k}, t = 0, 1, 2. Let

  pi_k = min over full trees of height k of |S_0| · |S_1| · |S_2|,

  sigma_k = min over full trees of height k of |S_0| + |S_1| + |S_2|.

1. **Theorem 78.** The limit beta_s exists, and beta_s = lim sigma_k^(1/k) = tau^(1/3), where
   tau = lim pi_k^(1/k) = inf_k pi_k^(1/k).
2. **Corollary 78.1 (finite certificate).** beta_s < 2 if and only if some full tree of some
   height k has |S_0| |S_1| |S_2| < 8^k. Such a tree gives beta_s <= (|S_0||S_1||S_2|)^(1/(3k)).
3. **Corollary 78.2.** Every full tree of height k has |S_0| |S_1| |S_2| >= 1.90499^(3k) = 6.913^k
   (from Theorem 72). The pair bound |S_a| |S_b| >= 3^k gives only 5.196^k.
4. **Lemma 162.** One node multiplies the slice product by at least 27/4 (quadratic root map) or
   9 (affine root map), relative to the geometric mean of its children's products. So
   pi_k >= (27/4)^k with no further input, and a tree of least product never has an affine root.
5. **Proposition 83.** pi_1 = 8 and pi_2 = 64 (all 27^4 trees of height 2 are checked), and the
   classical tree P(d) = (d_j^2) attains 8^k at every height.

So S7 is now a search problem with a checkable answer. One explicit tree whose slice product
falls below 8^k at any height settles S7 in the positive. We pre-registered a search for one
(`sticky-beam-v1`). Its rules were fixed before any run, and it has not run yet.

## 1. Two operations on full trees (Lemma 161)

- *Product.* For trees A (height a) and B (height b), P(d) = (P_A(d_1..d_a), P_B(d_(a+1)..d_(a+b)))
  is sticky, and S_t(A × B) = S_t(A) × S_t(B). So sizes multiply slice by slice.
- *Slice symmetries.* P'(d) = P(eps d) + c d (eps = ±1, c in F_3) is sticky and has
  S'_t = S_(eps(c + t)). These realise all six permutations of the three slices. Adding a constant
  vector w translates every slice by w.

*Balancing.* With R(P)(d) = P(d) + d, the tree T × R(T) × R^2(T) has height 3k and slice t equal
to S_t × S_(t+1) × S_(t+2). Every slice then has exactly |S_0||S_1||S_2| points. For a187's tree T
with slices (7, 7, 13), the balanced tree has height 9 and three slices of 637 points each (tested).

## 2. Proof of Theorem 78

*Lower bound.* Let P be a sticky family in F_3^n with Kakeya set K, and let T_x be the full tree
of height n - 1 below the root value x (directions with d_1 = x). For x != 0, the line of
direction (x, d') meets the plane y_1 = u at the point (u, P_(T_x)(d') + t d') with
t = (u - g(x))/x (a186). As u runs over F_3, t runs over F_3. So the planes of K contain the three
slices of T_1, one in each plane, and |K| >= |S_0(T_1)| + |S_1(T_1)| + |S_2(T_1)| >= sigma_(n-1).
(The tests check |K| >= the slice sum of both T_1 and T_2 on 21 families, including the 30-point
set of a187.)

*Upper bound.* Theorem 74's construction from a smallest sticky set K' in F_3^(n-1) and any full
tree T of height n - 1 has |K' ∪ S_h(T)| + sum_(t != h) |S_t(T)| <= U*(n-1) + sum_t |S_t(T)|
points. Hence U*(n) <= U*(n-1) + sigma_(n-1), and

  sigma_(n-1) <= U*(n) <= 3 + sigma_1 + ... + sigma_(n-1).

*Limits.* Products of trees give sigma_(a+b) <= sigma_a sigma_b and pi_(a+b) <= pi_a pi_b, so by
Fekete's lemma lim sigma_k^(1/k) = inf sigma_k^(1/k) =: s and lim pi_k^(1/k) = inf = tau. The two
bounds above give lim U*(n)^(1/n) = s, because a sum of n terms, each at most C (s + epsilon)^k,
grows no faster than (s + epsilon)^n. By AM-GM, sigma_k >= 3 pi_k^(1/3) >= 3 tau^(k/3), so
s >= tau^(1/3). Balancing a tree of least product gives sigma_(3k) <= 3 pi_k, so s <= tau^(1/3). ∎

*Corollary 78.1.* If pi_k < 8^k for some k, then tau <= pi_k^(1/k) < 8 and beta_s < 2. If
beta_s < 2, then inf pi_k^(1/k) = beta_s^3 < 8, so some pi_k < 8^k. *Corollary 78.2.* Since tau is
an infimum, pi_k >= tau^k = beta_s^(3k) >= 1.90499^(3k). ∎

## 3. One node at a time (Lemma 162)

Let a node have root map g and children of height k - 1 with slice-size vectors c_0, c_1, c_2 and
products G_x. Let L be the node's slice sizes and Pi = L_0 L_1 L_2.

- *Affine g* (g(x) + s x constant for one s): the children's slices s share one plane, and in every
  other slice they sit in three different planes. So L_s >= max_x c_x[s] and L_t = sum_x c_x[t].
  By AM-GM, Pi^3 >= 9^3 G_0 G_1 G_2.
- *Quadratic g:* in each slice t one child iso(t) is alone in its plane, and the other two share a
  plane, with iso a bijection. Write a_t = c_iso(t)[t] and m_t for the larger of the other two.
  Then L_t >= a_t + m_t, G_0 G_1 G_2 <= prod_t a_t m_t^2, and (a + m)^3 >= (27/4) a m^2. So
  64 Pi^3 >= 27^3 G_0 G_1 G_2.

The tests check both inequalities at the root of 120 random trees and of the trees of a187.
Since the classical doubling reaches exactly 8 per level, Lemma 162 says a certificate for S7
must use quadratic nodes whose children have **different** shapes, with the two children that
share a plane nested. The game of a183-a185 counts exactly these nodes, but with max in place of
union. That is why the game's base is below 2 (Theorem 73) while the real question stays open.

## 4. Small heights (Proposition 83)

| k | 1 | 2 | 3 |
|---|---|---|---|
| pi_k | 8 | 64 | open (<= 512) |
| sigma_k | 6 | 12 | open (<= 24) |
| 8^k | 8 | 64 | 512 |

Height 2 is exhaustive over all 27^4 = 531,441 trees. A hand proof: a child of height 1 has sizes
(2,2,2) (quadratic, "Q") or 1 at one slice s and 3 at the others (affine, "A_s"). With an affine
root merging slice s, all children Q or A_s give at least 2·6·6 = 72 or 1·9·9 = 81, and any other
child forces L_s >= 3 and L_t L_t' >= 3·9, so 81. With a quadratic root (iso = identity after
reordering), product < 64 needs some L_t <= 3. L_t = 2 forces all children to be A_t, and then
the other two slices are at least 6 (product >= 72). L_t = 3 leaves four patterns (child t = A_t
with the others Q,Q / A_t,Q / Q,A_t, or child t = Q with both others A_t), whose products are at
least 75, 90, 90 and 108. a187's height-3 tree T has product 637 > 512. Every tree we know has
product at least 8^k. For height 3, `sticky_pi3.py` (part of the pre-registered job, not yet run)
computes a proved lower bound: every real height-2 size vector, then max in place of union under
all 27 root maps. A hand case analysis predicts exactly 512, which would rule out certificates of
height 3 or less.

## 5. What it means

- S7 is now a finite search. One full tree with slice product below 8^k, at any height, proves
  that sticky Kakeya sets over F_3 grow at a base below 2. We pre-registered a beam search over
  real trees up to height 10. It computes unions exactly, keeps lopsided trees alive with 28
  weight vectors, and rebuilds every hit from explicit maps before counting it.
- The window is narrow: a certificate must have product between 6.913^k (Corollary 78.2) and 8^k.
- The game relaxation's analogue of tau is below 8 (Theorem 73), so the game has such
  certificates. The question is whether real unions can come as close to maxima as the game
  allows.

## Prior art

As in a182-a187, we know of no earlier study of sticky Kakeya sets over finite fields beyond the
classical product construction. The reduction to a submultiplicative tree quantity via Fekete's
lemma is standard in spirit. We have not seen it applied here. Pointers are welcome at
mv2@munimtech.com.
