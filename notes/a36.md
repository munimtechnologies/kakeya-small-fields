## What changes

- **Lemma 88.** In (B6) and (B5) at t = 7 (every element of rank 3 is in one of them, Corollary
  56), for every non-zero w in N = ker phi: A_w maps H0 = P + span(x0) onto A_u beta(w, V); in
  (B6) this is all of Im A_w, so rank A_w = dim(beta(w, V) + ker A_u) - 4; Lemma 30 applied to w
  gives dim(beta(w, V) + span(sigma(w))) >= rank A_w + 3, so that this space meets ker A_u in
  dimension at least 3; and when rank A_w = 3, w is itself an element of (B6) or (B5), with
  sigma(w) outside beta(w, V) and dim beta(w, V) in {5, 6}. This is Lemma 72 of [a19.md](a19.md)
  at t = 7, now for both shapes and without the hypothesis that Lemma 72 (c) needed, which
  Corollary 56 supplies.
- **Corollary 57 (d = 3).** When Im A_u lies in ker A_u, every A_w (w in N) sends H0 into ker A_u,
  the restricted system of Lemma 30 on N has maps A_w restricted to ker A_u with image in Im A_u,
  and no element outside N has sigma(h) = phi(h). These facts are short; they are recorded because
  the 13 classes with d = 3 are the only ones no search has ever decided.
- The targets of a33.md and a35.md stay open: no hand proof of "x0 is not in Im A_u" and no hand
  proof that d = 3 is impossible was found. The routes tried, and the exact point where each stops,

## Lemma 88 (the elements of ker phi at t = 7)

**Lemma 88.** Let w be a non-zero element of N. Then:

(a) A_w(H0) = A_u(P_w), a subspace of R of dimension dim(P_w + X_1) - 4. In (B6), Im A_w = A_u(P_w)
    and r_w = dim(P_w + X_1) - 4; so r_w = 0 exactly when P_w lies in X_1, which is exactly when
    A_w = 0, and r_w = 3 exactly when P_w + X_1 = X. In (B5), A_u(P_w) lies in Im A_w with
    codimension at most 1, so dim(P_w + X_1) - 4 <= r_w <= dim(P_w + X_1) - 3.

(b) dim U+(w) = 10 - dim Q_w <= 7 - r_w. Hence dim Q_w >= r_w + 3 and dim(Q_w n X_1) >= 3. If w
    is not in span(u), then z_w is not in span(x0), dim(P_w n X_1) >= 2, and dim(P_w n X_1) >= 3
    when z_w lies in P_w.

(c) If r_w = 3, then w is an element of rank exactly 3 in (B6) or (B5): z_w is not in P_w,
    dim P_w is 6 or 5, dim Q_w is 7 or 6, and ker beta(w, .) has dimension 3 or 4 and contains u
    and w. In (B6), r_w = 3 forces dim(P_w n X_1) = dim P_w - 3, that is 3 or 2.

*Proof.* (a) By (N), A_w x0 = 0 and A_w phi(h) = A_u beta(w, h), so A_w(H0) = A_w(P) = A_u(P_w).
A_u has kernel X_1, so dim A_u(P_w) = dim P_w - dim(P_w n X_1) = dim(P_w + X_1) - dim X_1 =
dim(P_w + X_1) - 4. In (B6), H0 = X. In (B5), X = H0 + span(e_6) for any e_6 outside H0, so
Im A_w = A_u(P_w) + span(A_w e_6). The equivalences follow, as A_w = 0 means A_w(H0) = 0 in (B6),
and dim X = 7.

(b) w != 0, so z_w != 0 (anisotropy) and Lemma 30 (b) ([rank-restriction.md](rank-restriction.md))
applies to w: dim U+(w) <= 1 + A(7 - r_w - 1) = 1 + A(6 - r_w) = 7 - r_w, since r_w <= 3 and
A(s) = s for s <= 6. U+(w) is the preimage of P_w n span(z_w) under beta(w, .), whose image is P_w,
so dim U+(w) = (9 - dim P_w) + dim(P_w n span(z_w)). As z_w != 0, dim(P_w n span(z_w)) is 1 when
z_w lies in P_w and 0 otherwise, which is dim P_w + 1 - dim Q_w. So dim U+(w) = 10 - dim Q_w, and
dim Q_w >= r_w + 3. Now z_w lies in X_1 by (N), so Q_w + X_1 = P_w + X_1, of dimension at most
r_w + 4 by (a) (with equality in (B6)). Hence

    dim(Q_w n X_1) = dim Q_w + 4 - dim(P_w + X_1) >= (r_w + 3) + 4 - (r_w + 4) = 3.

If w is not in span(u), Lemma 30 (b) for u (w lies in U+ = N and not in span(u)) says z_w is not in
span(x0). Since z_w lies in X_1, Q_w n X_1 = (P_w n X_1) + span(z_w), of dimension at most
dim(P_w n X_1) + 1, with equality exactly when z_w is not in P_w. So dim(P_w n X_1) >= 2, and >= 3
when z_w lies in P_w.

(c) By Corollary 55, r_w = 3 is the largest rank, and by Corollary 56 w is in (B6) or (B5): z_w is
not in P_w and dim P_w is 6 or 5. Then dim Q_w = dim P_w + 1, and ker beta(w, .) has dimension
9 - dim P_w, that is 3 or 4; it contains u (beta(w, u) = phi(w) = 0) and w. In (B6), (a) gives
dim(P_w + X_1) = 7, so dim(P_w n X_1) = dim P_w + 4 - 7. QED

**Remarks.**

- At t = 6, Lemma 72 (b) gave dim Q_w >= r_w + 2 and dim(Q_w n X_1) >= 2; one dimension up, both
  bounds rise by one, with the same proof. Lemma 72 (c) needed "no element of rank exactly 3 in
  (B4)" as a hypothesis; at t = 7, Corollary 56 plays that part without a hypothesis.
- (b) says that the solver cannot derive this lemma: the bound dim U+(w) <= 7 - r_w comes from the
  anisotropic system of dimension dim U+(w) - 1 with values in ker A_w / span(z_w) (dimension
  6 - r_w) in the proof of Lemma 30, and A(5) = 5 and A(6) = 6 are theorems about every system of
  that size, not consequences of the identities of one instance. The hint conditions of job m42
  (notes/a27.md) are all of the form (N) and are weaker than Lemma 88.
- For w = u the lemma is empty (Q_u = X, r_u = 3, and u is in (B6) or (B5) by assumption). Its
  content is for the 6 elements of N outside span(u) in (B6) and the 14 in (B5), which come in pairs
  w, w + u with A_(w + u) = A_u + A_w, z_(w + u) = x0 + z_w and P_(w + u) = (phi + beta(w, .))(V).
- Whether A_w = 0 can happen for some w != 0 in N is not decided here. In Case B at rank 4, Lemma 78
  ([a24.md](a24.md)) excluded it through Lemma 60; its proof uses the tight dimension of
  Proposition 27, which (B6) and (B5) at rank 3 do not have. If A_w = 0, then (*) with h = w gives
  beta(w, h') = A_(h') z_w for every h', so P_w = {A_h z_w : h in V} lies in X_1, and (b) gives
  dim P_w >= 2 (>= 3 if z_w lies in P_w).

## Corollary 57 (the classes with d = 3)

**Corollary 57.** Let u be as above with R inside X_1 (d = 3, A_u^2 = 0). Then:

(i) for every w in N, A_w maps H0 into R, which lies in X_1 = ker A_u, so A_u A_w vanishes on H0
    (on all of X in (B6)); in (B6) and in (B5) when X_1 lies in H0, the maps of the restricted
    system of Lemma 30 on N are A_w restricted to X_1, with image in R and kernel containing x0;

(ii) for every h with p = phi(h) in Y = X_1 n P: A_h x0 = p, A_h p = p + A_u sigma(h) lies in
     p + R, which lies in X_1, and A_h (x0 + p) = A_u sigma(h + u) lies in R;

(iii) no h outside N has sigma(h) = phi(h). (In general, sigma(h) = phi(h) = p != 0 forces A_h p = 0
     and A_u p = p, a non-zero fixed vector of A_u, which d = 3 forbids.)

*Proof.* (i) is (N) with R inside X_1; the restricted system is the one in the proof of Lemma 30
(b), whose maps are A_w restricted to X_1 and projected onto X_1, and no projection is needed when
A_w(X_1) lies in R. (ii) (1) of a24.md gives A_h x0 = (I + A_u) p = p, as p lies in X_1; (*) with
h' = u gives A_u sigma(h) = (I + A_h) p; and sigma(h + u) = x0 + sigma(h) + p with A_u x0 = A_u p
= 0. (iii) If sigma(h) = p = phi(h), then A_h p = A_h sigma(h) = 0 and A_u sigma(h) = (I + A_h) p
reads A_u p = p. Then p lies in R and A_u p = p != 0; but R lies in X_1 = ker A_u. QED

None of (i) to (iii) is beyond the solver: each is a few steps of unit propagation from the unit
clauses and the hint conditions of job m42, which is why they are a corollary and not a new
condition. They are the whole of what d = 3 adds to (N) by hand so far.

## What was tried on d = 3, and where it stops

Each route is recorded with its last true statement, so that it is not repeated.

1. *The form C of case-a-radical.md in Case B.* By (N), the class of A_h q modulo R, for h over p
   and q in H0, depends only on p = phi(h): C(p, q) = [A_h q] in X / R is a well-defined bilinear
   map P x H0 -> X / R, symmetric on P x P by (2) of a24.md, with C(p, p) = [p] (from
   A_u sigma(h) = (I + A_h) p) and C(p, x0) = [p] (from (1)). So C(p, p + x0) = 0 for every p:
   A_h (x0 + phi(h)) = A_u sigma(h + u) for every h, which is only Lemma 21 (b) for h + u. The
   radical Rad = {p : C(p, .) = 0} lies in R n P, and for p in Rad and h over p, A_h maps H0 into
   R. In Case A (Lemmas 51 and 77) the contradiction came from elements over x0 + Rad, which do
   not exist here because x0 is not in P. Nothing further was found.

2. *x0 in Im A_u.* Suppose x0 = A_u y with y in P, and let v be over y. Then A_v x0 = x0 + y,
   A_v y = y + A_u sigma(v), and in d = 3 also A_u A_v y = x0, so A_v y lies in y + R. For
   w = v + u (also over y) the same holds with sigma(w) = sigma(v) + x0 + y. Lemma 30 for v bounds
   dim U+(v) by 7 - rank A_v, but nothing here pins down rank A_v or P_v, and the step of Lemma 52
   that handled x0 in R used elements over x0 + r, which Case B does not have. Nothing further was
   found. (The solver's evidence stays as in a35.md: 91 of 97 kind-L classes with d <= 2 closed in
   (B5), 2 of 15 in (B6).)

3. *The restricted system on N.* In (B5), dim N = 4 = 1 + A(3): Lemma 30 for u is tight, and
   N / span(u) carries an anisotropic system of dimension 3 with values in X_1 / span(x0), also of
   dimension 3, with the maps induced by A_w restricted to X_1 (by Corollary 57 (i), without
   projection when X_1 lies in H0). Lemma 30 inside this small system gives, for w outside
   span(u), rank of A_w on X_1 modulo x0 at most 2 and, when it is 2, U+(w) n N = span(u, w): then
   beta(w, n) is neither 0 nor z_w for n in N outside span(u, w). Both facts are elementary (they
   need only A(1) = 1 and the two independent vectors x0, z_w in ker A_w n X_1), so the solver has
   them already. Maximal anisotropic systems with t = dim V = 3 are not classified in these notes
   (sigma(x) = x^3 on F_8 and a linear one-to-one sigma are two of them), so the tightness gives
   no structure beyond this.

4. *Elements over Y = X_1 n P.* Corollary 57 (ii) is all that (1), (*) and d = 3 give for them;
   the subspace phi^(-1)(Y) (dimension 6 in (B6)) carries no system with values in a proper
   subspace that could be seen, because A_u sigma(h) in R holds for every h.

5. *Lemma 88 as a solver condition.* In an instance of job m42 only A_u is fixed, so r_w and P_w
   are unknown and (b) is a rank condition on nine vectors, not a set of unit clauses. It becomes
   linear only after a second matrix A_w is fixed (the split of Lemma 71 at t = 6), and at t = 7
   that split has 2^18 candidates for A_w per value of z_w in (B6) (maps from X / span(x0) to R),
   against a stabiliser of order 168 x 2^9 = 86016 for the kind-P class; the count of classes was
   not done, and no such job is designed here.

So the 13 classes with d = 3 still need either a hand fact that is not in these notes, or budgets
far above 250 s. Jobs m45 to m48 give them about 9 to 11 minutes each; if they stay open there, the
second-matrix split of route 5 is the remaining machine route, and its class count by hand comes
first, as for jobs m43 and m44.
