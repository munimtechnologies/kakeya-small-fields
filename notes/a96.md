## Lemma 109 (anisotropy on a coset of N)

Notation as in [a93.md](a93.md) and [a94.md](a94.md): u is in (B7)_8 at t = 8, dim V = 11, in the
rank-0 case, N = ker phi (dimension 4), pi : X -> Q = X / X_1, and T_n is the map of Lemma 104 (a),
so A_n = A_u-bar T_n pi and pi beta(n, h) = T_n pi phi(h).

**Lemma 109.** For h in V define L_h : N -> X by L_h(n) = sigma(n) + beta(n, h). Then:

(a) L_h is linear;

(b) pi L_h(n) = T_n pi phi(h) for every n in N, so pi L_h(N) = T(N) pi phi(h);

(c) if h is not in N, then sigma(h + n) = sigma(h) + L_h(n) for every n in N, and sigma(h) is not in
    L_h(N);

(d) if h is not in N and T(N) pi phi(h) = Q, there is an n in N with sigma(h + n) in X_1, and
    sigma(h + n) != 0.

*Proof.* (a) In the rank-0 case sigma is linear on N and beta vanishes on N x N (Lemma 103 (b)), and
beta is bilinear. (b) sigma(n) lies in X_1 for n in N (facts (N) of [a92.md](a92.md)), so
pi L_h(n) = pi beta(n, h) = T_n pi phi(h) by Lemma 104 (a). (c) sigma(h + n) = sigma(h) + sigma(n)
+ beta(h, n), and beta is symmetric. If sigma(h) = L_h(n), then sigma(h + n) = 0 with h + n != 0,
against anisotropy. (d) By (b) there is an n with pi L_h(n) = pi sigma(h), so
sigma(h + n) = sigma(h) + L_h(n) lies in X_1, and it is not 0 by (c). QED

**What it gives.** T(N) pi phi(h) = Q can only happen in the t3 cases, where T(N) is an algebra and
T(N) q is the submodule generated by q. In a t2 case T(N) q = span(q, Mq) has dimension at most 2.
When k = 2 (T(N) = F_8), every q != 0 generates Q, so (d) holds for every h with phi(h) outside X_1.
phi^(-1)(X_1) = N + span(h_1, ..., h_4) has dimension 8 (phi(h_j) = e_j in the normal form, and
X_1 n P = span(e_1, ..., e_4)), so these are 112 of the 128 cosets of N. So in an F_8 case, each of
those 112 cosets contains a vector y with 0 != sigma(y) in X_1 = ker A_u. Lemma 109 alone gives no
contradiction. A proof of the k <= 4 cases would have to combine (d) with Lemma 105 (each w != 0
in N_0 has C_w = beta(w, V) + span(sigma(w)) of dimension 4 inside X_1, without x0) and with d,
which the solver data say matters. Job m104c tests whether the refutations need anisotropy beyond N
and the seven cosets h + N with h in span(h_5, h_6, h_7), the h with pi phi(h) != 0 in the normal
form.
