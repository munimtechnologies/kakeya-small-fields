## 1. Proposition 85: pi_4 >= 3971

**Proposition 85.** Every full sticky tree of height 4 over F_3 has |S_0||S_1||S_2| >= 3971. So
pi_4 lies in [3971, 4096], improving a189's [3456, 4096].

*Proof.* At a node with root map g and children T_0, T_1, T_2,
S_t(T) = union over x of {g(x) + t x} x S_t(T_x) (a188, Section 3). A union is at least its
largest member, so every real slice-size vector dominates (coordinatewise) the game vector of a
tree with the same shape, and the game is monotone, so every real vector of height h dominates
an element of the exact game front at height h. `sticky_front.py` builds these fronts from the
leaf (1,1,1) with the three affine moves and the triangle move over all ordered child triples,
which covers all 27 root maps (9 affine, 18 quadratic; a188, Lemma 162). It discards vectors with
a coordinate above 512; a real slice of height h has at most 3^h <= 243 points for h <= 5, and its
dominated game vectors and all their descendants stay below that, so nothing needed is
discarded. The front at height 4 has least product 3971. ∎

Two cross-checks in the output: the height-2 front is exactly the list of 19 minimal real
height-2 vectors found exhaustively in a189, and the height-3 front has least product 512
(Proposition 84).

**The extremal shape.** 3971 = 11 · 19 · 19, attained by (11,19,19) and its permutations. One
derivation (found by hand from the published height-3 front, a quadratic node with the isolated
child listed first in each slice):

(11,19,19) = triangle( (4,12,12), (7,7,12), (7,12,7) ),
(7,7,12) = triangle( (3,4,8), (4,3,8), (4,4,4) ).

Here triangle(A,B,C) = (A_0 + max(B_0,C_0), B_1 + max(A_1,C_1), C_2 + max(A_2,B_2)). Every max is
attained with equality between equal sizes, so a real tree with these sizes needs the two
plane-sharing children to have **identical** slice sets in each slice. The height-5 witness
(30,30,30) = triangle((11,19,19), (19,11,19), (19,19,11)) is built from these shapes.

## 2. Lemma 164: the relaxation is not exact at height 3

**Lemma 164.** (a) Every real height-2 tree with slice sizes (3,4,8) has a constant root map,
and its slice S_1 meets all three planes {p = u}. (b) Every real height-2 tree with sizes
(4,4,4) has a quadratic root map, and each of its slices meets exactly two planes. Hence, in the
derivation of (7,7,12) above, |S_1(A) u S_1(C)| >= 5 > 4 for every choice of real trees, and that
derivation is not realised.

*Proof.* (a) With a quadratic root every slice is one child's set plus the union of two
children's sets inside a second plane, so it has at most 3 + 3 = 6 < 8 points. So the root is
affine, with one slice s in which all three children share one plane (at most 3 points) and two
slices in which they sit in three different planes. Only slice 0 has at most 3 points, so s = 0,
which means g(x) + 0 · x is constant. In slice 1 the planes g(x) + x are then all different, and
each child's set is non-empty. (b) An affine root has a slice of at most 3 points, so the root is
quadratic, and then g(x) + t x takes exactly two values for each t. ∎

So the game's cheapest height-4 shape is built on a height-3 shape that cannot be realised in
the way the game builds it. This does not yet show that 3971 is not attained by real trees
(other derivations exist), but it shows that the game is not the right tool at height 3.
