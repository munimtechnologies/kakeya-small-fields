# a179. The fort polynomial: on almost every sparse support pattern, SR* holds for every choice of weights

This is **not** a new Kakeya bound. a178 proved the frame square-root conjecture SR* for
almost every linear part, but there the weights were random as well. Here the weights
are taken out of the randomness. Only the support pattern of M is random, and the bound
then holds for **every** weighting of that pattern, including adversarial, rank-degenerate
ones. The tool is a bound that depends only on the digraph of M, called its fort
polynomial.

## 0. Setting (as in a177 and a178)

q is an odd prime power and Y is uniform on F_q^k. For a k x k matrix M over F_q put
F(y) = y o y + My and H(M) = H(Y | F(Y)) (bits). Put a = (q-1)/q and b = 2^(1-1/q).

    SR*:  H(M) <= k(1 - 1/q),   i.e.   2^H(M) <= b^k.

For P(x) = A((Sx) o (Sx)) + Lx + c with A, S invertible, Lambda(P) = sum_t H(M_t), where
M_t = A^-1 (L + tI) S^-1 (a174 Cor 58.2). C_q(k) for P is Lambda(P) <= k(q-1).

The digraph G(M) has an arc i -> j when i != j and M_ij != 0 ("row i reads column j").
A set T in [k] is a **fort** of G if no vertex outside T has exactly one out-neighbour in
T (Fast and Hicks 2018). Here the empty set also counts as a fort.

**Pair count (a174 Thm 58).** E_y N_y = sum_T q^-|T| V(T), where V(T) counts the d with
support exactly T and (Md)_i = 0 for every i outside T. Jensen gives 2^H(M) <= E_y N_y.

## 1. The fort polynomial (Propositions 74 and 75)

**Definition.** For a digraph G on [k],

    Phi_q(G) = sum over forts T of G (the empty set included) of a^|T|.

**Proposition 74.** For every M over F_q,

    E_y N_y <= Phi_q(G(M)),   hence   H(M) <= log2 Phi_q(G(M)).

The bound depends only on the support pattern. It ignores the diagonal and the values
of the nonzero off-diagonal entries.

*Proof.* Suppose T is nonempty and not a fort. Then some row i outside T has exactly one
nonzero entry M_ij with j in T, so (Md)_i = M_ij d_j != 0 for every d of support T,
and V(T) = 0. For every T, V(T) <= (q-1)^|T|, the number of vectors of support T.
Hence q^-|T| V(T) <= a^|T| on forts and is 0 elsewhere. Then apply Jensen. []

Phi_q multiplies over disjoint unions of digraphs. With no arcs, every set is a fort and
Phi_q = (1 + a)^k = (2 - 1/q)^k, the DKSS/Jensen level. For a directed k-cycle the only
forts are the empty set and [k], so Phi_q = 1 + a^k. Every weighted cycle, with any
diagonal, therefore has H(M) <= log2(1 + a^k), which tends to 0.

**Proposition 75 (reader packings).** For a fort T, a *packing* is a set P of rows
outside T whose out-neighbourhoods inside T are nonempty and pairwise disjoint. Let
m_i = |N(i) ∩ T| and pi(m) = (1 + (q-1)(-1/(q-1))^m)/q. Then

    V(T) <= (q-1)^|T| * min over packings P of prod_{i in P} pi(m_i).

Here pi(1) = 0 and pi(m) <= 1/(q-1) for m >= 2, so this sharpens Proposition 74 by a
factor of at most 1/(q-1) for each disjoint reader.

*Proof.* The rows in P constrain disjoint blocks B_i of coordinates. Substituting
e_j = M_ij d_j maps (F_q^*)^(B_i) bijectively onto itself, and the number of e in
(F_q^*)^m with e_1 + ... + e_m = 0 is ((q-1)^m + (-1)^m (q-1))/q = (q-1)^m pi(m), by
orthogonality of additive characters. The other rows can only lower the count. []

## 2. Random patterns, every weighting (Lemma 142, Theorem 67)

Let G ~ D(k, p): each of the k(k-1) arcs is present independently with probability p.

**Lemma 142.** With g_0 = 1 and g_t = 1 - t p (1-p)^(t-1) for t >= 1,

    E_G Phi_q(G) = sum_{t=0}^{k} C(k,t) a^t g_t^(k-t).

*Proof.* A vertex outside T has Bin(|T|, p) out-neighbours in T. These are independent
across vertices, and g_t = P(Bin(t, p) != 1). []

**Theorem 67.** Let q be an odd prime power, 1 <= c <= 4, k >= 100 and p = c/k. Then

    P_G( Phi_q(G) >= b^k ) <= 0.9582^k + 0.9500^k + 0.9570^k.

So, with at least that probability, **every** matrix M whose off-diagonal support is
exactly G, with any nonzero values and any diagonal, satisfies strict SR*:
H(M) <= log2 Phi_q(G) < k(1 - 1/q). For example, the failure probability is below 0.033
at k = 100 and below 1e-9 at k = 500.

*Proof.* By Markov, the probability is at most E_G Phi_q(G) / b^k. Split the sum in
Lemma 142 at t1 = ceil(k/5) and t2 = floor(13k/20).

- *Head (t < t1, so t < k/5).* Since g_t <= 1, for 0 < z <= 1 the head is at most
  sum_{t <= k/5} C(k,t) a^t <= z^(-k/5) (1 + az)^k. With z = 1/(4a) this is
  (2^H2(1/5) a^(1/5))^k = (r_head b)^k.
- *Tail (t > t2, so t > 13k/20).* For z >= 1 the tail is at most z^(-13k/20) (1 + az)^k.
  With z = 13/(7a) this is (2^H2(13/20) a^(13/20))^k = (r_tail b)^k.
- *Middle.* h(t) = t p (1-p)^(t-1) is log-concave in t, because h(t+1)/h(t) = (1 + 1/t)(1-p)
  decreases. So on [t1, t2] it is smallest at an endpoint. Using
  ln(1-p) >= -p - p^2 (valid for p <= 1/2) and p <= 0.04:
  h(t1) >= (c/5) e^(-(c/5)(1+p)) >= 0.2 e^(-0.208) > 0.1624, since x e^(-1.04x) increases
  for x < 0.96. Also h(t2) >= (13c/20 - p) e^(-(13c/20)(1+p)) >= min(0.61 e^(-0.676),
  2.56 e^(-2.704)) > 0.1713, by log-concavity in c. So g_t <= 1 - m with m = 0.16 on the
  middle range, and the middle part is at most sum_t C(k,t) a^t (1-m)^(k-t) = (1 + a - m)^k
  = (r_mid b)^k.

**Constants for every odd q.** Write u = 1/q in (0, 1/3].
- log2 r_head = H2(1/5) - 1 + u + (1/5) log2(1-u). This increases in u, so q = 3 is the
  worst case: r_head = 0.958113... < 0.9582.
- log2 r_tail = H2(13/20) - 1 + phi(u) with phi(u) = u + 0.65 log2(1-u). phi is concave
  with its maximum at u* = 1 - 0.65/ln 2, which gives r_tail <= 0.95664 < 0.9570 for
  every q.
- r_mid = (1.84 - u) 2^(u-1). This increases in u on [0, 0.397], so its maximum is at
  q = 3: r_mid = 0.94914 < 0.9500. []

**Corollary 67.1 (Kakeya, every weighting).** Let A and S be invertible *diagonal*
matrices. Every slice M_t = A^-1 (L + tI) S^-1 has the same off-diagonal pattern as L. So
for every map P(x) = A((Sx) o (Sx)) + Lx + c,

    Lambda(P) <= q log2 Phi_q(G(L))                        (deterministic),

and for G ~ D(k, c/k) with 1 <= c <= 4 and k >= 100, with probability at least
1 - (0.9582^k + 0.95^k + 0.957^k), **every** such P whose L has off-diagonal support G
satisfies Lambda(P) < k(q - 1). No union bound over the q slices is needed, because all
slices share one pattern.

**Corollary 67.2 (a linear gap).** By Markov at level 2^-s b^k,
P(log2 Phi_q(G) >= k(1 - 1/q) - s) <= 2^s (0.9582^k + 0.95^k + 0.957^k). With s = 0.03k:
with probability at least 1 - 3 (0.97834)^k, every M on G has H(M) <= k(1 - 1/q - 0.03),
and every P as in Corollary 67.1 has Lambda(P) <= k(q - 1) - 0.03qk.

**Numerical remark (not part of the proof).** The exponent of the t = tau k term of
Lemma 142 tends to H2(tau) + tau log2 a + (1-tau) log2(1 - c tau e^(-c tau)). At q = 3,
on a grid of 999 values of tau, its maximum stays below 2/3 - 0.005 at c = 0.3 and at
c = 8. The same method should therefore cover roughly 0.3 <= c <= 8 at q = 3 with other
split points. At c = 0.1 and at c = 12 the exponent exceeds 2/3 at some tau, so plain fort
counting cannot work there. This is expected. Very sparse patterns have many unread
columns, which are singleton forts; peeling (a177 Lemma 139) handles those. Dense
patterns include the all-ones matrix cJ, which is near-extremal (a175 Thm 61), so no
statement that holds for every weighting can be proved by counting alone there.

## 3. Where this sits

| result | randomness | conclusion |
|---|---|---|
| a177 Thm 64 | none (needs half rank expansion, which depends on the weights) | SR* |
| a178 Thm 66 | pattern **and** weights random, pk >= 1 | SR* for almost every M |
| **a179 Thm 67** | pattern random, 1 <= pk <= 4; **weights arbitrary** | SR* for every weighting of almost every pattern |
| a179 Prop 74 | none | H(M) <= log2 Phi_q(G(M)) |

Theorem 67 covers matrices that a177 and a178 cannot reach. Take a random sparse pattern
and choose weights that make many 2 x 2 minors vanish. Then the weights are not random,
and half rank expansion fails, but the fort polynomial does not change.

## 4. What this does and does not do

Done:
- A weight-free bound H(M) <= log2 Phi_q(G(M)) for every frame matrix (Prop 74), with a
  sharpening by disjoint readers (Prop 75).
- An exact formula for E Phi_q over D(k, p) (Lemma 142).
- For every odd q, 1 <= pk <= 4 and k >= 100: with failure probability at most
  0.9582^k + 0.95^k + 0.957^k, SR* holds for every weighting of the pattern, with a linear
  gap 0.03k (Theorem 67, Cor 67.2). The same holds for the conjugated Kakeya maps
  (Cor 67.1).

Not done:
- Dense patterns with adversarial weights. For those no proof can rest on the pattern
  alone, because cJ is near-extremal. The open frame case is now **dense, structured
  weightings of high rank**.
- Explicit (non-random) families of patterns with Phi_q(G) < b^k for every k. de Bruijn
  digraphs are a natural candidate. Their forts are unions of "child pairs", plus splits
  that force both parents into T. Bounding this was not done.
- Other algebras (a173's general unital SR*), and C_q(k) for all maps, which is the
  actual Kakeya problem.

Prior art: forts and zero forcing come from Fast and Hicks (Discrete Applied Math. 2018),
and the first-moment method is standard. SR*, the entropy functional and the pair count
are MV2's own (notes a159-a178). We found no earlier use of fort counts to bound
fibre entropies of quadratic maps. A search on 2026-11-18 still found no improvement on
Bukh-Chao (Discrete Analysis 2021:26) for the fixed-q Kakeya constant.

## 5. Exact checks (`test_fortpoly.py`)

- pi(m) by brute force over (F_q^*)^m for q = 3, 5 and m <= 4, plus the stated values and
  bounds.
- Propositions 74 and 75 on 33 random sparse matrices at (q, k) = (3,3), (3,4) and (5,3),
  with nonzero diagonals, all exact. The checks are: a174's pair count; V(T) = 0 on
  non-forts; V(T) <= (q-1)^|T| times the packing factor; E N <= Phi* <= Phi; and the
  integer inequality prod_y N_y <= Phi^(q^k).
- Cycles of length 3-6 (only the empty set and [k] are forts, so Phi = 1 + a^k),
  multiplicativity over a disjoint union, and the pattern with no arcs.
- Corollary 67.1 (deterministic part) on 11 random conjugated maps at (3,3) and (5,3):
  each slice of P has the same fibre structure as the frame map of M_t, all slices share
  L's pattern, and prod_t prod_x N_x <= Phi^(q^(k+1)) exactly.
- Lemma 142 by summing over every digraph, exactly as Fractions, at (q, k, p) =
  (3,3,1/3), (3,4,1/2), (5,4,3/4), (3,4,1/5) and (5,3,1).
- Theorem 67: the three ratio constants for every odd q < 2001, together with the
  concavity and monotonicity facts for all q; the middle-range bound m >= 0.16 at the
  analytic endpoints, plus a direct grid over 100 <= k <= 2000 and 61 values of c in
  [1, 4]; exact E Phi < b^k (as E^q < 2^(k(q-1))) and the stated bound at
  (q, k, c) = (3,100,1), (3,100,4), (5,100,2) and (3,100,5/2).
- The numerical remark, on its grid.
