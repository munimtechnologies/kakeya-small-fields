## Summary

1. **Theorem 72.** Every sticky Kakeya set K in F_3^n has |K| >= 1.90499^n - 1.
2. **Corollary 72.1.** The smallest Kakeya sets in F_3^n are not sticky (in any basis) for all
   large n. Kopparty, Lev, Saraf and Sudan (KLSS, Theorem 8 at q = 3) give Kakeya sets of size
   (3 * 2^(-2/3))^(n + O(sqrt n)) = 1.889882^(n + O(sqrt n)), and 1.889882 < 1.90499.
3. **Proposition 78.** The selection game is submultiplicative. Its growth constant
   beta_s = lim f(h)^(1/h) exists and equals inf_h f(h)^(1/h), so Conjecture S2 holds iff
   f(h) = 2^h for every h. Now 1.90499 <= beta_s <= 2.

a182 proved the sticky bound with base (27/4)^(1/3) = 1.889882, which is exactly the KLSS base, so
it could not tell sticky sets apart from the smallest known sets. Theorem 72 separates them. In the
Euclidean problem, Wang and Zahl (2025) reduce the Kakeya conjecture in R^3 to sticky sets. Over
F_3, coordinate-by-coordinate stickiness is provably not where the extremal sets live.

## 1. Setting (recalled from a182 and the pre-registration)

K is *sticky* if, in some basis, there are points P(d) (d != 0) with P(d) + F_3 d in K and
coordinate j of P(d) depending only on (d_1, ..., d_j). Extend P to d = 0 through the same prefix
maps, and choose its last coordinate freely. The prefix tree of F_3^n is a ternary tree of
depth n. The node at prefix a carries the map g_a(x) = P(d)_j for d_<j = a and d_j = x. Every map
of F_3 is either affine with a constant slice s, or a triangle (degree 2). For a triangle, each
slice t: x -> g(x) + t x merges two children and isolates the third, iso(t), and iso is a
bijection. **Lemma 149** gives |Im Y_t| >= L_t(root), where Y_t(d) = P(d) + t d, and L is built from
the leaves (1, 1, 1) by

- affine(s): L_s = max_x L_s(x), and L_t = sum_x L_t(x) for t != s;
- triangle: L_t = L_t(iso(t)) + max_{x != iso(t)} L_t(x).

Hence |K| >= max_t L_t(root) - 1, where the -1 removes the point of d = 0. Let f(h) be the minimum
of max_t L_t over all trees of height h.

## 2. The potential

For 0 <= c <= 1/2 and a positive vector v, let

  phi_c(v) = (1 + c) (log v_0 + log v_1 + log v_2) - 3c max_t log v_t.

Then phi_c(1, 1, 1) = 0, and phi_c(v) <= 3 log max_t v_t because the logs sum to at most
3 log max and 1 + c >= 0. phi_c is nondecreasing in each coordinate, since 1 - 2c >= 0. Let h2 be
the binary entropy in nats.

**Lemma 153.** Let 0 <= c <= 1/2 and 0 < u < 1/2. At any node, for any positive child vectors
c_0, c_1, c_2 and the parent p they produce,

  phi_c(p) >= lambda(c, u) + min_x phi_c(c_x),
  lambda(c, u) = min{ (2 - c) log 3 ,  2(1 + c) h2(u) + (1 - 2c) h2(1 - 2u) }.

*Proof.* Let m be an index where log p_t is largest. Put alpha_m = 1 - 2c and alpha_t = 1 + c for
t != m. Then alpha_t >= 0, sum_t alpha_t = 3 and phi_c(p) = sum_t alpha_t log p_t. For every
child, max_t log c_x[t] >= log c_x[m], so phi_c(c_x) <= sum_t alpha_t log c_x[t]. With
d_t(x) = log(p_t / c_x[t]) and any probability vector w on the children,

  phi_c(p) - min_x phi_c(c_x) = max_x (phi_c(p) - phi_c(c_x)) >= sum_t alpha_t D_t,
  D_t = sum_x w_x d_t(x).

*Affine node, constant slice s.* For t != s, p_t = sum_x c_x[t]. Concavity of log gives
log sum_x c_x[t] >= sum_x w_x log(c_x[t] / w_x), so D_t >= H(w) = log 3 for uniform w. Also
D_s >= 0 because p_s = max_x c_x[s]. The gain is at least (3 - alpha_s) log 3 >= (2 - c) log 3.

*Triangle node.* Fix t. Let i = iso(t), let j be the non-isolated child with the larger t-coordinate
B = c_j[t], and let k be the other one. Then p_t = A + B with A = c_i[t], and c_k[t] <= B, so

  D_t >= w_i log(p_t/A) + (1 - w_i) log(p_t/B) = -w_i log r - (1 - w_i) log(1 - r) >= h2(w_i),

where r = A/(A + B). The last step holds because cross-entropy is at least entropy. Now choose
w_{iso(m)} = 1 - 2u and w_{iso(t)} = u for the two t != m (iso is a bijection). The gain is at
least 2(1 + c) h2(u) + (1 - 2c) h2(1 - 2u). ∎

**Theorem 72.** f(h) >= exp(lambda h / 3) for every h. With c = 0.24 and u = 0.38,
lambda = 1.9334406 > log(27/4) = 1.9095425, so f(h) >= 1.90499^h. Every sticky Kakeya set in
F_3^n has |K| >= 1.90499^n - 1.

*Proof.* By induction with Lemma 153, phi_c(root) >= h lambda, since phi_c(1, 1, 1) = 0. Then
3 log max_t L_t(root) >= phi_c(root). The numbers are (2 - 0.24) log 3 = 1.9335576 and
2.48 h2(0.38) + 0.52 h2(0.24) = 2.48 (0.6640641) + 0.52 (0.5510799) = 1.9334406, and
exp(1.9334406 / 3) = 1.9049966. The bound on |K| then follows from Lemma 149. ∎

*Checks* (`test_sticky_potential.py`; they run before anything is published):
- the two rates are recomputed to 1e-8;
- Lemma 153 is tested on 5,832 grid triples and 3,000 random triples of real vectors, over all
  9 node types, including the obstruction shape (1,2,1/2), (2,1,1/2), (2,2,1/4) of the

- a configuration where every Gibbs step is an equality reproduces the triangle rate exactly;
- every vector on the exact Pareto fronts of heights 1-3 satisfies phi >= h lambda.

**Corollary 72.1.** For all large n, no Kakeya set in F_3^n of minimum size is sticky.
*Proof.* KLSS give Kakeya sets of size 1.889882^(n + O(sqrt n)), which is below 1.90499^n - 1
once n is large. ∎

## 3. Where the bound comes from, and where it stops

The a182 bound is the special case c = 0 with uniform weights. Every triangle then contributes
exactly log(27/4), and the bound is tight for one triangle whose children are a vector m with one
coordinate halved. The new term -3c max log rewards the slice that holds the parent's largest
coordinate. Triangles then gain because the proof may weight the isolated children unevenly. The
price is paid at affine nodes, which grow only (2 - c) log 3 when the constant slice is not the
largest one. The two rates meet at c = 0.2401.

Consider potentials of the form "minimum over slice relabellings of sum_t alpha_t log v_t". With
ranked weights (a1, a2, a3), the same proof needs only the affine condition, which depends only on
the largest weight a1, and the triangle gain, which is convex in the weights. So for fixed a1 the
best choice is one of the two extremes, (a1, a1, 3 - 2a1) (ours) or (a1, b, b). To second order in
the spread, ours gains four times as much. We have not proved that this family stops at a base of
about 1.9050, but we expect it does. The affine case is tight on the family (1, 3^h, 3^h), whose maximum 3^h is far above
2^h. A potential that also sees the size of the largest coordinate should therefore do better.
That is the next step, by computer search over two-level potentials.

## 4. Proposition 78 (composition)

Let A_h be the set of vectors reachable at height h. **(a)** A_h is invariant under permuting
slices, and coordinatewise products satisfy A_{h1} * A_{h2} ⊆ A_{h1+h2}. **(b)** Hence
f(h1 + h2) <= f(h1) f(h2), and beta_s = lim f(h)^(1/h) = inf_h f(h)^(1/h) exists (Fekete).
**(c)** With P_h = min over A_h of v_0 v_1 v_2, P_h^(1/3) <= f(h) and f(3h) <= P_h, so
beta_s^3 = lim P_h^(1/h). **(d)** Conjecture S2 (f(h) = 2^(h - o(h))) holds iff f(h) = 2^h for
every h, iff P_h = 8^h for every h. A single height with f(h) < 2^h refutes S2.

*Proof.* (a) Relabel the constant slices and bijections. To compose, hang a height-h2 tree with
root vector w under every leaf of a height-h1 tree. Each L_t is built from the leaf values by max
and +, both of which are 1-homogeneous, so the root becomes (v_t w_t). (b) Take v and w attaining
f(h1) and f(h2). (c) Multiply v by its two cyclic relabellings. (d) This follows from (b): if
f(h) < 2^h for some h, then beta_s <= f(h)^(1/h) < 2. ∎

Note for the pre-registered job sticky-front-v1, added after its rules were fixed: by (d), its
S-BREAK outcome (f(h) < 2^h for some h <= 9) would refute Conjecture S2 outright, whether or not the
witness is realised by an actual sticky set. Theorem 72 says any such h has f(h) >= 1.90499^h.

## Prior art

We know of no lower bound for any structured class of Kakeya sets over a fixed small field that
beats the KLSS base, and no finite-field result that separates sticky sets from extremal ones.
Searches covered Dvir; Dvir-Kopparty-Saraf-Sudan; Kopparty-Lev-Saraf-Sudan (J. Algebr. Comb. 34,
2011); Bukh-Chao; Wang-Zahl; and the "plany" finite-field Kakeya work (arXiv:2507.09605). The
notion of sticky set used here is a182's coordinate-by-coordinate one. Pointers are welcome at
mv2@munimtech.com.
