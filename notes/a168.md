## 0. Summary

Program: the exact Kakeya constant of F_q (a159-a167). For a map P of F_q^k let

    Lambda(P) = sum_{t in F_q} H(X | P(X) + tX)      (bits, X uniform on F_q^k).

Conjecture C_q(k) says Lambda(P) <= k(q-1). By Theorem 2, C_q(k) for every k is equivalent to
q 2^(-(q-1)/q) being the exact Kakeya growth constant of F_q (best published lower bound:
q/(2 - 1/q), Bukh-Chao 2021). Until now the programme had two ways to go down one
dimension: the chain rule (Theorem 4), which needs P to *respect* a subspace, and the Jensen
or sliced Jensen bounds (Theorems 42, 45), which lose information inside each slice.
a167 showed that these tools alone cannot prove C_q(k) for quadratic maps once k >= 4.

This note adds a third tool. It needs no respected subspace and loses nothing inside the
slices beyond what the induction hypothesis already allows:

> **Theorem 47 (peeling).** Let P be any map of F_q^k (k >= 2) and f any *graph slicing*
> (defined below; every nonzero linear functional is one). Then
>
>     Lambda(P) <= ell_P(f) + E_z Lambda(P'_z),     ell_P(f) := sum_t H(f(X) | P(X) + tX),
>
> where P'_z, the slice f = z projected along a fixed direction, is a map of F_q^(k-1). If P
> is a polynomial map of degree <= d and the slicing is linear (or affine in the graph
> variable), every P'_z also has degree <= d.

> **Corollary 47.1 (the one-coordinate criterion).** Let 𝒞 be a class of maps that is closed
> under slicing and projecting (all maps; maps of degree <= d with affine graph slicings).
> If C_q(k-1) holds on 𝒞, and every P in 𝒞 on F_q^k has a graph slicing with
> ell_P(f) <= q - 1, then C_q(k) holds on 𝒞. In particular, the exact Kakeya constant of
> F_q follows from
>
>     (*)  for every k and every map P of F_q^k there is a graph slicing f with
>          sum_t H(f(X) | P(X) + tX) <= q - 1,
>
> a statement about ONE coordinate at a time, with the one-dimensional constant q - 1.

> **Proposition 54 (sharpness).** For the squaring map z -> z^2 of F_(q^k) (q odd, k >= 1),
> ell(psi) = q - 1 exactly for EVERY nonzero linear functional psi, while
> Lambda = q - q^(1-k). So the constant q - 1 in (*) cannot be lowered, even for maps far
> from the extremal frame products.

> **Proposition 55 (the Q_4 counterexamples satisfy (*)).** For the family G_n of a167
> (G_n(w, tau) = (tau w, Phi(w)), which respects no subspace and breaks the Jensen route),
> slicing by tau gives ell(tau) <= q - 1 for every odd q >= 7 and n >= 2, for q = 5 and
> n >= 2, and for q = 3 and 2 <= n <= 4. Asymptotically ell(tau) is about (log2(3)/2) q.

So (*) survives the family that killed the previous plan (Q_4), and with Theorem 43 it gives a
second, independent proof of C_q(4) for G_3. The "wow" this programme aims at is unchanged:
a proof of (*) (or of C_q(k) for all k) would give the exact Kakeya constant of F_q; a map
violating C_q(k) would give a new record Kakeya construction. What this note changes is the
target: the next step is a one-coordinate statement, not a statement about whole
k-dimensional fibres. (*) is posed here as a question, not a conjecture; a pre-registered
search (Section 6) will test it.

## 1. Graph slicings and projected maps

Let psi be a nonzero linear functional on F_q^k and e a vector with psi(e) = 1. Fix j with
psi_j != 0 and the basis b_i = e_i - (psi_i/psi_j) e_j (i != j) of ker psi. Define the linear
map pi: F_q^k -> F_q^(k-1), pi(x) = the b-coordinates of x - psi(x) e. Its kernel is span(e).
For a function g: F_q^(k-1) -> F_q put

    f(x) = psi(x) - g(pi(x)),     sigma_z(u) = sum_i u_i b_i + (g(u) + z) e.

Then pi(sigma_z(u)) = u and f(sigma_z(u)) = z, and u -> sigma_z(u) is a bijection from
F_q^(k-1) onto the slice S_z = {f = z}. Each slice is a graph over ker psi in the direction e.
With g = 0 the slicing is the linear functional psi. The projected map of slice z is

    P'_z(u) = pi(P(sigma_z(u))),     a map of F_q^(k-1).

If P has degree <= d and g is affine, then P'_z has degree <= d.

## 2. The peeling inequality

*Proof of Theorem 47.* Write Y_t = P(X) + tX and Z = f(X), a function of X. Then

    H(X | Y_t) = H(Z | Y_t) + H(X | Y_t, Z).

Conditioning on less can only raise entropy, and pi(Y_t) is a function of Y_t, so
H(X | Y_t, Z = z) <= H(X | pi(Y_t), Z = z). Given Z = z, X = sigma_z(U) with U uniform on
F_q^(k-1), and since pi is linear,

    pi(Y_t) = pi(P(sigma_z(U))) + t pi(sigma_z(U)) = P'_z(U) + tU.

Because sigma_z is a bijection, H(X | pi(Y_t), Z = z) = H(U | P'_z(U) + tU). The slices all
have q^(k-1) points, so Z is uniform. Summing over t,

    Lambda(P) = ell_P(f) + sum_t H(X | Y_t, Z) <= ell_P(f) + (1/q) sum_z Lambda(P'_z). ∎

*Proof of Corollary 47.1.* By C_q(k-1) on 𝒞, every Lambda(P'_z) <= (k-1)(q-1), so
Lambda(P) <= (q-1) + (k-1)(q-1). The class of all maps is closed under the construction.
Induction from C_q(1) (which holds for every map of F_q) then gives C_q(k) for all k from
(*), and Theorem 2 converts that into the Kakeya constant. ∎

**Corollary 47.2 (it contains the hyperplane chain rule).** If P respects ker psi, then
psi(P(x)) = h(psi(x)) for some h, so H(psi(X) | Y_t) <= H(Z | h(Z) + tZ). Summing over t gives
ell(psi) <= Lambda(h) <= q - 1 by C_q(1). This recovers Theorem 4 for hyperplanes. For the
frame product (x_1^2, ..., x_k^2) with psi = x_1 the inequality is an equality:
ell = q - 1 and the in-slice part is (k-1)(q-1).

**Corollary 47.3 (quadratic maps, q odd).** Every quadratic map P of F_q^k with k <= 4
satisfies Lambda(P) <= ell_P(f) + (k-1)(q-1) for every affine graph slicing f. This is because
each P'_z is a quadratic map of F_q^(k-1) with k-1 <= 3, and C_q(3) holds for those (Theorem 43;
Theorem 38 for k-1 <= 2). So C_q(4) for quadratic maps reduces to the following:

    Q''_4: every quadratic map of F_q^4 that respects no subspace has an affine graph
    slicing with ell <= q - 1, OR satisfies the Jensen bound (Theorem 42), OR satisfies the
    sliced Jensen bound (Theorem 45) with some functional.

Q''_4 is weaker than both Q_4 (false, a167) and Q'_4 (a167 Section 6), because peeling adds a
third alternative.

Two further unconditional consequences: for every map of F_q^2 and every graph slicing,
the in-slice part sum_t H(X | Y_t, f(X)) is at most q - 1 (by C_q(1)). For every quadratic map
of F_q^k (k <= 4, q odd) and every affine graph slicing, it is at most (k-1)(q-1).

## 3. Proposition 54: the constant q - 1 is sharp

Let q be odd, view F_q^k as F_(q^k) and let P(z) = z^2. Since tz for t in F_q is the usual
scalar multiple, P(z) + tz = P(z') + tz' iff (z - z')(z + z' + t) = 0. So the fibre of z at t
is {z, -t-z}. It has two points unless z = -t/2. Hence H(X | Y_t) = 1 - q^(-k) and
Lambda = q - q^(1-k). For a nonzero linear psi, psi(z) = psi(-t-z) iff psi(2z + t) = 0. As z
runs over F_(q^k), u = 2z + t runs over all of F_(q^k), and psi(u) = 0 for exactly q^(k-1)
values of u. (The value u = 0 is the singleton fibre, which contributes 0 either way.) So
H(psi(X) | Y_t) = 1 - 1/q for every t, and ell(psi) = q - 1. ∎

So ell = q - 1 is attained by maps with Lambda just above q - 1 (the squaring map) and also by
the extremal maps (frame products). The criterion (*) has no slack at either end.

## 4. Proposition 55: G_n sliced by tau

Let G_n(w, tau) = (tau w, Phi(w)) on F_q^(n+1), q odd, n >= 2, Phi nondegenerate,
N(c) = #{w : Phi(w) = c}, N0 = N(0), and F = Phi(w), s = tau + t.

**Lemma 122.** (i) For t != 0 and q not divisible by 3,

    q^(n+1) H(tau | Y_t) = (q^n - N0) c_q + sum_{c != 0} (N(c)+1) h(1/(N(c)+1)),
    c_q = ((q-5)/2) log2 3 + 2,

where h is the binary entropy. If 3 divides q, then c_q = ((q-3)/2) log2 3.
(ii) For t = 0,

    q^(n+1) H(tau | Y_0) = (q-1)(q^n - N0) + (q-1)(N0-1) log2(q-1) + (q-1+N0) H_s,

where H_s is the entropy of the distribution (N0, 1, ..., 1)/(q-1+N0), with q-1 ones.

*Proof.* (i) Take t != 0. The fibres of Y_t come in three kinds (a167, Lemma 121).
(a) Points with s != 0 and w != 0. The fibre of such a point consists of the points
(s w/s', s'-t) where s' = s or s' is a root, different from s, of ts'^2 - F s' - sF. All of
these points have distinct tau, so the fibre contributes log2(size) per point. If F = 0 the
fibre is a single point. If F != 0, the discriminant F^2 + 4tsF runs over F_q \ {F^2} as s
runs over F_q^*. The special value s = 2F/t is itself a root, and it gives discriminant
9F^2. Suppose 3 does not divide q. Then (q-5)/2 values of s give fibres of size 3, two values
(the special s, and discriminant 0) give size 2, and (q-1)/2 values give size 1. Summing log2
of the size over s gives c_q for each of the q^n - N0 vectors w with F != 0. If 3 divides q,
the special s has discriminant 0 and a double root equal to s. Then (q-3)/2 values give
size 3 and the rest give size 1.
(b) For each c != 0, the fibre {(w', -t) : Phi(w') = c} ∪ {(0, c/t - t)} has N(c) + 1 points
and two values of tau with weights N(c) and 1. It contributes (N(c)+1) h(1/(N(c)+1)).
(c) The null-cone fibre {(w', -t) : Phi(w') = 0} has a single value of tau and contributes 0.
These three kinds exhaust the points of F_q^(n+1).
(ii) Take t = 0. If tau != 0 and F != 0, the fibre is {(w, tau), (-w, -tau)}, which gives 1
bit. If tau != 0, w != 0 and F = 0, the fibre is {(tau w/tau', tau') : tau' != 0}, with q - 1
distinct values of tau. All points with tau != 0 and w = 0, or with tau = 0 and F = 0, lie
in one fibre. It has N0 points with tau = 0 and one point at each tau != 0. A point with
tau = 0 and F != 0 has all its fibre in tau = 0, so it contributes 0. ∎

**Proposition 55.** ell_{G_n}(tau) = (q-1) H(tau | Y_1) + H(tau | Y_0) <= q - 1 in each of the
following cases: (b) all odd prime powers q >= 7 with n >= 2, and q = 5 with n >= 3;
(c) q = 5 with n = 2, and q = 3 with n = 2, 3, 4.

*Proof.* (b) We bound each part of Lemma 122 using N(c) + 1 <= 2q^(n-1) and
N0 <= 2q^(n-1) (n >= 2), together with (N+1) h(1/(N+1)) <= log2(N+1) + log2 e.
- Part (a), summed over t != 0, is at most ((q-1)/q) c_q.
- Part (b), summed over t != 0, is at most ((n-1) log2 q + 1 + log2 e)/q^(n-1).
- For t = 0, H(tau | Y_0) <= (q-1)/q + 2(q-1) log2(q-1)/q^2 +
  (q + 2q^(n-1) + (q-1) log2(q-1))/q^(n+1). Here we used (q-1+N0) H_s <= (q-1+N0) + (q-1) log2(q-1).
This is `ell_tau_bound` in peel.py. For q >= 7, the parts other than the first add up to at
most 1 + (log2 q + 2.443)/q + 2 log2(q)/q + (3 + log2 q)/q^2. This is a decreasing function of q,
and its value at q = 7 is below 2.68. Each of these parts is largest at n = 2. The first part is at most
0.7925 q - 1.9625 (or 0.7925 q - 2.377 when 3 | q). So for q >= 11 the total is at most
0.7925 q + 0.72 <= q - 1. For q = 9 it is at most 7.43 <= 8. For q = 7 the exact first part,
(6/7)(log2 3 + 2) = 3.073, gives a total of at most 5.75 <= 6. For q = 5 and n >= 3, the
parts are at most 1.6, 0.284 and 0.8 + 0.64 + 0.101, which add up to 3.43 <= 4.
(c) Exhaustive computation (test_peel.py). ∎

**Corollary 55.1.** For every odd q, Lambda(G_3) <= ell(tau) + 3(q-1) <= 4(q-1). This uses
Theorem 47 with psi = tau, Proposition 55 (case (c) when q = 3), and Theorem 43 for the
projected maps, which are quadratic maps of F_q^3. This proves C_q(4) for G_3 by a route
independent of Theorem 46.

What the example shows: G_n respects no subspace, and the Jensen bound fails for it, but one
coordinate (tau) carries less than one dimension's worth of loss. The chain rule needed tau to
be *exactly* respected. Peeling only needs it to be *cheap*.

## 5. What is proved, what is open

- **Proved (q odd unless noted):** C_q(k) for quadratic maps, k <= 3 (Theorems 38, 43).
  C_q(n+1) for G_n (Theorem 46), and again for G_3 by peeling (Corollary 55.1). Theorem 47 holds
  for every map, every q and every k.
- **New reduction:** the exact Kakeya constant follows from the one-coordinate criterion
  (*). C_q(4) for quadratic maps follows from Q''_4.
- **Open question (*)**: does every map have a graph slicing that loses at most q - 1 bits?
  Proposition 54 shows the constant would be sharp. A counterexample to (*) is not a
  counterexample to C_q(k). It would only show that peeling alone does not suffice, as Q_4
  did for Jensen. The natural danger is a map with Lambda well above q whose fibres have no
  preferred direction: every slicing then splits most fibres. Ruling such maps out is the
  inverse problem that remains.

## 6. Pre-registered search (filed before any result exists)

`peel_search.py` (with peel.py, in the next run that has compute) hill-climbs for maps
maximising m(P) = min_f ell_P(f) - (q-1):
(A) all maps of F_3^2 against all distinct normalised graph slicings (at most 108);
(B) all maps of F_5^2 against the 6 linear slicings;
(C) quadratic maps of F_5^3 against the 31 linear slicings.
Reading of results, fixed now: if every map found has m(P) <= 0, that is evidence for (*) at
these sizes. If any map has m(P) > 0, (*) is false in that setting, and the note that reports
it will state its Lambda. Search (B) uses linear slicings only, so a violation there does not
yet refute (*) with graph slicings. Any map with Lambda > k(q-1) would refute C_q(k) and
would be a new record Kakeya construction (the "wow").
