# a180. Kakeya sets over F_3: the Katz-Tao sum-difference inequality beats the polynomial method

MV2 of Munim, Inc. (mv2@munimtech.com), 2026-11-18. Made with AI agents working in MV2's name.
Text CC BY 4.0, code Apache-2.0. **No human mathematician has checked this note yet.**
Code and exact checks: `kt_f3.py`, `test_kt_f3.py` (standard library only).

## Summary

Over F_3 a line is a three-term arithmetic progression {a, a+d, a+2d}, and its three points
sum to zero. So a Kakeya set K in F_3^n is exactly the kind of configuration that Bourgain's
sums-differences problem controls: for every nonzero direction d there are points
a, b = a + d in K whose sum a + b = -(a + 2d) also lies in -K. The Katz-Tao inequality
(1999), in its entropy form, holds in every abelian group. It gives

> **Theorem 68.** Every Kakeya set K in F_3^n satisfies |K| >= (3^n - 1)^(6/11).
> So K(n, 3) >= 3^(6n/11 - o(n)) = 1.82074...^n.

The best lower bound we know of for q = 3 has base 9/5 = 1.8. It is the polynomial method:
Dvir-Kopparty-Saraf-Sudan (2009), KLSS (2010, Thm 1 with r = 1), and Bukh-Chao (2021),
who sharpened it to 3^n / (5/3)^(n-1) without changing the base. Theorem 68 is larger than
the Bukh-Chao bound for every n >= 45 (exact integer check in the tests), and its base is
larger. In the notation of the README (Theorem 2), 1.82074 <= beta_3 <= 1.8899 now, where
before it was 1.8 <= beta_3 <= 1.8899.

If the November 2026 certified sum-difference constant of Farnamfar (arXiv:2611.19594;
computer-checked, not yet refereed) is used instead of 11/6, the base becomes 3^(83/152) =
1.82194 (his Theorem 3, every abelian group) or 3^(1/1.82634...) = 1.82492 (his Theorem 1,
no 2-torsion, which F_3^n satisfies). We did not check those certificates. Theorem 68 itself
uses only the 1999 Katz-Tao inequality, whose proof is reproduced in full below.

**Why it matters.** KLSS called q = 3 "arguably the most intriguing" case of the limit
lim K(n,q)^(1/n) (lines in F_3^n are 3-term APs). Its lower base has stood at 9/5 since 2009.
The bound here comes from additive combinatorics rather than polynomials, and it closes
about 23.5% of the gap between the polynomial-method level and MV2's conjectured exact value
(below; 28.2% with the certified constant).

**Prior art.** We searched for this application and did not find it: DKSS, KLSS
(arXiv:1003.3736, whose lower bound for q = 3 is (9/5)^n), Bukh-Chao (DA 2021:26),
Green-Ruzsa (arXiv:1712.02108, who use only the (p/2)^n form of DKSS for fixed p), Lemm
(arXiv:1404.3745), Farnamfar (arXiv:2611.19594, which does not mention finite-field Kakeya
sets), arXiv:2312.11017, Tao's constants page for C_3b, and the 2008 comment thread on Tao's
blog, where V. Lev asked for the smallest set in F_3^r with a line in every direction (trivial
lower bound 3^(r/2)). The argument is short, and someone may have noticed it without
publishing. We would be glad to learn of an earlier source.

## 1. The entropy inequality

**Lemma 143 (Katz-Tao 1999; entropy form by Ruzsa 2009 and Tao-Vu).** Let X, Y be random
variables with finite support in an abelian group. Then

    5 H(X, Y) + H(X - Y)  <=  4 H(X) + 4 H(Y) + 3 H(X + Y).

In particular, if X - Y determines (X, Y), then 6 H(X - Y) <= 4 H(X) + 4 H(Y) + 3 H(X + Y).

*Proof.* This is the proof of arXiv:2312.11017, Appendix A, re-derived step by step. It uses
only addition and subtraction in the group.

1. Let Z = (X, Y, Y') where Y and Y' are conditionally independent given X and
   (X, Y') ~ (X, Y). Then H(Z) = 2H(X,Y) - H(X).
2. Let f1(Z) = (X+Y, X+Y'), f2(Z) = (Y, Y'), f3(Z) = (X+Y, Y'). Take copies Z_1, ..., Z_4,
   each distributed as Z, with f_i(Z_i) = f_i(Z_{i+1}) for i = 1, 2, 3, glued so that each
   Z_{i+1} is conditionally independent of Z_1, ..., Z_{i-1} given f_i(Z_i). Each copy then
   has law Z, and

       H(Z_1, ..., Z_4) = 4H(Z) - H(f1) - H(f2) - H(f3).                         (a)

3. The gluing gives X_1 + Y_1 = X_2 + Y_2, X_1 + Y_1' = X_2 + Y_2', so Y_1 - Y_1' = Y_2 - Y_2';
   also Y_2 = Y_3, Y_2' = Y_3', X_3 + Y_3 = X_4 + Y_4 and Y_3' = Y_4'. Hence

       X_4 - Y_4' = X_3 + Y_3 - Y_4 - Y_3' = X_3 - Y_4 + (Y_1 - Y_1').

   So D := X_4 - Y_4' is a function of W := (X_1, Y_1, Y_1', X_3, Y_4).
4. Every variable is a function of (W, X_4, Y_4'): Y_3' = Y_2' = Y_4',
   Y_3 = Y_2 = X_4 + Y_4 - X_3, X_2 = X_1 + Y_1 - Y_2. Therefore

       H(Z_1..Z_4) = H(W) + H(X_4, Y_4' | W) = H(W) + H(X_4, Y_4' | W, D)
                   <= H(W) + H(X_4 | D) = H(W) + H(X, Y) - H(X - Y),

   since (X_4, Y_4') ~ (X, Y) and (X_4, D) determines Y_4'.
5. H(W) <= H(Z_1) + H(X_3) + H(Y_4) = H(Z) + H(X) + H(Y). Comparing with (a):
   3H(Z) <= H(f1) + H(f2) + H(f3) + H(X) + H(Y) + H(X,Y) - H(X-Y).
6. Bound H(f1) <= 2H(X+Y), H(f2) <= 2H(Y), H(f3) <= H(X+Y) + H(Y) and substitute
   H(Z) = 2H(X,Y) - H(X): 6H(X,Y) - 3H(X) <= 3H(X+Y) + 4H(Y) + H(X) + H(X,Y) - H(X-Y),
   which is the claim. The special case follows from H(X,Y) = H(X-Y). QED

`test_lemma_143_random_distributions` checks the inequality on random distributions in
Z_3, Z_3^2, Z_5, Z_2^2, Z_7 and Z_9.

## 2. Kakeya sets in F_3^n

*Proof of Theorem 68.* For each nonzero d in F_3^n choose a(d) with the line
{a(d), a(d) + d, a(d) + 2d} inside K. Let D be uniform on the 3^n - 1 nonzero vectors, and
put Y_0 = a(D), Y_1 = a(D) + D. Then Y_0, Y_1 are in K, and
Y_0 + Y_1 = 2a(D) + D = -(a(D) + 2D) lies in -K. So H(Y_0), H(Y_1), H(Y_0 + Y_1) <= log2 |K|.
Also Y_1 - Y_0 = D determines (Y_0, Y_1), and H(D) = log2(3^n - 1). Lemma 143 gives
6 log2(3^n - 1) <= 11 log2 |K|. QED

**Corollary 68.2 (comparisons; exact integer checks in `test_kt_f3.py`).**
- 3^(6/11) = 1.82074 > 9/5, since 3^6 * 5^11 > 9^11.
- (3^n - 1)^(6/11) > 3^(2n-1) / 5^(n-1) (Bukh-Chao for q = 3) exactly when n >= 45.
- 3^(6/11) < 1.8899, consistent with the known upper bound (KLSS Thm 8; README).

## 3. The entropy Kakeya functional of the program

For a map P of F_3^k and X uniform on F_3^k, let Y_t = P(X) + tX and
Lambda(P) = sum_t H(X | Y_t) = 3k log2 3 - sum_t H(Y_t). The README's h_k is
min_P (1/3) sum_t H(Y_t), and Theorem 2 there gives beta_3 = inf_k 2^(h_k / k).

**Corollary 68.1.** For every k and every map P of F_3^k,

    sum_t H(Y_t) >= (18/11) k log2 3 = 2.59357 k,   i.e.   Lambda(P) <= (15/11) k log2 3 = 2.16131 k.

So h_k >= (6/11) k log2 3, which gives beta_3 >= 3^(6/11) again through README Theorem 2.

*Proof.* Y_0 + Y_1 + Y_2 = 3P(X) + 3X = 0. For each of the three choices of c in {0,1,2},
with {a, b, c} = {0, 1, 2}: Y_a + Y_b = -Y_c, and Y_a - Y_b = (a - b)X determines X, hence
the pair. So H(Y_a - Y_b) = H(Y_a, Y_b) = k log2 3. Lemma 143 gives
6k log2 3 <= 4H(Y_a) + 4H(Y_b) + 3H(Y_c). Adding the three gives 18 k log2 3 <= 11 sum_t H(Y_t).
QED

In exact form, Corollary 68.1 says that the product, over t and over the fibres of Y_t, of
c^c is at most 3^(15 k 3^k / 11). The tests check this exactly for all 27 maps of F_3, 300
random maps of F_3^2, 60 of F_3^3 and the constant maps. Frame products have Lambda = 2k
exactly (product = 2^(2k 3^k)).

Where this leaves MV2's conjecture C_3(k) (Lambda <= 2k, i.e. beta_3 = 3 * 2^(-2/3) = 1.8899):

| per k (bits)              | polynomial method | Thm 68 (11/6) | with 2611.19594 Thm 1 | conjecture |
|---------------------------|------------------:|--------------:|----------------------:|-----------:|
| upper bound on Lambda / k | 2.21090           | 2.16131       | 2.15139               | 2          |
| lower bound on beta_3     | 1.8               | 1.82074       | 1.82492               | 1.8899     |

Here 3 log2(5/3) = 2.21090 is the level of the polynomial method, through README Theorem 2.
(15/11) log2 3 < 3 log2(5/3) is the exact inequality 3^48 < 5^33.

## 4. Remarks

**Remark 68.3 (only q = 3).** For q >= 4 the sum-difference route loses to the polynomial
method. q^(6/11) < q/(2 - 1/q) for q = 4, 5, ..., and the many-slope sum-difference
exponents (Katz-Tao 2002, 1.67513...) do not beat it for odd q >= 5 either
(5^(1/1.67513) = 2.61 < 25/9). For q = 4 the many-slope numbers come close to 16/7. Those
arguments use slopes that collapse in characteristic 2, and F_4 has only five slopes, so we
claim nothing there.

**Remark 68.4 (Ruzsa's example is the frame product).** Tao's table of C_3b lists Ruzsa's
unpublished lower example log 27 / log(27/4) = 1.72598. That is exactly the ratio
log2 3 / h(1/3) of the one-coordinate frame map x -> x^2 over F_3 (each Y_t has entropy
h(1/3) = log2(27/4)/3). So C_3(k) says: in the *Kakeya-restricted* sum-difference problem
over F_3^k, with the difference uniform on the whole group and the slice entropies summed,
Ruzsa's example is optimal. Lemm's examples (1.77898) beat it in the unrestricted problem.
An embedding of such an example into F_3^k with uniform difference would give Kakeya sets
of base 3^(1/1.779) = 1.854 < 1.8899, which would refute C_3. In the other direction, write
sum_t H(Y_t) >= c k log2 3. Corollary 68.1 has c = 18/11 = 1.63636, and C_3 says the best c is
3 h(1/3) / log2 3 = 1.73814. Any entropy certificate that also uses the uniformity of the
difference and raises c raises the lower bound on beta_3 to 3^(c/3). The next step is a
Shannon-inequality certificate search with these Kakeya constraints added.

**Remark 68.5 (small cases).** The smallest Kakeya set in F_3^2 has 7 points (four lines with
distinct directions, no three concurrent, do not exist in AG(2,3); a 7-point example is in
KLSS). The test enumerates all 512 subsets of F_3^2. Theorem 68 is far from tight for small
n: in F_3^3 it gives 6, against the minimum of 13 found by this repository's exhaustive search.
