## About the observation

At t = 7, (B6) is the shape with dim P = t - 1, and at t = 8 so is (B7)_8. In both, ker A_u =
span(x0) + Y with Y = ker A_u n P, and A_u is an isomorphism from X / ker A_u (dimension 3) onto
Im A_u. One step up, Y gains one dimension, and the pair orbits are the same 13, kind by kind
(Lemmas 83 and 101). A likely reason for the equal counts
is that the stabiliser of the pair acts on the 168 isomorphisms X / ker A_u -> Im A_u through the
same group at t = 7 and t = 8, because one vector of Y can be split off from everything Im A_u and
x0 touch. This is not proved here and nothing below uses it. If it holds, the classes of the
second matrix at t = 8 may also be read off those at t = 7 in part, which is worth checking before
counting them by hand.

## Setting

rank 3, x0 = sigma(u), phi = beta(u, .), P = phi(V), X_1 = ker A_u (dimension 5, containing x0),
R = Im A_u (dimension 3), d = dim(X_1 n R), H0 = P + span(x0). By Lemma 30, an element of rank
rho >= 5 gives dim V <= 8 + A(7 - rho) <= 8 + A(2) = 10, and an invertible A_u is impossible (A_u

    (B7)_8   x0 outside P, dim P = 7, H0 = X, N = ker phi of dimension 4;
    (B6)_8   x0 outside P, dim P = 6, H0 a hyperplane, N of dimension 5.

Since x0 is not in P, U+ = {h : phi(h) in span(x0)} is N. As at t = 7 (Proposition 29 (c) and
(2) of [a24.md](a24.md)), for every n in N

    A_n x0 = 0,   sigma(n) in X_1,   A_n phi(h) = A_u beta(n, h) for every h,          (N)

and beta(n, n') lies in X_1 for n, n' in N (m42's hints encode exactly these). For w in V write
P_w = beta(w, V), z_w = sigma(w), Q_w = P_w + span(z_w), r_w = rank A_w and
U+(w) = {h : beta(w, h) in span(z_w)}. We use A(s) = s for s <= 6 (Theorems 26, 27 and 31; Theorem

## Lemma 102 (the elements of ker phi at t = 8)

**Lemma 102.** Let w be a non-zero element of N. Then:

(a) A_w(H0) = A_u(P_w), a subspace of R of dimension dim(P_w + X_1) - 5. In (B7)_8,
    Im A_w = A_u(P_w) and r_w = dim(P_w + X_1) - 5; so A_w = 0 exactly when P_w lies in X_1, and
    r_w = 3 exactly when P_w + X_1 = X. In (B6)_8, dim(P_w + X_1) - 5 <= r_w <= dim(P_w + X_1) - 4.

(b) dim U+(w) = 12 - dim Q_w. If r_w >= 1, then dim U+(w) <= 8 - r_w, so dim Q_w >= r_w + 4 and
    dim(Q_w n X_1) >= 4. If moreover w is not in span(u), then z_w is not in span(x0),
    dim(P_w n X_1) >= 3, and dim(P_w n X_1) >= 4 when z_w lies in P_w.

(c) If r_w = 3, then w is an element of rank 3 in (B7)_8 or (B6)_8: z_w is not in P_w, dim P_w is
    7 or 6, dim Q_w is 8 or 7, and ker beta(w, .) has dimension 4 or 5 and contains u and w. In
    (B7)_8 (for u), r_w = 3 forces dim(P_w n X_1) = dim P_w - 3, that is 4 or 3.

*Proof.* (a) By (N), A_w x0 = 0 and A_w phi(h) = A_u beta(w, h), so A_w(H0) = A_w(P) = A_u(P_w).
A_u has kernel X_1, so dim A_u(P_w) = dim P_w - dim(P_w n X_1) = dim(P_w + X_1) - 5. In (B7)_8,
H0 = X. In (B6)_8, X = H0 + span(e) for any e outside H0, so Im A_w = A_u(P_w) + span(A_w e). The
equivalences follow, since dim X = 8 and A_u(P_w) = 0 exactly when P_w lies in X_1.

(b) U+(w) is the preimage of P_w n span(z_w) under beta(w, .), whose image is P_w, so
dim U+(w) = (11 - dim P_w) + dim(P_w n span(z_w)). As z_w != 0 (anisotropy), the last term is
dim P_w + 1 - dim Q_w, so dim U+(w) = 12 - dim Q_w. Lemma 30 (b)
([rank-restriction.md](rank-restriction.md)) for w gives dim U+(w) <= 1 + A(8 - r_w - 1) =
1 + A(7 - r_w), and for 1 <= r_w <= 3 this is 8 - r_w (A(6) = 6, A(5) = 5, A(4) = 4). So
dim Q_w >= r_w + 4. By (N), z_w lies in X_1, so Q_w + X_1 = P_w + X_1, of dimension at most
r_w + 5 by (a) (equality in (B7)_8). Hence

    dim(Q_w n X_1) = dim Q_w + 5 - dim(P_w + X_1) >= (r_w + 4) + 5 - (r_w + 5) = 4.

If w is not in span(u), Lemma 30 (b) for u (w lies in U+ = N) says z_w is not in span(x0). Since
z_w lies in X_1, Q_w n X_1 = (P_w n X_1) + span(z_w) (the modular law), of dimension
dim(P_w n X_1) + 1 when z_w is not in P_w and dim(P_w n X_1) when it is. So dim(P_w n X_1) >= 3,
and >= 4 when z_w lies in P_w.

(c) Every element has rank at most 3 (Setting), and by Proposition 36 with Corollary 122 an element
of rank 3 is in (B7)_8 or (B6)_8: z_w is not in P_w and dim P_w is 7 or 6. Then
dim Q_w = dim P_w + 1, and ker beta(w, .) has dimension 11 - dim P_w; it contains u
(beta(w, u) = phi(w) = 0) and w (beta(w, w) = 0). In (B7)_8, (a) gives dim(P_w + X_1) = 8, so
dim(P_w n X_1) = dim P_w + 5 - 8. QED

**Remarks.**

- Each bound of Lemma 88 rises by one, with the same proof. For r_w = 0 the bound of Lemma 30 is
  1 + A(7) <= 9 (Theorem 33), which gives only dim Q_w >= 3; Lemma 89 ([a37.md](a37.md)) treated
  the zero maps at t = 7 separately, and its analogue at t = 8 is not done here.
- In (B7)_8 every non-zero n in N has A_n mapping X into R and killing x0 and z_n, two independent
  vectors of X_1 when n is not in span(u). At t = 7, "rank at most 2 on X_1" cut the candidates for
  A_(h_1) from 512 to 344 on the part over X_1 n P (Proposition 33 (a)). At t = 8, X_1 n P has
  dimension 4 and R dimension 3, so every map from X_1 n P to R already has a kernel and the cut is
  empty: the admissible second matrices are all 2^21 maps X / span(x0) -> R (less any that a later
  lemma excludes, such as A_n = 0).
- Lemma 102 excludes no class by itself. As at t = 7, it becomes a solver condition only after a
  second matrix is fixed.

## Lemma 103 (the second element of largest rank, and the rank-0 case)

**Lemma 103.** Let u be in (B7)_8 or (B6)_8, and let r be the largest rank on X_1 of A_n over n in
N outside span(u).

(a) There is a system in the class with A_u fixed in which v_1 = h_1 has rank exactly r on X_1 and
    A_(h_1) is any chosen representative of its class under the stabiliser G of (x0, P, A_u) and
    h_1 -> h_1 + u. So a class is empty if and only if, for every representative of rank r, the
    instance with the added condition "every A_n, n in N, has rank at most r on X_1" is UNSAT.

(b) If r = 0, then A_n = 0 on X_1 and beta(n, n') = 0 for all n, n' in N. Then sigma is linear and
    one-to-one on N, and sigma(N) is a subspace of X_1 of dimension dim N that contains x0: a
    hyperplane of X_1 in (B7)_8, all of X_1 in (B6)_8.

*Proof.* (a) As in Lemma 93: the rank of A_n on X_1 is kept by G, since every g in G commutes
with A_u, keeps X_1 and conjugates A_n; and by n -> n + u, since A_u = 0 on X_1. Choose h_1 in N
outside span(u) of the largest rank; a base change in G (with a new basis of V) and, if needed, the
swap of h_1 and h_1 + u bring A_(h_1) to its representative, and the other elements of N keep their
ranks.

(b) With r = 0 and A_u = 0 on X_1, every A_n (n in N) vanishes on X_1, by linearity. For n, n' in
N, (*) with h = n and h' = n' reads A_(n') sigma(n) = beta(n, n') + A_n beta(n, n'). The left side
is 0, since sigma(n) lies in X_1; so is A_n beta(n, n'), since beta(n, n') lies in X_1. So
beta(n, n') = 0. Then sigma(n + n') = sigma(n) + sigma(n') on N, so sigma is linear there; it is
one-to-one since the system is anisotropic, and its image lies in X_1 by (N) and contains
x0 = sigma(u). dim N = 4 in (B7)_8 and 5 in (B6)_8, and dim X_1 = 5. QED

**The rank-0 sweep at t = 8.** For one class of A_u, the systems with r = 0 are the models of one
instance: m42's instance plus A_(v_i) y = 0 for y in a basis of X_1 and beta(v_i, v_j) = 0 for
1 <= i < j < dim N. In (B7)_8 that is 3 x 5 x 8 = 120 linear conditions and 3 x 8 = 24 unit
clauses. The beta conditions follow from the others by Lemma 103 (b); they are added so the solver
does not have to find them. It is a case split on the system and needs no symmetry argument: if the
instance is UNSAT, every system of the class has an element of N that is not zero on X_1, and by
(a) a later split of the class needs only the representatives of rank 1 to 3 on X_1.

In (B6)_8 the rank-0 case is tight: Lemma 30 for u gives dim N <= 1 + A(4) = 5, which holds with
equality, and sigma maps N onto X_1. This is recorded for the hand work on (B6)_8, not used yet.
