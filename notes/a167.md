## 0. Summary

Program: the exact Kakeya constant of F_q (a159-a166). For a map P of F_q^k let

    Lambda(P) = sum_{t in F_q} H(X | P(X) + tX)      (bits, X uniform on F_q^k).

Conjecture C_q(k) says Lambda(P) <= k(q-1). By Theorem 2, C_q(k) for every k is equivalent to
q 2^(-(q-1)/q) being the exact Kakeya growth constant of F_q. Note a166 proved C_q(3) for every
quadratic map (q odd) by combining two tools. The chain rule (Theorem 4) handles maps that
respect a subspace. The Jensen bound (Theorem 42), Lambda <= q log2(1 + Pibar/q), handles the
rest. a166 then proposed the same route for every k, reducing C_q(k) for quadratic maps to
statements Q_j (j <= k): every quadratic map of F_q^j that respects no subspace has
Pibar <= q(2^(j(q-1)/q) - 1).

This note shows that **the route fails as stated from dimension 4 on**, and repairs it for the
maps that break it:

> **Theorem 44.** For n >= 1 let G_n(w, tau) = (tau w, Phi(w)) on F_q^(n+1), q odd, with Phi a
> nondegenerate quadratic form on F_q^n. Then G_n respects no nonzero proper subspace and
> Pibar(G_n) = (q - 1) + (q^n - 1)/q. Consequently Q_4 is false for every odd q >= 11, and
> Q_(n+1) is false whenever q^(n-2) >= 2^(n+1). Neither the chain rule nor the Jensen bound
> proves C_q(n+1) for these maps.

> **Theorem 45 (sliced Jensen bound, any map).** For any map P and any function f on F_q^k,
> Lambda(P) <= sum_t [ log2 m_t + sum_z Pr(f(X) = z) log2(1 + p_t(z)) ], where m_t is the
> expected number of f-values met by the fibre of X under P_t, and p_t(z) is the average
> number of partners of a point inside its own slice f = z.

> **Theorem 46.** For every odd q and n >= 3, Lambda(G_n) < (n+1)(q-1). In fact
> Lambda(G_n) <= q - 0.1 + log2(q^(n-1) + 1), while the Jensen bound of a166 grows like
> q log2(q^(n-1)).

The maps G_n are not exotic. Their product, (u, s) o (w, t) = (s w + t u, phi(u, w)), is the
Jordan algebra of a quadratic form (the "spin factor") with the square of the extra basis
vector set to 0. The spin factor itself shows the same failure (Remark 3.2). What goes wrong:
inside the hyperplane tau = 0 every direction has rank 1, so a hyperplane's worth of
directions carries huge pair counts. Those pairs all live inside the single slice
tau = -t, and that slice makes up only a 1/q fraction of the points. Jensen is fooled by these
rare large fibres, while the sliced bound sees that they are rare.

The status of the programme is now: C_q(k) for quadratic maps is proved for k <= 3 (q odd).
For k >= 4 the right statement to aim at is Q'_k (Section 6), with the sliced bound in place
of Jensen. The "wow" (the exact Kakeya constant) is not closer in dimension terms, but a
false lemma has been removed from the plan before anyone built on it.

## 1. Notation (a163-a166)

Y_t = P(X) + tX. Write P = Q + L + const with Q homogeneous quadratic, and let
beta(x, w) = Q(x+w) - Q(x) - Q(w) and x o w = beta(x, w). This makes F_q^k a commutative,
possibly non-associative, algebra A. R_y is the matrix of w -> y o w. P *respects* V if
P(x+v) - P(x) lies in V for all x and all v in V. That is the same as A o V in V and LV in V
(an L-invariant ideal). For a direction w, r_w is the rank of x -> x o w mod w, and Pi_w and
Pibar are as in a166. For q odd, Prop 47 (a164) gives Pi_w = (q-1)q^(k - r_w) if w is active
and 0 otherwise.

## 2. Two exact forms of Pibar for quadratic maps

**Proposition 52 (eigendirections).** For q odd and P of degree <= 2,

    Pibar = (q - 1) E_y e(R_y + L),

where e(T) is the number of eigendirections of T in PG(k-1, q) and y is uniform on F_q^k.

*Proof.* With v = x' - x != 0 and the midpoint y = x + v/2,
P(x') - P(x) + t v = y o v + (L + t)v, because beta(v, v)/2 = Q(v). So x and x' collide at t
iff (R_y + L)v = -t v. Each pair (y, v) with v an eigenvector of R_y + L gives exactly one t.
Hence q^k Pibar = #{(y, v) : v != 0, v an eigenvector of R_y + L} = (q-1) sum_y e(R_y + L). ∎

So Q_k asks whether the affine family {R_y + L} has fewer than about 2^k - 1 eigendirections
on average when it has no common invariant subspace. A uniformly random matrix has about one
eigendirection on average, and the frame product (x_1^2, ..., x_k^2) has about 2^k - 1. The
counterexample below has about q^(n-1).

**Proposition 53 (dual form: a linear system of quadrics).** For q odd and P of degree <= 2,

    Pibar = q^(1-k) sum_{psi != 0} |V_psi| [psi L vanishes on V_psi],
    V_psi = rad(psi o Q) ∩ ker psi,

where psi runs over the linear functionals on F_q^k and rad(psi o Q) is the radical of the
quadratic form psi(Q(x)).

*Proof.* By Parseval, sum_psi |sum_x e(psi(P_t(x)))|^2 = q^k #{(x, x') : P_t(x) = P_t(x')}.
The quadratic exponential sum has |sum_x e(psi Q(x) + psi(L+t)x)|^2 = q^k |R_psi| if
psi(L + t) vanishes on R_psi = rad(psi Q), and 0 otherwise. Summing over t gives
q^(k+1) |V_psi| [psi L = 0 on V_psi]. (If psi is nonzero on R_psi, exactly one t works,
provided psi L vanishes on V_psi. If psi is zero on R_psi, then V_psi = R_psi and all q values
of t work under the same condition.) Divide by q^(2k) and sum over t. ∎

In this picture, P respects the hyperplane ker psi_0 iff psi_0 Q = c psi_0^2 and psi_0 L is
proportional to psi_0. The frame product's system {sum psi_i x_i^2} contains k squares. G_n's
system {tau alpha(w) + beta Phi(w)} contains an n-dimensional space of rank-2 forms
tau alpha(w), all sharing the factor tau. That subspace is what produces the large Pibar
below.

## 3. The counterexample family

Fix q odd, n >= 1, and a nondegenerate quadratic form Phi on W = F_q^n with polar form
phi(u, w) = Phi(u+w) - Phi(u) - Phi(w). Let G_n(w, tau) = (tau w, Phi(w)) on
A = W x F_q, k = n + 1. Then (u, s) o (w, t) = (s w + t u, phi(u, w)) and L = 0.

**Theorem 44.**
(a) G_n respects no nonzero proper subspace.
(b) For a direction v = (w', tau'): Pi_v = (q-1) q if tau' != 0, and Pi_v = (q-1) q^n if
    tau' = 0 (so r_v = n, resp. r_v = 1).
(c) Pibar(G_n) = (q - 1) + (q^n - 1)/q. For k = 4 this is (q-1)(q+1)^2/q.
(d) The Jensen bound q log2(1 + Pibar/q) exceeds k(q-1) (equivalently, G_n violates Q_k)
    for k = 4 and every odd q >= 11, and for k = n + 1 whenever q^(n-2) >= 2^(n+1). Examples:
    n = 4 and q >= 7; n = 5, 6 and q >= 5; n >= 8 and q = 3.

*Proof.* (a) Let V be a nonzero invariant subspace (A o V in V). If V lies in W x 0, then for
(w, 0) in V we get (u, 0) o (w, 0) = (0, phi(u, w)) in V for all u, so phi(u, w) = 0 and w = 0.
Otherwise V contains (w, tau) with tau != 0. Then (u, 0) o (w, tau) = (tau u, phi(u, w)) lies in
V for every u, so V contains the n-dimensional graph
Gamma = {(u, g(u))} with g = phi(·, w)/tau. If V != A then V = Gamma. But
(0, 1) o (u, g(u)) = (u, 0) must lie in Gamma, which forces g = 0 and hence w = 0. Then
Gamma = W x 0, which does not contain (0, tau). (For n >= 2 a second argument works for any
value of (0,1) o (0,1), including the spin factor: (u'', 0) o (u', g(u')) in Gamma forces
phi = g ⊗ g, which has rank <= 1 < n.)
(b) Take v = (u, 1). Then P(x + lambda v) - P(x) =
(lambda w + (tau lambda + lambda^2) u, lambda phi(w, u) + lambda^2 Phi(u)). This lies in F_q v
iff w = c u for some c (or w = 0 when u = 0) and tau is the unique value fixed by the second
coordinate, so there are q solutions for each lambda != 0. For v = (u, 0) with u != 0, the
difference lies in F_q v iff phi(w, u) + lambda Phi(u) = 0. That is one linear condition on w,
with tau free, giving q^n solutions.
(c) There are q^n directions with tau' != 0 and (q^n - 1)/(q - 1) with tau' = 0. So
q^k Pibar = q^n (q-1) q + (q^n - 1) q^n.
(d) For k = 4, (q-1)(q+1)^2/q > 15q > q(2^(4(q-1)/q) - 1) once (q-1)(q+1)^2 > 15q^2, which
holds for q >= 17. The cases q = 11 and 13 are checked directly: Pibar = 130.9 > 125.8 and
180.9 > 155.1. In general Pibar > q^(n-1) >= q 2^(n+1) > q(2^(k(q-1)/q) - 1). For q <= 9 and
k = 4 the Jensen bound still works for G_3. ∎

**Remark 3.1 (what this does and does not refute).** Q_k was a *sufficient* condition. Its
failure does not touch C_q(k): Theorem 46 shows that C_q(n+1) holds for G_n. What Theorem 44
shows is that no proof of C_q(k) for all quadratic maps (k >= 4) can consist of the chain
rule plus the Jensen bound alone. Theorem 43 (k = 3) is unaffected: there G_2 has
Pibar = (q-1) + (q^2-1)/q, well inside the k = 3 threshold.

**Remark 3.2 (the spin factor).** The Jordan algebra of Phi has product
(u, s) o (w, t) = (s w + t u, phi(u, w) + s t), and its squaring map is
x o x / 2 = (tau w, Phi(w) + tau^2 / 2). It also respects no subspace for n >= 2. It has the
same rank-1 hyperplane, and its Pibar is larger: Pibar(G_n) + (q-1)^2 N(1/2)/q^n, where
N(c) = #{w : Phi(w) = c}. The extra directions are the null cone tau^2 = 2 Phi(w), where
r = n - 1. So a classical simple algebra already violates Q_4.

## 4. The sliced Jensen bound

**Theorem 45.** Let P be any map of F_q^k and f any function on F_q^k, and write Z = f(X).
For t in F_q let m_t = E_X #{f(x') : P_t(x') = P_t(X)}. For each value z let
1 + p_t(z) = E[ #{x' in f^{-1}(z) : P_t(x') = P_t(X)} | Z = z ]. Then

    Lambda(P) <= sum_t log2 m_t + sum_t sum_z Pr(Z = z) log2(1 + p_t(z)).

*Proof.* Since Z is a function of X, H(X | Y_t) = H(Z | Y_t) + H(X | Y_t, Z). Given Y_t = y,
Z takes at most d(y) values, the number of slices met by the fibre y. So
H(Z | Y_t) <= E log2 d(Y_t) <= log2 E d(Y_t) = log2 m_t. Given Z = z, X is uniform on the
slice, and H(X | Y_t, Z = z) is the mean log-size of the in-slice fibres, which is at most
log2(1 + p_t(z)) by Jensen. ∎

A constant f gives the per-t Jensen bound sum_t log2(1 + p_t), which is at most Theorem 42 by
concavity. The point of the theorem is that the in-slice Jensen is averaged over slices
*outside* the logarithm, so a few slices with huge fibres cost only their probability times
their log-size.

## 5. C_q(n+1) for G_n

**Lemma 120.** With N(c) = #{w in F_q^n : Phi(w) = c}, sum_c N(c)^2 = q^(2n-1) + (q-1) q^(n-1).

*Proof.* The left side counts the zeros of Phi(w) - Phi(w') on F_q^(2n). That is a
nondegenerate form of Witt index n (hyperbolic), so it has q^(2n-1) + q^n - q^(n-1) zeros. ∎

**Lemma 121 (fibres of G_n, sliced by tau).** Write s = tau + t, F = Phi(w) and N0 = N(0).
(i) Inside a slice tau = z, two points collide at t only if z = -t. On that slice P_t is
    (0, Phi(w) + const), so 1 + p_t(-t) = q^(-n) sum_c N(c)^2 = q^(n-1) + 1 - 1/q, and
    p_t(z) = 0 for z != -t.
(ii) For t != 0 and n >= 2, D_t := q^(n+1) m_t = (2q-2) q^n + (2-q) N0 + (q-1).
(iii) D_0 = (2q-1) q^n + (q-1)(q-2) N0 + (q-1).

*Proof of (ii).* The fibre of (w, s) consists of the points (w', s') with s' w' = s w and
Phi(w') + t s' = F + t s. If s != 0 and w != 0, every s' is nonzero, w' = s w/s', and s' is a
root of t s'^3 - (F + ts) s'^2 + s^2 F = (s' - s)(t s'^2 - F s' - s F). If F = 0 the only
other root is s' = 0, which is excluded, so there is 1 slice. If F != 0, the quadratic has
discriminant F^2 + 4tsF. As s runs over F_q^*, this runs over F_q \ {F^2}. Summing 1 + eta
(eta the quadratic character) gives q - 2 roots in total, and removing the single root s' = s
(at s = 2F/t) leaves q - 3. So these points contribute (q^n - N0)(2q - 4) in total. A point
(0, s) with s != 0 meets 2 slices (s, and 0, because Phi represents ts when n >= 2). A point
with s = 0 meets 1 + [F != 0] slices: 0, and s' = F/t with w' = 0. Adding up gives (ii).
*(iii)* At t = 0 the fibre of (w, tau) is as follows. If tau != 0 and F != 0, it is
{(w, tau), (-w, -tau)}: 2 slices. If tau != 0 and F = 0 with w != 0, it is
{(tau w/tau', tau') : tau' != 0}: q - 1 slices. If w = 0 and tau != 0, all q slices are met.
If tau = 0, the fibre meets 1 slice, or q slices if F = 0. Adding up gives (iii). ∎

**Theorem 46.** For every odd q and every n >= 3,

    Lambda(G_n) <= (q-1) log2(D_1/q^(n+1)) + log2(D_0/q^(n+1)) + log2(q^(n-1) + 1 - 1/q)
                <= q - 0.1 + log2(q^(n-1) + 1) < (n+1)(q-1).

*Proof.* The first inequality is Theorem 45 with f = tau, using Lemma 121. For n >= 3, N0 >= 2
(isotropic vectors exist), so D_1 <= 2(q-1) q^n. Then
(q-1) log2(2(q-1)/q) <= (q-1) - ((q-1)/q) log2 e <= q - 1.9618 for q >= 3.
Next, N0 <= q^(n-1) + (q-1) q^((n-2)/2) gives D_0/q^(n+1) < 2 + (1 + q^(1-n/2)) + 2/81 < 3.61,
so log2(D_0/q^(n+1)) < 1.852. That proves the middle inequality. For the last one, use
log2(q^(n-1) + 1) <= (n-1) log2 q + 0.152 <= (n-1)(q-1) + 0.152, and 1.052 < q - 1. ∎

For comparison at q = 11, k = 4: the sliced bound gives Lambda(G_3) <= 16.37 (D_1 = 25541,
D_0 = 38851, q^4 = 14641), the true value is smaller still, the target is 40, and the Jensen bound of a166 gives 40.58 > 40.

## 6. What changes, and what is next

- **Proved so far (q odd):** C_q(1), C_q(2) and C_q(3) for quadratic maps (Theorems 38, 43);
  C_q(n+1) for the family G_n (Theorem 46).
- **Retired:** the reduction "Q_j for all j implies C_q(k) for all quadratic maps" (a166 §5)
  is still a valid implication, but Q_4 is false, so it proves nothing for k >= 4.
- **Replacement (Q'_k):** every quadratic map of F_q^k (q odd) that respects no subspace and
  has Q != 0 admits a linear functional psi (psi = 0 allowed) whose sliced bound
  (Theorem 45 with f = psi) is at most k(q-1). By the same induction with Theorem 4,
  Q'_j for all j <= k implies C_q(k) for every quadratic map of F_q^k. Q'_2 and Q'_3 hold
  (psi = 0), and Q'_(n+1) holds for G_n (psi = tau).
- **The inverse problem behind Q'_4.** By Prop 52, a large Pibar means many directions of
  small rank. In G_n they fill a hyperplane W, with A o w in span(w, e) for one fixed e. The
  next target is a structure theorem in this direction: if an irreducible quadratic map of
  F_q^4 has Pibar > q(2^(4(q-1)/q) - 1), then its rank-<=1 directions span a hyperplane
  ker psi whose slices carry all the excess, so that the sliced bound with that psi wins.
- **A search when compute returns:** quadratic maps of F_5^4 and F_7^4 that respect no
  subspace, maximising min over psi of the sliced bound. A map above 4(q-1) would refute
  Q'_4. A map whose actual Lambda is above 4(q-1) would refute C_q(4) and give a new record
  Kakeya construction.
