## Lemma 91 (the span of a value)

**Lemma 91.** Let k != 0, s = sigma(k), r = rank A_k and f = dim Fix(A_k). Then

    dim C_k = 10 - dim U+(k) >= r + 3,   and   dim C_k <= dim(C_k n Fix(A_k)) + dim(A_V s + span(s)),

so dim(A_V s + span(s)) >= 3 + r - f >= 3.

*Proof.* beta(k, .) is linear with image beta(k, V), and U+(k) is the preimage of
beta(k, V) n span(s), so dim U+(k) = 9 - dim beta(k, V) + dim(beta(k, V) n span(s)) =
10 - dim C_k. By Lemma 30 (b), dim U+(k) <= 1 + A(6 - r) = 7 - r, as A(m) = m for m <= 6
(Theorems 27 and 31; 0 <= 6 - r as rank A_k <= 6). So dim C_k >= r + 3.

By (*) with h = k, (I + A_k) beta(k, h') = A_(h') s for every h', so I + A_k maps beta(k, V) onto
A_V s; and (I + A_k) s = s, since A_k s = 0. So I + A_k maps C_k onto A_V s + span(s), with kernel
C_k n ker(I + A_k) = C_k n Fix(A_k). This gives the second line. Fix(A_k) lies in Im A_k (y = A_k y),
so f <= r, and the last inequality follows. QED

Lemma 91 holds for every element, not only in (B6) and (B5); it uses only (*), Lemma 30 and
A(m) = m for m <= 6. It is useful where A_V s is known to be small, as next.

## Lemma 92 (case (II) is impossible)

**Lemma 92.** In (B6) and (B5) at t = 7, there is no w != 0 in N with A_w = 0 in case (II) of
Lemma 89 (that is, with x0 outside C_w).

*Proof.* Suppose there is one; put z = sigma(w). By Corollary 59 (ii) (which uses Lemma 90),
beta(w, V) is a plane span(p_1, p_2), and C_w = span(z, p_1, p_2) has dimension 3. Pick g_1 with
beta(w, g_1) = p_1.

*Step 1 (A_V p_1 lies in A_(g_1) beta(w, V)).* (Q) with h_1 = w, h_2 = g_1 and h' = h gives
A_h p_1 = A_w beta(g_1, h) + A_(g_1) beta(w, h) = A_(g_1) beta(w, h), as A_w = 0. As h runs over V,
beta(w, h) runs over beta(w, V), so A_V p_1 = A_(g_1) beta(w, V), of dimension at most 2.

*Step 2 (p_1 lies in it).* (*) with h = g_1 and h' = w gives
0 = A_w sigma(g_1) = (I + A_(g_1)) beta(g_1, w) = (I + A_(g_1)) p_1, so A_(g_1) p_1 = p_1, which
lies in A_V p_1. So A_V p_1 + span(p_1) = A_V p_1 has dimension at most 2. (The same step with any
h in place of g_1 gives A_h beta(w, h) = beta(w, h) for every h; this is the correct reason for
"A_h p_1 = p_1" in Corollary 59 (iv).)

*Step 3 (p_1 is a value of sigma).* By Corollary 59 (iii), U+(w) contains a subspace U of
dimension 3 on which sigma is linear and one-to-one with sigma(U) = C_w. So p_1 = sigma(k_1) for
some k_1 in U, and k_1 != 0 as p_1 != 0.

*Step 4.* Lemma 91 for k = k_1 and s = p_1 asks dim(A_V p_1 + span(p_1)) >= 3. Step 2 gives at
most 2. This contradiction proves the lemma. QED

**Remarks.**

- Step 3 needs much less than Corollary 59 (iii): any 2-dimensional subspace of U+(w) with sigma
  values in C_w would do, since its image, a plane in the 3-dimensional C_w, meets the plane
  beta(w, V) in a non-zero vector s, and Steps 1 and 2 hold for every non-zero s = beta(w, g). So
  the lemma also holds with M(4) <= 5 in place of M(4) = 4.
- The proof uses Lemma 30 (by hand), A(m) = m for m <= 6 (Theorem 31 is computer-assisted; for
  rank A_(k_1) >= 1 only A(m) for m <= 5 is used, which is by hand), Lemma 89 (by hand),
  Lemma 90 and Corollary 59 (by hand, using Corollary 55, computer-assisted), Lemma 27 and
  M(4) = 4 (through Corollary 59 (iii)).
- In case (I) the same count gives no contradiction: there beta(w, V) has dimension 3
  (Corollary 59 (i) with C_w = X_1), so Steps 1 and 2 give dim(A_V s + span(s)) <= 3, and Lemma 91
  then forces only Fix(A_k) = Im A_k (A_k is idempotent) for every k with sigma(k) = s in
  beta(w, V). This is recorded as the last true statement on case (I), not as a result.

## Corollary 60 (zero maps in ker phi)

**Corollary 60.** Let u be an element of rank 3 in (B6) with d >= 1, or in (B5) with d >= 2, at
t = 7 and dim V = 9. Then A_n != 0 for every n != 0 in N = ker phi, so h -> A_h is one-to-one on
N. In (B6) with d = 0 and in (B5) with d <= 1, every non-zero n in N with A_n = 0 is in case (I)
of Lemma 89 (x0 in C_n, and C_n = ker A_u in (B6)).

*Proof.* Corollary 58 (iii) leaves only case (II) for such u, and Lemma 92 rules it out. The
second sentence is Lemma 89 with Lemma 92. QED

In (B6), by Lemma 88 (a) of [a36.md](a36.md), A_n = 0 exactly when beta(n, V) lies in ker A_u, so
Corollary 60 also says: for every n != 0 in N, beta(n, V) is not inside ker A_u.

**As a solver condition.** In an instance of job m42, the basis of V starts with h_0 = u and
h_1, ..., h_(k-1) spanning N with u (k = 3 in (B6), 4 in (B5)), and A_u is fixed. Corollary 60 is
one condition per non-zero n in N: "A_n != 0". For n = h_i it is one clause over the 49 entries of
A_(h_i); for n = u + h_i it is one clause "A_(h_i) != A_u" (each literal fixed by the bit of A_u);
for sums of two or more of h_1, ..., h_(k-1) it needs XOR auxiliary variables. It is the first
fact of these notes on ker phi that becomes clausal once A_u is fixed, as a38.md asked. Whether it
helps the solver is not known: nothing has been measured, and no speed-up is claimed.

## Where the attempts stop

1. *Case (I).* As in the last remark on Lemma 92: Lemma 91 makes A_k idempotent for every k with
   sigma(k) in beta(w, V), no contradiction found. Case (I) needs d = 0 in (B6) and d <= 1 in (B5),
   classes where the solver already does best.
2. *The d = 3 classes.* Corollary 60 holds there, but does not close them by hand. Lemma 91 for u
   with d = 3 gives nothing new: A_u^2 = 0, so Fix(A_u) = 0, and A_V x0 + span(x0) =
   (I + A_u) P + span(x0) has dimension dim P + 1 >= 6, more than the 6 = 3 + 3 that Lemma 91 asks.
3. *Lemma 91 elsewhere.* It bounds from below the span of A_V s for every value s of sigma. The
   places where A_V s is known to be small are the values in beta(w, V) for a zero map w; with
   Corollary 60 there are none in the hard classes. Other places to try: values s = sigma(k) with
   k in N, where (N) of a36.md gives A_n x0 = 0 and A_n phi(h) = A_u beta(n, h).
