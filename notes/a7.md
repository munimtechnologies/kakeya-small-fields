# Toward A(7) <= 9: at t = 7 every rank-3 element is in shape (c), with Im A_u inside ker A_u

MV2 of Munim, Inc., 2026-10-18. Added to kakeya-small-fields after release v1.7.14, next to
[a6.md](a6.md) and [case-b-shapes.md](case-b-shapes.md). Numbering continues from a6.md (Lemma 57,
Corollary 31, Lemma 58, Corollary 32). This is partial progress: it settles no new case of
Corollary 30. It was researched and written with AI agents working in MV2's name. Lemmas 57 and 58
and Corollary 31 are proofs by hand. Corollary 32 also uses a classical bound of Schur and Jacobson,
which `cube_groups/a7_c.py` checks directly for 3 x 3 matrices over F_2. That module also sets up
the search m21, which was waiting for compute when this note was written. No human mathematician has
checked the proofs. Text CC BY 4.0, code Apache-2.0.

## What changes

- **Lemma 57.** In an anisotropic system with t = 7 and dim V = 10, let u have rank 3. Then no
  non-zero n in U+ has its value sigma(n) in the span Z_N of the values of beta on U+.
- **Corollary 31.** In such a system **every element of rank 3 is in shape (c)** (beta vanishes on
  U+), and **Im A_u lies in ker A_u** (A_u^2 = 0). Shape (c) is the only case left for A(7) <= 9.
  This is the analogue at t = 7 of Corollary 22 (t = 6). It has a different proof, which does not
  need a list of the shapes at k = 4. It uses none of the solver answers of jobs m12 to m19, and
  none of Theorems 27 and 28.
- **Lemma 58.** In shape (c) at t = 7, an element n != 0 of U+ with A_n = 0 has sigma(n) = y in
  Y = beta(u, V) n ker A_u, its U+ is exactly W, and y lies in Im A_u.
- **Corollary 32.** Such an element always exists. So a system with t = 7 and dim V = 10 gives one in
  a normal form with M_(v_1) = 0, which splits into 16 exact searches with five families of linear
  side conditions (job m21-a7-v1, queued).
- If all 16 searches come back UNSAT, then A(7) <= 9, which settles **Z_4^10 x Z_2^2**, the first
  open case (10, 2) (Corollary 18(b)).

## Setting

As in [case-b.md](case-b.md) and [shape-c.md](shape-c.md): X = F_2^t, sigma : V -> X quadratic with
polar form beta, h -> A_h linear, and

    A_(h') sigma(h) = (I + A_h) beta(h, h')                                    (*)
    A_(h') beta(h_1, h_2) = A_(h_1) beta(h_2, h') + A_(h_2) beta(h_1, h').      (Q)

Throughout, the system is anisotropic, t = 7, dim V = 10, and u has rank rho = 3, so k = t - rho = 4
and dim V = t + k - 1. Put x0 = sigma(u), phi = beta(u, .), X_1 = ker A_u (dimension 4),
R = Im A_u (dimension 3), N = U+ = ker phi (dimension 4), P = phi(V), Y = P n X_1 (dimension 3),
W = phi^(-1)(Y) (dimension 7), and Z_N = span beta(N, N). Since 2 rho <= t and A(s) = s for s <= 4,
u is in Case B (Proposition 26), and we use:

- Proposition 26(e): for n in N, A_n x0 = 0, sigma(n) lies in X_1 and Im A_n lies in R;
- Proposition 27(a): Z_N lies in X_1 n R; and (Z) of case-b-shapes.md: A_h z lies in R for every
  z in Z_N and every h;
- (4) of case-b-shapes.md: A_n phi(h) = A_u beta(n, h) for n in N; and (1) of case-b.md:
  A_h x0 = (I + A_u) phi(h);
- Lemma 30 for any element n != 0 of rank s: with U+(n) = {h : beta(n, h) in span(sigma(n))},
  dim U+(n) <= 1 + A(t - s - 1), and U+(n) / span(n) carries an anisotropic system (its proof);
- Lemma 27(c): an anisotropic system with an invariant subspace of dimension c, 0 < c < t, has
  dim V <= M(t - c) + A(c);
- the bounds A(1), A(2), A(3), A(4) = 1, 2, 3, 4 and M(4) = 4 (Theorem 26), A(5) <= 6 and A(6) <= 8
  (Proposition 24), and M(5) <= 5 + E(5) <= 6 (Theorem 24). The sharper A(5) = M(5) = 5
  (Theorem 27) and A(6) <= 7 (Theorem 28) are not needed.

## Lemma 57 (no value of U+ in Z_N)

**Lemma 57.** In the setting above, no n != 0 in N has sigma(n) in Z_N.

*Proof.* Suppose n is one, and put z = sigma(n) (non-zero, as the system is anisotropic),
B_n = beta(n, V) and C = B_n + span(z).

*Step 1: C lies in R.* (*) with h -> n and h' -> h gives A_h z = (I + A_n) beta(n, h), that is,
beta(n, h) = A_h z + A_n beta(n, h). The first term lies in R by (Z), the second by Proposition
26(e). So B_n lies in R, and so does z (Proposition 27(a)). Put c = dim C - 1; as dim R = 3,
c is 0, 1 or 2.

*Step 2: codim U+(n) = c.* U+(n) is the preimage under beta(n, .) of B_n n span(z), so its
codimension is dim B_n - dim(B_n n span(z)) = dim C - 1 = c. Hence dim U+(n) = 10 - c >= 8.

*Step 3: A_n = 0.* Let s = rank A_n. If s >= 1, Lemma 30 for n gives
dim U+(n) <= 1 + A(6 - s) <= 1 + A(5) <= 7 < 8. So s = 0.

*Step 4: C is invariant under A_h for every h in U+(n).* As A_n = 0, Step 1 reads A_h z = beta(n, h)
for every h, and (Q) with h_1 = n, h_2 = h'' and h' = h reads A_h beta(n, h'') = A_(h'') beta(n, h).
For h in U+(n), beta(n, h) = e z with e in F_2. Then A_h z = e z lies in C, and
A_h beta(n, h'') = e A_(h'') z = e beta(n, h'') lies in B_n.

*Step 5: a smaller system.* As in the proof of Lemma 30(b) for the element n (whose kernel is all
of X, since A_n = 0): span(z) is invariant under A_h for h in U+(n) (A_h z = beta(n, h) lies in
span(z)), dividing by it (Lemma 27(a)) and factoring out n, which is a zero of sigma modulo z with
A_n = 0 (Lemma 21(a)), gives an anisotropic system on U+(n) / span(n), of dimension 9 - c, with
values in X / span(z), of dimension 6. Its maps are induced by the A_h, so by Step 4 the subspace
C / span(z), of dimension c, is invariant.

*Step 6.* If c = 0, then 9 <= A(6) <= 8. If c = 1, Lemma 27(c) gives 8 <= M(5) + A(1) <= 6 + 1. If
c = 2, it gives 7 <= M(4) + A(2) = 4 + 2. Each is false. QED

## Corollary 31 (only shape (c) at t = 7)

**Corollary 31.** In an anisotropic system with t = 7 and dim V = 10, every element u of rank 3 is
in Case B with beta = 0 on U+ (shape (c)), and Im A_u lies in ker A_u, that is, A_u^2 = 0. Hence
A(7) <= 9 holds if and only if no anisotropic system with t = 7 and dim V = 10 has an element of
rank 3 in shape (c).

*Proof.* Suppose beta does not vanish on N, so Z_N != 0. If sigma is not one-to-one on N, say
sigma(a) = sigma(b) with a != b in N, then n = a + b != 0 has sigma(n) = sigma(a) + sigma(b) +
beta(a, b) = beta(a, b), which lies in Z_N. If sigma is one-to-one on N, then, as sigma maps N into
X_1 (Proposition 26(e)) and both have 16 elements, it maps N onto X_1, which contains Z_N; so some
n != 0 has sigma(n) in Z_N \ {0}. Either way Lemma 57 is contradicted. So beta = 0 on N, and
Proposition 27(c4) gives dim(X_1 n R) >= k - 1 = 3 = dim R, that is, R lies in X_1. The last
sentence is Corollary 18(b) with this. QED

Corollary 19(b) of case-b.md said A_u^2 = 0 *if* beta vanishes on U+; Corollary 31 says that it
always does. The same argument does not settle t = 6 (k = 3): there Steps 1 to 3 still give
A_n = 0, but Step 6 for c = 2 reads 5 <= M(3) + A(2) = 5, which holds.

## Lemma 58 (shape (c): an element of U+ whose map is 0)

From here on u is in shape (c), so (Corollary 31) R lies in X_1, and we use the matrices M_n of
Lemma 38 (A_n = T M_n T^(-1) A_u for n in N, where T : X/X_1 -> R is induced by A_u; M_u = I; the M_n
commute), the maps G_y = A_(h_y) on X_1 and the classes q(y) = [sigma(h_y)] of Lemma 38(d) for y in
Y (h_y in W with phi(h_y) = y), and n_y, the element of N_Y = sigma^(-1)(Y) with sigma(n_y) = y.
Since R lies in X_1, the subspace L = [R] of Lemma 46 is 0, so Lemma 46(c) reads
M_(n_y) q(y) = 0 for every y in Y.

**Lemma 58.** Let u be in shape (c) at t = 7 (dim V = 10, rank 3), and let n != 0 in N have
A_n = 0. Put z = sigma(n). Then:

(a) X_1 = span(z) + beta(n, V);

(b) U+(n) = W: for h in V, beta(n, h) lies in span(z) if and only if h lies in W;

(c) z lies in Y, so n = n_z; for every y' in Y, G_(y') z lies in span(z); G_z z = 0; and T q(z) = z,
    so z lies in R.

*Proof.* (a) Steps 2, 4, 5 and 6 of the proof of Lemma 57 use only A_n = 0 and C = beta(n, V) +
span(z) with c = dim C - 1, together with Step 1's identity A_h z = beta(n, h), which here is (*)
with A_n = 0. Now C lies in X_1: z does (Proposition 26(e)), and by (4),
A_u beta(n, h) = A_n phi(h) = 0. So c <= 3, and Step 6 rules out c = 0, 1, 2. Hence c = 3 and
C = X_1.

(b) By Step 4, X_1 = C is invariant under A_h for every h in U+(n). By (1),
A_h x0 = phi(h) + A_u phi(h), and A_u phi(h) lies in R, inside X_1; so A_h x0 lies in X_1 only if
phi(h) lies in X_1 n P = Y, that is, only if h lies in W. So U+(n) lies in W. Both have dimension
7 (codim U+(n) = c = 3 by Step 2, and dim W = 2k - 1), so they are equal.

(c) Write n = n_y + e u with y in Y and e in F_2 (N = N_Y + span(u)). As A_n = 0 and T is one-to-one,
M_n = M_(n_y) + e I = 0. y != 0, since otherwise n is 0 or u, and A_u != 0. By Lemma 46(c) (with
L = 0) and Lemma 38(e), M_(n_y) q(y) = 0 with q(y) != 0, so M_(n_y) is singular; hence e = 0,
n = n_y and z = y. By (b) and Lemma 38(d), G_(y') y = beta(n, h_(y')) lies in span(y) for every y'
in Y. (5) of shape-c.md with n = n_y gives (G_y + G_y^2) y = T M_(n_y) q(y) = 0. If G_y y = y, then
by Lemma 46(b) T q(y) = y + G_y y = 0, against q(y) != 0. So G_y y = 0, and T q(y) = y lies in R.
QED

## Corollary 32 (a normal form with M_1 = 0)

**Corollary 32.** If some anisotropic system with t = 7 has dim V = 10, then some such system has an
element u of rank 3 in shape (c) with R inside X_1, in the normal form of Lemmas 35, 37 and 39 with
M_1 = M_(v_1) = 0 and (M_2, M_3) the least pair of one of the 16 orbits of commuting pairs of
3 x 3 matrices (under GL_3(F_2) x GL_2(F_2)) whose span has no invertible element, and with:

    (D) A_u e_c lies in X_1 for c = 4, 5, 6                              (R in X_1, Corollary 31)
    (W) A_(v_(3+j)) maps X_1 into X_1 and induces M_j on X/X_1, j = 1, 2, 3   (Prop. 27(c2), Lemma 46(a))
    (K) M_(n_y) q(y) = 0 for the 7 non-zero y in Y                       (Lemma 46(c))
    (U) beta(v_1, v_(3+j)) lies in span(e_1), j = 1, 2, 3                (Lemma 58(b))
    (G) A_(v_4) e_1 = 0                                                  (Lemma 58(c))

Here X_1 = span(e_0, ..., e_3) with e_0 = x0, v_1, v_2, v_3 in N with sigma(v_j) = e_j, and v_(3+j) in W
with phi(v_(3+j)) = e_j, as in Lemmas 35 and 37.

*Proof.* Corollary 18(b) gives an element u of rank 3, and Corollary 31 puts it in shape (c) with R
inside X_1. The M_n (n in N) commute and M_u = I (Lemma 38), so the algebra they generate is a
commutative subalgebra of M_3(F_2). By Schur's bound (I. Schur 1905; N. Jacobson, Bull. Amer. Math.
Soc. 50 (1944) 431-436, for every field), it has dimension at most floor(3^2 / 4) + 1 = 3; we use
only the consequence that a space of commuting 3 x 3 matrices over F_2 containing I has dimension at
most 3, which `a7_c.py` checks by exhaustion. As dim N = 4, some n != 0 has M_n = 0, that is,
A_n = 0. By Lemma 58(c), sigma(n) = y lies in Y \ {0}. Start the normal form of Lemma 37 from the
basis e_1 = y, e_2, e_3 of Y with v_1 = n; then M_1 = 0. Lemma 39 with a recombination matrix of the
form diag(1, c') (c' in GL_2) and any g in GL_3 keeps v_1, e_1, v_4 and W, keeps M_1 = 0, and moves
(M_2, M_3) anywhere in its orbit under GL_3 x GL_2. By (K) and q(y) != 0, every M_(n_y) with y != 0
is singular, so span(M_2, M_3) has no invertible element; job m18 found 16 such orbits among the 38
(a6-d3.md). (D) is Corollary 31; (W) is Proposition 27(c2) and Lemma 46(a) with L = 0; (K) is Lemma
46(c); (U) is Lemma 58(b) for v_1, as v_4, v_5, v_6 lie in W; (G) is G_(e_1) e_1 = 0 from Lemma
58(c). QED

## The search (job m21-a7-v1, queued 2026-10-18)

`cube_groups/a7_c.py` builds, for each of the 16 orbits, the CNF of `shape_c.encode_split` at
(t, k) = (7, 4) with (M_1, M_2, M_3) = (0, M_2, M_3) (the normal form, shape (c) values and the
equations (S) of shape-c.md), adds (D), (W) and (K) exactly as `shape_c3.py` does (those clauses are
valid whenever R lies in X_1), and adds (U) and (G) as 22 unit clauses. By Corollary 32, A(7) <= 9
holds if all 16 CNFs are unsatisfiable. The same construction at (3, 2) (1 instance) and (5, 3)
(3 instances) gives controls: there dim V = t + k - 1 exceeds A(3) = 3 and A(5) = 5, so they must be
UNSAT whatever is added.

Predictions, written before the job was queued (m21/predictions.md): the unit tests and the
selfcheck pass (1, 3 and 16 instances; the commutative bound for 2 x 2 and 3 x 3 matrices); the 4
controls are UNSAT; any SAT answer is a verified model. The 16 instances at (7, 4) are
exploratory, 9 minutes each. If all are UNSAT, A(7) <= 9 follows (computer-assisted), and with it the
answer yes for Z_4^10 x Z_2^2. A verified SAT answer would be an anisotropic system with t = 7 and
dim V = 10, so A(7) = 10; we would publish it with its matrices.

## Computation

`cube_groups/a7_c.py` (new). Its unit tests check that the appended clauses accept exactly the
coordinates that a direct check of (D), (W), (K), (U) and (G) accepts, at (3, 2), (5, 3) and (7, 4),
on points built to satisfy them, on random points and on one-bit changes; that (U) and (G) add
exactly (k - 1)(t - 1) + k unit clauses and no variables, and that flipping any bit they fix is
rejected; that the instances are the kept orbits of `shape_c3.py` with M_1 = 0 in front; and the
commutative bound for m = 2 and 3, by checking that for any m - 1 commuting matrices independent
together with I, every matrix commuting with all of them lies in their span with I.

Lemmas 57 and 58 and Corollaries 31 and 32 are hand proofs with no computer check of their own,
apart from the commutative bound.
