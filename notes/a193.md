## 1. Proposition 87: why S(P) = 162 forces a diagonalisable linear part

Notation of a192. For P: F_3^3 -> F_3^3,
S(P) = sum_{t in F_3} sum_{fibres F of x -> P(x) + t x} |F| log2 |F|,
and the KLSS value is 162 (base (27/4)^(1/3) = 1.889882). a192 (Proposition 86, an exhaustive
scan of all 15 * 3^18 quadratic maps up to symmetry) found that every quadratic P has S(P) <= 162,
that equality holds for exactly **50,544** maps with P(0) = 0, and that all of them have DP(0)
diagonalisable over F_3. It asked for a conceptual reason. Here it is.

**Definition.** A *product map* is P = B o (p_1 x p_2 x p_3) o B^{-1} with B in GL_3(F_3) and
p_j(y) = a_j y^2 + lam_j y, a_j in {1, 2}, lam_j in F_3. In words: in some basis, P acts on each
coordinate separately by a one-dimensional quadratic.

**Proposition 87.** A quadratic map P: F_3^3 -> F_3^3 with P(0) = 0 has S(P) = 162 if and only if
it is a product map. In particular DP(0) = B diag(lam) B^{-1} is diagonalisable.

*Proof.* (if) S is invariant under P -> B o P o B^{-1}, since P + t id is conjugated to
p + t id and fibres are mapped bijectively. For p = p_1 x p_2 x p_3, each p_j + t id is a
non-affine map of F_3 with fibres of sizes 2 and 1, so every fibre of p + t id is a product
F_1 x F_2 x F_3 and
sum_F |F| log2|F| = sum_i (sum_{F_i} |F_i| log2|F_i|) * prod_{j != i} 3 = 3 * 2 * 9 = 54
for every t. Hence S = 3 * 54 = 162.

(only if) We count product maps. The frame {B e_1, B e_2, B e_3} as a set of three lines is
recovered from the quadratic part Q of P. Lemma 165 below shows this. Fix a representative
vector b_j on each line. Q is then fixed by the three values Q(b_j) = a_j b_j, so by
a in {1,2}^3, and the linear part is fixed by L b_j = lam_j b_j. Distinct parameters
(frame, a, lam) therefore give distinct maps. There are 11232 / (2^3 * 3!) = **234** unordered
frames of lines in F_3^3, so there are 234 * 8 * 27 = **50,544** distinct product maps with
P(0) = 0. By the first part, each of them attains 162. a192 found exactly 50,544 quadratic maps
with P(0) = 0 attaining 162. The two sets therefore coincide. []

**Lemma 165.** If Q = B o (a_1 y_1^2, a_2 y_2^2, a_3 y_3^2) o B^{-1} with all a_j != 0, then the
vectors u != 0 for which the linear map x -> B_Q(u, x) has rank 1 are exactly the nonzero
multiples of B e_1, B e_2, B e_3. Here B_Q is the symmetric bilinear map with
Q(x + u) = Q(x) + 2 B_Q(x, u) + Q(u).

*Proof.* In the coordinates y = B^{-1} x, B_Q(u, .) is diag(a_1 u_1, a_2 u_2, a_3 u_3). Its rank
is the number of nonzero coordinates of u. []

**Per-class check, independent of the proof.** A product map has DP(0) = L exactly when its frame
consists of eigenvectors of L with the matching eigenvalues. So for a fixed L the number of
equality maps should be 8 times the number of eigen-frames of L.

| L (a192 class representative) | eigen-frames of L | predicted 8 x frames | a192 scan |
|---|---|---|---|
| scalar (0 or I) | all 234 | 1,872 | 1,872 |
| diag(1,0,0) or diag(2,0,0) | the e_1 line + 2 of the 4 lines of the 0-eigenplane: 6 | 48 | 48 |
| diag(0,1,2) | 1 | 8 | 8 |
| not diagonalisable (11 classes) | 0 | 0 | 0 |

All four rows agree with the counts the C scanner produced in a192, which were made without this
structure in mind. The table therefore also checks the scanner itself.

**Verification.** `a193_product_maps.py` (standard library only) enumerates the 234 frames, the
8 sign patterns and the 27 linear diagonals. It checks that the 50,544 maps are distinct and all
have S = 162, and it recounts the table above for the representatives L = 0, I, diag(1,0,0),
diag(2,0,0), diag(0,1,2) and one non-diagonalisable L. It also checks that exactly 2,109 distinct
linear parts occur (3 scalar + 702 + 1,404 diagonalisable matrices).
`test_a193_product_maps.py` runs it.

**What it means.** At block length 3, the KLSS value 162 is attained by quadratic maps only in the
trivial way, as a tensor cube of the one-dimensional map y -> y^2. There is no "twisted" quadratic
equality case that could be perturbed upward. This is a rigidity statement for the quadratic case
of C_3(3). It suggests the following.

**Conjecture Q(k)** (open). For every k, every quadratic P: F_3^k -> F_3^k has S(P) <= 2k * 3^k.
Equality (with P(0) = 0) holds if and only if P is a product map in some frame. If Q(k) holds,
quadratic maps can never beat KLSS at any block length. A counterexample to the equality
clause at some k would be the first structurally new candidate for doing so.

The proof of Proposition 87 uses a192's exhaustive count for the "only if" direction. A proof of
the inequality itself without computation is still open. (Rényi-2 entropy is too weak here: for
y -> y^2 it gives a deficit of log2(5/3) = 0.737 per slice and coordinate, against the true 2/3.)

## 2. Observation 87.1: the non-classical (8,8,8) shape is realised

a189 noted that the height-3 relaxation reaches (8,8,8) with a non-classical shape: root x^2 and
children of slice sizes (2,6,6), (6,2,6), (6,6,2). It left open whether real trees realise this.
They do. In the triangular-map form of a sticky tree (slice t is the image of x -> G(x) + t x
with G_j depending only on x_1..x_j), take

G(x_1, x_2, x_3) = (x_1^2, -x_1 x_2, x_3^2 - x_1 x_3 + 1).

In slice t the child x_1 = t is isolated, at first coordinate 2t^2. It contributes
{2t^2} x {0} x {1, 2}, which is 2 points. The other two children share first coordinate 1 - t^2.
For each of them (t - x_1) x_2 runs over all of F_3, and x_3^2 + (t - x_1) x_3 + 1 has image
{0, 1}, so both give the same 6-point set {1 - t^2} x F_3 x {0, 1}. Each slice has 8 points with
column profile (2, 6), where the classical tree has (4, 4). This is checked in
`a193_product_maps.py`. It is a second, structurally different optimal tree at height 3 (pi_3 = 512
is still exact). Because the union equalities are arranged by a common "column template",
the same device may give other unusual shapes at height 4. That is where S7 is decided.

As a190 predicted, the relaxation run returned **PI4-OPEN** with lower bound **3971** (affine-root
