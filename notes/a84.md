## Corollary 121 (rank 4 at t = 8 is in shape (c))

**Corollary 121 (by hand, using Theorems 29 and 31).** Let an anisotropic system have t = 8 and
dim V = 11, and let u have rank 4. Then u is in Case B, beta vanishes on N = U+ (shape (c)),
d = dim(ker A_u n Im A_u) is 3 or 4, and A_n != 0 for every n != 0 in N.

*Proof.* This is case (i) of Proposition 28 of [a8.md](a8.md). Case (ii) there needs an element
n != 0 of N with rank A_n = 1 and dim U+(n) = 8 = 1 + A(6). By Theorem 31, A(6) = 6, so Lemma 30
gives dim U+(n) <= 1 + A(6) = 7 for every n of rank 1, and case (ii) is empty. The other numbers in
the proof of Proposition 28 only get smaller with the bounds now known: for s = 0 and c <= 2 it
needs 10 <= A(7), 9 <= M(6) + A(1) and 8 <= M(5) + A(2) to fail, and with Theorem 29
(A(7) <= 9) and Theorems 31 and 27 (M(6) = 6, M(5) = 5) they read 10 <= 9, 9 <= 7 and 8 <= 7;
Theorem 33 is not needed. d <= 4 as dim Im A_u = 4. QED

So Proposition 36(b) of [a83.md](a83.md) sharpens: the rank-4 configuration of A(8) <= 10 is Case B
in shape (c). From here on we use the setting of [shape-c.md](shape-c.md) with t = 8, k = 4,
rho = 4: X_1 = ker A_u and R = Im A_u have dimension 4, Y = P n X_1 has dimension 3, sigma maps N
linearly onto X_1 (Proposition 27(c1)), N_Y = sigma^(-1)(Y) has dimension 3 and N = span(u) + N_Y,
T : X/X_1 -> R is the isomorphism that A_u induces, A_n = T M_n T^(-1) A_u for n in N with the
M_n commuting 4 x 4 matrices and M_u = I (Lemma 38), D = T^(-1)(X_1 n R) and L = [R], of
dimensions d and 4 - d (Lemma 46). For y in Y, n_y is the element of N_Y with sigma(n_y) = y.

## Lemma 94 (the type of A_u, and the singular matrices of U+)

**Lemma 94.** In the setting of Corollary 121:

(a) A_u is similar to one of

    (N4)   d = 4: A_u^2 = 0, Jordan blocks 2, 2, 2, 2 (Im A_u = ker A_u);
    (N3)   d = 3 and A_u^3 = 0: nilpotent with Jordan blocks 3, 2, 2, 1;
    (F3)   d = 3 and A_u^3 != 0: Jordan blocks 2, 2, 2, 1 for the eigenvalue 0 and one block 1 for
           the eigenvalue 1, so A_u fixes a vector v != 0, and Im A_u^2 = span(v).

(b) In (N4) and (F3), M_(n_y) q(y) = 0 for every y in Y. So M_n is singular for every n != 0 in
    N_Y, and the M_n with n in N_Y form a 3-dimensional space of commuting 4 x 4 matrices in which
    every matrix is singular.

(c) Let n != 0 in N have M_n singular, of rank s (1 <= s <= 3), and put z = sigma(n) and
    C = span(z) + beta(n, V). Then dim U+(n) = 8 - s = 1 + A(7 - s), so the bound of Lemma 30 for n
    is reached; dim C = s + 4; and C = beta(n, V) + X_1, so C contains X_1, and x0 in particular.

*Proof of Lemma 94.* (a) d is 3 or 4 by Corollary 121, and A_u maps R onto Im A_u^2 with kernel X_1 n R, so
rank A_u^2 = 4 - d. If d = 4, then R = X_1 (both have dimension 4) and A_u^2 = 0; a map of rank 4
on F_2^8 with square 0 has four blocks of size 2. If d = 3, Im A_u^2 is a line span(v), with
v = A_u^2 w for some w. If A_u^3 = 0, A_u is nilpotent with rank sequence 4, 1, 0, so the numbers of
Jordan blocks of size at least 1, 2 and 3 are 8 - 4 = 4, 4 - 1 = 3 and 1 - 0 = 1: blocks 3, 2, 2, 1.
If A_u^3 != 0, then A_u v = A_u^3 w is non-zero and lies in Im A_u^3, inside Im A_u^2 = span(v), so
A_u v = v. Then rank A_u^j = 1 for every j >= 2, the eigenvalue 1 has a single block of size 1, and
on the rest (of dimension 7) A_u is nilpotent with rank sequence 3, 0: blocks 2, 2, 2, 1.

(b) By Lemma 46(c) (which holds in shape (c) for every Case B element, [shape-c.md](shape-c.md)),
M_(n_y) q(y) lies in L n D, and T maps L n D onto Im A_u^2 n X_1. In (N4), L = 0. In (F3),
Im A_u^2 = span(v) with A_u v = v != 0, so v is not in X_1 and Im A_u^2 n X_1 = 0. So in both,
M_(n_y) q(y) = 0. For y != 0, q(y) != 0 (Lemma 38(e)), so M_(n_y) is singular; n_y runs over
N_Y \ {0} as y runs over Y \ {0}. M_n != 0 for n != 0 by Corollary 121, as rank A_n = rank M_n
(Lemma 38(a)). The M_n commute (Lemma 38(b)), and n -> M_n is linear and one-to-one, so the
M_n with n in N_Y span a space of dimension 3.

(c) s >= 1 by Corollary 121 and s <= 3 as M_n is singular; rank A_n = s. Step 2 of the proof of
Lemma 57 (which uses nothing about t or k; (2) of [a8.md](a8.md)) gives dim U+(n) = 11 - c with
c = dim C - 1. Lemma 30 for n gives dim U+(n) <= 1 + A(8 - s - 1) = 1 + A(7 - s), and
A(7 - s) = 7 - s for s = 1, 2, 3 (Theorems 31, 27 and 26), so c >= 3 + s. On the other side,
[beta(n, h)] = M_n [phi(h)] (Lemma 38(a)), and the classes [phi(h)] fill X/X_1 (as [P] = X/X_1),
so the image of beta(n, V) in X/X_1 is Im M_n, of dimension s. Hence beta(n, V) + X_1 has
dimension s + 4, and it contains C, as z lies in X_1. So c <= 3 + s. Together, c = 3 + s,
dim U+(n) = 8 - s, and C, of dimension s + 4, equals beta(n, V) + X_1. QED

What Lemma 94 uses: Corollary 121 (so Proposition 28, Lemma 60, Corollary 35, Theorems 29 and 31),
Lemmas 30, 38 and 46, Proposition 27 and Theorems 26 and 27. Through Theorem 31 it is
computer-assisted (775 solver answers at t = 6, [a23.md](a23.md)); it does not use Theorem 33.

## What rank 4 at (8, 11) still needs

- **No contradiction yet.** Lemma 94 is a list of necessary conditions. A 3-dimensional space of
  commuting singular 4 x 4 matrices over F_2 that together with I spans a space of dimension 4
  exists (for example, inside the 4-dimensional space of block matrices with a single 2 x 2 block
  above the diagonal, whose products are all 0), so (b) alone is not a contradiction. At t = 7 the
  analogous step was decisive because Schur's bound forced a zero matrix (Theorem 29); at t = 8
  Schur's bound is 5 > 4 = dim N, as a8.md noted.
- **Which way next.** Two routes, to be chosen in the next run:
  (1) by hand: use (c) for each singular M_n. U+(n) / span(n) then carries an anisotropic system
  of the largest possible dimension, 7 - s, with values in a space of dimension 7 - s (the proof
  of Lemma 30), and C contains x0, as in Lemma 60(c); for A_n = 0 that was a contradiction, and the
  question is whether a version of it holds for A_n of rank 1 to 3.
  (2) by machine, as at t = 7 (Lemmas 85 and 86, job m44, where all 54 classes of shape (c) closed
  in under 4 s each): fix A_u to one of the three types of (a), and in (N4) and (F3) the space
  span{M_n : n in N_Y} to one orbit of 3-dimensional commuting spaces of singular matrices under
  GL_4(F_2) x GL_3(F_2) (Lemma 39), then run the shape (c) search at (t, k) = (8, 4) per orbit.
  The orbits have not been counted. Before any queue of instances at t = 8, one pilot instance
  should measure their size and solver time (1 GB, short cap).
- **(B7)_8 and (B6)_8** (rank 3 with x0 outside P) are untouched; [a83.md](a83.md) has the plan.

  as a claim with its evidence, not as an established result.
