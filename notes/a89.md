# Why the control failed: a square identity in type (N4), and 8 orbits at t = 8 ruled out by hand

MV2 of Munim, Inc., 2026-10-24. Added to kakeya-small-fields next to [a88.md](a88.md). It was
researched and written with AI agents working in MV2's name. On 2026-10-23, job m96a-relax-cores-v1
ran from 23:37 to 23:40 UTC and job m96b-relax-cores-v1 from 23:40 to 00:07 UTC on 2026-10-24, both
to the end. They asked why m95's positive control failed: why the CNFs of rank 4 at t = 8 have no
model even without their anisotropy clauses ([a88.md](a88.md)). This note grades them and proves by
hand **Lemma 98**, an identity that holds in type (N4) without anisotropy. **Lemma 99** draws its
consequences. It explains every small case m96 found and rules out by hand 8 of the 23 orbits of
type (N4) at (t, dim V) = (8, 11), m94's pilot among them. No result about A(8) is claimed yet:
Corollary 122 and Proposition 37 stay unused. The next free numbers are Lemma 100, Corollary 122,
Proposition 37 and Theorem 34. No human mathematician has checked the proofs. Text CC BY 4.0, code
Apache-2.0.

- **The positive control now exists at t = 4 and t = 6.** Without anisotropy, the CNF of type (N4)
  has models for M = N and M = E at (4, 2), and for (E_00, E_11) and (E_00, E_12) at (6, 3). Every

  sets of hypothesis groups that are already contradictory have 11 groups (I + N), 12 (F) and 19
  ((N, N^2)). At (8, 4) the sets found have 34 and 31 groups but are not proven minimal (some
  deletions hit their 60 s cap).
- **Lemma 98 (by hand, no anisotropy).** In type (N4), every y in Y satisfies
  M_y^2 = M_(n(G_y y)) and (G_y + G_y^2) y = 0. Here M_y is the matrix of the element n_y of U+ with
  sigma(n_y) = y, and G_y is A_(h_y) on ker A_u.
- **Lemma 99 (by hand).** (a) At k = 2, M^2 = 0 or M^2 = M. This is exactly m96's split at t = 4:
  N and E have models without anisotropy, and I + N and F have none. (b) (N, N^2) has no system at
  (6, 3), even without anisotropy. (c) With anisotropy, no M_y with y != 0 is idempotent. So **the 8
  orbits of type (N4) at (8, 11) whose recorded basis starts with E_00 have no anisotropic system**,
  m94's pilot among them, by hand and independently of the SAT answers.
- **Job m97 (queued, predictions written first)** reads Lemma 98 off every model the solver finds
  at t = 4, 6 and 8. It solves a small reduced system built from Lemma 98 for all 23 orbits of type
  (N4). And it solves the relax CNF of every orbit at t = 8, which is the control m95 lacked.

## Lemma 98 (the square identity of type (N4))

Setting as in [shape-c.md](shape-c.md): the normal form of Lemmas 35 and 37 in shape (c), with u of
rank t - k, X_1 = ker A_u = span(x0 = e_0, e_1, ..., e_(k-1)), R = Im A_u, T : X/X_1 -> R the
isomorphism A_u induces, N = U+ with sigma linear from N onto X_1, A_n = T M_n T^(-1) A_u for n in N
(Lemma 38(a)), Y = P n X_1, and for y in Y an element h_y of W with phi(h_y) = y, G_y = A_(h_y) on X_1
and q(y) = [sigma(h_y)] (Lemma 38(d)). **Type (N4)** means R = X_1 (so t = 2 k and A_u^2 = 0). For
x in X_1 let n(x) be the element of N with sigma(n(x)) = x; in the normal form n(x0) = u and
n(e_i) = v_i, so M_(n(x)) = x_0 I + sum of x_i M_i. Put n_y = n(y), M_y = M_(n_y) and z_y = G_y y.

**Lemma 98.** In type (N4), for every y in Y:

(a) M_y^2 = M_(n(z_y));

(b) G_y z_y = z_y, that is, (G_y + G_y^2) y = 0, and M_y q(y) = 0;

(c) T q(y) = y + z_y, and T M_n q(y) = (G_y + G_y^2) sigma(n) for every n in N.

The proof uses (*), (Q), the normal form, shape (c), (S), R = X_1 and T one-to-one, and **does not
use anisotropy**.

*Proof.* As R = X_1, the space L = [R] of Lemma 46 is 0. So by Lemma 46(a), A_(h_y) (which maps X_1
into itself, Lemma 38(d)) induces exactly M_y on X/X_1. Lemmas 38(a), 38(d) and 46 do not use
anisotropy ([a88.md](a88.md)).

(a) Let h be in V and pi = [phi(h)]. (Q) with h_1 = n_y, h_2 = h, h' = h_y gives

    A_(h_y) beta(n_y, h) = A_(n_y) beta(h, h_y) + A_h beta(n_y, h_y).

Take classes in X/X_1. On the left, [beta(n_y, h)] = M_y pi (Lemma 38(a)), and A_(h_y) induces M_y,
so the class is M_y^2 pi. The first term on the right lies in Im A_(n_y), inside R = X_1, so its
class is 0. In the second, beta(n_y, h_y) = G_y sigma(n_y) = G_y y = z_y (Lemma 38(d)). As z_y lies
in X_1 = sigma(N), (*) with h -> n(z_y) and h' -> h gives A_h z_y = (I + A_(n(z_y))) beta(n(z_y), h),
whose class is [beta(n(z_y), h)] = M_(n(z_y)) pi, because A_(n(z_y)) maps into R = X_1. So
M_y^2 pi = M_(n(z_y)) pi, and the classes pi fill X/X_1 (P + X_1 = X).

(b) Lemma 46(c) puts M_y q(y) in L n D = 0. Then (5) of Lemma 38(d) with n = n_y gives
(G_y + G_y^2) y = T M_y q(y) = 0, so G_y z_y = G_y^2 y = G_y y = z_y.

(c) This is (5) of Lemma 38(d), with n = u for the first part (Lemma 46(b)). QED

## Lemma 99 (consequences)

**Lemma 99.** In type (N4):

(a) If k = 2 (t = 4), then M = M_v satisfies M^2 = 0 or M^2 = M. So the classes I + N and F of
    2 x 2 matrices have no system in this normal form, even without anisotropy. With anisotropy
    M^2 = 0.

(b) At (t, k) = (6, 3) with (M_(v_1), M_(v_2)) = (N, N^2), N the 3 x 3 shift, there is no system,
    even without anisotropy.

(c) Suppose n -> M_n is one-to-one on N. Then with anisotropy, no y != 0 in Y has M_y^2 = M_y. In
    particular, at t = 8, rank 4 and type (N4), no orbit whose space W = span{M_y : y in Y}
    contains a non-zero idempotent holds an anisotropic system. This rules out the 8 orbits of
    m93's list whose recorded basis starts with E_00: orbits 0, 1, 4, 5, 6, 7, 11 and 14, with m94's
    pilot (orbit 5, W = span(E_00, E_12, E_11 + E_22)).

*Proof.* (a) Here Y = span(e_1), n(e_1) = v and n(x0) = u. Write c = z_(e_1) = G e_1 = a x0 + b e_1.
As G x0 = e_1, G c = a e_1 + b c, and (G + G^2) e_1 = c + G c = (1 + b) c + a e_1 =
(1 + b) a x0 + a e_1, using b (1 + b) = 0. Lemma 98(b) makes this 0, so a = 0. Lemma 98(a) then
reads M^2 = M_(n(b e_1)) = b M. Of the 2 x 2 classes other than 0 and I, N^2 = 0 and E^2 = E, while
(I + N)^2 = I and F^2 = F + I are neither 0 nor the matrix itself. With anisotropy, q(e_1) != 0
(Lemma 38(e)), and T q(e_1) = e_1 + c = (1 + b) e_1 forces b = 0.

(b) Here I, N and N^2 are independent, so n -> M_n is one-to-one and M_(n(x)) determines x. G_y is
linear in y (take h_(y + y') = h_y + h_(y'); G_y does not depend on the choice). Lemma 98(a):

    y = e_1:        N^2 = M_(v_2)              so  G_1 e_1 = e_2;
    y = e_2:        N^4 = 0                    so  G_2 e_2 = 0;
    y = e_1 + e_2:  (N + N^2)^2 = N^2 + N^4 = N^2,  so  (G_1 + G_2)(e_1 + e_2) = e_2,
                    that is, G_1 e_2 + G_2 e_1 = 0 (the cross term 2 N^3 vanishes).

Lemma 98(b) at y = e_1: G_1 z = z for z = e_2, so G_1 e_2 = e_2, and then G_2 e_1 = e_2. At y = e_2,
z = 0, so T q(e_2) = e_2 (Lemma 98(c)), and Lemma 98(c) with n = v_1 gives

    T N q(e_2) = (G_2 + G_2^2) e_1 = G_2 e_1 + G_2 e_2 = e_2 + 0 = T q(e_2).

As T is one-to-one, N q(e_2) = q(e_2), so (N + I) q(e_2) = 0. N + I is invertible, so q(e_2) = 0
and T q(e_2) = 0, which contradicts T q(e_2) = e_2.

(c) If M_y^2 = M_y = M_(n(y)), Lemma 98(a) and injectivity give n(z_y) = n(y), so z_y = y. Then
T q(y) = y + z_y = 0 (Lemma 98(c)), so q(y) = 0, which contradicts q(y) != 0 for y != 0 (Lemma
38(e), which uses anisotropy through Proposition 27(c3)). At t = 8 and rank 4, n -> M_n is
one-to-one by Corollary 121, so Lemma 98 applies to every orbit of type (N4) (Lemmas 94 to 96 and
Corollary 121 put u in this setting). E_00 is idempotent, and in the 8 orbits listed it is M_(v_1).
QED

So the failed control has a simple cause at t = 4 and t = 6. In type (N4), (*) alone forces
M_y^2 = M_(n(G_y y)), which only some tuples of matrices allow. The CNF without anisotropy is UNSAT
exactly when the tuple does not allow it. Lemma 99(a) predicts all four answers at t = 4, and 99(b)
the answer for (N, N^2). The two tuples with models at (6, 3), (E_00, E_11) and (E_00, E_12), are
consistent with Lemma 98 (their squares lie in the span). At (8, 4), Lemma 99(c) rules out the pilot
with anisotropy. Without anisotropy the pilot's CNF is still UNSAT for a reason not yet found by
hand: Lemma 98 alone may or may not be enough, and job m97 checks this.

These lemmas are for type (N4). For d = 3 (m95b) the space L = [R] is not 0, Lemma 46(a) only
gives A_(h_y) = M_y modulo L, and Lemma 98 needs a version with error terms in L.
