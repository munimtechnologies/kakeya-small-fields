## Summary

Recall from a181: a *configuration* in F_3^N is a law mu of a direction D in F_3^N together with
a base point P(d) for each direction, with slices Y_t = P(D) + tD (t in F_3). Write
R0 = log 27 / log(27/4) = 1.7259825. **Conjecture R3** says H(D) <= (R0/3) sum_t H(Y_t) for every
configuration. It would give the exact Kakeya growth base beta_3 = (27/4)^(1/3) = 1.889882.

Since each Y_t is a function of D, H(Y_t) = H(D) - H(D | Y_t), and R3 is equivalent to

> (R3') sum_t H(D | Y_t) <= C3 * H(D),  C3 = 3 - 3/R0 = log 4 / log 3 = 1.2618595.

1. **Theorem 70.** R3 holds for every configuration in F_3 (N = 1): any law, any map. This
   settles the one-dimensional case left open in a181 (Remark 69.4 had only a grid check).
2. **Theorem 71 (extensions).** Suppose a linear quotient Q: F_3^N -> F_3^m carries the
   configuration to a configuration, i.e. Q(P(d)) depends only on Q(d) on the support. If the
   quotient and every fibre satisfy R3, so does the whole configuration.
3. **Corollary 71.1.** R3 holds for every *triangular* configuration, in every dimension: in some
   basis, coordinate j of P(d) depends only on d_1, ..., d_j. Ruzsa's product rho^n is
   triangular and attains R0, so **R0 is the exact sums-differences constant of triangular
   configurations in characteristic 3.**
4. **Corollary 71.2.** A smallest counterexample to R3, if one exists, is *irreducible*: no
   nonzero proper subspace is invariant. In F_3^2 this means no invariant line. Of the 9^9 maps of
   F_3^2 with full support, 2,121,471 (0.55%) have one.
5. **Corollary 71.3 (sticky Kakeya sets).** If the lines of a Kakeya set K in F_3^n can be chosen
   triangularly, then |K| >= (3^n - 1)^(1/R0), which has base (27/4)^(1/3) = 1.889882. For general
   Kakeya sets the best lower base is 1.82074 (a180).
6. **Proposition 77.** A robust form: for any configuration the failure of R3 is at most three
   times a measured distance from triangularity.

This does not prove R3. It proves R3 on the natural class that contains Ruzsa's example and all
coordinatewise constructions, and it reduces the conjecture to irreducible configurations.

## 1. Dimension one (Theorem 70)

**Merge structure.** Let d != e in F_3. Their slice-t values agree iff P(d) - P(e) = -t(d - e).
Since d - e is invertible, this happens for **exactly one** t. If two of the three pairs merge in
the same slice t, then all three directions share their slice-t value, so P(d) = -td + c is
affine and the third pair merges there too. So a map of F_3 is either *affine* (9 maps: one
slice is constant and the other two are injective) or a *triangle* (18 maps,
P(d) = ±d^2 + sd + c: slice t merges a pair and isolates the remaining direction i(t), and
t -> i(t) is a bijection). Checked over all 27 maps (`test_merge_structure`).

For a law p on F_3 the cases are:
- one point: H(D) = 0;
- affine map, or two points: one slice is constant, so sum_t H(Y_t) >= 2H(D) and R_avg <= 3/2 < R0;
- triangle map on three points: H(Y_{t}) = h(p_{i(t)}) = psi(p_i) + psi(1 - p_i), with
  psi(x) = -x log x. Then R3 reads sum_i psi(p_i) <= (R0/3) sum_i [psi(p_i) + psi(1 - p_i)], i.e.
  G(p) >= 0 in the following lemma, with C_TRI = 3/R0 - 1 = log(9/4)/log 3 = 0.7381405.

**Lemma 148.** For every law p = (p_1, p_2, p_3),
G(p) = sum_i [psi(1 - p_i) - C_TRI psi(p_i)] >= 0, with equality only at the vertices and at the
uniform law.

*Proof.* G is continuous on the simplex. Take a minimiser p*.

*Boundary.* If p_3 = 0 then G = psi(p_2) + psi(p_1) - C_TRI (psi(p_1) + psi(p_2)) = (1 - C_TRI) h(p_1),
which is >= 0 and is zero only at a vertex.

*Interior.* Lagrange: g(p_1) = g(p_2) = g(p_3) for g(x) = d/dx[psi(1 - x) - C_TRI psi(x)]
= log(1 - x) + C_TRI log x + 1 + C_TRI. Since g'(x) = C_TRI/x - 1/(1 - x) changes sign once (at
C_TRI/(1 + C_TRI)), g takes each value at most twice. So two coordinates of p* are equal, say
p* = (a, a, 1 - 2a) with 0 < a < 1/2, and G(p*) = phi(a), where
phi(a) = 2 psi(1 - a) + psi(2a) - C_TRI [2 psi(a) + psi(1 - 2a)].

*The segment.* Differentiating,
phi'(a) = 2 [log((1 - a)/(2a)) - C_TRI log((1 - 2a)/a)] = 2 M(u), with u = (1 - 2a)/a and
M(u) = log((1 + u)/2) - C_TRI log u.
(`test_phi_prime_closed_form` compares this with a numerical derivative.) As a runs over (0, 1/2),
u decreases from infinity to 0, and a = 1/3 corresponds to u = 1. Now
M'(u) = ((1 - C_TRI) u - C_TRI) / (u (1 + u)) is negative below u* = C_TRI/(1 - C_TRI) = 2.818842
and positive above it. Since 1/2 < C_TRI < 1, u* > 1. Also M(1) = 0, M -> +infinity as u -> 0,
and M(u) = (1 - C_TRI) log u + log((1 + u)/(2u)) -> +infinity as u -> infinity. Hence M > 0 on (0, 1),
M < 0 on (1, u*] (M(u*) = -0.118154), and M has exactly one zero u1 on (u*, infinity), with
u1 = 9.703 (bisection). With a1 = 1/(u1 + 2) = 0.08545, phi increases on [0, a1], decreases on
[a1, 1/3] and increases on [1/3, 1/2]. Since phi(0) = 0 and phi(1/3) = 0, phi >= 0 on
[0, 1/2], with zeros only at a = 0 (a vertex) and a = 1/3 (the uniform law). ∎

**Theorem 70.** Every configuration in F_3 satisfies R3 (equivalently R3'). Equality with H(D) > 0
holds exactly for a triangle map with the uniform law (Ruzsa's example up to affine change). ∎

## 2. Extensions (Theorem 71)

Linear changes of coordinates act on configurations (D -> AD, P -> A P A^{-1}). Since
A(P + tD) = AP + tAD, they preserve every entropy in R3. Choose coordinates
D = (U, V) with U = Q(D) in F_3^m. Suppose the first m coordinates of P(D) are a function
Pbar(U) of U on the support ("P descends"). Then:
- the **quotient** is the configuration (law of U, map Pbar) in F_3^m, with slices
  Ybar_t = Pbar(U) + tU, the first m coordinates of Y_t;
- for each x, the **fibre** is the configuration in F_3^(N-m) given by the law of V given U = x
  and the map v -> (last N - m coordinates of P(x, v)). Its slices are the last coordinates
  Y^V_t of Y_t.

**Theorem 71.** If the quotient satisfies R3' and almost every fibre satisfies R3', then the
configuration satisfies R3'.

*Proof.* By the chain rule and because conditioning on less cannot decrease entropy,
H(D | Y_t) = H(U | Y_t) + H(V | U, Y_t) <= H(U | Ybar_t) + H(V | U, Y^V_t).
Sum over t. The quotient's R3' bounds the first sum by C3 H(U). Averaged over U = x, the fibres'
R3' bounds the second by C3 H(V | U). The total is C3 (H(U) + H(V | U)) = C3 H(D). ∎

**Corollary 71.1 (triangular configurations).** Suppose that in some basis coordinate j of P(d)
depends only on (d_1, ..., d_j) on the support. Then the configuration satisfies R3. *Proof:*
apply Theorem 71 along the flag of coordinate quotients. Every one-dimensional step is a
configuration in F_3, so Theorem 70 applies. Concretely,
sum_t H(D | Y_t) <= sum_t sum_j H(D_j | Y_{t,j}, D_<j) <= C3 sum_j H(D_j | D_<j) = C3 H(D),
and both inequalities are checked on random triangular configurations in F_3, F_3^2 and F_3^3,
in standard and in randomly changed bases (`TestTheorem71`). ∎

So **for triangular configurations the exact constant is R0.** Ruzsa's product rho^n
(P(d) = d o d) is diagonal, hence triangular, and attains R0 (`test_ruzsa_equality`).

**Corollary 71.2 (where a counterexample must live).** If R3 fails, it fails for a configuration
that is *irreducible*: no nonzero proper subspace W has P(d + w) - P(d) in W whenever
d, d + w are in the support. (Take a counterexample of least dimension N. If W were invariant,
the quotient by W and the fibres would have smaller dimension and satisfy R3, and Theorem 71
would give R3 for the counterexample.) In F_3^2 the irreducible configurations are those with
no invariant line. Among the 9^9 = 387,420,489 maps of F_3^2 (full support), the number with an
invariant line is 4·3^12 - 6·3^6 + 4·27 - 27 = 2,121,471 (0.55%), by inclusion-exclusion over the
4 lines. Two lines intersect in 3^6 maps, and three or four lines in the 27 maps P = alpha·I + c.
The 27 is checked by enumeration (`test_triple_intersections`). By count, then, most maps of
F_3^2 are not covered; the pre-registered search sd3-search-v1 (a181, section 6) should be read
with this in mind.

**Proposition 77 (robust form).** Let Z_1, ..., Z_N be random variables such that P_j(D) is a
function of (D_1, ..., D_j, Z_j). Then for every configuration
sum_t H(D | Y_t) <= C3 H(D) + 3 sum_j H(Z_j | D_<j), equivalently
H(D) <= (R0/3) sum_t H(Y_t) + R0 sum_j H(Z_j | D_<j).
*Proof.* H(D_j | Y_{t,j}, D_<j) <= H(Z_j | D_<j) + H(D_j | Y_{t,j}, D_<j, Z_j). Given
(D_<j, Z_j) the coordinate is a configuration in F_3, so Theorem 70 applies to the second term.
Then sum over t and j. ∎ (Checked with Z_j = P_j(D) on random maps, `TestProposition77`.)

## 3. Sticky Kakeya sets (Corollary 71.3)

Call a Kakeya set K in F_3^n *sticky* if there are a basis and, for each nonzero d, a point
P(d) with P(d) + F_3 d contained in K, such that coordinate j of P(d) depends only on
(d_1, ..., d_j). In words: directions that agree in their first j coordinates get lines whose
chosen points agree in their first j coordinates. This is the finite-field, digit-by-digit analogue
of the "sticky" Kakeya sets of the Euclidean problem (nearby directions get nearby lines).

**Corollary 71.3.** Every sticky Kakeya set in F_3^n has |K| >= (3^n - 1)^(1/R0)
= (27/4)^(n/3) (1 - 3^-n)^(1/R0).
*Proof.* Take D uniform on the 3^n - 1 nonzero directions. The configuration is triangular, so
log(3^n - 1) = H(D) <= (R0/3) sum_t H(Y_t) <= R0 log |K|. ∎

| class | lower base | upper base |
|---|---|---|
| all Kakeya sets in F_3^n | 1.82074 (a180); 1.824918 with Farnamfar's unrefereed constant | 1.889882 (KLSS) |
| sticky Kakeya sets | **1.889882 (Corollary 71.3)** | 2 ({0,1}^n ∪ {0,2}^n, size 2^(n+1) - 1, sticky) |

**What this does and does not show.** For sticky sets the lower bound reaches the KLSS value.
We do not know whether a sticky set reaches it. The explicit KLSS-type construction in this
repository (notes on q = 3) is sticky only *block by block*: inside each block of m coordinates
it looks ahead at the whole block. With block-level stickiness, Theorem 71 reduces the matching
lower bound to R3 in F_3^m. Two questions are open:
(i) is the least sticky Kakeya set in F_3^n of size 1.889882^(n + o(n)), or does stickiness
force base 2? (ii) Are minimal Kakeya sets over F_3 sticky at all? This is the finite-field
counterpart of the role stickiness plays in Wang and Zahl's 2025 proof of the Kakeya conjecture
in R^3.

## 4. Status of the program

- Proved: R3 for N = 1 (Theorem 70); R3 for all triangular configurations in all dimensions
  (Corollary 71.1); local optimality of rho^n among all configurations (a181, Theorem 69).
- Reduced: R3 holds if and only if it holds for irreducible configurations (Corollary 71.2).
- Open: R3 for irreducible configurations, starting with F_3^2 (no invariant line). A proof
  there would be the first case where no coordinate structure helps.
- Practical consequence for the searches: sampling should be restricted to irreducible maps.
  Triangular and reducible maps cannot beat R0.

## Prior art

We found no earlier treatment of the sums-differences constant in characteristic 3 (see a181),
no finite-field definition of sticky Kakeya sets, and no lower bound for a structured class
of Kakeya sets over F_3 at the KLSS value. Searches covered Dvir; Dvir-Kopparty-Saraf-Sudan;
Kopparty-Lev-Saraf-Sudan; Bukh-Chao (arXiv:2108.00074); Lund-Saraf-Wolf; the Polymath Kakeya
page; and Wang-Zahl's Euclidean sticky Kakeya work. The chain-rule step in Theorem 71 is
standard entropy technique. What is new is its use together with the exact one-dimensional
inequality (Lemma 148). Pointers to earlier work are welcome.
