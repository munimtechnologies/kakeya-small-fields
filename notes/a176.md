## 0. Why this matters

The program in this repository (README Theorem 2; notes a159-a175) reduces the exact Kakeya
growth constant of F_q to one inequality about maps P : F_q^k -> F_q^k:

    Lambda(P) = sum_{t in F_q} H(X | P(X) + tX)  <=  k(q-1)      (C_q(k))

with X uniform on F_q^k and entropy in bits. Write S(P) = q^k Lambda(P), which is the sum over t
and over the fibres F of A_t(x) = P(x) + tx of |F| log2 |F|. If C_q(k) holds for every k, then
beta_q = q 2^{-(q-1)/q}. At q = 3 that is about 1.89, against the best published lower bound of
1.8 (Dvir-Kopparty-Saraf-Sudan; Bukh-Chao). A single map with Lambda(P) > k(q-1) would instead
give Kakeya sets smaller than every known product construction.

Every inequality proved so far, in a171-a175, is about quadratic maps. This note gives the first
structural fact about **all** maps. The known extremal maps, the frame products, are **strict
local maxima** in Hamming distance: changing a frame product at one point always lowers Lambda
(for k >= 2). For q >= 5, changing it at any s points with s < 1 + gamma(q,k)/2 also lowers it,
and gamma grows like (q-3)k/2. One consequence: if C_q(k) fails, no counterexample lies near a
frame product. It complements the pre-registered all-maps search (notes/prereg-allmaps-anneal.md),
which explores far from frames.

A **diagonal frame product** is a map affinely conjugate to
P(x) = (p_1(x_1), ..., p_k(x_k)) with p_i(y) = a_i y^2 + b_i y + c_i and every a_i != 0 (q odd).
Fibres of a product map are products of fibres, so Lambda is additive over coordinates. For a
one-variable quadratic each A_t has one singleton fibre and (q-1)/2 pairs, so S(P) = k(q-1)q^k
exactly. Lambda is unchanged by conjugation x -> T P(T^{-1} x) and by translations, and both send
one-point changes to one-point changes, so it suffices to treat the diagonal form.

Notation: g(n) = n log2 n (g(0) = g(1) = 0); h(m) = g(m+1) - g(m) (increasing, concave,
h(0) = 0, h(1) = 2; every increment h(j+1) - h(j) is at most 2); psi(a) = h(2^a - 1);
chi = quadratic character, chi(0) = 0.

## 1. Changing a map at a few points (any map)

**Lemma 135 (one-point identity).** Let P be any map and let P' differ from P exactly at x0, with
P'(x0) = v. For each t let N_t = |{y : A_t(y) = A_t(x0)}| and M_t = |{y : A_t(y) = v + t x0}|. Then

    S(P) - S(P') = sum_t [ h(N_t - 1) - h(M_t) ].

*Proof.* Under A'_t the point x0 leaves its fibre (size N_t -> N_t - 1) and joins the fibre of
v + t x0, which held M_t points, none of them x0 because v + t x0 != A_t(x0). []

**Lemma 136 (near-additivity).** Let P' differ from P exactly on a set D of s points, and let
P^(x) denote P changed only at x (to P'(x)). Then

    S(P) - S(P')  >=  sum_{x in D} [ S(P) - S(P^(x)) ]  -  2 s (s - 1).

*Proof.* Order the points with D last. Telescoping g(n) = h(0) + ... + h(n-1) gives
S(P) = sum_t sum_x h(rho_t(x)), where rho_t(x) is the number of earlier points in the A_t-fibre
of x. Points outside D have the same rho under P and P'. For x in D:
rho_t(x) = N_t(x) - 1 - c_t(x), where c_t(x) counts the later points of D in the old fibre of x;
and rho'_t(x) <= M_t(x) + e_t(x), where e_t(x) counts the earlier points y of D with
A'_t(y) = A'_t(x). Two distinct points x, y share a fibre of A_t for at most one t, because
P(x) - P(y) = -t(x - y). So sum_{x,t} c_t(x) <= C(s,2), and likewise for e under P'. Since every
increment of h is at most 2, sum_t [h(rho_t) - h(rho'_t)] >= [S(P) - S(P^(x))] - 2 sum_t (c_t + e_t)
by Lemma 135. Summing over x in D gives the claim. []

## 2. One-point changes of a frame product

Fix a diagonal frame product P, a point x0 and a new value v != P(x0). For coordinate i put

    u_i(t) = x0_i + (b_i + t)/(2a_i),     delta_i = (v_i - p_i(x0_i))/a_i.

Completing the square in a_i y^2 + (b_i + t)y + c_i shows that the fibre of x0_i has
1 + [u_i(t) != 0] points and that the equation A^i_t(y) = v_i + t x0_i has 1 + chi(u_i(t)^2 + delta_i)
solutions. Hence

    N_t = prod_i (1 + [u_i(t) != 0]) = 2^{k - z(t)},     M_t = prod_i (1 + chi(u_i(t)^2 + delta_i)),

where z(t) = #{i : u_i(t) = 0}. Each u_i is a bijection of F_q, so sum_t z(t) = k. Some delta_i != 0
because v != P(x0). (Checked exhaustively against brute force in `test_closed_form_counts`.)

**Lemma 137.** psi(a)/a is strictly decreasing for a >= 1. Consequently
L := sum_t h(N_t - 1) >= (q-1) psi(k).

*Proof.* psi(a) = a + r(a) with r(a) = m log2(1 + 1/m) and m = 2^a - 1. r increases from r(1) = 1
towards log2 e, and log2 e - r(a) <= log2 e/(2m). So a(r(a+1) - r(a)) <= a log2 e/(2(2^a - 1))
< 1 <= r(a), which is the claim. Write a_t = k - z(t), so 0 <= a_t <= k and sum_t a_t = (q-1)k. Then
psi(a_t) >= (a_t/k) psi(k), and summing gives L >= (q-1) psi(k). []

**Lemma 138.** h(m) - h(m-1) <= log2(e)/(m-1) for m >= 2. In particular h(2^k) <= psi(k) + log2(e)/(2^k - 1).

*Proof.* h(m) - h(m-1) = g(m+1) - 2g(m) + g(m-1), and this is at most max g'' = log2(e)/x on
[m-1, m+1]. []

**Theorem 62 (frames are strict local maxima).** Let q be an odd prime power, k >= 1, P a
diagonal frame product (or any affine conjugate of one), and P' a map that differs from P at
exactly one point. Then Lambda(P') <= Lambda(P) = k(q-1), with equality possible only when
(q, k) = (3, 1). Quantitatively, q^k (Lambda(P) - Lambda(P')) is at least:

* gamma(q,k) := (q-1) psi(k) - ((q+1)/2) h(2^k) > 0, if q >= 5 and k >= 2;
* 0.64, if q = 3 and k >= 2 (Proposition 70);
* (2 - h(2)/2)(q-3) = 0.6226(q-3), if k = 1.

*Proof for q >= 5, k >= 2.* Pick i with delta_i != 0. M_t = 0 unless chi(u_i(t)^2 + delta_i) >= 0.
Since sum_u chi(u^2 + delta) = -1, the number of such u is (q - 1 + e)/2 <= (q+1)/2, where
e = 1 + chi(-delta) is in {0, 2}. Since M_t <= 2^k, G := sum_t h(M_t) <= ((q+1)/2) h(2^k). By
Lemma 137, L >= (q-1) psi(k). Lemma 138 and psi(k) >= psi(2) = 3.245 give
h(2^k) <= 1.149 psi(k) < (4/3) psi(k) <= (2(q-1)/(q+1)) psi(k), so G < L. Lemma 135 finishes it.

*k = 1.* L = 2(q-1), and G = 2e + h(2)(q-1-e)/2, so L - G = (2 - h(2)/2)(q - 1 - e) >= 0.6226(q-3).
Equality needs q = 3 and e = 2. This case already follows from the proved C_q(1); it is included
only to make the equality case explicit. []

**Proposition 70 (q = 3).** For q = 3 and k >= 2, every one-point change lowers S by at least
2 log2(e) ln(5/4) > 0.644. At k = 2 the exact minimum is 2(h(3) - h(2)) = 0.9804, and it is attained.

*Proof.* Over F_3, delta = 1 gives M-factor 2[u = 0] and delta = 2 gives [u != 0]. Let I_1, I_2 be the
coordinates with delta = 1, 2.

*Case I_1 nonempty.* M_t != 0 forces u_i(t) = 0 for all i in I_1, so this happens for at most one t.
Then G <= h(2^k) <= psi(k) + 0.481, while L >= 2 psi(k), so L - G >= psi(k) - 0.481 >= 2.76.

*Case I_1 empty (I = I_2 nonempty).* Let T_I be the set of t where some u_i (i in I) vanishes.
For t in T_I, M_t = 0 and the term is psi(a_t). For t not in T_I, M_t = 2^{a_t - |I|} and the term is
psi(a_t) - h(2^{a_t - |I|}) >= 0. If some t in T_I has a_t >= 1, its term is at least psi(1) = 2.
Otherwise z(t*) = k for the unique t* in T_I, so the two other t have a_t = k and the gap is at least
2[h(2^k - 1) - h(2^{k-1})]. The bracket is a sum of 2^{k-1} - 1 increments h(j+1) - h(j),
j = 2^{k-1}, ..., 2^k - 2, each at least min g'' = log2(e)/(j+2), so the bracket is at least
log2(e) ln((2^k + 1)/(2^{k-1} + 2)). This bound increases with k, and at k = 2 it equals
log2(e) ln(5/4), so the gap is at least 2 log2(e) ln(5/4). The k = 2 minimum is attained when both u_i vanish at the same t, |I| = 1
and delta = 2. []

The tests check Theorem 62 **exhaustively** (every point, every new value, with an exact
integer comparison of prod n^n) for (q,k) = (3,2), (3,3), (3,4), (5,2), (5,3), (7,2), also for
conjugated frames, and over every abstract configuration (t_i, delta_i) for q = 3 with k <= 7, for
q = 5 with k <= 4 and for q = 7 with k <= 3.

## 3. A Hamming ball around each frame product

**Corollary 62.1.** Let q >= 5 and k >= 2. If P' differs from a diagonal frame product P at s >= 1
points and s < 1 + gamma(q,k)/2, then

    q^k (Lambda(P) - Lambda(P'))  >=  s (gamma(q,k) - 2(s-1))  >  0.

*Proof.* Lemma 136 together with Theorem 62. []

Since psi(k) >= k + 1 and h(2^k) <= psi(k) + log2(e)/(2^k - 1), we get
gamma(q,k) >= (q-3)(k+1)/2 - 0.73(q+1)/(2^k - 1). So the radius grows linearly in both q and k.
Some values of the largest admissible s: (q,k) = (5,2): 2; (5,3): 2; (5,4): 3; (7,2): 3; (7,3): 4.
Lemma 136 is checked on random maps, and the corollary on all two-point changes from two base
points at (5,2) and on random samples at (7,2) s=3, (5,3) s=2 and (7,3) s=4.

## 4. Limits and what is next

* This is **not** a new Kakeya bound. Local maximality is necessary for C_q(k), not sufficient.
  The radius is tiny next to q^k, and at q = 3 (the case that decides beta_3) it covers one point only.
* Only diagonal frame products are treated. If other maps attain k(q-1), such as frames with an
  acyclic (triangular) linear part (a174, Proposition 67), they need their own analysis.
* Next: (i) extend Lemma 136 to changes on a whole line or affine subspace, where the
  pair-collision count is structured rather than worst-case; (ii) the monodromy route for all
  linear parts at large q; (iii) the pre-registered all-maps annealing search will test whether
  any map, far from frames, beats k(q-1).

Prior art: no published treatment of this functional's local structure was found (arXiv; Zahl's
2025 survey; Bukh-Chao, Discrete Analysis 2021:26; DKSS arXiv:0808.2499). The functional and the
reduction to it come from this repository.
