## 0. Summary

Fix q and put X uniform on F_q^2. For a map P : F_q^2 -> F_q^2, let Y_t = P(X) + tX and

    Lambda(P) = sum_{t in F_q} H(X | Y_t)    (bits).

Conjecture C_q(2) says Lambda(P) <= 2(q - 1). With the tensor-power construction of
Theorem 2, a single counterexample, for any k, would give a new record upper bound for
Kakeya sets in F_q^n as n grows. If C_q(k) holds for every k, then q 2^(-(q-1)/q) is the
exact Kakeya growth constant of F_q. Conjecture R_q(2) (a162) says the equality cases are
exactly the *frame products* P(x) = f(l1 x) e1 + g(l2 x) e2 + c, where (e1, e2) is a basis
with dual basis (l1, l2) and f, g are 1D maximisers (ovals, Prop 42).

The classical finite-field Kakeya constructions (Mockenhaupt-Tao, Dvir, Saraf-Sudan) are
quadratic. So the first family to settle is the maps whose coordinates are polynomials of
total degree at most 2. This note settles it for every field size q >= 3, odd or even:

**Theorem 38.** Let q >= 3 be a prime power and let P : F_q^2 -> F_q^2 have coordinates of
total degree <= 2. Then Lambda(P) <= 2(q - 1), with equality iff P is a frame product.
More precisely:

* (A) If no direction is *full* (Section 1), then Lambda(P) <= (q^2 - 1)/q for odd q, and
  Lambda(P) <= q + 1 for even q. Both are strictly below 2(q - 1), by about a factor of 2.
* (B) If some direction is full, P is triangular in an adapted basis. Then
  Lambda(P) <= 2(q - 1) by Theorem 4, and equality holds exactly for frame products
  (Proposition 45 for odd q, Proposition 46 for even q).

Consequences:

* The pre-registered predictions Q1 and Q2 of a162 (job kakeya-quad-v1, q = 3, 5, 7) now
  follow from a proof for every q >= 3, including even q. The job is now a check of the proof.
* Conjecture R_q(2) holds among degree-2 maps.
* Stability: a degree-2 map with Lambda > (q^2 - 1)/q (odd q) or Lambda > q + 1 (even q)
  must respect a 1-dimensional quotient.
* A counterexample to C_q(2) must have degree >= 3. Over F_3 every map has degree <= 2 in
  each variable, but total degree up to 4. For q = 4, 5, 7 the search should now skip
  degree 2.

q = 2 is excluded. There, Case (A) gives only Lambda <= 3 > 2, and R_2(2) is false (a162).
C_2(k) itself was already known.

## 1. Pairs, directions and full directions

**Lemma 112 (a162), recalled.** Let z_t(x) be the size of the fibre of Y_t through x, and let
N(x) = #{u != 0 : P(x + u) - P(x) in F_q u}. Then q^2 Lambda = sum_x sum_t log2 z_t(x) and
sum_t (z_t(x) - 1) = N(x). Since log2 z <= z - 1 for integers z >= 1,

    q^2 Lambda(P) <= sum_x N(x) = sum_{w in PG(1,q)} Pi_w,
    Pi_w := #{(x, lam) : lam in F_q^*, det[P(x + lam w) - P(x), w] = 0}.        (1)

(Write each u != 0 uniquely as lam w with w a fixed representative of its direction.)

**Definition.** A direction w is *full* if Pi_w = q^2 (q - 1). Equivalently,
P(x + lam w) - P(x) lies in F_q w for all x and lam. Equivalently, P respects the quotient
F_q^2 / F_q w: in a basis (w, e2), the second coordinate of P depends only on x2. This
is the hypothesis of Theorem 4.

**Lemma 114 (degree 2).** Let P have degree <= 2 and let w be a direction that is not full.
Then Pi_w <= q(q - 1) if q is odd, and Pi_w <= q^2 if q is even.

*Proof.* Write P(x) = Q(x) + Lx + c, with Q a vector-valued quadratic form, beta(x, y) =
Q(x + y) - Q(x) - Q(y) its polar form (bilinear, symmetric, beta(w, w) = 2Q(w)) and L linear.
Then

    P(x + lam w) - P(x) = lam^2 Q(w) + lam (beta(x, w) + L w),
    det[P(x + lam w) - P(x), w] = lam (lam C(w) + h_x(w)),

where C(w) = det[Q(w), w] and h_x(w) = det[beta(x, w) + L w, w]. The function x -> h_x(w)
is affine. Its linear part x -> det[beta(x, w), w] takes the value
det[2Q(w), w] = 2C(w) at x = w. So h_{x + mu w}(w) = h_x(w) + 2 mu C(w).

* If C(w) != 0, then x has at most one partner on its w-line: lam = -h_x(w)/C(w), which
  counts only if it is nonzero. For odd q, h is a non-constant affine function along each
  w-line. So exactly one point per line has no partner, and Pi_w = q(q - 1). For even q,
  h is constant along w-lines, and Pi_w <= q^2.
* If C(w) = 0, then the pair condition is h_x(w) = 0 for every lam. h is constant along
  w-lines, so its zero set is empty, one w-line, or everything. "Everything" means w is
  full. Otherwise Pi_w <= q(q - 1). QED

(For odd q this is the direction rule of Lemma 113: h_x(w) = 0 iff w is an eigenvector of
M_x.)

## 2. Case (A): no full direction

By (1) and Lemma 114, summed over the q + 1 directions:

    odd q:   q^2 Lambda <= (q + 1) q (q - 1),  so  Lambda <= (q^2 - 1)/q < 2(q - 1);
    even q:  q^2 Lambda <= (q + 1) q^2,        so  Lambda <= q + 1 < 2(q - 1)  (q >= 4).

The odd bound is below 2(q - 1) because q^2 - 1 < 2q^2 - 2q, that is, (q - 1)^2 > 0.

## 3. Case (B): a full direction gives a triangular map, then the chain rule

Take the full direction as e1. Then P(x) = (F(x1, x2), g(x2)). Write f_a = F(., a). By the
chain rule, H(X | Y_t) = H(X2 | Y_t) + H(X1 | X2, Y_t), and
H(X2 | Y_t) <= H(X2 | g(X2) + t X2). Given X2 = a, H(X1 | X2 = a, Y_t) = H(X1 | f_a(X1) + t X1).
Summing over t:

    Lambda(P) <= Lambda_1(g) + E_a Lambda_1(f_a) <= (q - 1) + (q - 1)            (2)

by C_q(1). This is Theorem 4, and it holds for every map, not only degree 2. Equality in
(2) needs three things:

* (i) Lambda_1(g) = q - 1;
* (ii) Lambda_1(f_a) = q - 1 for every a;
* (iii) for every t, I(X2 ; Y1_t | Y2_t) = 0, where Y1_t = F(X) + t X1 and
  Y2_t = g(X2) + t X2. So the law of Y1_t given X2 = a must equal its law given X2 = a',
  whenever a and a' lie in the same fibre of Y2_t.

Now let P have degree <= 2. Subtract cI (this changes neither Lambda nor whether P is a
frame product) so that

    F = al x1^2 + ga x1 x2 + de x2^2 + ep x1 + ze x2,     g = be x2^2 + et x2.

A degree-2 polynomial in one variable is a 1D maximiser iff its x^2 coefficient is nonzero
(Prop 42 for odd q). For even q, s -> al s^2 + b s is F_2-linear with kernel {0, b/al}, so
z_t takes the value 2 for q - 1 of the t and 1 for one t. A degree-1 map has
Lambda_1 = log2 q < q - 1. So (i) and (ii) hold iff al, be != 0.

**Proposition 45 (odd q).** Assume al, be != 0. Then (iii) holds iff, with
kappa = -ga/(2 al),

    de = al kappa^2 + kappa be,   ze = kappa (et - ep).

These are exactly the frame products f(x1 - kappa x2) e1 + g(x2) (e2 + kappa e1), with
f(y) = al y^2 + ep y.

*Proof.* The fibres of Y2_t are the pairs {a, a'} with a + a' = sig := -(et + t)/be, plus one
fixed point. Given X2 = a, Y1_t = al s^2 + (ga a + ep + t) s + de a^2 + ze a with s uniform.
Its law is al * (law of a uniform square) + c(a), where
c(a) = de a^2 + ze a - (ga a + K)^2/(4 al) and K = ep + t. For q odd this law determines
c(a), because c(a) is the only value taken exactly once. So (iii) says c(a) = c(a') on
every pair. Now

    c(a) - c(a') = (a - a') [ D sig + ze - ga K/(2 al) ],   D = de - ga^2/(4 al).

The bracket is affine in t. Its t-coefficient is -D/be - ga/(2 al), and its constant term
is -D et/be + ze - ga ep/(2 al). Every t has pairs (q >= 3), so both must vanish:
D = kappa be and ze = kappa (et - ep). Expanding the frame product gives
ga = -2 al kappa, de = al kappa^2 + kappa be and ze = kappa (et - ep), the same system.
QED

**Proposition 46 (even q >= 4).** Assume al, be != 0. Then (iii) holds iff ga = 0 and there is
a kappa with

    de = al kappa^2 + kappa be,   ze = kappa (ep + et).

These are again exactly the frame products in the bases (e1, e2 + kappa e1).

*Proof.* For t != et, the fibres of Y2_t are {a, a + d} with d = (et + t)/be != 0. Given
X2 = a, Y1_t = al s^2 + B_a s + c(a), where B_a = ga a + ep + t and c(a) = de a^2 + ze a.
If B_a = 0, this law is uniform on F_q. If B_a != 0, it is uniform on the coset
c(a) + (B_a^2/al) T0, two-to-one, where T0 = {r^2 + r} = ker Tr.

*Case ga != 0.* Take a with B_a = 0. Its partner has B = ga d != 0, and a uniform law
differs from a two-to-one law. So (iii) fails and equality is strict.

*Case ga = 0.* B = ep + t is constant on the pair. For t not in {et, ep}, the condition is
Tr(al (de d^2 + ze d)/(ep + t)^2) = 0. Put u = et + t, v = ep + t and c0 = ep + et.
- If c0 != 0, rho = u/v runs over F_q \ {0, 1} as t varies, and v = c0/(1 + rho).
  The condition becomes Tr((A + B) rho^2 + B rho) = 0, with A = al de/be^2 and
  B = al ze/(be c0). Since Tr(y^2) = Tr(y), this is Tr(c rho) = 0 with
  c = sqrt(A + B) + B. A nonzero c kills only q/2 - 1 nonzero rho, fewer than q - 2.
  So c = 0, that is, A = B^2 + B. With kappa = B be/al this is de = al kappa^2 + kappa be
  and ze = kappa c0.
- If c0 = 0, the condition reads Tr(A) + Tr(al ze/(be v)) = 0 for all v != 0. This forces
  ze = 0 and Tr(A) = 0, that is, A = r^2 + r. That is the same system with
  kappa = r be/al.

Expanding the frame product (the cross term 2 al kappa vanishes) gives the same system.
QED

Theorem 38 follows: Case (A) is strict, and Case (B) is at most 2(q - 1) with equality
exactly for frame products. **QED**

**Corollary 129 (counts, normalised by ep = 0).** In the triangular family, the
maximisers number q^2 (q - 1)^2 for odd q, and (q - 1)^2 q (2q - 1)/2 for even q. That is
36, 126 and 400 for q = 3, 4, 5. (For even q with et = 0, the two values kappa and
kappa + be/al give the same map: (y^2) is additive, so these frame products have three
full directions.)

## 3a. Remarks: what the proof says about the general problem

* The proof has two sides, and only one of them used the log. Counting pairs (1) is
  enough whenever every direction gives each point O(1) partners. Large loss needs
  a direction along which P is "1-dimensional" (a full direction), and then Theorem 4's
  chain rule applies. For degree d, a non-full direction still gives at most d - 1
  partners per point on all but its full lines. So the same split works whenever the
  number of points on full w-lines is controlled. That is the stability statement the
  chain route needs for general maps (a162, idea 1).
* The gap in Case (A) is large: about q, against 2(q - 1). Near-maximisers of degree 2 are
  therefore triangular, and then Props 45/46 show they are near frame products.
* For k >= 3, the counting in (1) alone gives only (q^k - 1)/q. Degree-2 maps in higher
  dimension need a second idea (full *planes*, or induction through Theorem 4). This is
  open.

## 4. Verification (code in this commit)

`quad_rigidity.py` (standard library; prime q and q = 4, 8, 16) computes Lambda exactly as
the integer prod_t prod_F |F|^|F|, the counts Pi_w, the full directions and a frame-product

  Theorem 4 holds. "Maximal" equals the prediction of Props 45/46 map by map. The number of
  maximisers equals Corollary 129. Every maximiser is detected as a frame product.

  perturbations of them, all conjugated by random GL_2 matrices. Same assertions.

## 5. Prior art

* The entropy reformulation (Thm 2) and Theorem 4 are this project's (see the README).
* Bukh and Chao (arXiv:2108.00074) give the best lower bound, q^n/(2 - 1/q)^(n-1). In our
  language it is the Renyi-2 version of C_q(k).
* Quadratic constructions: Mockenhaupt-Tao; Dvir; Saraf-Sudan (Analysis & PDE 1 (2008));
  Kopparty-Lev-Saraf-Sudan. Georgiev, Gomez-Serrano, Tao and Wagner (arXiv:2511.02864)
  slightly improved the d = 3 construction by an O(q) term. That is the fixed-dimension,
  q -> infinity regime, not the fixed-q growth constant studied here.
* A web search (2026-11-17) found no statement that degree-2 blocks cannot beat
  q 2^(-(q-1)/q), and no classification of their equality cases. We know of no earlier
  treatment of the Shannon block problem outside this repository.
