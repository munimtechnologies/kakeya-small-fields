## Lemma 108 (invariant subspaces)

**Lemma 108.** The number k(T) of subspaces of F_2^3 invariant under T is: for span(I, M), nil1 8,
irr 2, proj 10, nil3 4, x(x^2+x+1) 4, x^2(x+1) 6; for the 3-dimensional commutative subalgebras,
F_8 2, F_2 x F_4 4, F_2^3 8, F_2 x F_2[x]/(x^2) 6, F_2[x]/(x^3) 4, radical square 0 with a shared
image 6, with a shared kernel 6; and k(span(I)) = 16.

*Proof.* A subspace is invariant under span(I, M) if and only if it is invariant under M. If M is
cyclic, its invariant subspaces correspond to the monic divisors of its characteristic polynomial:
2 for an irreducible cubic, 4 for x^3 and for x(x^2+x+1), and 6 for x^2(x+1). nil1 (N^2 = 0, rank
1, image l inside the kernel plane K): a line is invariant if and only if it lies in K (3 lines),
and a plane if and only if it contains l (3 planes), so k = 1 + 3 + 3 + 1 = 8. proj (eigenspaces of
dimensions 1 and 2): the invariant subspaces are the sums of subspaces of the two eigenspaces,
2 x 5 = 10.

A 3-dimensional commutative subalgebra with non-trivial idempotents splits Q into its summands, and
an invariant subspace is a sum of invariant subspaces of the summands. That gives F_2 x F_4: 2 x 2;
F_2^3: 2 x 2 x 2; F_2 x F_2[x]/(x^2): 2 x 3, since a nilpotent of a plane leaves 0, its kernel and
the plane invariant. F_8 and F_2[x]/(x^3) contain a cyclic element that generates them: 2 and 4.
Radical square 0 with a shared image line l: each radical element N maps a line U to 0 or to l.
So an invariant line either equals l or lies in every kernel, and the kernels are different planes
that meet in l. The only invariant line is l. Planes are invariant if and only if they contain l
(3). So k = 1 + 1 + 3 + 1 = 6. With a shared kernel plane K and different
image lines spanning K, the invariant lines are the 3 lines of K. A plane P other than K would have
to contain both image lines, so P = K. So k = 1 + 3 + 1 + 1 = 6. QED

Lemma 108 is not used for soundness. Job m103 counts the invariant subspaces of all 438 spaces by
brute force and grades the table.
