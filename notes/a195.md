## Summary

Question S7 asks whether sticky Kakeya sets over F_3 grow with base below 2. By a188 it is
equivalent to finding one full sticky tree of some height k with slice product below 8^k. Such a
tree has a root and three subtrees, and the slice sizes depend on unions of slices taken from
*different* subtrees. This note shows that one natural family of trees, the cyclic triangles,
needs only *one* subtree, and that the extremal height-4 tree of a194 is of this kind.

For a full sticky tree A of height h with slices A_0, A_1, A_2 (subsets of F_3^h) define

    kappa(A) = min over i in {0,1,2}, w in F_3^h of |A_i| + |A_{i+1} u (A_{i+2} + w)|

(indices mod 3) and kappa_h = min kappa(A) over trees of height h.

**Proposition 89 (cyclic triangle).** For every tree A of height h, every i and every w there is
a tree A' of height h+1 with |A'_0| = |A'_1| = |A'_2| = |A_i| + |A_{i+1} u (A_{i+2} + w)|.
Hence pi_{h+1} <= kappa_h^3.

**Corollary 89.1.** (a) kappa_h >= pi_{h+1}^(1/3); with Propositions 84 and 88, kappa_h = 2^(h+1)
for h <= 3, and with a190, 30 <= kappa_4 <= 32. (b) If kappa_h < 2^(h+1) for one h, then S7 holds:
sticky Kakeya sets over F_3 have growth base at most kappa_h^(1/(h+1)) < 2. (c) If S7 fails
(pi_k = 8^k for all k), then kappa_h = 2^(h+1) for all h.

**Proposition 90.** kappa_{h+1} <= 2 kappa_h, so kappa_h / 2^(h+1) is non-increasing in h.

**Conjecture T.** kappa_h = 2^(h+1) for every h. By Corollary 89.1, Conjecture T is necessary for
the classical sticky construction to be optimal, and one tree that breaks it answers S7.

## 1. Proof of Proposition 89

Write rho_c(P)(d) = P(d) + c d. This keeps a map triangular, and
S_t(rho_c P) = {P(d) + (t + c) d} = S_{t+c}(P) (a188, Lemma 161). Adding a constant vector v to P
adds v to every slice. Let B = rho_i(A), so B_t = A_{t+i}.

Take the root map x -> x^2 and put three subtrees under x = 0, 1, 2:

- child 0: B, slices B_t;
- child 1: rho_2(B) + 2w, slices B_{t-1} + 2w;
- child 2: rho_1(B) + w, slices B_{t+1} + w.

A point of slice t over x lies in the plane y_1 = x^2 + t x. The planes are:

| t | x = 0 | x = 1 | x = 2 |
|---|---|---|---|
| 0 | 0 | 1 | 1 |
| 1 | 0 | 2 | 0 |
| 2 | 0 | 0 | 2 |

So, with u(X, Y) = |X u Y|:

- |A'_0| = |B_0| + u(B_2 + 2w, B_1 + w) = |B_0| + u(B_1, B_2 + w) (translate by -w);
- |A'_1| = u(B_1, B_2 + w) + |B_0 + 2w|;
- |A'_2| = u(B_2, B_1 + 2w) + |B_0 + w| = u(B_1, B_2 + w) + |B_0| (translate by w; 3w = 0).

All three equal |A_i| + |A_{i+1} u (A_{i+2} + w)|. The map of A' is (x, d) -> (x^2, P_x(d)) with P_x
triangular, so A' is a full sticky tree. ∎

The proof uses that 3w = 0 in characteristic 3: the three translation offsets that appear,
v_B - v_C, v_C - v_A and v_A - v_B, always sum to zero, and equal offsets are possible only because
3w = 0.

*Proof of Corollary 89.1.* (a) A' is a tree of height h+1 with product kappa(A)^3. The values of
pi_3, pi_4 and the lower bound pi_5 >= 27,000 = 30^3 are Propositions 84, 88 and 85. The classical
tree P(d) = (d_j^2) has A_1 = A_2 = {0,2}^h and |A_0| = 2^h, so kappa_h <= 2^(h+1).
(b) is Corollary 78.1 applied to A'. (c) follows from (a). ∎

*Proof of Proposition 90.* In the tree A' above (i fixed, w as chosen), the slices are
A'_1 = {0} x (B_1 u (B_2 + w)) u {2} x (B_0 + 2w) and A'_2 = {0} x (B_2 u (B_1 + 2w)) u {2} x (B_0 + w).
So A'_2 + (0, w) = A'_1, and kappa(A') <= |A'_0| + |A'_1 u (A'_2 + (0, w))| = |A'_0| + |A'_1|
= 2 kappa(A). ∎

## 2. The known extremal trees are cyclic triangles

- **Classical.** The classical height-(h+1) tree is the cyclic triangle (i = 0, w = 0) of the
  classical height-h tree: B_1 = B_2 = {0,2}^h, so every slice has 2^h + 2^h points.
- **a194's tree.** The tree P(d) = (d1^2, 0, -d1 d3) has slices (4, 12, 12) with A_1 = A_2
  (a194, section 2), so kappa = 4 + 12 = 16 = 2^4. Its cyclic triangle is the height-4 tree of
  a194 built from the three slice permutations of (4,12,12), with product 16^3 = 4096. So the
  only non-classical shape that can enter a height-4 tree below 4096 enters through a cyclic
  triangle, and it is tight for Conjecture T.
- **A second operation.** Put the constant root map 0 over the children T, T and T^s, where
  T^s(d) = P_T(-d) swaps slices 1 and 2. The slice-1 and slice-2 planes are 0, 1, 2 and 0, 2, 1,
  which gives kappa <= |T_0| + |T_1 u T_2| + |T_1| + |T_2|. For trees with T_1 = T_2 (all cyclic
  triangles with w = 0 have this), the pair (|T_0|, |T_1|) = (a, b) goes to (a + b, a + b) under
  the cyclic triangle and to (a, 3b) under this operation, and both results again have equal
  slices 1 and 2, with kappa at most a + b. Starting from the height-1 quadratic (2, 2), the
  invariant "b >= a and a + b >= 2^(h+1)" is kept by both operations (the swap needs b >= a for
  a + 3b >= 2(a + b)). So in this bookkeeping the bound a + b never drops below 2^(h+1); it equals
  2^(h+1) exactly when the swap is applied only to states with a = b. This is how (4, 12, 12)
  arises: (2,2) -> (4,4) -> (4,12).

These are only examples: Conjecture T is open from h = 4 on.

## 3. Why the reduction helps

The general height-(h+1) problem has three independent subtrees and three unions between
different subtrees; the size relaxation ("game") that replaces each union by a maximum falls
below 8^k (a185, Theorem 73), and no relaxation of sizes can prove S7 false. kappa involves one
tree and the union of two of its own slices, and it is computed exactly on real trees. A search
for a tree with small kappa ranges over single trees of height h, which is far smaller than the
space of triples, and every candidate is checked by building A' and counting its slices.

The queued job `sticky-h4r-v1` (a194) gives a proved lower bound L for pi_5. By Corollary 89.1,
kappa_4 >= L^(1/3); if L > 29,791 = 31^3, then kappa_4 = 32 and Conjecture T holds at h = 4.
