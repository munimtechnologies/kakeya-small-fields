## Summary

The pre-registered job `sticky-h3-v1` ran on 2026-11-20 (80 s wall time, all unit tests passed,
no self-check failed). It made height 3 exact (real unions of slice sets, all 27^4 height-2
trees) and relaxed only height 4. Verdict: **PI4-EXACT**.

**Proposition 88.** Every full sticky tree of height 4 over F_3 has |S_0||S_1||S_2| >= 4096.
Hence pi_4 = 4096 = 8^4.

**Corollary 88.1.** pi_k = 8^k for k = 1, 2, 3, 4. By Corollary 78.1, any explicit certificate
that sticky Kakeya sets over F_3 grow with base below 2 (Question S7) must be a tree of height
at least 5.

Both pre-registered predictions held: PI4-EXACT (stated with 55% confidence), and the game vector
(7,7,12) is among those the exact unions raise.

## 1. What the job did and why it is a proof

Notation as in a188: a full tree of height k is a sticky map P: F_3^k -> F_3^k, with slices
S_t = {P(d) + t d}, t = 0, 1, 2. A node with root map g and children T_0, T_1, T_2 has
S_t(T) = union over x of {g(x) + t x} x S_t(T_x).

1. **Height 2, exhaustive.** All 531,441 height-2 trees, slices as 9-bit masks over F_3^2:
   96 slice-size vectors, 19 minimal (as in a189).
2. **The down-set W.** A height-3 vector can only take part in a height-4 quadratic node of
   product < 4096 if it does so with the other two children taken from the game front at height 3
   (real vectors dominate the game front, and the node bound is monotone). W is the set of such
   vectors; it is a down-set. Of the 112 game-front vectors, 6 lie in W: the permutations of
   (4,12,12) and of (7,7,12).
3. **Exact quadratic unions at height 3.** For a quadratic root the isolated child in slice t is
   a bijection of t (Lemma 162), so after relabelling, the vector is
   (|A0| + |B0 u C0|, |B1| + |A1 u C1|, |C2| + |A2 u B2|), computed on real masks. Only exact
   reductions are used: entries whose masks contain another entry's masks with no smaller size
   are dropped, Pareto pruning of partial pairs, and one child taken up to the 108 lower-triangular
   affine maps of F_3^2 (applied to all three children; this maps trees to trees and preserves
   every union size). 188 orbit representatives, 46,016,815 combinations, search complete.
   Affine roots at height 3 stay relaxed (union >= max), which is still a valid lower bound.
4. **Result at height 3.** The minimal real (or affine-relaxed) height-3 vectors inside W are
   exactly H3 = {(4,12,12), (12,4,12), (12,12,4)}. The game vectors (7,7,12), (7,12,7), (12,7,7)
   are **not** attained: every real height-3 vector in W dominates a permutation of (4,12,12).
5. **Height 4, relaxed over H3.** The least quadratic-root product over H3 is
   (4+12)(4+12)(4+12) = 4096, attained by the triangle of the three permutations; no ordered
   triple gives less. Affine roots at height 4 cost at least 9 * pi_3 = 4608 (Lemma 162 with
   Proposition 84). So every height-4 tree has product >= 4096, and the classical product map
   (x_j -> x_j^2 in every coordinate, slices (16,16,16)) attains it. ∎

Self-checks that passed (any failure would have given verdict BUG): 3,000 sampled group images of
height-2 trees are trees; 96 vectors and 19 minimal at height 2; the game front at height 3 has
112 vectors and least product 512; no H3 vector lies below the game front; H3 is symmetric under
the six slice permutations; (8,8,8) is dominated; no H3 product is below 512.

## 2. The (4,12,12) tree by hand

The job's witness for (4,12,12) is a short formula:

    P(d1, d2, d3) = (d1^2, 0, -d1 d3).

Slice 0 is {(d1^2, 0, -d1 d3)}: the point (0,0,0) for d1 = 0, and {(1, 0, z)} (three points) for
d1 = 1 and d1 = 2 together, so |S_0| = 4. Slice 1 is {(d1^2 + d1, d2, (1 - d1) d3)}: first
coordinate 0 for d1 in {0, 2} and 2 for d1 = 1; the two d1 in {0, 2} give all of {0} x F_3^2
(9 points) and d1 = 1 gives {(2, d2, 0)} (3 points), so |S_1| = 12. Slice 2 is symmetric:
|S_2| = 12. Product 576 > 512: not extremal at height 3, but it is the only kind of height-3
shape that can enter a height-4 tree below 4096.

## 3. What this says about the game

a190 found that the union-to-max relaxation ("game") allows 3971 < 4096 at height 4, through
(11,19,19) = triangle((4,12,12), (7,7,12), (7,12,7)). Lemma 164 showed that one derivation of
(7,7,12) is not realised; Proposition 88 shows that no derivation is, at least not inside W. The
first place where the game and real trees differ is therefore height 3, and the gap is exactly
the three permutations of (7,7,12).

| k | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| pi_k | 8 | 64 | 512 | **4096** | [27,000, 32,768] |
| 8^k | 8 | 64 | 512 | 4096 | 32,768 |
| game minimum | 8 | 64 | 512 | 3971 | 27,000 |

By a185 (Theorem 73) the game eventually falls below 8^k by an exponential factor, so its value at
height 5 (27,000 = 30^3) is a real question for sticky trees: either exact unions keep raising the
cheap shapes, height after height (which would point towards beta_s = 2, i.e. S7 false), or some
real tree of height 5 or more realises a sub-classical shape (S7 true).
