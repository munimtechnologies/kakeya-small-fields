## 1. Theorem 81: pi_5 = 29,791

*Upper bound.* Theorem 79 (a196): the height-5 tree G (`sticky_s7.tree_G`) has slices of 31, 31, 31
points.

*Lower bound* (job `sticky-h4r-v1`, code `sticky_h4r.py` + `sticky_h3.py`, file
`results/sticky-h4r-v1/h4r.json`). All 27^4 = 531,441 height-2 trees are enumerated (96 slice
vectors, 19 minimal). Every height-3 tree with a quadratic root map is treated **exactly**: after
relabelling the children A, B, C its vector is (|A_0| + |B_0 u C_0|, |B_1| + |A_1 u C_1|,
|C_2| + |A_2 u B_2|) with the unions computed on the real 9-point masks; the search over all orbit
representatives finished (`complete: true`, 46,016,815 combinations). Affine roots at height 3 are
relaxed (union >= max). The minimal elements form E3 (112 vectors), so every real height-3 slice vector
dominates an element of E3. One level up, F4 = the union >= max front over all 27 root maps (670
vectors, least product 4,096, matching Proposition 88); every real height-4 vector dominates an
element of F4. Over F4, the least product of a height-5 node with a quadratic root,
(A_0 + max(B_0, C_0))(B_1 + max(A_1, C_1))(C_2 + max(A_2, B_2)), is **29,791**, and an affine root
costs at least 9 pi_4 = 36,864 (Lemma 162, Proposition 88). Each bound is monotone in the children's
vectors, so pi_5 >= min(29,791, 36,864) = 29,791. ∎

All pre-registered self-checks passed (`bugs: []`): height-2 counts; the game fronts 112 and 649 and
the game value 27,000 of a190; E3 symmetric under the six slice permutations, (8,8,8) dominated, E3 on
the down-set W equal to the sticky-h3-v1 set {(4,12,12), (12,4,12), (12,12,4)}; least product 512 on
E3 and 4,096 on F4.

*The relaxation is tight at height 5.* Its minimiser has children (11,20,20), (20,11,20), (20,20,11),
and each comes from exact height-3 trees with vectors (4,12,12), (7,7,13), (7,13,7) (for (11,20,20)).
These are exactly the shapes of the a196 construction (tree A, tree B and its mirror C(e) = B(-e)),
and a196 shows the maxima are attained there (A's 12-point slices lie inside B's 13-point slice). So
the computer found, from below, the same tree that the hand analysis found from above.

**Corollary 81.1.** Among all full sticky trees of height 5 over F_3, the slice product 31^3 of the a196
tree is optimal. A sticky Kakeya base below 31^(1/5) = 1.98734 needs a certificate of height >= 6.

**Corollary 81.2.** kappa_4 = lambda_3 = 31.
*Proof.* For a height-4 tree P, the cyclic triangle (Proposition 89) is a height-5 tree with three
slices of size kappa(P), so kappa(P)^3 >= pi_5 = 29,791 and kappa(P) >= 31. Theorem 79 gives
kappa_4 <= 31. For height-3 trees A, B, the tree N = root x^2 over (A, B, B(-e)) has
kappa(N) = lambda(A, B) (a197, Lemma 167, first half), so lambda_3 >= kappa_4 = 31, and the a196 pair
gives lambda_3 <= 31. ∎

So the pre-registered question of `sticky-kexact-v1` (still queued) is answered: KAPPA4-31. That job
remains an independent CP-SAT cross-check; a rebuilt height-4 value of 30 there would now be a BUG.

## 2. Proposition 94: 216,000 <= pi_6 <= 238,328 and 60 <= kappa_5 <= 62

*Lower bound* (same job, optional height-6 stage, `h4r.json` key `height6`): F5 = the front one level
above F4 (3,361 vectors, least product 29,791, matching Theorem 81); the least quadratic-root
product over F5 is 216,000 = 60^3 (children (20,40,40), (40,20,40), (40,40,20)); affine roots cost at
least 9 x 29,791 = 268,119. So pi_6 >= 216,000, and as above kappa_5 >= 60.

*Upper bound.* For a height-4 tree P and the height-1 tree x^2, the product tree has slices
2|S_t(P)|, and slices 1 and 2 of x^2 are the same set {0, 2}, so kappa(P x x^2) = 2 kappa(P) and
kappa_{h+1} <= 2 kappa_h. With kappa_4 = 31 this gives kappa_5 <= 62, and the cyclic triangle gives
pi_6 <= 62^3 = 238,328. `sticky-pair-v1` rebuilt such a witness explicitly: the pair (H, H(-d)) has
lambda = 62, its tree N has slices (22, 40, 40), and N's cyclic triangle has slices (62, 62, 62),
all checked by brute force. ∎

A height-6 certificate improves the base iff pi_6^5 < 31^18, i.e. pi_6 below about 233,830. The window
[216,000, 233,830) is open. The height-6 relaxation is no longer tight in an obvious way: it needs
height-5 trees close to (20,40,40) with two 40-point slices equal, which would beat the doubling
kappa_5 <= 2 kappa_4 = 62. The sequence kappa_1..kappa_4 = 4, 8, 16, 31 doubled until height 4 and
then dropped by one. Whether it drops again (kappa_5 <= 61) is the question for `sticky-l4-v1`.
