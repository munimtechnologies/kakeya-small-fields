with AI agents working in MV2's name. **This note settles no case: A(7) <= 8 is still open.** It
was written while jobs m45a, m45b, m46a and m46b were still waiting in the shared compute queue

in a36.md ("can A_w = 0 happen for some w != 0 in ker phi at rank 3?") in part: Lemma 60 of
[a8.md](a8.md) carries over to (B6) and (B5) without the tight Case B, and it leaves a single rigid
shape for a zero map in every class with d >= 1 in (B6) and d >= 2 in (B5), which includes all 13
classes with d = 3. That shape is not ruled out. No human mathematician has checked the proofs.

## What changes

- **Lemma 89.** In (B6) and (B5) at t = 7, let w != 0 in N = ker phi have A_w = 0, and put
  z = sigma(w) and C = beta(w, V) + span(z). Then w is not in span(u), C lies in ker A_u, every
  element of U+(w) acts on C as 0 or as the identity, and exactly one of the following holds:
  (I) x0 lies in C; then in (B6) C = ker A_u and d = 0, and in (B5) d <= 1 (with C = ker A_u when
  d = 1); (II) x0 is not in C; then dim C = 3, ker A_u = C + span(x0), dim U+(w) = 7, and
  U+(w) / span(w) is an anisotropic system of dimension 6 = A(6) with values in X / span(z) in
  which C / span(z), of dimension 2, is invariant: the equality case of M(4) + A(2) = 6.
- **Corollary 58.** The elements of N with zero map form a subspace N_0 with N_0 n span(u) = 0; beta
  vanishes on N_0 and sigma is linear and one-to-one on it, with values in ker A_u and
  sigma(N_0) n span(x0) = 0. In every class of (B6) with d >= 1 and of (B5) with d >= 2, so in all
  13 classes with d = 3, every non-zero element of N_0 is in case (II).
- Nothing is ruled out: case (II) is consistent with every check tried here. The note records where
  the attempts on it stop.

## Setting

As in [a36.md](a36.md): t = 7, dim V = 9, the system is anisotropic, there is no element of rank 4

3), d = dim(X_1 n R), N = ker phi (dimension 3 in (B6), 4 in (B5)), and x0 is not in P. We use (*)

U+(w) = {h : beta(w, h) in span(sigma(w))}. Fix(A_u) = {y : A_u y = y}.

## Lemma 89 (an element of ker phi with zero map)

**Lemma 89.** Let w != 0 in N have A_w = 0, z = sigma(w), C = beta(w, V) + span(z). Then:

(a) w is not in span(u); A_h z = beta(w, h) for every h; C lies in X_1, and z is not in span(x0);

(b) for h in U+(w), with beta(w, h) = e z (e in F_2), A_h acts on C as e times the identity;

(c) dim U+(w) = 10 - dim C, and dim C >= 3;

(d) if x0 lies in C, then 10 - dim C <= dim N + 3 - d. So in (B6), C = X_1 and d = 0; in (B5),
    d <= 1, and C = X_1 when d = 1;

(e) if x0 is not in C, then dim C = 3, X_1 = C + span(x0), dim U+(w) = 7, and U+(w) / span(w)
    carries an anisotropic system of dimension 6 with values in X / span(z), of dimension 6, in
    which C / span(z), of dimension 2, is invariant under every map.

*Proof.* (a) A_u != 0, so w is not u, and w != 0, so w is not in span(u). (*) with h -> w and
h' -> h gives A_h z = (I + A_w) beta(w, h) = beta(w, h). By (2) of a24.md with h_1 = w,
h_2 = h, A_u beta(w, h) = A_w phi(h) + A_h phi(w) = 0, as A_w = 0 and phi(w) = 0. So beta(w, V)
lies in X_1, and z lies in X_1 by (N). Lemma 30 (b) for u (w is in U+ = N and not in span(u))
says z is not in span(x0).

(b) A_h z = beta(w, h) = e z. For every g, (Q) with h_1 = w, h_2 = g and h' = h gives
A_h beta(w, g) = A_w beta(g, h) + A_g beta(w, h) = e A_g z = e beta(w, g). This is Lemma 60 (b) of
a8.md word for word.

(c) As in Lemma 88 (b) of a36.md: dim U+(w) = (9 - dim beta(w, V)) + dim(beta(w, V) n span(z)) =
10 - dim C. Lemma 30 (b) for w (rank 0) gives dim U+(w) <= 1 + A(6) = 7 (Theorem 31), so
dim C >= 3.

(d) The argument of Lemma 60 (c). Let h be in U+(w), with beta(w, h) = e z. By (b), A_h x0 = e x0,
since x0 lies in C, and by (1), (I + A_u) phi(h) = e x0. Let F = {y : (I + A_u) y in span(x0)}.
As (I + A_u) x0 = x0, F = Fix(A_u) + span(x0), and x0 is not in Fix(A_u) (A_u x0 = 0 != x0), so
dim F = dim Fix(A_u) + 1. So phi maps U+(w) into F n P, and since F contains x0 and P does not,
dim(F n P) <= dim F - 1 = dim Fix(A_u). A fixed vector lies in R, and a non-zero one is not in
X_1, so Fix(A_u) meets X_1 n R only in 0 and dim Fix(A_u) <= 3 - d. The kernel of phi on U+(w)
lies in N. So

    10 - dim C = dim U+(w) <= dim N + dim(F n P) <= dim N + 3 - d.

As C lies in X_1, dim C <= 4 and the left side is at least 6. In (B6), dim N = 3: 6 <= 6 - d, so
d = 0 and dim C = 4, that is C = X_1. In (B5), dim N = 4: 6 <= 7 - d, so d <= 1, and when d = 1,
10 - dim C <= 6 gives C = X_1.

(e) C lies in X_1 and misses x0, so dim C <= 3, and dim C >= 3 by (c). So dim C = 3,
X_1 = C + span(x0) and dim U+(w) = 7. The system is the one in the proof of Corollary 35 of a8.md
(Steps 4 and 5 of the proof of Lemma 57), which uses only A_w = 0 and A_h z = beta(w, h): by (b)
every A_h with h in U+(w) keeps span(z) and C, so it induces a map of X / span(z) that keeps
C / span(z); sigma and beta on U+(w), taken modulo span(z), satisfy (*) with these maps; w is a zero
of the quotient whose map is 0, so it lies in the radical (Lemma 21 (a)) and the system factors
through U+(w) / span(w), of dimension 6. It is anisotropic by Lemma 30 (b) for w (no h in U+(w)
outside span(w) has sigma(h) in span(z)). QED

**Remarks.**

- (d) is Lemma 60 (c) of a8.md with the tight Case B replaced by what (B6) and (B5) give: x0 is not
  in P, and N has dimension 3 or 4. In the tight Case B the count gave d = 0 in every case; here it
  gives d = 0 in (B6) and leaves d = 1 open in (B5), because dim N = 4 there.
- (e) is an equality case twice over. By Lemma 27 (c) of finite-groups.md, a system of dimension 6
  in F_2^6 with an invariant plane has dimension at most M(4) + A(2) = 4 + 2 = 6 (Theorem 26), and
  6 = A(6) (Theorem 31). Neither is a contradiction. Classifying the systems that meet one of these
  bounds is not done in these notes, so (e) gives no structure beyond what is written.
- Both (c) and (e) use A(6) = 6, which is computer-assisted (Theorem 31). With only A(6) <= 7
  (Theorem 28), (c) gives dim C >= 2, and case (II) would also allow dim C = 2 with
  dim U+(w) = 8.
- For w with A_w = 0, u lies in U+(w) with e = 0 (beta(w, u) = phi(w) = 0), so (b) says only that
  A_u kills C, which (a) already gives. The element u + w has A_(u + w) = A_u, sigma(u + w) = x0 + z
  and ker beta(u + w, .) containing w, so by Lemma 88 (c) it is a second element of (B6) or (B5)
  with the same X_1, R and d, and Lemma 89 for w relative to u + w gives the same case, since
  x0 + z lies in C exactly when x0 does.

## Corollary 58 (the zero maps of ker phi)

**Corollary 58.** Let N_0 = {w in N : A_w = 0}. Then:

(i) N_0 is a subspace with N_0 n span(u) = 0, so dim N_0 <= dim N - 1;

(ii) beta vanishes on N_0, and sigma is linear and one-to-one on N_0, with values in X_1 and
     sigma(N_0) n span(x0) = 0;

(iii) if u is in (B6) with d >= 1, or in (B5) with d >= 2, every non-zero w in N_0 is in case (II)
      of Lemma 89: beta(w, V) + span(sigma(w)) is a complement of span(x0) in X_1.

*Proof.* (i) h -> A_h is linear and A_u != 0. (ii) For w, w' in N_0, beta(w, w') = A_(w') sigma(w)
= 0 by Lemma 89 (a), so sigma(w + w') = sigma(w) + sigma(w'); anisotropy makes sigma one-to-one on
N_0, Lemma 89 (a) puts its values in X_1 and outside span(x0). (iii) Lemma 89 (d) excludes case (I).
QED

In the tables of [a33.md](a33.md), [a34.md](a34.md) and [a36.md](a36.md), (iii) covers every
class of (B6) with d >= 1, every class of (B5) with d >= 2, and so all 13 classes with d = 3 and the
hard core "d >= 2 with x0 outside Im A_u" that a33.md describes.

## Where the attempts on case (II) stop

Each with its last true statement, as in a36.md, so that the next run does not repeat it.

1. *Irreducibility.* C contains z and A_h z = beta(w, h) lies in C for every h, but C need not be
   invariant: A_h beta(w, g) = A_g A_h z, which (Q) makes symmetric in g and h but does not put in
   C. By Proposition 29 (a) the smallest invariant subspace containing z is X, so some A_h A_g z is
   outside C. This is no contradiction.
2. *The count of (d) at another element.* For any g with sigma(g) in C, (b) and (*) give
   (I + A_g) beta(g, h) = e sigma(g) for h in U+(w), so beta(g, U+(w)) lies in
   Fix(A_g) + span(sigma(g)). For g = u this is (d) when x0 is in C. In case (II) the elements with
   sigma(g) in C that are known are w itself (where the bound is the definition of U+(w)) and other
   elements of N_0 (where it gives U+(w) inside U+(g), so U+(w) = U+(g) when both have dimension 7).
   Neither bounds dim U+(w) below 7.
3. *The system on U+(w) / span(w).* It is maximal (dimension A(6)), reducible, and the image of u in
   it has map A_u modulo z, of rank 2 or 3. Lemma 30 inside it gives 6 <= 6 + A(5 - rank), which is
   no constraint. Maximal anisotropic systems with t = dim V = 6 are not classified.
4. *As a solver condition.* In an instance of job m42, A_u, phi and so N are fixed. "A_w != 0" for
   one w in N would be a single clause over the 49 entries of A_w, but Lemma 89 does not give it;
   it gives "A_w = 0 implies x0 is not in beta(w, V) + span(sigma(w)) and that space has dimension
   3", which is a rank condition on the unknown vectors beta(w, e_i), not a set of clauses. So, as
   with Corollary 57, no job is designed from this note.

## What does not follow

- Nothing is decided for (B6) or (B5): 9 of 68 and 327 of 420 classes are UNSAT. 7 <= A(7) <= 9.
- Lemma 89 (a), (b) and (d) are by hand from (*), (Q), (1), Lemma 30 and Corollaries 55 and 56
  (the last two computer-assisted). (c) and (e) also use Theorem 31 (computer-assisted).
- Case (II) is not ruled out, and Corollary 58 does not say that N_0 is 0 in any class. A proof that
  case (II) is impossible would give A_w != 0 for every w != 0 in N in those classes, one clause per
  w, which a job could use.
