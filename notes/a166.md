## 0. Summary

Program: the exact Kakeya constant of F_q (a159-a165). For a map P of F_q^k let

    Lambda(P) = sum_{t in F_q} H(X | P(X) + tX)      (bits, X uniform on F_q^k).

Conjecture C_q(k) is Lambda(P) <= k(q-1). By Theorem 2, C_q(k) for every k is equivalent to
q 2^(-(q-1)/q) being the exact Kakeya growth constant of F_q. The best published lower bound
for that constant is q/(2-1/q) (Bukh-Chao, Discrete Analysis 2021).

a164 (Theorem 40) proved C_q(3) for degree-2 maps (q odd) except in a *residual case*.
a165 found the first residual map E and computed Lambda(E) exactly. It turned out to be far
below the bound, and the overshoot came from the pair count (log2 n <= n - 1). This note
replaces the pair count by Jensen's inequality and closes the problem:

> **Theorem 43.** Let q be odd. Every map P : F_q^3 -> F_q^3 whose coordinates are
> polynomials of total degree <= 2 satisfies Lambda(P) <= 3(q-1). If P respects no nonzero
> proper subspace, the inequality is strict.

The ingredients are:
- **Theorem 42** (any map, any k): Lambda(P) <= q log2(1 + Pibar/q), where Pibar is the
  average number of partners per point. This is useless for frame products, which is why
  the earlier notes discarded it. It is strong for maps that respect no subspace, and those
  are exactly the maps the chain rule (Theorem 4) cannot handle.
- **Proposition 50**: if all 3x3 minors of the pencil [M_w | w | Lw] vanish identically
  (Z = P^2), then P respects a line or P is affine. This needs two lemmas on matrices
  (Lemmas 118 and 119).
- **Lemma 117**: otherwise |D| <= |Z(F_q)| <= 3(q+1), so Pibar/q < 4 and
  Lambda < q log2 5 <= 3(q-1).

**Corollary 132 (Kakeya form).** If q is odd and K is a subset of F_q^4 containing, for every
x in F_q^3, the line {(P(x) + t x, t) : t in F_q} with P quadratic, then
|K| >= q^4 2^(-3(q-1)/q). For this class of Kakeya sets that beats the general bound
q^4/(2-1/q)^3 of Bukh-Chao. It says nothing yet about Kakeya sets built from maps of higher
degree.

## 1. Notation (a163-a164)

Y_t = P(X) + tX. A pair x != y *collides at t* if P(x) + tx = P(y) + ty. That happens for
at most one t, and for some t exactly when P(y) - P(x) lies in F_q(y - x). For a direction w
in PG(k-1, q) let Pi_w = #{(x, lambda) : lambda != 0, P(x + lambda w) - P(x) in F_q w}, and
let Pibar = q^-k sum_w Pi_w. This is the average number of y != x that collide with x at
some t.

For P = Q + L + const of degree <= 2 with q odd, let beta(x, w) = Q(x+w) - Q(x) - Q(w), and
M_w the matrix of x -> beta(x, w). Let r_w be the rank of x -> beta(x, w) mod w, and call w
*active* if Lw mod w lies in that image. Prop 47 (a164) says Pi_w = (q-1) q^(k - r_w) if w
is active and Pi_w = 0 otherwise. A *full* direction (active, r_w = 0) is a line that P
respects. For k = 3, D is the set of cylinder directions (active, r_w = 1), Z0 the set of
inactive directions, and Z the set of w (over the algebraic closure) where rank[M_w | w | Lw]
<= 2, cut out by the ten 3x3 minors. *P respects V* means P(x+v) - P(x) lies in V for all x
and all v in V.

## 2. Theorem 42 (Jensen bound)

**Theorem 42.** For every map P of F_q^k,

    Lambda(P) <= q log2(1 + Pibar/q).

*Proof.* Let n(x, t) be the size of the fibre of Y_t containing x. Then
H(X | Y_t) = E log2 n(X, t) <= log2 E n(X, t) = log2(1 + p_t), where p_t is q^-k times the
number of ordered pairs that collide at t. Each colliding pair collides at exactly one t, so
sum_t p_t = Pibar. Concavity of log2 again gives
sum_t log2(1 + p_t) <= q log2(1 + Pibar/q). ∎

*Comparison.* The pair count gives Lambda <= Pibar. Theorem 42 is better as soon as
Pibar > q, which is the regime of the residual case. For a frame product, Pibar is about
7(q-1) and the bound is about 3q, so it fails there, but frame products respect subspaces
and are handled by Theorem 4.

**Proposition 51 (eigendirection form, q odd, degree <= 2, any k).** Let e(M) be the number
of directions w with Mw in F_q w. Then sum_w q^(-r_w) = E_x e(M_x), with M_x w = beta(x, w),
so Pibar <= (q-1) E_x e(M_x) and

    Lambda(P) <= q log2(1 + (q-1)/q · E_x e(M_x)).

*Proof.* #{x : beta(x, w) in F_q w} = q^(k - r_w). Count the pairs (x, w) with
beta(x, w) in F_q w both ways. Then use Prop 47. ∎

## 3. The case Z = P^2

**Lemma 118.** Let T in M_3(F_q) be *regular* (minimal polynomial of degree 3). Then
{A in M_3(F_q) : det(w, Tw, Aw) = 0 identically in w} = span(I, T).

*Proof.* The condition is linear in A, so the dimension of the solution space does not change
under extension to the algebraic closure, and conjugation (w -> gw) preserves it. So it
suffices to treat the three regular Jordan shapes, writing det = sum_i (Aw)_i C_i(w), where
C_i are the cofactors of the 3x2 matrix [w | Tw].
(a) T = diag(t1, t2, t3), t_i distinct: C = ((t3-t2) w2w3, -(t3-t1) w1w3, (t2-t1) w1w2).
The entry A_ij with i != j contributes the monomial w_j^2 w_m ({i, j, m} = {1, 2, 3}).
These six monomials are distinct and have nonzero coefficients, so A is diagonal. The
diagonal gives one linear condition, so the space is 2-dimensional.
(b) T ~ S = [[0,1,0],[0,0,0],[0,0,d]] (d != 0, after subtracting a scalar):
comparing the coefficients of w1^2w3, w1w3^2, w1w2^2, w2^3, w2w3^2, w1w2w3, w2^2w3 gives
A21 = A23 = A13 = A31 = A32 = 0, A11 = A22 and A33 = A22 + d A12, that is, A in span(I, S).
(c) T ~ N = [[0,1,0],[0,0,1],[0,0,0]]: the monomials w3^3, w1^2w3, w1w2^2, w2^3, w1w2w3,
w1w3^2, w2^2w3, w2w3^2 give A13 = A31 = A32 = A21 = 0, A11 = A22 = A33 and A12 = A23,
that is, A in span(I, N).
In each case I and T are solutions, so the space is span(I, T). ∎

**Lemma 119.** Let T be regular and a, b linear forms with
a(y) w + b(y) Tw = a(w) y + b(w) Ty for all y, w. Then a = b = 0.

*Proof.* Again pass to the algebraic closure and a Jordan form; the identity is preserved
with a, b replaced by a∘g, b∘g. (a) T = diag(t_i): coordinate i reads
g_i(y) w_i = g_i(w) y_i with g_i = a + t_i b, so g_i = kappa_i e_i^*. The three g_i lie in
span(a, b), which has dimension <= 2, so some kappa_i = 0, say g_3 = 0. Then
g_1 = (t1 - t3) b and g_2 = (t2 - t3) b are multiples of b and of e_1^*, e_2^* respectively,
which forces b = 0 and then a = 0. (b) With S as above and a' = a + (scalar) b: coordinate 2
gives a' = kappa e_2^*, coordinate 3 gives a' + d b = mu e_3^*, and coordinate 1 at
(y, w) = (e2, e1) and (e3, e2) gives kappa = mu = 0. (c) With N: coordinate 3 gives
a' = kappa e_3^*, coordinate 2 gives b(e1) = 0 and b(e2) = kappa, and coordinate 1 at
(e3, e1) and (e3, e2) gives kappa = 0 and b(e3) = 0. ∎

**Proposition 50.** Let q be odd and P of degree <= 2 on F_q^3, and suppose all ten 3x3
minors of B(w) = [beta(e1,w), beta(e2,w), beta(e3,w), w, Lw] vanish identically
(Z = P^2). Then Q = 0 (P is affine), or P respects a line F_q u.

*Proof.* Let r be the rank of B(w) over the function field F_q(w); 1 <= r <= 2.
*r = 1.* Every column is a multiple of w, so beta(y, w) lies in F_q w for all y, w. By
symmetry beta(y, w) = 0 whenever y and w are independent, and so beta = 0 by bilinearity.
Since q is odd, Q = 0.
*r = 2.* Some column Tw (T one of beta(e_j, .), L) is generically independent of w, and
every column Aw satisfies det(w, Tw, Aw) = 0 identically.
- If T is not regular, then T - aI has rank 1 for an eigenvalue a of geometric
  multiplicity 2. Such an a is a double root of the characteristic polynomial, hence lies in
  F_q, so T = aI + u psi^T with u, psi rational and nonzero. Then
  det(w, Tw, Aw) = psi(w) det(w, u, Aw), so Aw lies in span(w, u) for every w. For fixed y,
  the map w -> beta(y, w) mod u sends every vector of the 2-dimensional quotient
  F_q^3/F_q u to a multiple of itself, so it is a scalar lambda(y). The same holds for L,
  with a scalar s. Symmetry gives lambda(y) w = lambda(w) y mod u, so lambda = 0. Hence
  beta takes values in F_q u, Q(u) = beta(u, u)/2 lies in F_q u, and Lu lies in F_q u.
  Therefore P(x + lambda u) - P(x) lies in F_q u: P respects F_q u.
- If T is regular, Lemma 118 gives beta(e_j, .) and L in span(I, T), so
  beta(y, w) = a(y) w + b(y) Tw with a, b linear. Symmetry of beta and Lemma 119 give
  a = b = 0, so beta = 0 and Q = 0. ∎

## 4. Lemma 117 and the proof of Theorem 43

**Lemma 117.** If q >= 5 and f is a nonzero ternary cubic form over F_q, then f has at most
3(q+1) zeros in PG(2, q). (Three concurrent lines have 3q+1.)

*Proof.* As a polynomial, f has degree <= 3 < q in each variable, so it is not zero on all of
F_q^3: pick a rational p with f(p) != 0. Each of the q+1 lines through p is not contained in
V(f), so it meets V(f) in at most 3 points, and these lines cover PG(2, q). ∎

**Proof of Theorem 43.** If P respects a nonzero proper subspace, use Theorem 40(a)
(Theorem 4 with C_q(1) and Theorem 38). If Q = 0, then
Lambda = log2 q · sum_t dim ker(L + tI) <= 3 log2 q < 3(q-1). Otherwise P has no full
direction, so by Prop 47 every Pi_w is 0, (q-1)q or (q-1)q^2, and

    q^2 Pibar = (q-1) [q^2 + q + 1 + (q-1)|D| - |Z0|].

- q = 3: |D| <= 13 gives q^2 Pibar <= 78 and 1 + Pibar/q <= 35/9. Since
  (35/9)^3 = 58.8 < 64, Theorem 42 gives Lambda < 6.
- q >= 5: by Proposition 50, Z != P^2, so some minor is a nonzero cubic form f. Every
  cylinder direction has rank[M_w | w | Lw] <= 2 (its column space is Im M_w + F_q w, of
  dimension 2), so D is contained in V(f)(F_q), and |D| <= 3q + 3 by Lemma 117. Then
  q^2 Pibar <= (q-1)(4q^2 + q - 2) < 4q^3, so Pibar/q < 4 and Theorem 42 gives
  Lambda < q log2 5 <= 3(q-1) (5^q <= 8^(q-1) for q >= 5). ∎

**Corollary 132.** Under the hypotheses of Theorem 43, sum_t |Im(P + tI)| >=
q^4 2^(-3(q-1)/q).

*Proof.* |Im(P + tI)| >= 2^(H(Y_t)) = q^3 2^(-H(X|Y_t)). By AM-GM, the sum is at least
q · q^3 2^(-Lambda/q). ∎

The base q 2^(-(q-1)/q) exceeds q/(2 - 1/q) for every q >= 2, because
2(2q-1)^q > (2q)^q. So for Kakeya sets in F_q^4 whose non-horizontal lines have a quadratic
intercept map, this improves Bukh-Chao's q^4/(2-1/q)^3. The frame product
P = (x1^2, x2^2, x3^2) gives q((q+1)/2)^3, consistent with the bound.

## 5. What changes, and what is next

- **Degree-2 maps in dimension 3 are done (q odd).** The residual case of a164, the type-(b)
  pencils and the map E of a165 are all covered by Theorem 43. Theorem 41 and Proposition 49
  remain as exact examples.
- **The two tools are complementary.** The chain rule (Theorem 4) is sharp on maps that
  respect subspaces, where Jensen is weak. Jensen is strong exactly when no subspace is
  respected.
- **All k, degree 2.** Start from C_q(1), which holds for every map. By induction with
  Theorem 4 (and the affine case, Lambda <= k log2 q), C_q(k) holds for every degree-<=2
  map of F_q^k as soon as the following holds for each 2 <= j <= k:
  **(Q_j)** every degree-<=2 map of F_q^j (q odd) that respects no subspace and has Q != 0
  satisfies Pibar <= q(2^(j(q-1)/q) - 1).
  Q_2 follows from Prop 47: with no full direction, Pibar <= (q^2-1)/q < q, and
  q < q(2^(2(q-1)/q) - 1) for q > 2. Q_3 is proved here. (The analogue of Q_1 is false: the
  parabola has Pibar = q - 1 and is extremal, which is why the induction starts from C_q(1).)
  Heuristic: for the frame product,
  E_x e(M_x) tends to 2^j - 1 as q grows, which is exactly the threshold in Proposition 51.
  So Q_j asks that maps respecting no subspace stay strictly below the product. If Q_j holds
  for all j, then no quadratic Kakeya construction, in any dimension, beats the frame
  product's growth constant.
- **Other open fronts:** even q (Prop 47 changes because beta(w,w) = 0); degree 3; general
  maps with k = 2, where Theorem 42 reduces C_q(2) to an inverse statement (maps with
  Pibar > 3q are close to respecting a direction).
