## Proposition 34 (the split for the three classes of (B5) with d = 2)

The three open classes of (B5) with d = 2 are r3b_t7_B5_o004_c001, o005_c005 and o006_c000, in
pair orbits 4, 5 and 6, so X_1 = ker A_u = span(e_0, ..., e_3) lies in H0 = span(e_0, ..., e_5).
Their sweeps were UNSAT (job m64b), so by Lemma 93 (a) their splits need only the classes of rank
1 and 2 on X_1. Coordinates and notation are those of Proposition 32 ([a45.md](a45.md)); P =
span(e_1, ..., e_5). m42d's representatives (m57.py's LEFTOVERS), column by column:

    o004_c001   A_u e_4 = e_2,              A_u e_5 = e_4,  A_u e_6 = e_1          R = span(e_4, e_2, e_1)
    o005_c005   A_u e_4 = e_0 + e_1 + e_2,  A_u e_5 = e_4,  A_u e_6 = e_0 + e_1    R = span(e_4, e_2, e_0 + e_1)
    o006_c000   A_u e_4 = e_0 + e_4,        A_u e_5 = e_2,  A_u e_6 = e_1          R = span(e_0 + e_4, e_2, e_1)

with A_u = 0 on X_1. In each, X_1 n R is a plane (span(e_1, e_2), span(e_2, e_0 + e_1) and
span(e_1, e_2)), so d = 2.

**Proposition 34.** For each of these three classes:

(a) Proposition 32 (a) holds as stated: every A_n, n in N outside span(u), lies in Adm.

(b) |Adm| = 405566, as in Proposition 32 (b) for X_1 inside H0.

(c) The group G of g in GL(X) with g x0 = x0, g P = P and g A_u = A_u g has order 2048 for
    o004_c001, 512 for o005_c005 and 1024 for o006_c000.

(d) Up to G and A -> A + A_u, Adm has at least ceil(405566 / (2 |G|)) classes: 100, 397 and 199.

*Proof.* (a) The proof of Proposition 32 (a) uses Proposition 29 (c), which holds for every u in
(B5) ([a24.md](a24.md)), the rank bound on X_1 from (N) of [a36.md](a36.md) and Lemma 30 (b),
Corollary 60, which needs d >= 2 in (B5) and so applies, and Corollary 55. None of them needs
d = 3.

(b) The count of Proposition 32 (b) for X_1 inside H0 uses only that A_u is 0 on X_1 and maps
D = span(e_4, e_5) onto a plane R_P of R; that holds here, because A_u is one-to-one on
span(e_4, e_5, e_6). It does not use R inside X_1.

(c) g keeps X_1 = ker A_u and P, so g e_1, g e_2, g e_3 lie in X_1 n P = span(e_1, e_2, e_3), and
g e_4, g e_5 lie in P. The conditions g A_u e_j = A_u g e_j for j = 0, ..., 3 say that g keeps
X_1. Write g e_5 = y = y_1 e_1 + ... + y_5 e_5, g e_6 = z = c_0 e_0 + ... + c_6 e_6 and
g e_3 = w.

- o004_c001. j = 5: g e_4 = A_u y = y_4 e_2 + y_5 e_4. j = 4: g e_2 = A_u g e_4 = y_5 e_2, so
  y_5 = 1. j = 6: g e_1 = A_u z = c_6 e_1 + c_4 e_2 + c_5 e_4, which lies in X_1 only if c_5 = 0.
  g is invertible on X_1 if and only if c_6 = 1 and w = e_3 + (span(e_1, e_2)) (4 choices), and
  then it is invertible: modulo X_1 it is triangular. Free: y_1, ..., y_4 (16), c_0, ..., c_4 (32)
  and w (4): |G| = 2048.
- o005_c005. j = 5: g e_4 = A_u y = y_4 (e_0 + e_1 + e_2) + y_5 e_4 lies in P, so y_4 = 0, and
  y_5 = 1. j = 4: g(e_0 + e_1 + e_2) = A_u e_4, so g e_1 + g e_2 = e_1 + e_2. j = 6:
  e_0 + g e_1 = A_u z = c_4 (e_0 + e_1 + e_2) + c_5 e_4 + c_6 (e_0 + e_1), and g e_1 in
  span(e_1, e_2, e_3) forces c_5 = 0 and c_6 = c_4 + 1, so g e_1 = e_1 + c_4 e_2 and
  g e_2 = (1 + c_4) e_2; invertibility forces c_4 = 0. Free: y_1, y_2, y_3 (8), c_0, ..., c_3 (16)
  and w (4): |G| = 512.
- o006_c000. j = 4: e_0 + g e_4 = A_u g e_4; with g e_4 = x in P, A_u x = x_4 (e_0 + e_4) + x_5 e_2,
  so x_4 = 1 (the e_0 coordinate), x_5 = 0 (the e_5 coordinate), and then x = e_4. j = 5:
  g e_2 = A_u y = y_4 (e_0 + e_4) + y_5 e_2 lies in X_1, so y_4 = 0, y_5 = 1. j = 6:
  g e_1 = A_u z = c_4 (e_0 + e_4) + c_5 e_2 + c_6 e_1, so c_4 = 0 and c_6 = 1. Free: y_1, y_2, y_3
  (8), c_0, ..., c_3 and c_5 (32) and w (4): |G| = 1024.

(d) Each class of the action of G x Z_2 has at most 2 |G| elements. QED
