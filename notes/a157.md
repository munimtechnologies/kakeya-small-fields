## Where this sits

Theorem 2 of this repository says that the Kakeya growth base over F_q is

    beta_q = lim K(n, q)^(1/n) = inf_k 2^(h_k / k),

where h_k is the least value of h(P) = (1/q) sum_{t in F_q} H(P(X) + tX) over maps
P : F_q^k -> F_q^k, with X uniform on F_q^k. Theorem 1 is the case k = 1. Whether **blocks** help
(whether h_k < k h_1 for some k) is the open question that decides whether Theorem 1's bound
q * 2^(-(q-1)/q) can be improved by this method. In the score S(P) = sum over t and over the fibres
of x -> P(x) + tx of s log2 s, a block beats Theorem 1 exactly when S(P) > k (q - 1) q^k
(Corollary 1).

What was already ruled out: maps that respect a linear quotient, including all F_q-affine maps
(Theorem 4, Corollary 3); all maps for q = 3, k = 2 (exhaustive, section 9); permutation-invariant
sets (section 7). This note rules out the next natural family: **additive** maps, i.e. maps that
are F_p-linear (q = p^m) plus a constant. For q = 4, 8, 16, ... this family contains the
coordinatewise square map that *attains* the threshold, and over F_{q^k} it contains every
linearised polynomial sum a_i x^(p^i). They are the obvious algebraic candidates.

## Theorem 34

Let q = p^m, k >= 1, and let P : F_q^k -> F_q^k be F_p-linear. For t in F_q let
n_t = dim_{F_p} ker(P + t), where t acts by scalar multiplication. Then

    sum_{t in F_q} n_t  <=  k (q - 1)/(p - 1)  =  k (1 + p + ... + p^(m-1)).

The bound is attained by the coordinatewise Frobenius x -> x^p, for every q and k.

**Corollary 124.** For every F_p-affine map P (F_p-linear plus a constant),

    S(P) = q^k log2(p) sum_t n_t  <=  k (q - 1) q^k * log2(p)/(p - 1).

Since log2(p) <= p - 1, with equality only for p = 2, no additive map beats Theorem 1 for any q.
For odd p every additive map is strictly worse than the threshold. For p = 2 the best additive maps
tie it exactly (h(P) = k h_1), so for q = 2^m the coordinatewise square map has many additive equals
but no additive improvement.

The formula for S(P) holds because x -> P(x) + tx is F_p-affine: its fibres are the cosets of
ker(P + t), each of size p^(n_t), so the fibre sum is q^k * n_t * log2(p). Adding a constant to P
changes no fibre.

## Proof

**Extending scalars.** Let V = F_q^k, an F_p-space of dimension N = mk. Extend scalars to
V' = V (x)_{F_p} F_q. Multiplication by c in F_q on V extends to an F_q-linear map on V' that is
diagonalisable with eigenvalues c, c^p, ..., c^(p^(m-1)), each with multiplicity k. Concretely,
F_q (x)_{F_p} F_q is isomorphic to F_q^m via a (x) b -> (a^(p^j) b)_j. Fix a basis of V' adapted
to this decomposition V' = V_0 + ... + V_{m-1} (each V_j of dimension k), where c acts on V_j as
c^(p^j). In this basis the extension of P is some mk x mk matrix M over F_q, and the extension of
t is T_t = diag(t I_k, t^p I_k, ..., t^(p^(m-1)) I_k). Kernel dimensions do not change under
extension of scalars, so n_t = dim_{F_q} ker(M + T_t).

**The polynomial.** Let f(y_0, ..., y_{m-1}) = det(M + diag(y_0 I_k, ..., y_{m-1} I_k)), a
polynomial over F_q of degree at most k in each y_j. The coefficient of y_0^k ... y_{m-1}^k is 1.
Put g(y) = f(y, y^p, ..., y^(p^(m-1))). A monomial prod y_j^(a_j) with all a_j <= k becomes
y^(sum a_j p^j), and the exponent equals the maximum D = k (1 + p + ... + p^(m-1)) only when every
a_j = k. So g has degree exactly D, with leading coefficient 1; in particular g is not the zero
polynomial.

**Lemma 110 (multiplicity).** For t in F_q, g has a root of multiplicity at least n_t at y = t.

*Proof.* Write y = t + u. In characteristic p, (t + u)^(p^j) = t^(p^j) + u^(p^j). So
g(t + u) = det(C + E), with C = M + T_t of rank N - n_t and E = diag(u I_k, u^p I_k, ...).
Expanding the determinant of C + E along the diagonal entries of E gives a sum over subsets I of
the diagonal positions of (product of the E-entries in I) times (the principal minor of C on the
complement of I). That minor has size N - |I|; it vanishes when N - |I| > rank C, i.e. when
|I| < n_t. Every surviving term has at least n_t diagonal factors, each a power u^(p^j) with
p^j >= 1, so g(t + u) is divisible by u^(n_t). QED

**End of proof.** The q elements of F_q are distinct roots of g with multiplicities at least n_t,
and g is a nonzero polynomial of degree D, so sum_t n_t <= D. For the Frobenius x -> x^p applied
in each coordinate, ker(x^p + tx) in F_q is {0} together with the roots of x^(p-1) = -t. There are
p - 1 such roots exactly when -t is a nonzero (p-1)-th power, which happens for (q - 1)/(p - 1)
values of t, so n_t = 1 for those t and 0 otherwise. Summing over the k coordinates gives
sum_t n_t = k (q - 1)/(p - 1). QED

For k = 1 the theorem is elementary: every nonzero x lies in exactly one kernel, so
sum_t (p^(n_t) - 1) = q - 1, and p^n - 1 >= n (p - 1) finishes. For k >= 2 that count only gives
sum_t (p^(n_t) - 1) <= q^k - 1, which allows far more than k (q - 1)/(p - 1). For q = 4 and k = 2,
four pairwise-disjoint planes in F_2^4 would allow sum n_t = 8 against the true maximum 6. The
determinant along the curve (y, y^p, ..., y^(p^(m-1))) is what closes the gap.

## What it means for the search

A map that beats Theorem 1 must now be (Theorem 4, Corollary 3, Theorem 34) **non-additive** and
must **respect no proper F_q-subspace**. For q = 4 the threshold map itself is additive, so any
improvement has to break additivity. The local search must leave the additive family, where
annealing from the square map is likely to stall.

## Pre-registered: block search for q = 4 and q = 5 (job kakeya-h2q45-v1, not yet run)

The October job kakeya-h2-v1 planned 1,200-second anneals for (q, k) = (4, 2) and (5, 2), but it was
stopped from outside (exit 143) after its (3, 3) anneal, so **these two cases have never been
searched**. (Results so far: q = 3, k = 2 exhaustive max 36 = threshold; anneals at
(3, 3) and (2, 4) found exactly the thresholds 162 and 64.) The next job runs this commit's tests
and census, then `search_h2.py anneal` for (4, 2) and (5, 2), each twice with different seeds, 40
minutes per run (search space 16^15 and 25^24 maps after fixing P(0) = 0). Predictions:

- **K1.** The census prints THEOREM_34_CHECK OK, and every exhaustive maximum equals the bound.
- **K2.** Both (4, 2) anneals end at max_score = 96 exactly (threshold 96, ceiling 103.34).
- **K3.** Both (5, 2) anneals end at max_score = 200 exactly (threshold 200, ceiling 212.00).

Why K2 and K3 are worth running even though we expect "no": any map scoring above the threshold is
a finite certificate of a **new upper bound on the Kakeya growth base beta_4 or beta_5**, below
q * 2^(-(q-1)/q). The comparison would be made exactly in integers (prod s^s > 2^threshold). A
second "no" at (4, 2) and (5, 2), together with q = 3, k = 2 (exhaustive) and q = 3, k = 3
(annealing), supports the conjecture that blocks never help. In that case Theorem 1's bound would
be the true value of beta_q for this whole family of constructions, which would be the next thing
to try to prove.
