the longer limit they needed far less than 1,500 s: m103 and m122 at most 480 s (a140), m062 332 s

2,224 s row for a 1,500 s limit), and CaDiCaL's run time also varies from run to run, so an UNKNOWN
at 1,500 s is weak evidence that a case is hard. This is four cases, so it is an observation only.
