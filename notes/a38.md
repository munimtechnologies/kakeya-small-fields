## Lemma 90 (sigma(w) is not a value of beta(w, .))

**Lemma 90.** Let w != 0 in N have A_w = 0 and z = sigma(w). Then beta(w, g) != z for every g.

*Proof.* Suppose beta(w, g0) = z. Then g0 != 0, and since beta(w, u) = phi(w) = 0, also
beta(w, g0 + u) = z, so g0 + u != 0.

*Step 1 (ranks).* By Lemma 89 (b), A_(g0) and A_(g0 + u) both act on C as the identity, so both
have rank at least dim C >= 3. By Corollary 55 every map has rank at most 3. So dim C = 3, and
Im A_(g0) = Im A_(g0 + u) = C.

*Step 2 (R = C, and x0 is not in C).* A_u = A_(g0) + A_(g0 + u), so R = Im A_u lies in C. Both have
dimension 3, so R = C, and as C lies in X_1, d = dim(X_1 n R) = 3. Lemma 89 (d) says that x0 in C
forces d = 0 in (B6) and d <= 1 in (B5). So x0 is not in C, and X_1 = C + span(x0), a direct sum.

*Step 3 (phi(g0) lies in C).* By (1), A_(g0) x0 = (I + A_u) phi(g0), so
phi(g0) = A_(g0) x0 + A_u phi(g0) lies in Im A_(g0) + R = C.

*Step 4 (two values in a line).* (*) with h = g0 and h' = u gives
A_u sigma(g0) = (I + A_(g0)) phi(g0) = 0, as A_(g0) is the identity on C. (*) with h = g0 + u and
h' = u gives A_u sigma(g0 + u) = (I + A_(g0 + u)) beta(g0 + u, u) = (I + A_(g0 + u)) phi(g0) = 0. (*)
with h = g0 + u and h' = g0 gives A_(g0) sigma(g0 + u) = (I + A_(g0 + u)) beta(g0 + u, g0) =
(I + A_(g0 + u)) phi(g0) = 0, and A_(g0) sigma(g0) = 0. So sigma(g0) and sigma(g0 + u) both lie in
ker A_(g0) n X_1, and both are non-zero (anisotropy). Now ker A_(g0) meets C only in 0 (A_(g0) is
the identity on C), and X_1 = C + span(x0), so ker A_(g0) n X_1 has dimension at most 1: it has one
non-zero vector at most. Hence sigma(g0 + u) = sigma(g0). But

    sigma(g0 + u) = sigma(g0) + sigma(u) + beta(g0, u) = sigma(g0) + x0 + phi(g0),

so x0 = phi(g0), which lies in C by Step 3. This contradicts Step 2. QED

**Remarks.**

- Step 1 is where the rank bound enters: an element that is the identity on a space of dimension 3
  already has the largest rank allowed, so its image is that space. With a rank-4 element allowed,
  Step 1 would give nothing in case (I) (dim C = 4) and only Im A_(g0) containing C otherwise.
- The proof uses Lemma 89 (b), (c) and (d), Corollary 55 (computer-assisted) and, through Lemma
  89 (c), Theorem 31 (A(6) = 6, computer-assisted). It uses the configuration of u only through
  Lemma 89 (d) (that is, through dim N and x0 not in P).
- In case (I) of Lemma 89 the lemma also follows from Step 1 and Step 2 alone: dim C = 4 contradicts
  Step 1, and dim C = 3 with x0 in C gives d = 3 against Lemma 89 (d).

## Corollary 59 (what a zero map in ker phi must look like now)

**Corollary 59.** Let w != 0 in N have A_w = 0, z = sigma(w), C = beta(w, V) + span(z). Then:

(i) U+(w) = ker beta(w, .), every A_h with h in U+(w) kills C, and dim beta(w, V) = dim C - 1;

(ii) in case (II) of Lemma 89: beta(w, V) is a plane span(p_1, p_2) inside X_1, C = span(z, p_1,
     p_2), and U+(w) has dimension 7 and contains u;

(iii) in case (II), U+(w) contains a subspace U of dimension 3 with w in U, beta(U, U) = 0 and sigma
      linear from U onto C;

(iv) in case (II), for g_1, g_2 with beta(w, g_i) = p_i, the vector q = A_(g_1) p_2 depends only on
     p_1 and p_2, equals A_(g_2) p_1, and is not in C. Every h with beta(w, h) = p_1 maps z and p_1
     to p_1 and p_2 to q.

*Proof.* (i) By Lemma 90, beta(w, h) lies in span(z) only when it is 0, so U+(w) = ker beta(w, .),
and its elements act on C as 0 (Lemma 89 (b) with e = 0). As z is not in beta(w, V),
dim C = dim beta(w, V) + 1. (ii) In case (II) dim C = 3 (Lemma 89 (e)), so dim beta(w, V) = 2;
beta(w, V) lies in X_1 by Lemma 89 (a); dim U+(w) = 9 - 2 = 7; and beta(w, u) = phi(w) = 0.
(iii) C is invariant under the maps of U+(w), which all kill it. By Lemma 27 (a) of
[finite-groups.md](../finite-groups.md), sigma modulo C on U+(w) is a system with t = 4, so it
vanishes on a subspace U of codimension at most M(4) = 4, that is dim U >= 3. By Lemma 27 (b), sigma
on U is an anisotropic system with values in C (t = 3), so dim U <= A(3) = 3, and dim U = 3. Its maps
are the restrictions of the A_h to C, which are 0, so (*) on U reads beta(h, h') = 0: sigma is
linear on U, one-to-one, and onto C. Some k in U has sigma(k) = z; then
sigma(k + w) = z + z + beta(k, w) = 0, as k lies in U+(w) = ker beta(w, .), so k = w. (iv) By (Q)
with h_1 = w, h_2 = g and h' = h, A_h beta(w, g) = A_g beta(w, h) for all g, h. So for h with
beta(w, h) = p_1: A_h z = p_1 (Lemma 89 (a)), A_h p_1 = p_1 (take g = h) and A_h p_2 = A_(g_2) p_1,
which does not depend on h; symmetrically A_(g_2) p_1 = A_(g_1) p_2. If q were in C, then C would be
mapped into itself by A_(g_1), A_(g_2) and every A_h with h in U+(w), which together span all the
maps (V = U+(w) + span(g_1, g_2)), so C would be invariant, against Proposition 29 (a)
(alpha(V) is irreducible). QED

So, compared with a37.md, the invariant plane C / span(z) of the system on U+(w) / span(w) is now in
the common kernel of all its maps, and the elements over p_1, p_2 and p_1 + p_2 act on C with rank 2
(kernel span(z + p_1), span(z + p_2), span(z + p_1 + p_2) respectively).

## Where the attempts on what is left stop

Each with its last true statement, as in a36.md and a37.md, so that the next run does not repeat it.

1. *Lemma 90's argument at g_1.* For g in g_1 + U+(w), A_g has rank 2 on C, so the rank bound does
   not fix Im A_g, and the analogue of Step 4 (sigma(g_1) and sigma(g_1 + u) in a small space) has
   no small space to use. (*) with h = g_1 + u, h' = g_1 gives back only (1).
2. *The subspace U.* For k in U, (*) gives A_(h') sigma(k) = (I + A_k) beta(k, h'): so
   beta(k, U+(w)) lies in Fix(A_k), which meets C only in 0, and for k with sigma(k) in
   span(z + p_1), beta(k, g_1) lies in Fix(A_k) too. (Q) gives A_k beta(k', h) = A_(k') beta(k, h)
   for k, k' in U. Whether A_k = 0 for k in U other than w is not decided; nothing forces it.
3. *Tightness.* dim U+(w) = 7 = M(4) + A(3) is the equality case of Lemma 27 (c) for the invariant
   space C; a system in which every map is 0 and sigma is linear and onto (X / C) meets it, so
   tightness alone gives no contradiction.
4. *As a solver condition.* As for Lemma 89: in an instance of job m42, "A_w = 0" for a fixed w in N
   implies that beta(w, .) avoids sigma(w) and takes values in a plane of ker A_u, which is still a
   condition on unknown vectors, not a set of clauses. No job is designed from this note.
