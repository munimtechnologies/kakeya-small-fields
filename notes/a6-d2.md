## Why this case

A(6) <= 7 holds if and only if no anisotropic system with t = 6 and dim V = 8 has an element u of
rank 3 in Case B of shape (c) (Corollaries 18 and 22). In shape (c), d = dim(X_1 n R) is 2 or 3,
where X_1 = ker A_u and R = Im A_u (Proposition 27(c4)). Job m18 ([a6-d3.md](a6-d3.md)) searches
d = 3, where R = X_1 and the subspace L = [R] of X/X_1 is 0. This note is the other half, d = 2,
where L is a line and D = T^(-1)(X_1 n R) is a plane. The difficulty named in a6-d3.md was that
Lemma 46(a) is linear only once L is fixed. The remedy is to fix more: the whole map that A_u
induces on X/X_1.

## Lemma 56 (the block of A_u)

In the normal form of Lemmas 35, 37 and 39 at (t, k) = (2k, k), X_1 = span(e_0, ..., e_(k-1)), and
A_u kills X_1, so A_u induces a linear map Abar_u of X/X_1 whose matrix in the basis
[e_k], ..., [e_(t-1)] is the lower-right k x k block of the matrix of A_u.

**Lemma 56.** Let u be in Case B of shape (c) at (t, k) = (2k, k), and let d = dim(X_1 n R).

(a) Im Abar_u = L = [R] and ker Abar_u = D, so rank Abar_u = k - d. In particular d = k - 1 if and
    only if Abar_u has rank 1, Abar_u = a b^T with L = span(a) and D = ker b^T.

(b) If d = k - 1, exactly one of the following holds. **Type J:** b^T a = 0, Abar_u^2 = 0, L lies
    in D, and A_u^3 = 0. **Type E:** b^T a = 1, Abar_u is idempotent, L n D = 0, and the vector
    w = A_u x for any x with [x] = a is fixed by A_u, lies outside X_1, and spans Im A_u^2. At
    t = 6, type J is the Jordan type 3, 2, 1 of Corollary 23(a) and Corollary 28, and type E is
    its complement.

(c) The symmetries of Lemma 39 act on Abar_u by conjugation with the same g in GL_k(F_2) that
    conjugates the matrices M_i, and the recombination of v_1, ..., v_(k-1) leaves Abar_u
    unchanged. So if some anisotropic system has an element in Case B of shape (c) with d = k - 1,
    it has one in the normal form whose triple (M_1, ..., M_(k-1), Abar_u) is any chosen
    representative of its orbit under GL_k x GL_(k-1).

*Proof.* (a) [A_u x] depends only on [x], and the classes [A_u x] fill [R] = L. Abar_u [x] = 0
means A_u x in X_1, that is, [x] in T^(-1)(X_1 n R) = D. Lemma 46 gives dim L = rho - d = k - d.
A rank-1 matrix over F_2 is a b^T with a its non-zero column and b^T its non-zero row.

(b) Abar_u^2 = a (b^T a) b^T, so Abar_u^2 is 0 or Abar_u according as b^T a is 0 or 1. If b^T a = 0,
a lies in ker b^T = D, so L lies in D; then Im A_u^2 = T(L) lies in T(D) = X_1 n R, which A_u kills,
so A_u^3 = 0. If b^T a = 1, a is not in D, so L n D = 0; put w = A_u x with [x] = a, a vector of R
with [w] = Abar_u a = a, so w is not in X_1 and spans T(L) = Im A_u^2; A_u w = A_u^2 x lies in
Im A_u^2 = span(w) and is not 0 (as w is not in X_1 = ker A_u), so A_u w = w. At t = 6, A_u has
rank 3 and Im A_u^2 = T(L) is a line; A_u^3 = 0 is then the Jordan type 3, 2, 1 (as in the proof of
Corollary 23(a)), and in type E, w is an eigenvector with eigenvalue 1, so A_u is not nilpotent.

(c) In the proof of Lemma 39, the new basis of X/X_1 is [e'_(k+j)] = sum over l of g[l][j] [e_(k+l)],
and the matrix of any linear map of X/X_1 changes to g^(-1) (old matrix) g; Abar_u is such a map.
Replacing v_1, ..., v_(k-1) by combinations of themselves changes neither u nor the basis of X.
QED

So shape (c) with d = k - 1 at (2k, k) splits into one search per orbit of triples: for each orbit of
commuting tuples (M_1, ..., M_(k-1)) (the 38 orbits of shape-c.md at k = 3), the orbits of the
rank-1 matrices Abar_u under the stabiliser of the orbit's least tuple. There are 49 rank-1
matrices in M_3(F_2), 21 of them nilpotent (type J) and 28 idempotent (type E); for the pair
(0, 0), whose stabiliser is the whole group, this gives exactly 2 triples. The code computes the
others, and its selfcheck confirms that the triples partition the 7,456 x 49 pairs (tuple, matrix).

## What becomes linear

With Abar_u fixed, L = span(a) and D = ker b^T are known, and these hand results are linear (or
fixed) in the coordinates of the normal form:

- **(D2)** the lower-right block of A_u is Abar_u (unit clauses).
- **(B2)** [beta(v_i, h)] = M_i [phi(h)] for i < k and every basis element h (Lemma 38(a)): the
  lower rows of beta(v_i, v_(k-1+j)) are 0 and those of beta(v_i, v_(2k-1+j)) are column j of M_i
  (unit clauses).
- **(W2)** A_(v_(k-1+j)) maps X_1 into X_1 (Proposition 27(c2)) and induces M_j + (a map into L)
  on X/X_1 (Lemma 46(a)): each column of its lower-right block differs from the column of M_j by
  0 or a (parity equations).
- **(Q2)** q(y) lies in D and M_n q(y) lies in D for every n in N (Lemma 38(e)): b^T M_n q(y) = 0
  (parity equations; q(y) is the class of sigma(h_y), quadratic in the coordinates only through
  beta(v_3, v_4) for y = e_1 + e_2).
- **(K2)** M_(n_y) q(y) lies in L n D (Lemma 46(c)): M_(n_y) q(y) = 0 in type E, and in span(a) in
  type J.
- **(T2)** T q(y) = y + G_y y (Lemma 46(b)) on the rows of X_1. T q(y) is the sum of the columns
  k + c of A_u over the bits c of q(y), a product of variables, so this is quadratic (AND clauses).
- **(J2)** In type J: if I + M_(n_y) maps X/X_1 into L for some y != 0, then by Lemma 54(d)
  Im A_u^2 = T(L) = span(y), so T a = y on X_1; q(y) = a (as L = span(q(y))); G_y y = 0; and the
  columns of G_y lie in span(y). Two such y contradict Corollary 28(b).

Filters, so that fewer instances are built: in type E, Corollary 23(a) makes every non-zero element
of span(M_1, M_2) singular, and Corollary 28(a) says none of them is I + K with K of rank <= 1 and
image in L; in type J, triples with two or more y as in (J2) are dropped. Every condition follows
from (*) by the hand proofs cited, so adding them removes no model with d = 2 at t = 6. At (4, 2) the
same code gives control instances (d = 1 = k - 1 there), all of which must be UNSAT because
A(4) = 4; the filters are proved at t = 6 and are used at (4, 2) only for controls.

## The search (job m19-d2-v1)

`shape_c4.py` takes the CNF of `shape_c.encode_split` for the orbit's least pair (the CNF of job
m13) and appends (D2) to (J2). It solves the instances of one type in passes: 25 seconds each
first, then 4 minutes for those still undecided, under a total of 75 minutes for type E and 90 for
type J at (6, 3); instances not reached in the first pass are reported as SKIPPED and a later job
takes them from the undecided list. The predictions, written before the job was queued
(m19/predictions.md):

- the selfcheck passes (the counts above, the partition of the triples, both types present, no
  type-E instance with an invertible element in its span);
- (4, 2), controls: every instance UNSAT;
- (6, 3), exploratory. Type E all UNSAT: in every shape (c) system at t = 6 with d = 2, A_u has
  Jordan type 3, 2, 1. Type J all UNSAT too, and job m18 all UNSAT: **A(6) <= 7**, computer-assisted,
  without proof certificates, resting on the hand lemmas cited. A SAT answer counts only if the
  model passes the brute-force check of (*), anisotropy, the normal form, (S) and every added
  constraint; it would be an anisotropic system with t = 6 and dim V = 8, so A(6) = 8, and we
  would publish it with its matrices.

## Computation

The unit tests of `shape_c4.py` check, for each family of constraints separately and for all of
them together, that the appended clauses accept exactly the coordinates that a direct check
accepts: on random coordinates built to satisfy the family, on random ones, and on one-bit changes
of both, at (4, 2) and (6, 3); that the filter, the type and the number of y in (J2) are constant on
every orbit of triples; that every type-E instance has a singular span and no y as in (J2), and
every type-J instance at most one; and the counts of the selfcheck.

## What it does not settle

A(6) <= 7 is open. Lemma 56 is a normal form, not a contradiction. The constraints (Q2), (K2) and
(T2) are consequences of (*) that the solver would otherwise have to find for itself; whether they
make the (6, 3) instances tractable in minutes is what the job measures. The 1-CPU job will not
reach every type-J instance; the undecided list is the input of the next job.
