# a178. The annealed pair count: random frame maps are far from extremal at every density down to average degree 1

MV2 of Munim, Inc., 2026-11-18. Made with AI agents working in MV2's name. **No human
mathematician has checked this note yet.** Text CC BY 4.0; code (`sr_random.py`,
`test_sr_random.py`) Apache-2.0. Exact checks: `python -m unittest test_sr_random -v`.

This is **not** a new Kakeya bound. It proves the program's frame square-root conjecture
SR* for almost every linear part in every density regime with average degree at least 1.
That includes the sparse, large-SCC, poorly expanding regime that a177 left open. It also
replaces a177's Corollary 64.1 with a much sharper, dimension-free tail bound.

## 0. Setting (as in a177)

q is an odd prime power and Y is uniform on F_q^k. For a k x k matrix M over F_q, let
F(y) = y o y + My and H(M) = H(Y | F(Y)) (bits). N_y is the size of the F-fibre through y,
so H(M) = E_y log2 N_y. Put a = (q-1)/q and b = 2^(1-1/q).

    SR*:  H(M) <= k(1 - 1/q),   i.e.   2^H(M) <= b^k.

For P(x) = x o x + Lx + c we have Lambda(P) = q H(L), so SR* for L is the conjecture
C_q(k) for P (a174 Prop 67(a), a177 section 0). For P = A((Sx) o (Sx)) + Lx + c with A, S
invertible, Lambda(P) = sum_t H(M_t) with M_t = A^-1 (L + tI) S^-1 (a174 Cor 58.2).

**Pair count (a174 Thm 58).** For every M,

    E_y N_y = sum_{d} q^-|supp d| [ M[T^c, T] d_T = 0 ],   T = supp d.

Here F(y) = F(y - d) iff d o d = (2 D_y + M) d. For i in T this fixes y_i uniquely. For
i not in T it reads (Md)_i = 0, which involves only off-diagonal entries. **So E_y N_y
does not depend on the diagonal of M**, and neither does H(M).

## 1. The annealed identity (Lemma 141)

**Random model.** The off-diagonal entries M_ij (i != j) are independent. M_ij = 0 with
probability 1 - p_ij, and otherwise it is uniform on F_q^*. The diagonal is arbitrary.
Put lam_ij = 1 - p_ij q/(q-1), which lies in [-1/(q-1), 1].

**Lemma 141.**

    E_M E_y N_y = sum_{T in [k]} a^|T| prod_{i not in T} (1/q)(1 + (q-1) prod_{j in T} lam_ij).

*Proof.* Fix d with support T. For each row i not in T, the terms W_j = M_ij d_j (j in T)
are independent, and each is 0 with probability 1 - p_ij and uniform on F_q^* otherwise,
because d_j != 0. For a nontrivial additive character chi,
E chi(W_j) = 1 - p_ij - p_ij/(q-1) = lam_ij. So by orthogonality,
P(sum_j W_j = 0) = (1/q)(1 + (q-1) prod_j lam_ij). Rows are independent. There are
(q-1)^|T| vectors d with support T, and each carries weight q^-|T|. []

**Homogeneous model R(k, p)** (every p_ij = p, lam = 1 - pq/(q-1)):

    S_q(k, p) := E_M E_y N_y = sum_{t=0}^{k} C(k,t) a^t pi_t^(k-t),   pi_t = (1 + (q-1) lam^t)/q.

At p = 0 (diagonal M) this is (2 - 1/q)^k, the DKSS/Jensen level. For lam >= 0, S is
decreasing in p.

**Markov step.** Jensen gives 2^H(M) <= E_y N_y for every M, so E_M 2^H(M) <= S and

    P_M( H(M) >= s ) <= S * 2^-s   for every s.        (*)

## 2. Dense: a dimension-free tail (Theorem 65)

**Theorem 65.** Let M be uniform over all k x k matrices over F_q (p = (q-1)/q, lam = 0). Then

    E_M E_y N_y = 2 - q^-k   exactly,   so   E_M 2^H(M) < 2   and   P(H(M) >= s) < 2^(1-s).

In particular SR* fails with probability < 2 * 2^-(k(1-1/q)).

*Proof.* pi_0 = 1 and pi_t = 1/q for t >= 1, so
S = 1 + q^-k sum_{t>=1} C(k,t)(q-1)^t = 2 - q^-k. Then apply (*). []

So a uniformly random frame map has H(M) = O(1), with an exponential tail that does not
depend on k. a177's Corollary 64.1 only gave failure probability <= 4x/(1-x) with
x = k q^(-k/8). That is superseded.

**Corollary 65.1 (Kakeya, dense).** Fix invertible A and S, and let L be uniform. Every
slice M_t = A^-1 (L + tI) S^-1 is then uniform. By AM-GM,
2^(Lambda/q) = prod_t (2^H(M_t))^(1/q) <= (1/q) sum_t 2^H(M_t), so

    E_L 2^(Lambda(P)/q) < 2   and   P( Lambda(P) >= s ) < 2^(1 - s/q).

Typical maps of this form have Lambda = O(q), against the conjectured maximum k(q-1).

## 3. Sparse: every density with average degree at least 1 (Theorem 66)

**Theorem 66.** Let q be an odd prime power, k >= 1, and M ~ R(k, p) with pk >= 1 (the
expected number of off-diagonal nonzeros per row is about pk). Then

    P( H(M) >= k(1 - 1/q) ) <= 0.9582^k + 0.9739^k.

*Proof.* **Case lam >= 0** (p <= (q-1)/q). Then pi_t is decreasing in t. Put
t0 = ceil(k/5) and split S at t0:

    S <= sum_{t < t0} C(k,t) a^t  +  sum_{t >= t0} C(k,t) a^t pi_{t0}^(k-t)
      <= sum_{t <= k/5} C(k,t) a^t  +  (a + pi_{t0})^k.

- *Head.* For 0 < z <= 1, sum_{t <= k/5} C(k,t) a^t <= z^(-k/5) (1 + az)^k. With
  z = 1/(4a) (allowed, since a >= 2/3) this is (2^(H2(1/5)) a^(1/5))^k, where
  H2(1/5) = 0.721928...
- *Tail.* a + pi_{t0} = 1 + a lam^t0. Also lam^t0 <= exp(-pq t0/(q-1)) <= exp(-pk/5)
  <= e^(-1/5).

Divide by b^k and use (*) with s = k(1 - 1/q):

    P <= r_A^k + r_B^k,   r_A = 2^(H2(1/5) + log2(a)/5) / b,   r_B = (1 + a e^(-1/5)) / b.

For every odd q < 300, r_A < 0.9582 and r_B < 0.9739 (the maxima are at q = 3:
r_A = 0.95811..., r_B = 0.97381...). For q >= 300, use a <= 1 and b >= 2^(299/300):
then r_A <= 0.827 and r_B <= 0.912.

**Case lam < 0** (p > (q-1)/q). Then |lam| <= 1/(q-1), so pi_t <= 2/q for t >= 1, and
S <= 1 + ((q+1)/q)^k. Since 1/b < 0.63 and (1 + 1/q)/b < 0.8400 for every odd q, the
claimed bound follows. []

**Why this is the open regime.** Take p = c/k with constant c > 1. The digraph of M
(arc i -> j when M_ij != 0) is then the random digraph D(k, c/k). That digraph has a
strongly connected component of linear size with high probability (Karp 1990). So
a174's Corollary 58.1, which needs SCCs of size <= K0(q), does not reach it. Each column
is read by no other row with probability (1-p)^(k-1), about e^-c, so about k e^-c columns
violate a177's half-expansion hypothesis, and Theorem 64 does not apply either. Theorem
66 covers this whole range, and sparser ones too, down to c = 1 for every q.

Numerically the method goes further. The asymptotic exponent max_tau [H(tau) +
tau log2 a + (1 - tau) log2 pi(tau)] stays below 1 - 1/q down to c of about 1/3 at q = 3.
The tests check exactly that S < b^k (so the failure probability is < 1) at p = 1/k for
(q, k) = (3, 30), (3, 40), (3, 60) and (5, 30).

**Corollary 66.1 (Kakeya, sparse).** Let P(x) = A((Sx) o (Sx)) + Lx + c with A, S
invertible diagonal and L ~ R(k, p), pk >= 1. Then each slice M_t = A^-1 (L + tI) S^-1 has
off-diagonal entries (A^-1)_ii L_ij (S^-1)_jj. These are independent with the same
scale-invariant laws, so every slice is again R(k, p) up to its diagonal, which does not
matter. A union bound over the q slices gives

    P( Lambda(P) >= k(q - 1) ) <= q (0.9582^k + 0.9739^k).

(For A = S = I all slices coincide, and the factor q can be dropped.)

## 4. Fixed digraphs: the annealed count is a sum over forts (Proposition 72)

Fix a digraph G on [k] without loops and give its arcs independent uniform *nonzero*
weights. Then p_ij = 1 on arcs (lam = -1/(q-1)) and 0 off arcs (lam = 1), and Lemma 141
reads

    E_w E_y N_y = Phi_q(G) := sum_T a^|T| prod_{i not in T} pi(m_i(T)),
    pi(m) = (1 + (q-1)(-1/(q-1))^m)/q,

where m_i(T) is the number of out-neighbours of i inside T. Here pi(0) = 1, pi(1) = 0 and
0 <= pi(m) <= 1/(q-1) for m >= 2.

**Proposition 72.** A set T contributes to Phi_q(G) only if no vertex outside T has exactly
one out-neighbour in T, that is, only if T is empty or a *fort* in the sense of
zero-forcing theory (Fast and Hicks, 2018). Hence

    E_w 2^H(M_w) <= Phi_q(G) <= sum_{T empty or a fort} a^|T| (q-1)^(-out(T)),

where out(T) counts the vertices outside T that have an out-neighbour in T. If the
right-hand side is below b^k, then a positive fraction of weightings of G satisfy strict
SR*.

This matches a177 from the other side. There, Corollary 139.1 shows that a zero-forcing
set S (a set meeting every fort) gives H(M) <= |S| log2 q for *every* weighting. Here,
for *random* weightings, every non-fort is invisible to the pair count. Forts are
exactly the obstruction in both pictures.

**Proposition 73 (deterministic: expansion is only needed on forts).** Let M be any
k x k matrix with k >= 2, with digraph G(M) (arc i -> j when i != j and M_ij != 0).
Suppose a177's half-rank-expansion inequality

    rho(T) = rank M[T^c, T] >= ceil(min(|T|, k - |T|) / 2)

holds for every nonempty proper fort T of G(M). Then H(M) < k(1 - 1/q), with the same
quantitative bound as a177 Theorem 64.

*Proof.* Take a nonempty T that is not a fort. Some row i outside T then has exactly one
nonzero entry M_ij with j in T, so (Md)_i = M_ij d_j != 0 for every d of support T, and
V(T) = 0 in a174's identity E N = sum_T q^-|T| V(T). Forts get a177's bound
V(T) <= (q-1)^(|T| - rho(T)). The terms for T = empty and T = [k] are 1 and a^k, as in
a177. So a177's chain of inequalities goes through unchanged for k >= 7 (q = 3) and
k >= 5 (q >= 5). For smaller k: if G(M) is not strongly connected, some nonempty proper
T is read by no outside row. That T is a fort with rho(T) = 0, which violates the
hypothesis. So G(M) is strongly connected, and a174 Cor 58.1 applies as in a177. []

This weakens Theorem 64's hypothesis. A set that some outside row reads through exactly
one entry no longer has to expand. For k <= 5 both hypotheses are equivalent to strong
connectivity, because then ceil(min/2) = 1 for every proper T. For k >= 6 the fort
version asks for strictly less on paper. Whether that captures new matrices was not
checked here.

## 5. What this does and does not do

Done:
- The exact annealed pair count for any independent scale-invariant off-diagonal law
  (Lemma 141).
- Dense M: E 2^H(M) < 2 and P(H(M) >= s) < 2^(1-s), dimension-free (Theorem 65). The
  same holds for conjugated frame Kakeya maps with uniform L: P(Lambda >= s) < 2^(1-s/q).
- Sparse M at every density with pk >= 1, for every odd q: SR* fails with probability
  <= 0.9582^k + 0.9739^k (Theorem 66). This covers random digraphs with a giant strong
  component, which a174 and a177 left open.
- For a fixed pattern, an exact fort expansion of the annealed count (Proposition 72).
  Deterministically, a177's expansion hypothesis is only needed on forts (Proposition 73).

Not done:
- **Worst-case** sparse matrices. These results hold for almost every M in each model,
  not for every M. The frame regime that remains is structured. It consists of
  deterministic sparse patterns with many small forts and weightings that are
  atypically degenerate (for example rings of rank-one blocks).
- Other algebras (a173's general unital SR*), and C_q(k) for all maps.

Prior art: the first-moment method and character sums are standard. The giant strong
component of D(n, c/n) for c > 1 is due to Karp (Random Structures & Algorithms, 1990).
Forts are from zero-forcing theory (Fast and Hicks, 2018). SR* and the entropy
functional are MV2's own (notes a159-a177). A search on 2026-11-18 still found no
improvement on Bukh-Chao (Discrete Analysis 2021:26) for the fixed-q Kakeya constant.

## 6. Exact checks (`test_sr_random.py`)

- Lemma 141 by brute force over every matrix, exactly as Fractions: homogeneous at
  (q, k) = (3,2), (3,3), (5,2), (7,2) for six values of p, including p = 0, (q-1)/q and
  1; inhomogeneous random p_ij; a nonzero diagonal.
- Jensen 2^H <= E N as an exact integer inequality for all 729 zero-diagonal 3 x 3
  matrices over F_3.
- Theorem 65: S = 2 - q^-k for q in {3, 5, 7, 11} and k < 40. The uniform averages equal
  2 - 1/27 (q = 3, k = 3) and 2 - 1/q^2 (q = 5, 7, k = 2). The tail bound holds at s = 1, 2.
- Theorem 66: the ratio constants for every odd q < 300, plus the q >= 300 case. The
  exact split inequality, the Chernoff head and lam^t0 <= e^(-1/5) for q in {3, 5, 7},
  k <= 60 and several p with pk >= 1. The lam < 0 case. Exact S^q < 2^(k(q-1)) at
  p = 1/k for (3,30), (3,40), (3,60), (5,30). Monotonicity in p, and S(k,0) = (2-1/q)^k.
- Proposition 72 on four patterns (directed 4-cycle, a 2-out-regular digraph on 4
  vertices and the complete digraph at q = 3, and a 4-arc digraph at q = 5), by brute
  force over every nonzero weighting: brute force = Lemma 141 = Phi_q(G) <= fort bound.
- Proposition 73: V(T) = 0 for every nonempty non-fort T, the rank bound for every T, and
  sum_T V(T) q^-|T| = E N, on 26 random matrices at (3,3), (3,4) and (5,3) with nonzero
  diagonals. Strict SR* for every fort-half-expanding zero-diagonal 3 x 3 matrix over F_3
  (exhaustive). A set read by no outside row is a fort with rho = 0, so the hypothesis
  fails there (exhaustive at (3,3)).
