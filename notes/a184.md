## Summary

The selection game of a182/a183 bounds sticky Kakeya sets in F_3^n: |K| >= f(n) - 1, where f(h) is
the least possible largest coordinate of a game vector at height h. Theorem 72 (a183) gives
f(h) >= 1.90499^h, and Conjecture S2 says f(h) = 2^h. This note proves four facts about the game.

1. **Lemma 154 (doubling).** 2 A_h ⊆ A_{h+1}. Hence f(h)/2^h never increases with h. So
   f(H) = 2^H implies f(h) = 2^h for every h <= H.
2. **Proposition 79 (min + max).** For every v in A_h, the vector (min v + max v)(1, 1, 1) lies in
   A_{h+1}. Hence f(h+1) <= min over A_h of (min v + max v), and **Conjecture S2 is equivalent to
   Conjecture M**: min v + max v >= 2^(h+1) for every v in A_h and every h.
3. **Proposition 80.** The minimal vectors at height 2 are the 19 permutations of (4,4,4),
   (3,5,5), (2,6,6), (1,9,9), (3,3,9) and (3,4,8). From this, f(3) = 8 by hand.
4. **Proposition 81 (finite certificates fail).** A finite set of vectors that is invariant under
   the game at scale beta (definition below) certifies nothing once beta > sqrt(3) = 1.732.
   Computer certificates for a base near 2 therefore need infinite families, such as
   potentials in log space.

Item 2 corrects the pre-registration of job sticky-front-v1. It says "a failure of M alone decides
nothing about S". In fact, a failure of M at height h refutes S2, because then f(h+1) < 2^(h+1)
(Proposition 78(d)). The job's rules stay as they were. Under its own S-BREAK rule, such a failure
also appears as f(h+1) < 2^(h+1) whenever h + 1 <= 9.

## 1. The game (recalled)

Vectors L in Z^3 are indexed by slices t in F_3. A leaf is (1, 1, 1). An affine node with constant
slice s has L_s = max_x L_s(x) and L_t = sum_x L_t(x) for t != s. A triangle node with bijection
iso has L_t = L_t(iso(t)) + max over x != iso(t) of L_t(x). A_h is the set of vectors reachable at
height h. It is closed under permuting slices (Proposition 78(a)). f(h) = min over A_h of max_t L_t.

## 2. Lemma 154 and Proposition 79

**Lemma 154.** If v ∈ A_h, then 2v ∈ A_{h+1}. *Proof.* A triangle over three copies of v gives
v_t + max(v_t, v_t) = 2v_t. ∎

So f(h+1) <= 2 f(h), and the normalised sets A_h / 2^h increase with h. Conjecture S2 holds iff
f(h) = 2^h for every h, and it fails iff f(h) < 2^h for some h (Proposition 78(d)).

**Proposition 79.** Let v ∈ A_h have values m <= mid <= M. Then (m + M)(1, 1, 1) ∈ A_{h+1}.

*Proof.* For x ∈ F_3, let child x be the relabelling of v that carries m at slot x, mid at slot
x + 1 and M at slot x + 2. Take a triangle with iso = identity. In slice t, the isolated child t has
value m. The other two children, t + 1 and t + 2, have values M and mid there. So
L_t = m + max(M, mid) = m + M. ∎

**Corollary.** f(h+1) <= min over A_h of (m + M). If S2 holds, then m + M >= f(h+1) = 2^(h+1)
on A_h, which is Conjecture M. Conversely, M gives max v >= (m + M)/2 >= 2^h. Hence S2 ⟺ M.

The two conjectures are therefore one, and its tight cases are visible. At heights 1 and 2, the
vectors with m + M = 2^(h+1) are exactly (1,3,3) and (2,2,2) at height 1, and (2,6,6), (3,5,5) and
(4,4,4) at height 2. After normalising by 2^h, all of them lie on the line (a, 2 - a, 2 - a). A
triangle with children (a, b, b), (1,1,1) and (1,1,1) maps this line into itself.

## 3. Proposition 80: the height-2 front and f(3) = 8

**Proposition 80.** (a) The minimal vectors of A_2 are the 19 permutations of (4,4,4), (3,5,5),
(2,6,6), (1,9,9), (3,3,9) and (3,4,8). (b) f(3) = 8.

*Proof of (a), sketch.* The minimal vectors of A_1 are (2,2,2) and the permutations of (1,3,3).
Sort the candidates by their smallest coordinate, placed at slot 0 by symmetry. A 1 there needs an
affine node with s = 0 over three copies of (1,3,3), giving (1,9,9). A 2 needs s = 0 with children in
{(2,2,2), (1,3,3)}, including at least one (2,2,2), or a triangle over three copies of (1,3,3). The
best result is (2,6,6). A 3 arises from an affine node with s = 0, which gives (3,3,9), (3,4,8) and
also (3,5,7) and (3,6,6), the last two dominated by (3,5,5) and (2,6,6). It also arises from an
affine node with s != 0 over three copies of (1,3,3), giving (3,3,9), or from a triangle. A triangle
with L_0 = 3 forces L_1, L_2 >= 5, and (3,5,5) is reached. Everything with all coordinates >= 4 is
dominated by (4,4,4) = triangle(2,2,2). The code recomputes the front exhaustively and the tests
compare it with this list.

*Proof of (b).* Triangles give (8,8,8). Suppose a height-3 vector has every coordinate <= 7. It is
enough to take children from the list in (a), because every node is monotone.
- *Affine root.* Its two summed slices total <= 14. But every vector in (a) has each pair of
  coordinates summing to >= 6, so three children give >= 18.
- *Triangle root* (relabel so iso = identity). L_x = c_x[x] + max_{y != x} c_y[x] <= 7, and
  every coordinate is >= 1. So every coordinate of every child is <= 6, isolated or not. This
  rules out (1,9,9), (3,3,9) and (3,4,8) and leaves (4,4,4), (3,5,5) and (2,6,6).
  Every isolated value is >= 2, so non-isolated values are <= 5. This removes (2,6,6) in both of
  its placements. Now every isolated value is >= 3, so non-isolated values are <= 4. This removes
  both placements of (3,5,5). It also removes (4,4,4), whose isolated value 4 forces the others
  to be <= 3. No triangle remains. ∎

So S2 holds up to height 3 (and, by Lemma 154, the check at any height H covers all heights
below it). Theorem 72 only gave f(3) >= 1.90499^3 = 6.91.

## 4. Proposition 81: finite certificates cannot pass sqrt(3)

A natural computer route to a better lower bound is a **finite up-set certificate**. It is a
finite set F of nonnegative vectors and a beta > 1 with
(i) some g ∈ F has g <= (1,1,1), and
(ii) for every node type and g_0, g_1, g_2 ∈ F, the parent is >= beta g' for some g' ∈ F.
Since every node is monotone and 1-homogeneous, induction gives: every v ∈ A_h is >= beta^h g for
some g ∈ F. Hence f(h) >= c beta^h with c = min over F of max g.

**Proposition 81.** If beta > sqrt(3), every finite certificate contains (0, 0, 0), so c = 0.

*Proof.* The affine chain (1,1,1) -> (1,3,3) -> (1,9,9) -> ... puts (1, 3^h, 3^h) in A_h. So for
every h some g_h ∈ F satisfies g_h <= (beta^(-h), (3/beta)^h, (3/beta)^h). F is finite, so one g
serves infinitely many h, and then g = (0, y, z). Apply (ii) to three copies of g at an affine node
with s = 1. The parent is (0, y, 3z), so F contains some g' with g'_0 = 0, g'_1 <= y/beta and
g'_2 <= 3z/beta. Apply (ii) again at s = 2. The parent is (0, 3g'_1, g'_2), so F contains some
g'' <= (3/beta^2)(0, y, z). Since 3/beta^2 < 1, iterating gives elements of F below
(3/beta^2)^k (0, y, z) for every k. Finiteness then forces (0, 0, 0) ∈ F. ∎

The obstruction is the boundary. Real game vectors never drop below 1, and the vectors
(1, 3^h, 3^h) keep their smallest coordinate exactly at that floor. A scale-invariant finite object
cannot see the floor. The a183 potential escapes because it is an infinite family: its level set
{v_max^(1-2c) (v_mid v_min)^(1+c) >= 1} has no zero coordinates. Any computer search for a base
near 2 should therefore look for potentials on the two-dimensional space of log-shapes, with exact
linear behaviour at infinity. Grids of vectors will not work.

## 5. Status of Conjecture S2

- Proved: f(h) = 2^h for h <= 3; 1.90499^h <= f(h) <= 2^h for all h (a183); S2 ⟺ M (this note).
- Open: f(h) for h >= 4. The pre-registered job sticky-front-v1 computes f(h) and min(m + M)
  exactly for h <= 9. It has not run yet.
- If S2 holds, the exact growth constant of sticky Kakeya sets over F_3 is 2. Their minimum size
  would then be 2^(n + o(n)), while all Kakeya sets reach 1.889882^(n + o(n)) (KLSS).
