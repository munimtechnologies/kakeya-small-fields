## Lemma 72 (the elements of ker phi outside span(u))

**Lemma 72.** Let (sigma, alpha) be anisotropic with t = 6 and dim V = 7, and let u be an element
of rank exactly 3 in (B5). Let w be h_1 or u + h_1, and Q_w = P_w + span(sigma(w)). Then:

(a) Im A_w = A_u P_w, so r_w = dim(P_w + X_1) - 3. In particular r_w <= 3, r_w = 0 if and only if
P_w lies in X_1, and r_w = 3 if and only if P_w + X_1 = X.

(b) dim Q_w >= r_w + 2, equivalently dim(Q_w n X_1) >= 2.

(c) If r_w = 3, then w is an element of rank exactly 3 in (A4), (B4) or (B5). If moreover no
element of rank exactly 3 is in (B4) (Corollary 46 (ii) plus the two pair orbits o001 and o026 of
(B4), which jobs m32 re-runs), then w is in (B5): dim P_w = 5, sigma(w) is not in P_w,
beta(w, .) has kernel exactly W, and Q_w = X.

*Proof.* (a) w lies in ker phi, so (Q) of [a10.md](a10.md) with (a, b, c) = (u, w, h) gives
A_u beta(w, h) + A_w beta(h, u) + A_h beta(u, w) = 0, and beta(u, w) = 0, so A_w phi(h) =
A_u beta(w, h) for every h (this is Lemma 71 (iv) for w; for w = u + h_1 the same proof applies,
since u + h_1 is in ker phi). So A_w P = A_u P_w. Also A_w x0 = 0 (Lemma 69 (a), or (*) with
h = u, h' = w: A_w x0 = (I + A_u) phi(w) = 0). As X = P + span(x0), Im A_w = A_w P = A_u P_w, whose
dimension is dim P_w - dim(P_w n X_1) = dim(P_w + X_1) - 3. The rest follows, as dim X = 6.

(b) w != 0, so Lemma 30 (b) applies to w: dim U+(w) <= 1 + A(6 - r_w - 1) = 6 - r_w, by A(s) = s
for s <= 5 (Theorem 27). U+(w) is the preimage of P_w n span(sigma(w)) under beta(w, .), so
dim U+(w) = (7 - dim P_w) + dim(P_w n span(sigma(w))) = 8 - dim Q_w. Hence dim Q_w >= r_w + 2.
sigma(w) is in X_1 (Lemma 71 (i) for w = h_1; sigma(u + h_1) = x0 + sigma(h_1) + beta(u, h_1) =
x0 + sigma(h_1), also in X_1), so Q_w + X_1 = P_w + X_1 has dimension r_w + 3 by (a), and
dim(Q_w n X_1) = dim Q_w + 3 - (r_w + 3) >= 2.

(c) Corollary 39 ([a10.md](a10.md)) puts every element of rank exactly 3 of an anisotropic system
with t = 6 and dim V = 7 in (A4), (B4) or (B5). Corollary 46 (i) ([a17.md](a17.md)) excludes (A4)
for every such element, not only for u. Under the extra hypothesis, w is in (B5): sigma(w) is not
in P_w and dim P_w = 5, so Q_w = P_w + span(sigma(w)) = X; the kernel of beta(w, .) has dimension
7 - 5 = 2 and contains u and h_1 (beta(w, u) = 0 and beta(w, w) = 0), so it is W. QED

**Remarks.**

- For u itself, Q_u = P + span(x0) = X, so (b) holds trivially; the content is for h_1 and
  u + h_1. The two matrices A_(h_1) and A_u + A_(h_1) both kill span(x0, sigma(h_1)) and map into R
  (Lemma 71 (ii)), so together with A_u they form a pencil of maps from a 4-dimensional quotient
  of X into the 3-dimensional R in which A_u has rank 3. Lemma 72 ties the rank of each member to
  how its own map beta(w, .) meets X_1.
- In the candidates of Lemma 71 for one choice of s, A_(h_1) runs over all maps from
  P / span(s) (dimension 4) to R (dimension 3). By the usual count of matrices of given rank, 1,
  105, 1470 and 2520 of the 4096 have rank 0, 1, 2 and 3. So about 62 percent of the candidates
  have r_(h_1) = 3, where (c) applies in its strongest form.
- (c) is used only for w in W, but its argument applies to every element of rank 3: in a
  counterexample to A(6) = 6, every element of rank exactly 3 is in (B5) once (B4) closes. So a
  class of (B5) found UNSAT excludes rank-3 elements of that type anywhere in the system, not only
  at u. Using that inside a search would need the class of A_w in w's own normal form, which the
  instances do not fix. It is recorded as an idea, not used.

**How it would enter a search.** In an instance of job m35's split, s = sigma(h_1) and
N = A_(h_1) are fixed, and in the normal form phi(h_j) = e_(j-1) for j = 2, ..., 6. So
P_(h_1) = span(beta(h_1, h_j) : j >= 2) and P_(u + h_1) = span(e_(j-1) + beta(h_1, h_j) : j >= 2),
and r_(h_1) = rank N and r_(u + h_1) = rank (A_u + N) are known. If r_w = 3 and (B4) is closed,
(c) says that the six vectors sigma(w), beta(w, h_2), ..., beta(w, h_6) are linearly independent:
63 conditions "this combination is not 0", each the same kind of condition as the anisotropy
clauses the encoding already has. If r_w <= 2, (b) says that these six vectors span at least
r_w + 2 dimensions, which needs a rank encoding and is left out of a first version. Before any such
job, its controls must include an instance that has a model at t = 6 (as in job m35), because a
wrong condition would make instances UNSAT for the wrong reason.

## Review of job m35's code before it runs

`a6_r3n.py` was read against Lemma 71 and `sat_aniso.py` (the copy in the publish file):

- Stabiliser constraints. Entry (row, col) of D is bit 6 row + col. D x0 = 0 gives one mask per row
  over the columns where x0 has a 1. D W in W uses the annihilator of W from `sat_aniso.nullspace`
  (vectors f with f . w = 0 for every w in W) and asks f . (D w) = 0, the mask with bits (row, c)
  for f_row = 1 and w_c = 1. D A_u = A_u D is written entry by entry, (D A_u)(row, col) = sum over
  k of D(row, k) A_u(k, col) and (A_u D)(row, col) = sum over k of A_u(row, k) D(k, col), which is
  what the two inner tests add. g = I + D commutes with A_u if and only if D does, and g P in P with
  g invertible gives g P = P, so the invertible solutions are exactly H_A (and the t = 4 selfcheck
  compares them with the brute-force stabiliser in G).
- Candidates. N is built as Vals times the inverse of the basis matrix (x0, s, a completion inside
  P, a completion of X), with `from_cols` putting vector c in column c, `mat_mul` the usual product
  and `mat_apply` computing N x by rows; so N sends the k-th basis vector to the k-th value. In
  (B5) the completion of X is empty (P + span(x0, s) = X), which gives 8^4 = 4096 per s, as the
  selfcheck expects.
- The action. A pair (s, N) goes to (g s, g N g^(-1)) and is then normalised by
  (s, N) -> (s + x0, N + A_u) when the e_0-coordinate of g s is 1. That is the replacement
  h_1 -> h_1 + u of Lemma 71 (i), and it commutes with H_A because g x0 = x0 and g A_u = A_u g.
- Unit clauses. `encode_r3n` fixes S[1] (sigma of basis vector h_1) bit by bit and A[1][row][col]
  from bit 6 row + col, the same layout as `a6_r3m.encode_r3m` uses for A[0] and as
  `sat_aniso.decode` reads models back. Index 1 is h_1, which lies in ker phi in the normal form
  because d - p = 2.
- The t = 6 controls. 1152 = 2^7 + 2^10 has entries (1, 1) and (1, 4); applied to s = 51 =
  e_0 + e_1 + e_4 + e_5 it gives e_1 + e_1 = 0. Its transpose 33554560 = 2^7 + 2^25 has entries
  (1, 1) and (4, 1) and gives e_1 + e_4, which is not 0, so that instance contradicts
  A_h sigma(h) = 0 and must be UNSAT, as predicted.
- Every function the module calls from `a6_r3`, `a6_r3h`, `a6_r3m`, `m32` and `sat_aniso` exists
  in the copies listed in the publish file, under the name used.

The review cannot replace running the code: this run has no way to execute it, and the selfcheck
and controls of m35 remain the real test.
