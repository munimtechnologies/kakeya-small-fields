## 0. Summary

Fix q, put X uniform on F_q^k, and for a map P : F_q^k -> F_q^k let Y_t = P(X) + tX and
Lambda(P) = sum_{t in F_q} H(X | Y_t) (bits). Conjecture C_q(k) says Lambda(P) <= k(q - 1).
If it holds for every k, then q 2^(-(q-1)/q) is the exact Kakeya growth constant of F_q
(Theorem 2). One counterexample, for any k, would give a new record upper bound for
Kakeya sets over F_q. The classical finite-field Kakeya constructions are quadratic, and
a163 (Theorem 38) settled degree-2 maps for k = 2. This note moves to k = 3.

* **Theorem 39 (splitting inequality; every map, every k).** For every hyperplane U of
  F_q^k:

      Lambda(P) <= E_a Lambda_{k-1}(pi P_a) + q^-k sum_{w not in U} Pi_w.

  The first term is the average loss of the maps induced on the cosets a + U (projected
  onto U). The second counts pairs whose direction leaves U. Unlike Theorem 4, U does
  not have to be respected by P.
* **Proposition 47 (exact pair counts for degree 2, q odd, every k).** For each
  direction w, Pi_w = (q - 1) q^(k - r_w) if w is *active*, and Pi_w = 0 otherwise. Here
  r_w is the rank of x -> beta(x, w) modulo w. So Lambda(P) <= (q - 1) sum_{w active} q^(-r_w).
* **Theorem 40 (k = 3, degree 2, q odd).** Lambda(P) <= 3(q - 1) holds in each of these
  cases:
  (a) P respects a nonzero proper subspace;
  (b) for some plane U, (q - 1)|D \ U| <= |Z0 \ U|, in particular when all *cylinder
      directions* D lie in one plane;
  (c) |D| <= 2q + 1 + |Z0|/(q - 1).
  Here D is the set of directions w with r_w = 1 that are active, and Z0 is the set of
  directions with Pi_w = 0.
* **Corollary 130.** A degree-2 counterexample to C_q(3) (q odd) respects no nonzero
  proper subspace and has at least 2q + 2 cylinder directions, not all in one plane.
  By Proposition 48, for q >= 5 its *cylinder locus*, a plane curve of degree <= 3, must
  then contain two F_q-rational lines, or a rational line and a rational conic, or be
  the whole plane.

So C_q(3) holds for every degree-2 map with q odd, outside an explicit thin algebraic
family. A cylinder direction w is one along which one linear functional of P is constant
(Lemma 115). The remaining case is where a counterexample would have to hide. It is the
next target, together with the pre-registered search `survey3.py`.

## 1. Theorem 39: the splitting inequality

Let U be a hyperplane, A = X mod U in F_q^k / U (q values), and pi : F_q^k -> U a linear
projection that fixes U (along any c not in U). For a coset representative x_a, let
P_a(v) = P(x_a + v) for v in U.

**Theorem 39.** For every map P of F_q^k (k >= 2) and every hyperplane U,

    Lambda_k(P) <= E_a Lambda_{k-1}(pi o P_a) + q^-k sum_{w in PG(k-1,q), w not in U} Pi_w,

where Pi_w = #{(x, lam) : lam != 0, P(x + lam w) - P(x) in F_q w} and Lambda_{k-1} is the
loss of a map U -> U (U identified with F_q^(k-1) by any basis).

*Proof.* By the chain rule, H(X | Y_t) = H(A | Y_t) + H(X | A, Y_t).

*In-plane term.* Given A = a, X = x_a + V with V uniform on U. Since pi(Y_t) is a function
of Y_t, H(X | A = a, Y_t) <= H(V | pi(Y_t)), and pi(Y_t) = pi P_a(V) + tV + (constant).
Summing over t gives at most Lambda_{k-1}(pi o P_a). Averaging over a gives the first term.

*Cross term.* Fix t and a fibre F of Y_t. Let it meet n distinct cosets of U, with
m_1, ..., m_n points (sum M = |F|). Then H(A | Y_t = y) <= log2 n <= n - 1. Also
M(n - 1) = sum_i sum_{j != i} m_i <= sum_i sum_{j != i} m_i m_j, which is the number of
ordered pairs in F lying in different cosets. Hence

    H(A | Y_t) <= q^-k #{(x, x') : x' != x in the same fibre of Y_t, x' - x not in U}.

An ordered pair x != x' lies in a common fibre of Y_t for at most one t, namely when
P(x') - P(x) = -t(x' - x). Summing over t, the right side becomes q^-k times the number
of partner pairs whose direction is outside U, that is q^-k sum_{w not in U} Pi_w. QED

Remarks. (i) If U is respected by P, the cross term can be replaced by the loss of the
quotient map (Theorem 4). Theorem 39 needs no such structure. (ii) For k = 2 and U = a
line, Theorem 39 with C_q(1) gives Lambda <= (q - 1) + q^-2 sum_{w != U} Pi_w. For
degree-2 maps without a full direction and q odd, Lemma 114 (Pi_w <= q(q - 1)) then
gives Case (A) of Theorem 38 again, with bound 2(q - 1).

## 2. Proposition 47: exact pair counts for degree-2 maps

Let q be odd and P(x) = Q(x) + Lx + c, with Q a vector-valued quadratic form,
beta(x, y) = Q(x + y) - Q(x) - Q(y) its polar form, and L linear. For a direction w
(a fixed representative), write bar for reduction modulo F_q w. Define
B_w : x -> bar beta(x, w), a linear map F_q^k -> F_q^k / F_q w of rank r_w. Call w
**active** if bar(Lw) lies in Im B_w.

**Proposition 47.** Pi_w = (q - 1) q^(k - r_w) if w is active, and Pi_w = 0 otherwise.
In particular, w is a full direction (P respects F_q w) iff w is active with r_w = 0, and

    q^k Lambda(P) <= sum_w Pi_w = (q - 1) q^k sum_{w active} q^(-r_w).

*Proof.* P(x + lam w) - P(x) = lam^2 Q(w) + lam (beta(x, w) + Lw). For lam != 0, this
lies in F_q w iff alpha(x) = -lam c_w, where alpha(x) = B_w x + bar(Lw) and
c_w = bar Q(w). Since beta(w, w) = 2Q(w) and q is odd, c_w = B_w(w)/2 lies in Im B_w. If
w is not active, alpha(x) is never in Im B_w, so Pi_w = 0. If w is active, alpha maps
F_q^k onto Im B_w with fibres of size q^(k - r_w). For c_w != 0, each lam != 0 has
q^(k - r_w) solutions x. For c_w = 0, the condition is alpha(x) = 0, with q^(k - r_w)
solutions for every lam. Either way Pi_w = (q - 1) q^(k - r_w). The inequality is
Lemma 112: q^k Lambda = sum_x sum_t log2 z_t(x) <= sum_x sum_t (z_t(x) - 1), and every
partner of x is counted at exactly one t. QED

For k = 3 every direction has one of: r_w = 2 (always active, Pi_w = (q - 1)q);
r_w = 1 active (Pi_w = (q - 1)q^2, a **cylinder direction**); Pi_w = 0 (set Z0); or
r_w = 0 active (a full direction).

**Lemma 115 (cylinder directions).** For k = 3, q odd and degree <= 2, w is a cylinder
direction or a full direction iff there is a nonzero linear functional phi with
phi(w) = 0 such that phi o P is constant along every line in direction w. If P respects
no nonzero proper subspace, this phi is unique up to scale for each cylinder direction,
and different cylinder directions have different phi.

*Proof.* phi(P(x + lam w) - P(x)) = lam^2 phi(Q(w)) + lam phi(beta(x, w) + Lw). This
vanishes for all x and lam iff phi kills Im(x -> beta(x, w)), Lw and Q(w) = beta(w, w)/2.
Equivalently, the plane ker phi contains w, Im B_w (lifted) and Lw, which says
dim(Im M_w + F_q w + F_q Lw) <= 2. That is "r_w <= 1 and active" when r_w = 1, and is
automatic when r_w = 0. If two independent directions w, w' had the same phi, then phi o P
would be invariant under translation by span(w, w') = ker phi. Then
P(x + v) - P(x) lies in ker phi for every v in ker phi, so P respects ker phi. QED

## 3. Theorem 40: dimension 3

**Theorem 40.** Let q be odd and P : F_q^3 -> F_q^3 of degree <= 2. Then
Lambda(P) <= 3(q - 1) in each of the cases (a), (b), (c) of Section 0.

*Proof.* (a) Let P respect V, with dim V = 1 or 2. By Theorem 4 (chain rule through the
quotient; the proof in a163, Section 3, works for any subspace V),
Lambda(P) <= Lambda(tilde P) + E_a Lambda(f_a). Here tilde P is the induced map on
F_q^3 / V and f_a : V -> V are the coset maps, all of degree <= 2. Of dimensions 1 and 2,
they obey C_q(1) and Theorem 38. So Lambda <= (3 - dim V)(q - 1) + dim V (q - 1).

Now assume P respects no nonzero proper subspace. Then there is no full direction, and
by Proposition 47 every Pi_w is 0, (q - 1)q, or (q - 1)q^2 (the last exactly for w in D).

(b) Apply Theorem 39 with the plane U. The coset maps pi o P_a have degree <= 2, so
E_a Lambda_2 <= 2(q - 1) by Theorem 38. Among the q^2 directions outside U, |D \ U| have
Pi_w = (q - 1)q^2, |Z0 \ U| have Pi_w = 0, and the rest have (q - 1)q. So

    q^-3 sum_{w not in U} Pi_w = (q - 1) q^-2 [q^2 + (q - 1)|D \ U| - |Z0 \ U|] <= q - 1.

(c) By Proposition 47 over all q^2 + q + 1 directions,
q^3 Lambda <= (q - 1)[q^2 |D| + q (q^2 + q + 1 - |D| - |Z0|)]. This is <= 3(q - 1)q^3 iff
(q - 1)|D| <= (2q + 1)(q - 1) + |Z0|. QED

**Corollary 130.** If a degree-2 map P of F_q^3 (q odd) has Lambda(P) > 3(q - 1), then
P respects no nonzero proper subspace, |D| >= 2q + 2, and D is not contained in any
plane (indeed (q - 1)|D \ U| > |Z0 \ U| for every plane U).

**Proposition 48 (where the residual case lives, q >= 5).** Let Z be the set of
directions w over the algebraic closure with rank [M_w | w | Lw] <= 2, where M_w is the
3x3 matrix of x -> beta(x, w). Then Z is cut out by the ten 3x3 minors, which are cubic
forms in w, and D lies in the F_q-points of Z (Lemma 115). If |D| >= 2q + 2, then Z
contains two F_q-rational lines, or a rational line and an absolutely irreducible
rational conic, or Z is the whole plane (all minors vanish identically).

*Proof.* Assume the minors are not all zero, and let g be their gcd, of degree d <= 3. g is
defined over F_q. Write each minor as g h_i. The h_i have no common factor, so two
F_q-bar-combinations of them have no common factor either: avoid the finitely many
components of one fixed nonzero h_i, using that F_q-bar is infinite. By Bezout,
V(h_1, ..., h_10) has at most (3 - d)^2 points. So |D| <= #V(g)(F_q) + (3 - d)^2.
d = 0: |D| <= 9 < 2q + 2. d = 1: |D| <= q + 5 < 2q + 2. d = 2: a smooth conic, a double
line or a conjugate pair gives at most q + 2. Only two rational lines reach 2q + 2. d = 3:
an absolutely irreducible cubic has at most q + 1 + 2 sqrt(q) < 2q + 2 rational points
(Hasse-Weil, smooth case), or at most q + 2 if singular. Three conjugate lines have at
most one rational point. A line and a conjugate pair have at most q + 2. A double line
and a line have at most 2q + 1. So |D| >= 2q + 2 forces two rational lines (possibly
with a third component), or a rational line plus an absolutely irreducible rational
conic. QED

(For q = 3 the finite part, up to 9 points, can exceed 2q + 1 = 7, so q = 3 needs a
separate argument.)

## 4. Examples: cylinder directions can fill a line of PG(2, q)

* **Type (b).** P(x) = psi(x) e1 + (0, x1 x2, x1 x3) + Lx with
  L = [[*, *, *], [*, lam, 0], [*, 0, lam]], for any quadratic psi. For w = (0, w2, w3),
  P(x + mu w) - P(x) = mu x1 w + (psi(x + mu w) - psi(x)) e1 + mu Lw, which lies in
  span(w, e1). So the whole line {w1 = 0} lies in Z: q + 1 directions. (A hand
  derivation, not written out here, suggests this is the general shape of a pencil of
  degenerate conics phi o Q whose moving vertices are all cylinder directions. It is
  not used anywhere.)
* **Veronese.** Q(x) = (x1^2, x1 x2, x2^2) and L = [[a, 2b, 0], [c, d, b], [0, 2c, e]] with
  a - 2d + e = 0. Then every direction (1, s, s^2) lies in Z: a conic of q + 1 directions,
  including (0, 0, 1). (Check: Im M_w + F_q w is spanned by (2, s, 0) and (0, 1, 2s), with
  normal (s^2, -2s, 1), and (s^2, -2s, 1) . L(1, s, s^2) = (a - 2d + e) s^2.)

If Z is one such line or conic plus finitely many points, the proof of Proposition 48
gives |D| <= q + 5. That is below the 2q + 2 of Corollary 130 for q >= 5, so the example
is not a counterexample. A counterexample would have to combine two such structures and
still respect no subspace. For q = 3, 5, 7 the tests below check Theorem 40 on these
families and print how often each case occurs.

## 5. Prior art

* The entropy formulation, Theorem 2 (equivalence with the Kakeya growth constant),
  Theorem 4 and Theorem 38 are this project's (README, notes a159-a163).
* Bukh and Chao (Discrete Analysis 2021:26, arXiv:2108.00074) prove that Kakeya sets in
  F_q^n have size at least q^n / (2 - 1/q)^(n-1). In our language, the gap between their
  constant q/(2 - 1/q) and q 2^(-(q-1)/q) is the gap this program is trying to close.
* Classical constructions (Mockenhaupt-Tao; Dvir; Saraf-Sudan; Kopparty-Lev-Saraf-Sudan)
  are quadratic. Georgiev, Gomez-Serrano, Tao and Wagner (arXiv:2511.02864) improved the
  lower-order terms in the fixed-dimension regime.
* A web search (2026-11-17) found no treatment of the Shannon block problem outside this
  repository. Splitting a Kakeya-type entropy along a hyperplane that the map does not
  respect, with the cross term bounded by pair counts, appears to be new.

## 6. Verification (code in this commit)

`quad3.py` (standard library, prime q) computes Lambda exactly as the integer
prod_t prod_F |F|^|F|, every Pi_w by brute force, the ranks r_w and activity from the
polar form, invariant lines and planes, the Theorem 39 terms for any plane, and the case
of Theorem 40. `test_quad3.py` asserts only proved facts:

* For arbitrary maps (any degree; q = 3 with all 13 planes, q = 5 with 8 random planes):
  the pair bound and Theorem 39.
* For degree-2 maps (random maps for q = 3, 5, 7; maps respecting a flag, in random
  bases; the type (b) and Veronese families): Theorem 39, Theorem 38 on every coset map,
  Proposition 47 exactly for every direction, "full = active of rank 0", the trichotomy
  of Pi_w, and Lambda <= 3(q - 1) whenever case (a), (b) or (c) applies. Frame products
  in random bases give exactly 3(q - 1).
* The type (b) and Veronese families put their stated directions on Z.

`survey3.py` is the pre-registered search (predictions S1-S4 in its header). Its
"wow" outcome would be a degree-2 map of F_5^3 or F_7^3 with Lambda > 3(q - 1), which would
be a new record Kakeya block. It needs a compute host and has not been run.
