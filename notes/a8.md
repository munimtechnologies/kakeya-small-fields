## What changes

- **Lemma 60.** In the tight Case B, let n != 0 in U+ have A_n = 0. Then beta(n, V) lies in ker A_u,
  every element of U+(n) acts on C = span(sigma(n)) + beta(n, V) as a scalar, and if C contains
  x0 = sigma(u), then **Im A_u meets ker A_u only in 0**. Lemma 59 of a7.md is the case t = 7,
  rank 3.
- **Corollary 35.** In shape (c) such an n never has x0 in C. With the known bounds on A and M this
  rules out zero maps in U+ at t = 6 (rank 3 and rank 4) and at t = 8 (rank 4).
- **Proposition 28 (rank 4 at t = 8).** In an anisotropic system with t = 8 and dim V = 11, an element
  of rank 4 is in Case B. It is in shape (c) unless A(6) = 7. In shape (c), dim(ker A_u n Im A_u) >= 3
  and n -> A_n is one-to-one on U+.
- **Corollary 36 and job m23 (rank 4 at t = 6).** In a system with t = 6 and dim V = 7, Case B at
  rank 4 comes down to 32 similarity classes of a 4 x 4 matrix (the classes of 0 and I are ruled out
  by hand). Job m23 searches them.
- The last section lists what A(6) = 6 and A(8) <= 10 still need. Both need a new idea for rank 3,
  where the bound of Lemma 30 is not tight.

## Setting

As in [a7.md](a7.md): X = F_2^t, sigma : V -> X quadratic with polar form beta, h -> A_h linear, and

    A_(h') sigma(h) = (I + A_h) beta(h, h')                                    (*)
    A_(h') beta(h_1, h_2) = A_(h_1) beta(h_2, h') + A_(h_2) beta(h_1, h').      (Q)
    A_h x0 = (I + A_u) phi(h)      for all h                                   (1)

Throughout, the system is anisotropic with dim V = t + k - 1, u has rank rho = t - k with
1 <= rho <= t - 2, A(s) = s for s <= k - 1, and u is in Case B (Proposition 26 of
[tight-cases.md](tight-cases.md)): P = phi(V) is a hyperplane that does not contain x0 = sigma(u),
and N = U+ = ker phi has dimension k. Put X_1 = ker A_u (dimension k), R = Im A_u (dimension rho),
d = dim(X_1 n R) and Fix(A_u) = {x : A_u x = x}. For n in N put z = sigma(n),
U+(n) = {h : beta(n, h) in span(z)}, C = span(z) + beta(n, V) and c = dim C - 1. Step 2 of the proof
of Lemma 57, which uses nothing about t or k, gives codim U+(n) = c, so

    dim U+(n) = t + k - 1 - c.                                                  (2)

## Lemma 60 (an element of U+ with zero map)

**Lemma 60.** In the setting above, let n != 0 in N have A_n = 0. Then:

(a) A_h z = beta(n, h) for every h, and C lies in X_1; so c <= k - 1;

(b) for h in U+(n), with beta(n, h) = e z (e in F_2), A_h acts on C as e times the identity;

(c) if x0 lies in C, then C = X_1 and d = 0, that is, Im A_u n ker A_u = 0.

*Proof.* (a) (*) with h -> n and h' -> h gives A_h z = (I + A_n) beta(n, h) = beta(n, h). z lies in
X_1 (Proposition 26(e)), and by (4) of [case-b-shapes.md](case-b-shapes.md),
A_u beta(n, h) = A_n phi(h) = 0.

(b) A_h z = beta(n, h) = e z. For every g, (Q) with h_1 = n, h_2 = g and h' = h gives
A_h beta(n, g) = A_n beta(g, h) + A_g beta(n, h) = e A_g z = e beta(n, g).

(c) Let h be in U+(n). By (b) and (1), (I + A_u) phi(h) = A_h x0 = e x0. Let F be the set of y with
(I + A_u) y in span(x0). As (I + A_u) x0 = x0, F = Fix(A_u) + span(x0), and x0 is not in Fix(A_u)
(A_u x0 = 0), so dim F = dim Fix(A_u) + 1. So phi maps U+(n) into F n P, and as F contains x0 and P
does not, dim(F n P) <= dim Fix(A_u). A fixed vector y = A_u y lies in R and is not in X_1 unless it
is 0, so Fix(A_u) meets X_1 n R only in 0, and dim Fix(A_u) <= rho - d. The kernel of phi on U+(n)
lies in N, of dimension k. By (2),

    t + k - 1 - c = dim U+(n) <= k + rho - d = t - d,

that is, c >= k - 1 + d. With c <= k - 1 from (a), d = 0 and c = k - 1, so C = X_1. QED

In Lemma 59 (t = 7, rank 3) Lemma 58(a) gives C = X_1, which contains x0, while Corollary 31 gives
d = 3. So Lemma 59 is a case of Lemma 60(c); its proof is the argument above with A_u^2 = 0, where
Fix(A_u) = 0.

## Corollary 35 (zero maps in shape (c))

**Corollary 35.** Suppose moreover that A(s) = s for s <= k and that u is in shape (c) (beta = 0 on N).
Let n != 0 in N have A_n = 0. Then x0 is not in C, so c <= k - 2, and U+(n) / span(n) carries an
anisotropic system of dimension t + k - 2 - c with values in a space of dimension t - 1, in which a
subspace of dimension c is invariant. In particular no such n exists in the following three cases:

(a) t = 6, rank 3 (k = 3), dim V = 8;

(b) t = 6, rank 4 (k = 2), dim V = 7;

(c) t = 8, rank 4 (k = 4), dim V = 11.

*Proof.* Proposition 27(c4) of [case-b.md](case-b.md) gives d >= k - 1 >= 1, so by Lemma 60(c) x0 is
not in C, and as C lies in X_1 (Lemma 60(a)), C != X_1 and c <= k - 2. The system is the one of
Steps 4 and 5 of the proof of Lemma 57, which use only A_n = 0 and A_h z = beta(n, h): C / span(z) is
invariant under the maps of U+(n), and dividing by span(z) and factoring out n gives the system on
U+(n) / span(n), of dimension (t + k - 1 - c) - 1, with values in X / span(z). Then, with Lemma 27(c)
for c >= 1:

    (a) dimension 7 - c in F_2^5, c <= 1:   7 <= A(5) <= 6,   6 <= M(4) + A(1) = 5;
    (b) dimension 6 in F_2^5, c = 0:        6 <= A(5) = 5;
    (c) dimension 10 - c in F_2^7, c <= 2:  10 <= A(7) <= 9,  9 <= M(6) + A(1) <= 8,  8 <= M(5) + A(2) = 7.

Each is false. QED

Case (a) uses only Proposition 24 (A(5) <= 6) and Theorem 26; case (b) uses Theorem 27 (A(5) = 5);
case (c) uses Theorems 27, 28 and 29. In the matrices M_n of Lemma 38 (A_n = T M_n T^(-1) A_u for n
in N), Corollary 35 says that n -> M_n is one-to-one on N. At t = 7 Schur's bound forced the
opposite, which is how Theorem 29 was proved. At t = 8 and rank 4 the M_n are 4 x 4, Schur's bound is
floor(4^2 / 4) + 1 = 5 > 4 = dim N, and nothing forces a zero.

Case (a) is already contained in Theorem 28 (no system with t = 6 and dim V = 8 exists). It is a
hand-proved constraint that the searches m18 and m19 did not use.

## Proposition 28 (rank 4 at t = 8)

**Proposition 28.** Let an anisotropic system with t = 8 and dim V = 11 have an element u of rank 4.
Then u is in Case B, and one of the following holds:

(i) u is in shape (c), dim(X_1 n R) >= 3, and A_n != 0 for every n != 0 in N;

(ii) A(6) = 7, and some n != 0 in N has sigma(n) in Z_N = span beta(N, N), rank A_n = 1,
     beta(n, V) + span(sigma(n)) = R and dim U+(n) = 8 = 1 + A(6).

*Proof.* Here k = 4 and dim V = t + k - 1. Proposition 26 applies (A(s) = s for s <= 3), and Case A
needs 2 rho >= t + 1 = 9, so u is in Case B. Proposition 27 applies too (A(s) = s for s <= 4,
Theorem 26).

Let n != 0 in N have z = sigma(n) in Z_N, and let s = rank A_n. Step 1 of the proof of Lemma 57
((Z) of case-b-shapes.md and Proposition 26(e)) puts C inside R, of dimension 4, so c <= 3, and by
(2) dim U+(n) = 11 - c >= 8. Lemma 30 for n gives dim U+(n) <= 1 + A(7 - s).

- If s >= 2: dim U+(n) <= 1 + A(5) = 6 < 8.
- If s = 1: dim U+(n) <= 1 + A(6) <= 8 (Theorem 28). So c = 3, C = R (both have dimension 4), and
  A(6) >= 7, so A(6) = 7: this is (ii).
- If s = 0: by Lemma 60(a), C lies in X_1 n R. If c <= 2, Steps 4 to 6 of the proof of Lemma 57 give
  a system of dimension 10 - c with values in F_2^7 and an invariant subspace of dimension c, and
  10 <= A(7) <= 9, 9 <= M(6) + A(1) <= 8 and 8 <= M(5) + A(2) = 7 are false, as in Corollary 35(c).
  If c = 3, C has dimension 4 = dim X_1 = dim R, so C = X_1 = R, which contains x0; Lemma 60(c) gives
  X_1 n R = 0, but X_1 n R = X_1. Contradiction.

So if (ii) fails, no n != 0 in N has sigma(n) in Z_N. Then beta = 0 on N, by the argument of
Corollary 31 (sigma maps N into X_1, both have 16 elements, and Z_N lies in X_1): if sigma is not
one-to-one on N, some n != 0 has sigma(n) = beta(a, b) in Z_N; if it is, it maps N onto X_1, which
contains Z_N. So u is in shape (c), Proposition 27(c4) gives d >= k - 1 = 3, and Corollary 35(c)
gives A_n != 0 for n != 0. This is (i). QED

Proposition 28 uses Theorems 27 and 28, which rest on SAT answers without proof certificates (jobs
m13, m18 and m19), and Theorem 29. In case (i) we have no contradiction: Proposition 27(c4) allows
R != X_1 (d = 3), and the M_n need not have a zero. Case (ii) disappears if A(6) = 6.

## Corollary 36 (rank 4 at t = 6) and job m23

**Corollary 36.** Let an anisotropic system with t = 6 and dim V = 7 have an element u of rank 4. Then
k = 2 and dim V = t + k - 1, so u is in Case A or Case B (Proposition 26). In Case B, u is in shape (c)
(Proposition 27(c), as k = 2), and the system can be put in the normal form of shape (c) (Lemmas 35,
37 and 39) with M = M_v any chosen matrix of its similarity class in M_4(F_2), where M is neither 0
nor I.

*Proof.* As in Corollary 24(a) of [case-a.md](case-a.md): N = span(u, v), and Lemma 39 moves M_v
anywhere in its similarity class. If M = 0, then A_v = T M T^(-1) A_u = 0; if M = I, then A_v = A_u
and A_(u + v) = 0. Either contradicts Corollary 35(b). QED

The remark after Corollary 24 of case-a.md said that ruling out M = 0 and M = I at t = 6 would need
M(5) = 5; Theorem 27 now gives it (Corollary 35(b) uses A(5) = 5 in the same place).

There are 34 similarity classes of 4 x 4 matrices over F_2 (the sum over the partitions of 4 of
2^(number of parts): 2 + 4 + 4 + 8 + 16), so Case B at rank 4 and t = 6 comes down to 32 CNFs of
`shape_c.py` at (t, k) = (6, 2). Job m23 (`cube_groups/a6_r4.py`) runs them, 5 minutes each and 160
minutes in all, after the controls (3, 2) and (4, 2). Its predictions were written down before it
was queued (m23/predictions.md): the selfcheck and the controls are graded; the 32 classes are
exploratory. Job m13 decided the 12 classes at (5, 2) in 8 to 127 seconds each, and (6, 2) is
larger, so we expect some to time out. UNSAT for all 32 would show that no system with t = 6 and
dim V = 7 has an element of rank 4 in Case B. A verified SAT answer would be an anisotropic system
with t = 6 and dim V = 7, so A(6) = 7, and we would publish it.

## What A(6) = 6 and A(8) <= 10 still need

- **A(6) = 6.** A system with t = 6 and dim V = 7 is irreducible (the reducible bound
  max over d of M(6 - d) + A(d) is 6). Its non-zero elements have rank at most 4 (rank 5 gives
  dim V <= 6 + A(0) = 6 by Lemma 30), and not all have rank <= 2 (Lemmas 28 and 29). Rank 4 is
  tight (6 + A(1) = 7): Case A is possible there (2 x 4 >= 7) and untouched, and Case B is job m23.
  Rank 3 is not tight (6 + A(2) = 8), and even the bound of Question R, t + A(k - 2) = 6 + A(1) = 7,
  would not exclude it. This needs a new idea.
- **A(8) <= 10**, which would settle (11, 2). A system with t = 8 and dim V = 11 is irreducible (the
  reducible bound is 10, as in Step 1 of the proof of Theorem 30, which `a7_bounds.py` checks). Its
  non-zero elements have rank at most 4 (rank 5 gives 8 + A(2) = 10), and some element has rank 3 or
  4. Rank 4 is Proposition 28: case (i) is open, and so is case (ii) unless A(6) = 6. Rank 3 is not
  tight (8 + A(4) = 12, ruled out by Theorem 30), and Question R would give only 8 + A(3) = 11. So an
  element of rank 3 at dim V = 11 is beyond every tool in these notes.

So the next pairs, (11, 2) and (11, 3), need bounds of a new kind: for elements whose Lemma 30 bound
has slack 1.

## Computation

`cube_groups/a6_r4.py` (job m23) runs the 32 classes through `shape_c.solve_one`, unchanged; the CNF
does not encode Lemma 60 or Corollary 35. Its selfcheck counts the 34 classes and checks
orbit-stabiliser with |GL_4(F_2)| = 20,160 and that the two classes left out are the singletons 0
and I. Its unit tests (which gated this commit) check the classes kept and left out, that the
instance names agree with `shape_c.py`, the controls, and the grader on made-up results. Lemma 60,
Corollaries 35 and 36 and Proposition 28 are proofs by hand with no computer check of their own.
