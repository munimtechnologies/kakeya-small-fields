## Where this sits

The goal of this repository is the exact Kakeya growth constant of F_q. Write X for a uniform
point of F_q^k, Y_t = P(X) + tX, and Lambda(P) = sum_t H(X | Y_t) (bits). The block conjecture
C_q(k) says Lambda(P) <= k(q - 1) for every map P of F_q^k. By Theorem 2, C_q(k) for all k is
equivalent to beta_q = q 2^(-(q-1)/q) being the exact growth constant. For q = 3 that would mean
1.890, against the best known lower bound of 1.800 (Bukh-Chao, arXiv:2108.00074).

Theorem 35 (a159) gave the chain bound

    CB(l, v) = Lambda_l(P) + (1/q) sum_a Lambda(Q_a),    Q_a(w) = pi_v(P(a v + w)) on ker l,

with Lambda(P) <= CB(l, v). Theorem 36 (a160) showed that the short form of this route, Lemma L
(some l with Lambda_l <= q - 1), is false for every even q >= 4. The counterexample is
P(x) = x^(-1) + s x on F_{q^2}. The full form L'_q(2) (some (l, v) with CB <= 2(q - 1)) was
left open. This note shows:

1. **Lemma 111.** An exact formula for the slack CB - Lambda, valid for every map.
2. **Theorem 37.** Every slice of the inverse family is the set of affine points of a plane cubic
   with a non-split node. The group law on that cubic counts the slice's 3-point fibres exactly.
   As a result, **L'_q(2) holds for the whole inverse family for every even q >= 4**, with an
   explicit chain bound. So the chain route is not closed by Theorem 36. The predictions F1-F3
   registered in a160 are now proved; job kakeya-invfam-v1 stays as an independent check.
3. **Proposition 41.** At q = 3, the odd analogue x -> a/x + b x on F_9 never breaks Lemma L.

## Lemma 111 (the slack of the chain bound)

For every map P of F_q^k, every nonzero functional l and every v with l(v) = 1,

    CB(l, v) - Lambda(P) = sum over t of H( l(Y_t) | pi_v(Y_t), l(X) )  >=  0.

*Proof.* As in Theorem 35, (1/q) sum_a Lambda(Q_a) = sum_t H(X | pi(Y_t), l(X)), because on the
event l(X) = a we have pi(Y_t) = Q_a(X') + t X' with X' = pi(X). Also
Lambda(P) = sum_t [H(l(X) | Y_t) + H(X | Y_t, l(X))]. Since Y_t is a function of X,

    H(X | pi Y_t, l X) - H(X | Y_t, l X) = H(Y_t | pi Y_t, l X) = H(l(Y_t) | pi Y_t, l X),

where the last step uses that y -> (pi(y), l(y)) is a bijection. QED

**Corollary 126.** P satisfies L'_q(k) if and only if some (l, v) has slack at most
k(q - 1) - Lambda(P). In particular, a map with Lambda(P) = k(q - 1) (a maximiser) passes the
chain route only through a **zero-slack frame**. That is an (l, v) for which l(Y_t) is a
function of (pi_v(Y_t), l(X)) for every t. Products f x g have one, along a coordinate.

This turns the chain route into a structural question: *does every maximiser, and every map
near the maximum, have a (nearly) zero-slack frame?* Maps with small Lambda, like the inverse
family (Lambda = q), can afford a large slack. That is why Theorem 36 does not hurt the route.

## Theorem 37 (slices of inversion are nodal cubics)

Let E = F_{q^2}, D = F_q d a line through 0, v not in D, and write y = mu(y) d + l(y) v. For
a in F_q^*, let R_a(lambda) = mu(1/(a v + lambda d)) for lambda in F_q. For every q:

(i) The graph {(lambda, R_a(lambda))} is the set of affine F_q-points of the irreducible cubic

    mu * N(a v + lambda d) = mu_conj(lambda),   mu_conj(lambda) := mu((a v + lambda d)^q),

with N the norm to F_q. The right side is affine-linear in lambda with lambda-coefficient
p1 = mu(d^q). The left factor N(a v + lambda d) is an irreducible quadratic in lambda, because the
line a v + F_q d misses 0. The vertical point at infinity is a node whose two tangents are
conjugate over F_{q^2} (a non-split node). The other point at infinity, P_inf = (1:0:0), is
smooth. It is a flex iff p1 = 0, i.e. iff d^q is in F_q v.

(ii) The smooth F_q-points (the q graph points and P_inf) form a cyclic group G of order q + 1,
the norm-one torus. Three distinct smooth points are collinear iff they sum to a fixed c in G.
Non-vertical lines are exactly the fibres of R_a + t (id) for some slope t. Hence every such
fibre has at most 3 points, and the number of 3-point fibres is

    T_a = #{3-subsets of G \ {P_inf} with sum c} = ((q-2)^2 - 3 + 2r + 3 s2 - 6 eps) / 6,

where r = #{x in G : 3x = c} (the number of rational flexes), s2 = #{y : 2y = c - P_inf}
(= 1 for even q), and eps = [P_inf is a flex]. For even q this is
T_a = ((q-2)^2 + 2r - 6 eps)/6, with r = 1 if 3 does not divide q + 1, and r in {0, 3}
otherwise (r = 3 when eps = 1).

(iii) For P(x) = x^(-1) + s x the slice maps of Theorem 35 are Q_a = R_a + (an affine map of w),
so their fibre structure does not depend on s. A 1-dimensional map Q with fibre sizes <= 3 has
Lambda(Q) = q - 1 - (1/q) * 3(2 - log2 3) * T, because every pair of points collides at exactly
one t. Hence, for a != 0,

    Lambda(Q_a) = q - 1 - kappa T_a / q,      kappa = 3(2 - log2 3) = 1.2451...

For a = 0 the slice is R_0(lambda) = lambda^(-1) mu(d^(-1)). Its loss is Lambda(Q_0) = log2 q
when v is in F_q d^(-1) (then R_0 = 0 and Q_0 is affine). Otherwise R_0 is inversion on F_q,
which for even q is 2-to-1 after any nonzero shear, so Lambda(Q_0) = q - 1.

*Proof of (i)-(ii).* Since 1/x = x^q / N(x) and mu is F_q-linear, R_a = mu(x^q)/N(x) on the
line, which gives the curve in (i). It is irreducible, because N has no root in F_q and mu_conj
is not identically zero (d^q and v^q span E). Homogenising, the lowest-order terms at (0:1:0)
are N(lambda, z), an irreducible quadratic form that is separable (for even q an irreducible
quadratic has a nonzero middle coefficient). So (0:1:0) is a non-split node. All affine points
are smooth, since the mu-derivative is N(lambda) != 0. At (1:0:0) the local equation starts with
N(d) mu, so that point is smooth with tangent mu = 0. That tangent meets the cubic in
z^2 (p1 lambda + p0 z), so P_inf is a flex iff p1 = 0. A plane cubic with one node is rational.
Its smooth locus is a group isomorphic to the twisted torus, which has q + 1 rational points.
Collinear triples sum to a constant, as on any cubic (choose any smooth base point). A line not
through the node meets the cubic in 3 points with multiplicity. Vertical lines pass through the
node. Horizontal lines pass through P_inf, so their affine parts have at most 2 points. The
count is inclusion-exclusion in Z/(q+1):
ordered triples with sum c and distinct entries number (q+1)^2 - 3(q+1) + 2r. Those containing
P_inf number 3((q+1) - s2 - 2(1 - eps)). Divide by 6. QED

**Check against a160.** At q = 4 with l = first coordinate (ker l = F_4 a) and v = 1: eps = 0 and
r = 1 give T_a = 1. That is one 3-point fibre per slice, so Lambda(Q_a) = 3/2 + (3/4) log2 3. For
a = 0 the slice is inversion on F_4, with loss 3. Both are exactly the values a160 computed and
its tests confirmed.

### Corollary 127 (L'_q(2) for the inverse family)

Let q >= 4 be even, P(x) = x^(-1) + s x with s not in F_q, l any functional with ker l = F_q d
!= F_q, and v the unique element of F_q d^(-1) with l(v) = 1. Then eps = 1 (because
d^q = N(d) d^(-1)), Lambda(Q_0) = log2 q, and every a != 0 has
T_a = T := ((q-2)^2 + 2 gcd(3, q+1) - 6)/6. With Lambda_l = q - 1 + (q-2)/q^2 (Theorem 36):

    CB(l, v) = q - 1 + (q-2)/q^2 + ( log2 q + (q-1)(q - 1 - kappa T/q) ) / q,
    2(q-1) - CB(l, v) = ( q^2 - 2q + 2 - q log2 q + (q-1) kappa T ) / q^2  >  0.

The first bracket is already positive for q >= 4 (it equals 2 at q = 4). So L'_q(2) holds for
every map of the family. Values:

| q | T | CB at this frame | 2(q-1) |
|---|---|---|---|
| 4 | 0 | 47/8 = 5.875 | 6 |
| 8 | 6 | 309/32 + (63/32) log2 3 = 12.777 | 14 |
| 16 | 32 | 2319/128 + (45/8) log2 3 = 27.033 | 30 |

The margin grows like kappa q/6, about 0.21 q. **Pre-registered F1, F2 and F3 of a160 are
thereby proved:** L' holds for every s at q = 4 and 8, the q = 16 chain bound is at most 30, and
no tested q is tight. The slack of this frame (Lemma 111) is CB - q. At q = 4 it is 15/8 bits,
for a map whose total loss is only q = 4.

## Proposition 41 (q = 3: the odd analogue keeps Lemma L)

Consider P(x) = a/x + b x on F_9 = F_3[i], with a != 0 and b not in F_3 (48 maps). If a is a
nonsquare, then Lambda(P) = (2/3) log2 3 + 16/9 = 2.834 and min_l Lambda_l = 4/3 + (1/3) log2 3 =
1.862. If a is a square, then Lambda(P) = (1/3) log2 3 + 20/9 = 2.750 and min_l Lambda_l =
8/9 + (1/3) log2 3 = 1.417. Both are <= q - 1 = 2.

*Proof (by hand, re-checked over all 48 maps by the tests).* The fibres of a/x + u x
(u = b + t) are as follows: {0, +-sqrt(-a/u)}, a collinear triple, when a u is a square, plus
two singletons and two pairs; otherwise four pairs and {0}. A line b + F_3 holds exactly one
square u, so one t (a square) or two t (a nonsquare) have the triple. Listing the directions of
the pairs and triples for b = i and the two square classes of a gives the values above. Scaling
x -> lambda x, Frobenius and P -> -P cover the other cases.

So at q = 3 the matching argument of a160 cannot be beaten by this family. Pre-registered
E3 (L fails somewhere at (3, 2)) is still open and will be settled by the exhaustive census.

## What the "wow" would be, and what is next

If L'_q(2) holds for all maps, then C_q(2) holds for every q: blocks of size two never beat
products. With an induction on k, the route would give the exact Kakeya constant of F_q, which
would close the gap left by Bukh-Chao (1.800 vs 1.890 at q = 3). A counterexample to C at
(4, 2), Lambda > 6, would instead be a new record upper bound for Kakeya sets over F_4. Neither
has happened. This note removes the one known obstruction to the chain route and reduces it to
Corollary 126's zero-slack question.

Registered now, to be graded with the census of a159 (job kakeya-lemmal-v1):

- **G1.** Every one of the 216 maximisers at (3, 2) (Lambda = 4) has a zero-slack frame (l, v).
  This is the maximiser case of E3's second half, registered on its own because it is the
  sharpest structural test of the route.
- **G2 (a guess).** Every anneal map at (4, 2) that breaks L has Lambda(P) <= 5. That is, maps
  that break L stay well below the maximum 6, as the inverse family does (Lambda = 4).
