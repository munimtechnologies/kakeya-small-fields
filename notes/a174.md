## 0. Summary

Program (a159-a173): for a map P of F_q^k let A_t(x) = P(x) + tx and

    Lambda(P) = sum_{t in F_q} H(X | A_t(X))      (bits, X uniform on F_q^k).

By Theorem 2 (README) the Kakeya growth constant of F_q is beta_q = q 2^(-lambda*/q), with
lambda* = sup_k max_P Lambda(P)/k over **all** maps. The conjecture C_q(k), Lambda <= k(q-1),
would give the exact constant. a173 reduced the regular quadratic maps to the *unital
square-root entropy conjecture* SR*_q(k): for every unital commutative algebra B on F_q^k and
every linear map M, H(Y | Y o Y + M Y) <= k(1 - 1/q). It was known only for k <= 3, and for
larger k only for multiplication operators M = R_l (a172, a173).

The basic test case is the **frame** B = F_q^k with (y o y)_i = y_i^2, the algebra of the extremal
frame products. With M diagonal, H = k(1 - 1/q) exactly. With an arbitrary M, SR* was open
for every k >= 4. This note proves the following, for every odd q unless stated otherwise:

1. **Pair-count bound and planar maps (Theorem 57).** For every quadratic map,
   Lambda(P) <= q log2 rho(B), where rho(B) = sum_d q^(-rank R_d) depends only on the quadratic
   part. If the quadratic part is **planar** (a commutative presemifield: fields F_(q^k),
   Albert's twisted fields, Dickson's semifields), then Lambda(P) < q for **every** linear part
   and every k. So these maps are very far from extremal.
2. **Frames, Jensen and strong connectivity (Theorem 58, Corollaries 58.1-58.2).** The exact
   pair count of a frame map is a sum over supports. When the off-diagonal digraph of M is
   strongly connected, it is at most Phi_q(k), and log2 Phi_q(k) < k(1 - 1/q) for
   2 <= k <= K0(q), with **K0(3) = 14, K0(5) = 41, K0(7) = 71** (K0(q) ~ 5.18 q ln q). With a chain
   rule over strongly connected components this proves **SR*_q(k) for the frame with every M
   for all k <= K0(q)**. So C_3(k) holds for k <= 14 (previously k <= 3) for every quadratic map
   whose quadratic part is A((Sx) o (Sx)) with A, S invertible, whatever its linear part.
3. **Low-rank frames in every dimension (Theorem 59, Corollary 59.1).** If M is diagonal plus
   rank r, an averaging argument over r coordinates gives an explicit bound. For **rank one** it
   proves SR*_q(k) **for every k**. The inequality is strict whenever u has at least two nonzero
   entries and its support meets that of v.
4. **Near-extremal non-frame family (Proposition 66).** For q prime, every rank-one frame map
   has H >= k(1 - 1/q) - (q - 1), by Cauchy-Davenport. The all-c family
   y o y + c(y_1 + ... + y_k)(1, ..., 1) is strongly connected and strictly below the bound, yet
   Lambda/k -> q - 1. **Non-extremal maps can therefore come within a constant of the
   conjectured maximum in every dimension.** No proof of C_q(k) can rely on a gap that grows
   linearly in k.

**Limits.** Frames with large strongly connected components and high-rank M remain open
(K0(q) is finite at each q). Nothing here proves C_q(k) for all k even within quadratic maps,
and quadratic maps are only a test class for beta_q. So **this is not a new Kakeya bound.** It
moves the quadratic frontier at q = 3 from k <= 3 to k <= 14 for the frame class.

## 1. Pair counts and planar maps

For a commutative algebra (F_q^k, o) let R_d x = d o x. As in a172, write
P(x) = x o x + Lx + c.

> **Theorem 57.** For every L, c and t, with N_t(x) the size of the fibre of A_t through x,
>
>     E N_t(X) <= rho(B) := sum_{d in F_q^k} q^(-rank R_d),   H(X | A_t X) <= log2 rho(B),
>
> and so Lambda(P) <= q log2 rho(B).

*Proof.* A_t(x) - A_t(x') = (x - x') o (x + x') + (L + tI)(x - x'), because
x o x - x' o x' = (x - x') o (x + x') by commutativity. Since q is odd,
(x, x') -> (d, s) = (x - x', x + x') is a bijection. For fixed d, the pairs with equal image are
the solutions s of R_d s = -(L + tI) d, and there are either none or q^(k - rank R_d). So
q^k E N_t = #pairs <= sum_d q^(k - rank R_d). Jensen gives
H = E log2 N_t <= log2 E N_t. []

> **Corollary 57.1 (planar quadratic parts).** If R_d is invertible for every d != 0, i.e.
> x -> x o x is a planar function (equivalently (F_q^k, o) is a commutative presemifield), then
> for every linear part, every c and every k >= 2,
>
>     Lambda(P) <= q log2(2 - q^(-k)) < q <= k(q - 1).

*Proof.* rho = 1 + (q^k - 1) q^(-k) = 2 - q^(-k). []

Examples: squaring in F_(q^k) (a172 had only L = R_l), Albert's twisted fields
x o y = x^(q^i) y + x y^(q^i) when k/gcd(i, k) is odd, and Dickson's commutative semifields.
The tests check F_9, F_27, F_25, F_49 and the twisted field on F_27 (and that x^(q+1) on F_(q^2),
the norm, is not planar). So planar maps are the **opposite** of extremal: Lambda stays below q
in every dimension, while the frame product reaches k(q - 1).

## 2. Frames: normal form, chain rule, Jensen

From now on B = F_q^k is the frame, F(y) = y o y + My with (y o y)_i = y_i^2, H(M) = H(Y | F(Y)),
and the digraph of M has an edge i -> j when i != j and M_ij != 0 (output i reads input j).

> **Proposition 67 (normal form and chain rule).** (a) H(M) = H(M + D) for every diagonal D.
> (b) If S is a set of coordinates with M_(S, S^c) = 0, then H(M) <= H(M_SS) + H(M_(S^c S^c)).
> Hence H(M) <= sum over the strongly connected components C of H(M_CC), and a component of
> size 1 contributes exactly 1 - 1/q.

*Proof.* (a) F(y + a) = y o y + (M + 2 diag(a)) y + const, and translation preserves fibres
(q odd, so D = 2 diag(a) for a = D/2). (b) H(Y | F) = H(Y_S | F) + H(Y_(S^c) | F, Y_S). The
first term is at most H(Y_S | F_S), and F_S = Y_S o Y_S + M_SS Y_S. In the second term, given
Y_S = y_S, F_(S^c) = Y_(S^c) o Y_(S^c) + M_(S^c S^c) Y_(S^c) + (a constant fixed by y_S), and
Y_(S^c) is uniform and independent of Y_S. A constant shift of the output does not change the
fibres. A sink component of the condensation is such an S, so induct. For k = 1,
y^2 + my has fibres {y, -m - y}: H = 1 - 1/q. []

> **Theorem 58 (exact pair count).** For every M,
>
>     E N(Y) = sum_{T subset [k]} q^(-|T|) V(T),   V(T) = #{d : supp d = T, M_(T^c, T) d_T = 0},
>
> and V(T) <= (q - 1)^(|T| - rank M_(T^c, T)). If the digraph of M is strongly connected
> (k >= 2), then
>
>     H(M) <= log2 E N <= log2 Phi_q(k),
>     Phi_q(k) = (q-2)/(q-1) (1 + ((q-1)/q)^k) + (2 - 1/q)^k / (q - 1).

*Proof.* F(y) = F(z) with d = y - z iff 2 y_i d_i - d_i^2 + (Md)_i = 0 for all i. For i in
T = supp d this fixes y_i = (d_i^2 - (Md)_i)/(2 d_i). For i outside T it says (Md)_i = 0 (the
diagonal entry does not matter there, since d_i = 0), and y_i is free. So d is a partner of
exactly q^(k - |T|) points if M_(T^c, T) d_T = 0, and of none otherwise. That gives the
identity. For the bound on V(T), choose rank-many pivot columns: the other coordinates of d_T
(each in F_q^*) determine the pivots. If the digraph is strongly connected, every T other than
the empty set and [k] receives an edge from T^c, so rank >= 1 and V(T) <= (q - 1)^(|T| - 1). The
empty set contributes 1 and T = [k] contributes ((q-1)/q)^k. Summing
q^(-|T|) (q - 1)^(|T| - 1) over the other T gives Phi_q(k). Jensen finishes. []

For a cycle (M_(i, i+1) != 0 only) only T = empty and T = [k] survive. So
E N = 1 + ((q-1)/q)^k exactly and H < 1 in every dimension.

Let K0(q) be the largest K with log2 Phi_q(k) < k(1 - 1/q) for every 2 <= k <= K. Computed
exactly in the tests: **K0(3) = 14, K0(5) = 41, K0(7) = 71.** Asymptotically the condition is
about exp(k delta_q) < q - 1 with delta_q = ln(2 - 1/q) - (1 - 1/q) ln 2 = (ln 2 - 1/2)/q + O(q^(-2)),
so K0(q) ~ q ln q / (ln 2 - 1/2) ~ 5.18 q ln q.

> **Corollary 58.1.** For every odd q and every M whose strongly connected components all have
> at most K0(q) vertices, H(M) <= k(1 - 1/q), strictly if some component has >= 2 vertices. In
> particular SR*_q(k) holds for the frame algebra and **every** M when k <= K0(q): k <= 14 at
> q = 3, k <= 41 at q = 5, k <= 71 at q = 7.

*Proof.* Proposition 67 and Theorem 58. []

> **Corollary 58.2 (frame-type quadratic maps).** Let P(x) = A((Sx) o (Sx)) + Lx + c with A, S
> invertible and L arbitrary (the quadratic part is equivalent, on both sides, to k independent
> squares). Then every slice satisfies H(X | A_t X) = H(M_t) with M_t = A^(-1)(L + tI)S^(-1). So
> for k <= K0(q), Lambda(P) <= k(q - 1). At q = 3 this proves C_3(k) for this class for all
> k <= 14.

*Proof.* A^(-1) A_t(S^(-1) u) = u o u + M_t u + const, and x -> Sx, f -> A^(-1) f are
bijections. []

This is the regime opposite to a171, which covers nondegenerate maps for q >= q0(k) ~ 2^(4.3k).
Here q is fixed and small, and k ranges up to K0(q).

## 3. Low rank: every dimension

Write M = D + U V^T with U, V in F_q^(k x r) and D diagonal. By Proposition 67(a), take D = 0.
Put tau = V^T d. The partner equations become d_i^2 - 2 y_i d_i = (U tau)_i for all i, with
V^T d = tau. Let R_i(tau) = {x : x^2 - 2 y_i x = (U tau)_i}, so
|R_i(tau)| = 1 + chi(y_i^2 + (U tau)_i) (chi the quadratic character, chi(0) = 0), and
R_i(0) = {0, 2 y_i}.

> **Theorem 59 (low-rank criterion).** Suppose the rows J (|J| = r) of V form an invertible
> matrix. Let theta = (q + 1)/(2q), and for tau != 0 let w_J, w_(J^c) be the numbers of nonzero
> coordinates of U tau inside and outside J. Then
>
>     H(M) <= (k - r)(1 - 1/q) + log2(1 + B_J),
>     B_J = sum_{tau in F_q^r, tau != 0} q^(-w_J) theta^(w_(J^c)).

*Proof.* Split the partners by tau. **tau = 0:** each d_i is in {0, 2 y_i}, so d = 2y on a set
T of support coordinates with sum_{i in T} y_i V_i = 0 (V_i the rows of V). Call their number
Z(y). **tau != 0:** given tau and d_(J^c), the constraint V^T d = tau determines d_J. Now average
over y_J with y_(J^c) fixed (s' = the number of nonzero y_i outside J).

* E_(y_J) Z <= 2^(s'). For each T' among the support coordinates outside J, put
  w = -sum_{T'} y_i V_i = sum_{j in J} c_j V_j. A completion T_J must equal supp(c), with
  y_j = c_j there. That has probability q^(-|supp c|) <= 1.
* E_(y_J) R <= beta := sum_{tau != 0} q^(-w_J) prod_{i notin J} |R_i(tau)|. For j in J,
  d_j in R_j(tau) has probability 1/q over y_j if d_j != 0. It is impossible if d_j = 0 and
  (U tau)_j != 0. The y_j are independent.

Since log2 is concave, E_(y_J) log2 N <= log2(2^(s') + beta) = s' + log2(1 + beta 2^(-s')).
Averaging over y_(J^c) and using Jensen again,
H <= (k - r)(1 - 1/q) + log2(1 + E[beta 2^(-s')]). The factors are independent. A coordinate
with (U tau)_i = 0 gives E[|R_i| 2^(-[y_i != 0])] = 1. A coordinate with c = (U tau)_i != 0 gives

    (1/q)(1 + chi(c)) + (1/(2q)) sum_{y != 0} (1 + chi(y^2 + c)) = (q + chi(c))/(2q) <= theta,

using sum_y chi(y^2 + c) = -1. []

> **Corollary 59.1 (rank one, every k).** For M = D + u v^T, H(M) <= k(1 - 1/q) for every odd q
> and every k. If |supp u| >= 2 and supp u meets supp v, then
>
>     H(M) <= (k - 1)(1 - 1/q) + log2(1 + ((q-1)/q) theta^(|supp u| - 1)) < k(1 - 1/q).

*Proof.* If supp u and supp v meet, pick j in both, so J = {j}, w_J = 1 and
w_(J^c) = |supp u| - 1. Then B_J = ((q-1)/q) theta^(|supp u| - 1) <= (q^2 - 1)/(2q^2) < 1/2, and
log2(3/2) < 2/3 <= 1 - 1/q. If |supp u| = 1, the rows outside supp u are zero. If supp u and
supp v are disjoint, M_(supp u, supp u) = 0. In both cases Proposition 67(b) with S = (supp u)^c
splits M into two diagonal blocks. []

> **Proposition 66 (near-extremal).** Let q be prime and M = D + u v^T (any u, v). Then
> N(y) >= 2^(|supp y| - (q - 1)) for every y (with D = 0), so H(M) >= k(1 - 1/q) - (q - 1).

*Proof.* N(y) >= Z(y). Coordinates with v_i = 0 are free (factor 2). Among the s nonzero
elements v_i y_i, every subset A of the first s - (q - 1) can be completed to a zero-sum subset
by a subset of the last q - 1. By Cauchy-Davenport (q prime), the subset sums of q - 1 nonzero
residues cover F_q. []

So M = c J (all entries c != 0) is strongly connected and its Kakeya map y o y + c J y has
k(q - 1) - q(q - 1) <= Lambda <= (k - 1)(q - 1) + q log2(1 + ((q-1)/q) theta^(k-1)). Its
Lambda/k tends to q - 1, but it is never extremal. The deficit k(q - 1) - Lambda stays between
about q - 1 - q log2(1 + ...) and q(q - 1) for every k. (Heuristically, Z(y) is about
2^(|supp y|)/q, which suggests a deficit of about q log2 q. This is not proved.)

## 4. What this says about the program

* **SR* for frames** is now settled whenever the strongly connected components are small
  (Corollary 58.1) or M is close to diagonal in rank (Theorem 59). The open frame case is M with
  large strongly connected components **and** high rank, where Jensen loses k log2(2 - 1/q)
  against k(1 - 1/q).
* **Rigidity is weak.** Proposition 66 shows non-extremal maps whose deficit is O(1) in every
  dimension. Any proof of C_q(k) for all k must therefore be exact-entropy in nature (as for
  diagonal frames). A uniform "gap per coordinate" argument cannot work. This matches a171's
  gap q/(2^k ln 2) shrinking with k.
* **Planar maps** (Corollary 57.1) are a whole class with Lambda < q: the conjecture holds with
  room to spare there, so a counterexample search should not look among them.
* Next targets: (i) frames with strongly connected M of high rank for k = 15..20 at q = 3, using
  Theorem 59 with r large and the code structure of U; (ii) spin factors with arbitrary M
  (after a translation every such map has the normal form
  F(a, v) = (a^2 + Phi(v) + r(v), (K + 2a) v) with K any n x n matrix and r any linear form);
  (iii) the non-regular maps.

## 5. Tests (`test_frames.py`)

* Theorem 58: the exact identity E N = sum_T q^(-|T|) V(T) (in rationals) and the bound
  V(T) <= (q-1)^(|T| - rank) for random M, (q, k) in {(3,2..5), (5,2..3), (7,2)}. For random
  strongly connected M with (q, k) in {(3,2..6), (5,2..4), (7,2..3)}: H <= log2 E N <= log2 Phi_q(k)
  < k(1 - 1/q) - 10^(-3). For cycles: E N = 1 + ((q-1)/q)^k exactly, and H < 1.
* K0(3) = 14, K0(5) = 41, K0(7) = 71, and the defining inequality at k = 14 and 15 for q = 3.
* Proposition 67: diagonal invariance, and the chain rule over strongly connected components on
  random block-triangular M.
* Corollary 58.2: for random invertible A, S and random L, the slice entropy equals H(M_t),
  and both are at most k(1 - 1/q).
* Theorem 59 / Corollary 59.1 / Proposition 66: random rank-one M (q = 3, 5, 7), both bounds; the
  pointwise N(y) >= Z(y) >= 2^(|supp y| - (q-1)); the all-c family for k <= 6; random rank-2 and
  rank-3 M with the bound of Theorem 59, and its **pointwise averaging inequality**
  E_(y_J) N <= 2^(s') + beta, checked in rationals for every y_(J^c).
* Theorem 57: E N_t <= rho(B) and H <= log2 rho for random algebras; planarity, rho = 2 - q^(-k)
  and Lambda <= q log2(2 - q^(-k)) for F_9, F_27, F_25, F_49 and the twisted field on F_27; the
  norm map x^4 on F_9 is not planar.
