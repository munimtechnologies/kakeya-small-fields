We use (*), its polarised form

    A_g beta(h, k) = A_h beta(k, g) + A_k beta(h, g)     for all g, h, k in V,       (Q)

## Lemma 104 (the maps of ker phi in the rank-0 case)

**Lemma 104.** Let u be in (B7)_8, in the rank-0 case.

(a) For every n in N there is exactly one T_n in End(X / X_1) with A_n = A_u-bar T_n pi. The map
    n -> T_n is linear, T_u = I, and pi beta(n, h) = T_n pi phi(h) for every h in V.

(b) T_n T_(n') = T_(n') T_n for all n, n' in N.

(c) dim T(N) <= 3. So N_0 = {n in N : A_n = 0} is the kernel of n -> T_n, has dimension
    4 - dim T(N) >= 1, and meets span(u) only in 0.

*Proof.* (a) A_n vanishes on X_1, so A_n = M_n pi for exactly one linear M_n : X / X_1 -> X. By
(N), A_n x0 = 0 and A_n(P) = A_u(P_n), so A_n(X) = A_n(P + span(x0)) lies in R. So
T_n = A_u-bar^(-1) M_n is defined, and it is unique because pi is onto. Linearity follows from that
of h -> A_h, and A_u = A_u-bar pi gives T_u = I. By (N),
A_u-bar pi beta(n, h) = A_u beta(n, h) = A_n phi(h) = A_u-bar T_n pi phi(h), and A_u-bar is
one-to-one.

(b) (Q) with h = n, k = n' and beta(n, n') = 0 (Lemma 103 (b)) gives
A_n beta(n', g) = A_(n') beta(n, g) for every g. By (a) the left side is
A_u-bar T_n pi beta(n', g) = A_u-bar T_n T_(n') pi phi(g), and the right side is
A_u-bar T_(n') T_n pi phi(g). As g runs over V, pi phi(g) runs over pi(P), which is all of X / X_1
because P + X_1 contains P + span(x0) = X. Since A_u-bar is one-to-one, T_n T_(n') = T_(n') T_n.

(c) By (b), the T_n generate a commutative subalgebra of End(X / X_1), which is isomorphic to
M_3(F_2), and this subalgebra contains T(N). A commutative subalgebra of M_m(F) has dimension at most
floor(m^2 / 4) + 1. This is Schur's theorem (1905), proved for every field by Jacobson (1944). For
m = 3 the bound is 3, so dim T(N) <= 3 < 4 = dim N. A_n = 0 exactly when T_n = 0, because A_u-bar
is one-to-one and pi is onto. So N_0 = ker T has dimension 4 - dim T(N) >= 1. T_u = I is not 0, so
u is not in the subspace N_0, and N_0 n span(u) = 0. QED

**Remarks.**

- At t = 7 the same argument works in (B6), where dim P = t - 1 and X = P + span(x0), but there
  dim N = 3 and the bound dim T(N) <= 3 forces nothing. The forced zero map comes from the one extra
  dimension of N at t = 8 (Lemma 101).
- In (B6)_8, X = H0 + span(e) with H0 = P + span(x0) a hyperplane, and A_n e is not determined by
  beta(n, .). So Lemma 104 does not apply as it stands, and (B6)_8 is not treated here.
- Lemma 104 does not use anisotropy, so it also holds for the four control models of job m100
  (systems in the rank-0 case that are not anisotropic). They are consistent with it: each has
  A = 0, sigma = 0 and beta(v_i, .) = 0 for i = 1, 2, 3, so N_0 has dimension 3 there.

## Lemma 105 (an element of ker phi with zero map, at t = 8)

**Lemma 105.** Let u be in (B7)_8, let w != 0 in N have A_w = 0, and put z = sigma(w) and
C = beta(w, V) + span(z). Then:

(a) w is not in span(u); A_h z = beta(w, h) for every h; C lies in X_1, and z is not in span(x0);

(b) for h in U+(w), with beta(w, h) = e z (e in F_2), A_h acts on C as e times the identity;

(c) dim U+(w) = 12 - dim C, and dim C >= 3;

(d) if x0 lies in C, then d = 0, C = X_1, and A_u is idempotent: it is the projection onto R along
    X_1;

(e) if x0 is not in C, then dim C = 4, X_1 = C + span(x0), dim U+(w) = 8, and U+(w) / span(w)
    carries an anisotropic system of dimension 7 with values in X / span(z) (dimension 7). In that
    system, C / span(z), of dimension 3, is invariant under every map. This is the equality case of
    M(4) + A(3) = 7.

*Proof.* (a), (b) and the first part of (c) are Lemma 89 (a) to (c) of [a37.md](a37.md), word for
word. They use only (*), (Q), (1) and (N), with dim V = 11 in the count:
dim U+(w) = (11 - dim P_w) + dim(P_w n span(z)) = 12 - dim C. The fact that z is not in span(x0)
also follows directly: z != 0, and sigma(u + w) = x0 + z + beta(u, w) = x0 + z != 0 by
anisotropy. For the bound in (c), Lemma 30 (b) for w (rank 0) gives
dim U+(w) <= 1 + A(7) <= 9 (Theorem 33), so dim C >= 3.

(d) This is the count of Lemma 89 (d). Let h be in U+(w) with beta(w, h) = e z. By (b),
A_h x0 = e x0, and by (1), (I + A_u) phi(h) = e x0. So phi maps U+(w) into F n P, where
F = {y : (I + A_u) y in span(x0)} = Fix(A_u) + span(x0) has dimension dim Fix(A_u) + 1. F contains
x0 and P does not, so dim(F n P) <= dim Fix(A_u). Fix(A_u) lies in R and meets X_1 only in 0, so
dim Fix(A_u) <= 3 - d. The kernel of phi on U+(w) lies in N, of dimension 4. With dim C <= 5,

    7 <= 12 - dim C = dim U+(w) <= 4 + dim Fix(A_u) <= 7 - d.

So d = 0, C = X_1 and Fix(A_u) = R. Then X = X_1 + R is a direct sum, and A_u is 0 on X_1 and the
identity on R.

(e) C lies in X_1 and misses x0, so dim C <= 4. The system on U+(w) / span(w) is the one in Lemma
89 (e). By (b), every A_h with h in U+(w) keeps span(z) and C, so it induces a map of X / span(z)
that keeps C / span(z). sigma and beta on U+(w), taken modulo span(z), satisfy (*) with these
maps. w is a zero of the quotient whose map is 0, so the quotient factors through
U+(w) / span(w). It is anisotropic by Lemma 30 (b) for w. If dim C = 3, then dim U+(w) = 9, and
this is an anisotropic system of dimension 8 with values in a space of dimension 7, with an
invariant subspace C / span(z) of dimension 2. Lemma 27 (c) of finite-groups.md bounds its
dimension by M(5) + A(2) = 5 + 2 = 7 (Theorem 27 for M(5) = 5), which is a contradiction. So
dim C = 4, X_1 = C + span(x0) and dim U+(w) = 8. The quotient then has dimension 7 with an invariant
subspace of dimension 3, against the bound M(4) + A(3) = 4 + 3 = 7. QED

**Remarks.**

- Lemma 105 does not need the rank-0 case. It holds for every w != 0 in N with A_w = 0, in every
  class of (B7)_8.
- At t = 7, Lemma 89 (e) had only one size for C. At t = 8, Lemma 30 alone allows two sizes, 3 and
  4, and M(5) = 5 removes the smaller. Both M(5) = 5 and A(7) <= 8 are computer-assisted (Theorems
  27 and 33).
- Case (d) needs A_u idempotent. Among the 68 class representatives of (B7)_8 this happens exactly
  for the projections onto R along X_1, one per pair orbit with d = 0:
  o011_c005 (A_u = E_55 + E_66 + E_77, class size 1) and o012_c010 (A_u = E_55 + E_66 + E_77 + E_05,
  class size 1). Indices are 0-based and E_rc is the matrix unit at row r, column c. This was found
  by hand from the representatives; job m101 checks it by machine.

## Corollary 123 (the rank-0 case of (B7)_8)

**Corollary 123.** Let u be in (B7)_8, in the rank-0 case, in m42's normal form (u = e_0, x0 = e_0,
X_1 = span(e_0, ..., e_4) in every pair orbit, v_1, v_2, v_3 a basis of N modulo u, phi(e_j) fixed).
Then the basis can be chosen with A_(v_1) = 0. Then beta(v_1, e_j) lies in X_1 for every j. And
unless A_u is one of the two idempotent representatives, x0 = e_0 is not in
span(sigma(v_1), beta(v_1, e_j) : j).

*Proof.* By Lemma 104 (c) there is w != 0 in N_0, outside span(u). Extend u, w to a basis
u, w, v_2', v_3' of N, and replace v_1, v_2, v_3 by w, v_2', v_3'. This keeps A_u, sigma(u) and the
values of phi on the basis (0 on N, the fixed vectors of P elsewhere), so the normal form and m42's
hints are unchanged. The sweep conditions hold for every element of N. The rest is Lemma 105 (a),
(d) and (e) for w = v_1. QED

So one instance per class covers the rank-0 case: m100's sweep instance plus A_(v_1) = 0, plus
"x0 not in C" in 66 of the 68 classes. As with the sweep, this is a case split on the system with a
chosen basis, and it needs no symmetry argument. In the two idempotent classes, case (d) of Lemma
105 is still possible, and the instance has no clause for "x0 not in C".
